Notion 공식 배포

Notion Official MCP

• 패키지: makenotion/notion-mcp-server
• 기능: 노션 페이지/블록 실시간 검색, 데이터베이스 쿼리 및 새 행 자동 생성

GitHub: makenotion/notion-mcp-server

유정근 대표님 워크스페이스만의 최적 활용법

• 로컬 마운트 드라이브 활용: 대표님 PC에는 이미 I:\내 드라이브와 E:\OneDrive가 물리 드라이브로 연결되어 있어, 별도의 MCP 설정 없이도 AGY가 0.1초 만에 파일 읽기/쓰기를 즉시 수행할 수 있습니다.

• 노션(Notion) 연동 시: 웹 전용 노션 데이터베이스나 고객 상담 일지를 관리하실 때는 Notion 공식 MCP를 연결하시면 카카오톡이나 슬랙처럼 노션 데이터를 실시간으로 읽고 쓸 수 있습니다.
