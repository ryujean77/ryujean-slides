# 13강. 검색 우선 — 쓰기 전에 찾게 하기

유정근 · 마이웨이 아카데미 | C2 자료관리론

정본 교시: 3-2 MCP 기반 로컬 자료 연결 · 3-4 지식의 재가공과 산출물 지향적 아웃풋 파이프라인

## 오늘의 목표

에이전트가 글을 쓰기 전에 내 자료부터 찾아 보고하게 만드는 규칙을 11강 헌장(`charter.md`)에 넣고, 그 규칙이 있을 때와 없을 때의 초안을 비교합니다.

## 먼저 이해하기

좋은 요리사는 장을 보러 가기 전에 냉장고부터 엽니다. 이미 있는 재료를 모르면 같은 것을 또 사 오고, 정작 필요한 재료는 빠뜨립니다. AI도 같습니다. 찾으라고 하지 않으면 AI는 내 자료 대신 일반적인 지식으로 씁니다. 그럴듯하지만, 지난번 의뢰에서 바뀐 조건이나 내가 이미 내린 판단은 빠진 글이 나옵니다.

<strong>검색 우선(Retrieval-First, 쓰기 전에 먼저 내 자료를 찾아보게 하는 규칙)</strong>은 세 가지를 정해 두면 됩니다.

- **① 어디서 찾는가** — 작업 폴더, 12강에서 연결한 서비스 등.
- **② 몇 개까지 가져오는가** — 다섯 개 안팎, 필요한 부분만 짧게. 전문을 통째로 가져오면 정작 중요한 조건이 묻힙니다.
- **③ 무엇은 찾지 않는가** — 민감 자료(남의 이름·연락처·상담 내용 등).

그리고 결과물 끝에 **"참조한 자료" 목록**을 붙이게 합니다. 그래야 내가 원문으로 돌아가 검수(맞는지 직접 확인하는 일)할 수 있습니다. 여기서 **기준일**은 그 자료가 언제 기준으로 쓰였는지 적어 둔 날짜입니다. 두 자료가 서로 다른 말을 할 때 어느 쪽이 최신인지 가리는 근거가 됩니다.

모든 요청에 검색을 붙일 필요는 없습니다. 오탈자 수정이나 짧은 질문까지 매번 찾게 하면 시간만 듭니다. 기획안·안내문·강의안처럼 **내 과거 자료가 결과를 바꾸는 일**에만 씁니다.

## 실제 기록에서 배운 한 줄

강사는 워크스페이스에 "산출물을 쓰기 전에 통합 검색으로 관련 과거 자료를 먼저 조회한다"는 규칙을 넣으면서 한 가지 위험을 발견했습니다. 자동 조회를 그대로 켜 두면, 기관 제안서를 쓰는 도중에 고객 상담 기록이 "관련 자료"로 끌려 들어올 수 있었습니다. 그래서 상담 기록 같은 민감 자료는 기본 검색에서 빼고, 사람이 명시할 때만 찾도록 규칙과 도구를 함께 고쳤습니다. 검색을 먼저 하게 만드는 일과 무엇을 찾지 못하게 할지 정하는 일은 한 쌍입니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다. 워크북의 가상 자료 S01·S02·S03을 그대로 씁니다.

준비물: PC, AGY, 11강에서 `charter.md`·`AGENTS.md`를 넣은 내 작업 폴더.

**가. 가상 자료 세 개를 파일로 넣기 (메모장)**

1. '시작' 단추 → `메모장` 을 쳐서 메모장을 엽니다.
2. 아래 글을 그대로 적습니다(복사해 붙여 넣어도 됩니다).

   ```
   S01 이전 강의계획
   기준일: 2024-03-01. 대상: 성인 학습자. 수업 시간: 90분. 환경: 개인 노트북.
   내용: 자료 위치 확인, 개인 계정 연결, 자료 목록 작성, 안내문 제작.
   결과물: 자료 지도와 안내문.
   ```

3. '파일' → '다른 이름으로 저장'을 누르고, 작업 폴더 안의 `10_sources` 폴더를 두 번 눌러 들어갑니다. 창 위쪽 경로의 끝이 `10_sources` 인지 봅니다.
4. '파일 이름' 칸에 `S01_이전강의계획_20240301` 이라고 쓰고 '저장'을 누릅니다. 형식은 그대로 둡니다(`.txt` 로 저장됩니다).
   → 이렇게 보이면 됩니다: 메모장 제목이 `S01_이전강의계획_20240301.txt` 로 바뀝니다.
5. '파일' → '새 탭'을 누르고 아래 글을 적은 뒤, 같은 방법으로 `10_sources` 에 `S02_이번의뢰조건_20260901` 로 저장합니다.

   ```
   S02 이번 의뢰 조건
   기준일: 2026-09-01. 대상: 성인 학습자. 수업 시간: 60분. 환경: 공용 기기.
   자료: 제공된 가상 자료 사용. 개인 계정 로그인은 실습에서 제외한다.
   결과물: 자료 지도와 안내문.
   ```

6. 다시 '새 탭'에 아래 글을 적고 `10_sources` 에 `S03_과거진행메모_20240302` 로 저장합니다.

   ```
   S03 과거 진행 메모
   기준일: 2024-03-02. 개인 계정 연결에 시간이 걸렸다.
   핵심 실습은 자료 위치와 기준일 확인이었다.
   이 메모는 가상 관찰이며 실제 참여자 데이터가 아니다.
   ```

7. 메모장을 닫고, `Windows 키 + E` 로 탐색기를 열어 작업 폴더 → `10_sources` 를 누릅니다.
   → 이렇게 보이면 됩니다: `S01_…`, `S02_…`, `S03_…` 세 파일이 보입니다.

**나. 검색 우선 없이 먼저 받아 보기 (AGY)**

8. AGY를 열고 왼쪽 사이드바에서 내 작업 폴더 프로젝트를 누릅니다. 채팅 입력칸에 아래 한 줄만 보냅니다.

   `성인 대상 자료관리 수업 안내문을 다섯 문장으로 써 줘. 파일로 만들지 말고 대화창에만 보여 줘.`

   → 이렇게 보이면 됩니다: 대화 영역에 안내문 다섯 문장이 나옵니다.
9. 답을 마우스로 끌어 선택하고 `Ctrl + C` 로 복사한 뒤, 메모장 새 창에 붙여 넣고 작업 폴더의 `deliverables` 에 `초안A_검색없이` 로 저장합니다.
10. 초안 A에서 이번 조건(S02)과 맞지 않는 내용에 표시합니다. 예) 90분, 개인 노트북, 개인 계정 연결.

**다. 헌장에 '쓰기 전에 찾기' 조항 넣기 (메모장)**

11. 탐색기에서 작업 폴더의 `charter.md` 를 오른쪽 클릭 → '연결 프로그램' → '메모장'으로 엽니다.
12. 맨 아래 빈 줄로 가서(`Ctrl + End`) 아래 조항을 붙여 넣습니다. 윤하람 씨가 쓴 문장입니다. 내 말로 고쳐도 됩니다.

    ```markdown
    ## 6. 쓰기 전에 찾기
    - 안내문·기획안·강의안을 쓰기 전에는 작업 폴더에서 관련 자료를 5개 이내로 먼저 찾는다.
    - 찾은 자료마다 파일 이름, 기준일, 이번에 쓸 부분을 목록으로 보여 주고, 내 확인을 받은 뒤 쓴다.
    - 기준일이 다른 자료끼리 조건이 부딪치면 최신 의뢰 조건을 따르고, 부딪친 곳을 알려 준다.
    - 결과물 끝에 '참조한 자료'를 적는다.
    - 짧은 질문과 오탈자 수정에는 이 절차를 쓰지 않는다.
    ```

13. `Ctrl + S` 로 저장하고 메모장을 닫습니다.
    → 이렇게 보이면 됩니다: 저장할 곳을 묻지 않고 바로 저장됩니다(이미 이름이 있는 파일이기 때문입니다).

**라. 같은 요청을 다시 하기 (AGY)**

14. AGY로 돌아가 왼쪽 위쪽에서 새 대화를 엽니다(새 대화를 여는 '+' 모양이나 'New' 글자). 헌장은 새 대화가 시작될 때 읽히기 때문입니다.
15. 8번과 **똑같은 한 줄**을 보냅니다.
    → 이렇게 보이면 됩니다: 초안보다 **자료 목록**(파일 이름·기준일·쓸 부분)이 먼저 나오고, "확인해 주시면 쓰겠다"는 말로 끝납니다.
16. 목록을 검수합니다. S01·S02·S03을 모두 찾았는지, S01과 S02의 조건 차이(90분과 60분, 개인 노트북과 공용 기기)를 짚었는지 봅니다. 빠진 자료가 있으면 이유를 셋 중 하나로 분류합니다. 이름이 모호함 / 읽을 수 없는 형식 / 검색 범위 밖.
17. 목록이 맞으면 "AI에게 건네는 말"의 **두 번째 글**을 보내 초안 B를 받습니다. 9번처럼 `deliverables` 에 `초안B_검색우선` 으로 저장합니다.
18. 초안 A와 B를 나란히 놓고, 이번 조건과 어긋난 문장 수를 각각 셉니다. 차이가 없었다면 없었다고 적습니다.
19. 초안 B 끝의 "참조한 자료"에서 하나를 골라, 탐색기에서 그 파일을 메모장으로 직접 엽니다. 인용된 내용이 실제로 그 파일에 있는지 확인하고, 고치지 않고 닫습니다.

✖ 15번에서 목록 없이 바로 초안이 나오면: 새 대화가 아니었거나, 헌장 조항이 저장되지 않았을 수 있습니다. 탐색기에서 `charter.md` 를 다시 열어 6장이 있는지 보고, 있으면 새 대화에서 "AI에게 건네는 말"의 **첫 번째 글**로 직접 요청합니다.

이 조회를 매번 손으로 요청하지 않고 초안 만들기 과정에 자동으로 붙이는 방법은 C3 업무 자동화에서 다룹니다. (AGY 화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

첫 번째 글 — 헌장 조항이 작동하지 않을 때 직접 찾게 하기.

> 이번 안내문을 쓰기 전에 이 폴더에서 관련 자료를 5개 이내로 찾아 줘. 자료마다 파일 이름, 기준일, 이번에 쓸 부분을 한 줄씩 보여 주고, 자료끼리 조건이 다른 곳이 있으면 짚어 줘. 내가 확인하기 전에는 초안을 쓰지 마.

두 번째 글 — 목록 확인 뒤 초안 받기(17번).

> 확인한 자료만 근거로 다섯 문장 안내문을 써 줘. 자료에 없는 날짜·인원·효과는 넣지 말고, 끝에 '참조한 자료'와 내가 확인할 조건 세 가지를 붙여 줘. 파일로 만들지 말고 대화창에만 보여 줘.

## 손에 남길 것과 완료 확인

**헌장의 '쓰기 전에 찾기' 조항 · 검색 전후 초안 비교표**

`charter.md` 를 메모장으로 열어 6장이 있는지 봅니다. 비교표에 두 초안 각각에서 이번 조건과 어긋난 문장 수가 적혀 있는지 확인합니다. "참조한 자료" 중 하나를 원문과 대조한 결과를 한 줄로 남깁니다. 에이전트가 목록을 먼저 내놓지 않고 바로 초안을 썼다면, 그 사실을 적고 헌장 문장을 더 분명하게 고친 뒤 다시 시도합니다.
