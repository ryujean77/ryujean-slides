# 11강. 헌장과 스킬 — 에이전트가 가장 먼저 읽는 문서

유정근 · 마이웨이 아카데미 | C2 자료관리론

정본 교시: 3-1 AI 에이전트 아키텍처와 바이브 코딩의 이해 · 4-2 지속 가능한 워크스페이스 커스터마이징 (강사의 실제 워크스페이스 해부)

## 오늘의 목표

8강에서 만든 내 작업 폴더에 헌장 한 장(`charter.md`)과 스킬 한 개(`SKILL.md`)를 만들고, AGY가 그 두 파일을 실제로 읽었는지 답변 첫 줄로 확인합니다.

## 먼저 이해하기

새 직원이 첫 출근을 하면 두 가지를 받습니다. 모든 일에 통하는 **사내 규정 한 장**과, 특정 업무를 할 때 꺼내 보는 **업무 매뉴얼 묶음**입니다. 에이전트(내 대신 여러 단계를 스스로 해 나가는 AI 조수)에게 헌장은 사내 규정이고, 스킬은 업무 매뉴얼입니다.

<strong>헌장</strong>(憲章, 이 작업 공간에서 에이전트가 모든 일에 앞서 지켜야 할 규칙을 적은 한 장짜리 글)은 작업을 시작할 때마다 읽히는 문서입니다. 무엇을 먼저 읽을지, 무엇을 절대 하지 않을지, 결과물을 어디에 둘지, 어떤 말투로 쓸지, 무엇은 사람이 정할지를 적습니다. C1 4강에서 만든 약속 파일 `law.md`를 한 단계 키운 것입니다. 매번 읽히므로 **짧고 단단해야** 합니다.

<strong>스킬</strong>(자주 하는 한 가지 일의 절차를 적어 두고, 그 일을 할 때 에이전트가 꺼내 따르게 하는 절차서)은 폴더 하나에 `SKILL.md` 파일 하나로 만듭니다. "강의 안내문 쓰기", "화면 검수하기"처럼 일 하나에 스킬 하나입니다. 그 일을 할 때만 열리므로 **자세해도 됩니다.** 6강의 암묵지 캡슐화(머릿속으로만 밟던 순서를 글로 꺼내 담는 일)가 가장 실용적인 모양으로 굳은 것이 스킬입니다.

AGY가 두 문서를 어떻게 알아서 읽는지도 알아 둡니다. AGY 공식 도움말(`https://antigravity.google/docs/rules`, `https://antigravity.google/docs/skills`)에 따르면 다음과 같습니다.

- 작업 폴더 맨 위에 `AGENTS.md`(에이전트에게 주는 규칙 파일의 약속된 이름)가 있으면 AGY가 스스로 찾아 읽습니다. 그래서 헌장 본문은 `charter.md`에 쓰고, `AGENTS.md`에는 "charter.md를 가장 먼저 읽어라"는 안내 한 줄만 둡니다. 이런 파일을 **입구 파일**(도구가 작업을 시작할 때 자동으로 찾는 파일)이라고 부르겠습니다.
- 스킬은 작업 폴더 안의 `.agents\skills\<스킬 이름>\SKILL.md` 자리에 두어야 AGY가 찾습니다. 대화가 시작되면 AGY는 스킬들의 이름과 설명만 먼저 보고, 지금 일에 맞는 스킬이 있으면 그때 본문을 엽니다. 그래서 스킬 첫머리의 **설명(description)** 한 줄이 가장 중요합니다.

## 강사의 실제 워크스페이스 해부

구조만 봅니다. 헌장의 원문은 싣지 않습니다.

- **입구 파일 셋.** 에이전트 도구마다 작업을 시작할 때 자동으로 찾는 파일 이름이 다릅니다(예: Claude Code는 `CLAUDE.md`, AGY는 `AGENTS.md`). 강사는 도구별 입구 파일에 "헌장을 가장 먼저 읽으라"는 안내만 두고, 규칙 본문은 헌장 한 곳에만 둡니다. 규칙이 여러 곳에 흩어지면 어느 쪽이 맞는지 다투게 되기 때문입니다. 2강의 단일 진실 공급원(같은 내용의 기준은 한 곳에만 둔다는 원칙)이 규칙에도 적용된 셈입니다.
- **헌장 하나.** 용어 정의, 핵심 원칙, 작업 환경, 코딩·검증 기준, 표준 작업 순서, 에이전트 행동 수칙, 도구별 맞춤 규칙, 답변 양식의 여덟 장으로 되어 있습니다. 여러 조항은 처음부터 있던 것이 아니라, 실제로 문제가 생긴 뒤 "다음부터는 이렇게 한다"를 적어 넣은 것입니다.
- **스킬 폴더.** 스킬 하나가 폴더 하나입니다. 폴더 안의 `SKILL.md` 첫머리에 **이름**과 <strong>설명(언제 이 스킬을 쓰는지, 어떤 말이 나오면 켜는지)</strong>을 적고, 본문에 절차와 점검표를 씁니다. 필요하면 보조 스크립트(자동으로 돌아가는 작은 프로그램)를 함께 둡니다.
- **공개 예시 한 개.** 웹 화면 검수 스킬은 "색이 예쁜가" 같은 감상 대신 접근성·포커스·폼·애니메이션·글꼴·내용 넘침·이미지·성능의 여덟 영역 점검표로 검수하게 합니다. 사람마다 달랐던 눈대중을 같은 기준표로 바꾼 것이 이 스킬의 가치입니다.

## 실제 기록에서 배운 한 줄

워크스페이스 초기에는 에이전트가 헌장을 열어 보지 않고 기억과 짐작으로 답해 규칙이 빠지는 일이 있었습니다. 그래서 "가장 먼저 헌장을 연다"를 첫 원칙으로 올리고, **답변 첫 줄에 이번에 열어 본 파일 목록을 적게** 했습니다. 읽으라고 쓰는 것만으로는 부족하고, 읽었다는 증거가 남아야 합니다. 또 사용 기록을 세어 보니, 만들어 둔 스킬 가운데 실제로 자주 쓰인 것은 손에 꼽을 만큼이었습니다. 스킬은 미리 많이 만들어 두는 것이 아니라, 세 번째 반복되는 일에서 태어나야 합니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다.

준비물: PC, C1에서 설치한 AGY, 8강에서 만든 내 작업 폴더(하람 씨의 경우 `haram_space`). 아래에서 "작업 폴더"는 이 폴더를 말합니다.

**가. 헌장 초안 읽고 내 것 쓰기 (종이나 메모장)**

1. 윤하람 씨가 쓴 헌장 초안을 읽습니다. 모든 줄이 "무엇을 하라/하지 말라"로 끝나는지 봅니다.

   ```markdown
   # 하람 글방 헌장 (charter.md)

   ## 1. 먼저 할 일
   - 작업을 시작하면 이 문서와 index.md를 먼저 읽는다.
   - 답변 첫 줄에 이번에 열어 본 파일 이름을 적는다.

   ## 2. 지킬 것
   - 10_sources의 원본은 고치거나 지우지 않는다. 고칠 때는 사본에서 한다.
   - 확인하지 못한 날짜·인원·후기는 지어내지 않고 '확인 필요'로 남긴다.
   - 결과물은 deliverables/ 아래 '연월일_시분_영문주제' 폴더에 둔다.

   ## 3. 말투
   - 존댓말, 짧은 문장. 수강생을 평가하는 표현은 쓰지 않는다.

   ## 4. 사람이 정하는 것
   - 게시·발송·삭제는 하람 씨가 승인한 뒤에만 한다.

   ## 5. 스킬
   - 반복 작업은 .agents/skills/ 폴더에 해당 절차가 있는지 먼저 확인한다.
   ```

2. 내 헌장을 같은 다섯 장으로 씁니다. 장마다 1줄에서 3줄로 제한합니다. 넣고 싶은 말이 많으면 그것은 헌장이 아니라 스킬 후보이니 따로 적어 둡니다.

**나. `charter.md` 파일로 저장하기 (메모장)**

3. PC에서 '시작' 단추를 누르고 `메모장` 이라고 쳐서 메모장을 엽니다.
   → 이렇게 보이면 됩니다: 빈 흰 창이 열립니다.
4. 2번에서 쓴 내 헌장을 적습니다(하람 씨의 초안을 복사해 붙여 넣은 뒤 내 말로 고쳐도 됩니다).
5. 메모장 위쪽 '파일' → '다른 이름으로 저장'을 누릅니다.
   → 이렇게 보이면 됩니다: 저장할 곳을 고르는 창이 열립니다.
6. 창에서 내 작업 폴더를 찾아 두 번 눌러 들어갑니다. 창 위쪽 경로의 끝이 작업 폴더 이름(예: `haram_space`)인지 봅니다.
7. 아래쪽 '파일 형식' 칸을 눌러 '모든 파일 (*.*)'로 바꿉니다. 바꾸지 않으면 `charter.md.txt` 라는 엉뚱한 이름이 됩니다(C1 4강).
8. '파일 이름' 칸에 `charter.md` 라고 쓰고 '저장'을 누릅니다.
   → 이렇게 보이면 됩니다: 메모장 창 위쪽 제목이 `charter.md` 로 바뀝니다.

**다. 입구 파일 `AGENTS.md` 만들기 (메모장)**

9. 메모장 위쪽 '파일' → '새 탭'(또는 '새로 만들기')을 눌러 빈 문서를 엽니다.
10. 아래 두 줄을 적습니다.

    ```
    # 입구 안내
    작업을 시작하면 이 폴더의 charter.md를 가장 먼저 읽고 그대로 따른다.
    ```

11. 5~8번과 같은 방법으로 작업 폴더에 저장하되, 파일 이름은 `AGENTS.md` 로 씁니다(영문 대문자 그대로).
12. `Windows 키 + E` 로 파일 탐색기를 열고, 왼쪽 목록에서 작업 폴더를 누릅니다.
    → 이렇게 보이면 됩니다: 작업 폴더 맨 위 칸에 `AGENTS.md`, `charter.md`, 8강의 `index.md`·`timeline.md` 와 번호 폴더들이 보입니다.

✖ `charter.md.txt` 나 `AGENTS.md.txt` 로 보이면: 파일을 한 번 누르고 `F2` 를 눌러 끝의 `.txt` 를 지우고 `Enter` 를 누릅니다. 확장명(파일 이름 끝의 `.txt` 같은 꼬리표)을 바꾸겠느냐고 물으면 '예'를 누릅니다.

**라. 스킬 한 개 쓰기**

13. 최근 석 달 동안 세 번 이상 반복한 일 하나를 고릅니다. 하람 씨는 "강의 안내문 쓰기"를 골랐습니다.
14. 그 일의 스킬 초안을 씁니다. 맨 위 `---` 두 줄 사이에 이름(`name`, 영문 소문자와 `-` 만)과 설명(`description`, 언제 쓰는지)을 적고, 아래에 내가 실제로 밟는 순서를 번호로 적습니다.

    ```markdown
    ---
    name: class-notice
    description: 기록·글쓰기 강의의 수강생 안내문을 쓸 때 사용한다. "모집 글", "안내문" 요청에 적용한다.
    ---
    # 강의 안내문 쓰기

    1. 30_decisions에서 지난 강의 관련 판단 기록을 먼저 읽는다.
    2. 다섯 문장으로 쓴다: 누구를 / 무엇을 / 어떻게 / 무엇이 남는지 / 준비물.
    3. 날짜·장소·참가비는 하람 씨가 이번에 준 값만 쓴다.
    4. 초안 끝에 '하람 씨가 확인할 것 3가지'를 붙인다.
    ```

15. 메모장 '파일' → '새 탭'을 눌러 14번의 내 스킬을 적어 둡니다. 이번에는 저장하지 않고 창을 열어 둡니다. 스킬은 이름이 점(`.`)으로 시작하는 `.agents` 폴더 안에 들어가야 해서, 폴더 만들기는 AGY에게 맡기고 내용 확인은 내가 합니다.

**마. AGY로 스킬 자리 만들기**

16. 아래 "AI에게 건네는 말"의 **첫 번째 글**을 AGY에 보냅니다. 첫 번째 글 끝의 `(여기에 붙여 넣기)` 자리에, 15번 메모장에 적은 스킬 전체를 복사(`Ctrl + A` 로 전체 선택 → `Ctrl + C`)해 붙여 넣습니다.
    → 이렇게 보이면 됩니다: AGY가 폴더와 파일을 만들겠다는 계획이나 확인 카드를 보여 줍니다.
17. 확인 카드가 나오면 두 가지를 읽습니다. 만들 파일이 `.agents\skills\class-notice\SKILL.md`(내 스킬 이름)인가? 위치가 내 작업 폴더 안인가? 둘 다 맞으면 허용합니다. 다른 파일을 고치겠다고 적혀 있으면 허용하지 않습니다.
18. 탐색기로 돌아가 작업 폴더에서 `F5` 를 눌러 새로 고칩니다. `.agents` → `skills` → `class-notice` 를 차례로 두 번씩 눌러 들어갑니다.
    → 이렇게 보이면 됩니다: `SKILL.md` 파일 하나가 보입니다. 오른쪽 클릭 → '연결 프로그램' → '메모장'으로 열면 내가 쓴 스킬이 그대로 들어 있습니다. 확인만 하고 닫습니다.
19. 15번에서 열어 둔 메모장 탭은 저장하지 않고 닫습니다('저장 안 함').

**바. 읽었다는 증거 받기**

20. AGY 채팅 입력칸에 "AI에게 건네는 말"의 **두 번째 글**을 보냅니다.
    → 이렇게 보이면 됩니다: 답의 첫 줄에 `charter.md`(그리고 `AGENTS.md`)가 적혀 있고, 그 아래에 내 헌장 다섯 장이 요약되어 있습니다.
21. **세 번째 글**을 보내 스킬대로 안내문 초안을 받습니다.
    → 이렇게 보이면 됩니다: 답 첫 줄에 `SKILL.md` 가 적혀 있고, 작업 폴더의 `deliverables` 안에 새 폴더와 초안 파일이 생겼다고 알려 줍니다.

✖ 답 첫 줄에 파일 이름이 없거나, 내가 쓰지 않은 규칙이 요약에 섞여 있으면: AGY가 헌장을 읽지 않고 짐작한 것입니다. 입력칸에 "charter.md에 실제로 적힌 문장을 한 글자도 바꾸지 말고 그대로 옮겨 적어 줘" 라고 이어서 보냅니다.

✖ 스킬을 모른다고 하면: 18번의 폴더 이름을 다시 봅니다. `.agents`(점으로 시작, 끝에 s)·`skills`·스킬 이름 순서여야 합니다. `.agent` 처럼 s가 빠졌어도 읽는다고 공식 도움말에 적혀 있지만, 이 과정에서는 `.agents` 로 통일합니다. 그래도 모르면 새 대화를 열고 다시 묻습니다(스킬 목록은 대화가 시작될 때 읽힙니다).

스킬에 보조 스크립트를 붙여 자동으로 돌리는 일은 C3 업무 자동화에서 다룹니다. 이 수업의 스킬은 절차 문서 한 장으로 충분합니다. (AGY 화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).
