# 19강. 무엇을 나누고 무엇을 지키나 — 공개와 비공개

유정근 · 마이웨이 아카데미 | C2 자료관리론

정본 교시: 4-4 지식 커뮤니티 연계 및 향후 발전 로드맵 수립

## 오늘의 목표

내 자료를 비공개·지정인·공개 검토의 세 등급으로 나누고, 공개할 것만 담는 별도의 "공개 상자" 폴더와 내보내기 전 점검표를 만듭니다.

## 먼저 이해하기

정본은 과정을 마친 뒤 커뮤니티에서 프롬프트(AI에게 보내는 요청 글)와 방법을 나누며 서로의 시스템을 키워 가는 길을 말합니다. 나누려면 먼저 선이 있어야 합니다. 2강의 빅 버킷(버리지 않고 다 담아 두는 큰 바구니)에는 남에게 보여도 되는 것과 절대 나가면 안 되는 것이 섞여 있습니다. 그래서 **나누는 일은 바구니를 여는 것이 아니라, 나눌 것만 골라 다른 상자에 옮겨 담는 것**입니다.

- <strong>공개</strong>: 인터넷 주소만 알면 누구나 볼 수 있는 상태.
- <strong>비공개</strong>: 나만 볼 수 있는 상태.
- <strong>공개 상자</strong>: 공개해도 된다고 점검을 마친 **사본**만 담아 두는 별도 폴더. 원본은 넣지 않습니다.

비유하자면 집과 전시실입니다. 집에는 일기장도, 통장도, 가족 사진도 있습니다. 손님에게 보여 줄 작품은 집 안에서 꺼내 보이지 않고, 골라서 닦은 뒤 전시실에 겁니다. 손님은 전시실까지만 들어옵니다.

등급은 세 가지로 충분합니다.

| 등급 | 뜻 | 예 |
|---|---|---|
| 비공개 | 나만 본다 | 상담·고객 기록, 개인 연대기, 계정 정보, 가격·매출 계획 |
| 지정인 | 정한 사람만 본다 | 협업자와 함께 쓰는 초안, 내부 검토용 문서 |
| 공개 검토 | 점검을 통과하면 누구나 본다 | 수강생 안내문, 방법을 설명한 글, 가상 자료로 만든 워크북 |

같은 원천에서 나온 문서도 등급이 다를 수 있습니다. 한 프로젝트에서 **원천 문서 · 내부 검토용 문서 · 외부 발송용 문서**를 따로 두면, 내부 메모가 고객 문서에 섞여 나가는 사고를 막을 수 있습니다. 나눌 때는 원본이 아니라 방법을 나눕니다. 원본을 올리지 않아도 "무엇을 바꿨고 왜 바꿨는지"는 충분히 설명할 수 있습니다.

## 실제 기록에서 배운 한 줄

강사의 실제 워크스페이스는 저장소(파일을 모아 두고 변경 이력을 남기는 보관 공간)부터 둘로 나뉘어 있습니다. 모든 자료가 있는 **비공개 코어**와, 대외 공개물만 올리는 **공개 배포 공간**입니다. 이 과정의 대면판 폴더에도 "공개 대상은 검수된 안내 페이지와 워크북뿐이며, 내부 문서와 전체 폴더는 공개 공간에 복사하지 않는다"고 적혀 있습니다. 그리고 공개 전용 꾸러미 폴더 하나에서 배운 것이 있습니다. 그 폴더에 든 배포 스크립트(파일을 공개 공간으로 올려 주는 작은 자동 프로그램) 두 개 중 하나는 공개 공간의 기존 내용을 먼저 받아 온 뒤 새 파일을 더했고, 다른 하나는 이 폴더의 내용으로 공개 공간을 **통째로 덮어쓰는**(원래 있던 것을 지우고 새것으로 바꾸는) 방식이었습니다. 공개 공간은 여러 작업이 함께 전시되는 곳이라, 덮어쓰기는 남의 전시물을 치워 버립니다. 공개 상자는 따로 두고, 보낼 때는 더하는 방식으로 보냅니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다.

준비물: PC, 크롬, 4강의 구글 시트 `날짜_자료지도_v01`, 작업 폴더, 메모장.

**가. 자료 지도에 등급 칸 더하기 (구글 시트)**

1. 크롬에서 `https://sheets.google.com` 을 열고 `날짜_자료지도_v01` 을 엽니다. 아래쪽 `자료목록` 탭을 누릅니다.
2. 마지막 칸 오른쪽의 빈 칸 맨 위(제목 줄)에 `등급` 이라고 씁니다.
3. 행마다 `비공개` · `지정인` · `공개 검토` 중 하나를 적습니다. 윤하람 씨처럼 헷갈리는 행은 `비공개` 로 둡니다.
   → 이렇게 보이면 됩니다: 모든 행의 `등급` 칸이 채워져 있습니다.

**나. 공개 상자 폴더 만들기 (파일 탐색기)**

4. 공개 검토 등급 가운데 이번에 실제로 나눌 것 두 개를 고릅니다. 하람 씨의 예: 17강의 블로그 파생 설계, 16강 `지침문서_v02.md` 에서 개인 기준을 뺀 "틀"(이 틀은 아래 **다**에서 만듭니다).
5. `Windows 키 + E` 로 탐색기를 열고 왼쪽 목록의 '문서'를 누릅니다. 작업 폴더 **밖**에 두기 위해서입니다(작업 폴더는 AGY가 읽는 곳입니다).
6. 오른쪽 빈 곳에서 마우스 오른쪽 버튼 → '새로 만들기' → '폴더'를 누르고 이름을 `public_box` 로 씁니다(8강 규칙대로 폴더 이름은 영문).
   → 이렇게 보이면 됩니다: '문서' 안에 `public_box` 폴더가 생깁니다.
7. 작업 폴더로 가서 나눌 파일 하나를 오른쪽 클릭 → '복사'를 누르고, `public_box` 로 가서 빈 곳 오른쪽 클릭 → '붙여넣기'를 누릅니다. **잘라내기나 끌어다 놓기는 쓰지 않습니다**(원본이 옮겨질 수 있습니다).
   → 이렇게 보이면 됩니다: `public_box` 에 사본이 있고, 작업 폴더에도 원본이 그대로 있습니다.

**다. 사본에서 지울 것 찾기 (제미나이 → 메모장)**

8. `public_box` 안의 사본을 오른쪽 클릭 → '연결 프로그램' → '메모장'으로 열고, `Ctrl + A` → `Ctrl + C` 로 전체를 복사합니다.
9. 아래 "AI에게 건네는 말"의 "어디에 입력하나요"대로 제미나이를 열고 '새 채팅'을 누릅니다. **첫 번째 글** 아래에 사본 내용을 붙여 넣어 보냅니다.
   → 이렇게 보이면 됩니다: 지워야 할 곳이 줄 번호와 함께 목록으로 나옵니다.
10. 목록을 보며 메모장에서 사본을 직접 고칩니다. 지울 것: 실제 사람 이름·연락처·이메일·계정, 컴퓨터 속 폴더 경로(`C:\…`), 고객·수강생 이야기, 가격.
11. 기관 이름은 첫 두 글자를 별표로 가립니다. 예) 가상 기관 '새봄평생학습관' → '\*\*평생학습관'.
12. 사람 이야기가 꼭 필요하면 가상 인물로 바꾸고, 문서 맨 위에 "학습용 가상 설정"이라고 밝힙니다.
13. `Ctrl + S` 로 사본을 저장합니다. 원본은 열지도 고치지도 않습니다.
14. 지침 문서의 "틀"은 **두 번째 글**로 받습니다. 제미나이 새 채팅에서 두 번째 글 아래에 `지침문서_v02.md` 내용을 붙여 보냅니다. 받은 틀을 메모장 새 창에 붙여 `public_box` 에 `지침문서_틀_v01.md` 로 저장합니다('파일 형식'은 '모든 파일 (*.*)').

**라. 내보내기 전 점검표 (메모장)**

15. 메모장 새 창에 아래 일곱 항목을 적고, 사본마다 확인한 항목에 `[x]` 로 표시합니다.

    ```
    점검 대상: (사본 파일 이름)
    [ ] 사람 이름
    [ ] 연락처·이메일
    [ ] 계정
    [ ] 컴퓨터 폴더 경로
    [ ] 고객·수강생 이야기
    [ ] 가격
    [ ] 기관 실명
    ```

16. `public_box` 에 `공개전점검표_v01.md` 로 저장합니다.
17. 일곱 칸이 모두 `[x]` 인 사본만 공개합니다. 하나라도 남았으면 파일 이름 앞에 `검토중_` 을 붙여(`F2`) 공개하지 않습니다.

✖ 사본을 고쳤는데 원본도 바뀌어 있으면: 7번에서 '복사'가 아니라 '잘라내기'를 했거나 바로가기를 만든 것입니다. 작업 폴더의 원본을 먼저 확인하고, 8강 이후의 백업이나 C1 13강의 사본으로 되돌립니다.

(화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## AI에게 건네는 말

> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

첫 번째 글(9번) — 글 아래에 `Shift + Enter` 로 줄을 바꿔 공개하려는 사본 내용을 붙여 넣습니다.

> 공개하려는 문서야. 수정하지 말고, 사람 이름·연락처·이메일·계정·폴더 경로·고객 이야기·가격·기관 실명으로 보이는 부분을 모두 찾아 줄 번호와 함께 목록으로 보여 줘. 애매한 것도 빠뜨리지 말고 '확인 필요'로 넣어 줘.

두 번째 글(14번) — 글 아래에 지침 문서 v0.2 내용을 붙여 넣습니다.

> 이 지침 문서에서 내 개인 판단 기준과 사례는 빼고, 다른 사람이 자기 내용을 채워 쓸 수 있는 빈 틀만 남겨 줘. 칸 이름과 작성 요령만 남기고, 내 문장은 하나도 옮기지 마.

## 손에 남길 것과 완료 확인

**등급이 표시된 자료 지도 · `public_box` 폴더 · 내보내기 전 점검표(`공개전점검표_v01.md`)**

구글 시트 `자료목록` 탭의 모든 행에 등급이 적혀 있는지 확인합니다. `public_box` 안에는 사본만 있고, 원본은 작업 폴더의 원래 자리에 그대로 있어야 합니다(탐색기로 두 곳을 모두 열어 봅니다). 점검표에는 "이름·연락처·계정·경로·고객 이야기·가격·기관 실명"의 일곱 항목이 사본마다 표시되어 있어야 합니다. 아직 확인을 끝내지 못한 사본은 공개하지 않고 `검토중_` 이름으로 `public_box` 안에 둡니다. AI가 훑었다는 것만으로 공개하지 않습니다. 마지막 확인은 사람이 합니다.
