# 12강. MCP로 내 자료를 에이전트에 연결하기

유정근 · 마이웨이 아카데미 | C2 자료관리론

정본 교시: 3-2 MCP(Model Context Protocol) 기반 로컬 자료 연결

## 오늘의 목표

폴더 밖에 있는 내 자료 가운데 에이전트에게 연결할 것 하나를 골라 연결 설계표를 쓰고, AGY에서 실제로 연결한 뒤 에이전트가 볼 수 있는 범위를 직접 조회해 확인합니다.

## 먼저 이해하기

10강에서 본 것처럼 에이전트는 열어 준 폴더 안의 파일을 스스로 읽습니다. 그런데 내 자료는 폴더에만 있지 않습니다. 노션(Notion, 웹에서 쓰는 메모·문서 서비스) 페이지, Gemini Notebook(옛 이름 NotebookLM, 5강) 노트북, 캘린더처럼 각 서비스 안에 들어 있는 자료는 폴더를 열어 준다고 보이지 않습니다.

<strong>MCP(Model Context Protocol, 모델 맥락 규약)</strong>는 AI 에이전트와 바깥 서비스를 잇는 공통 규격입니다. 나라마다 모양이 다른 콘센트에 여행용 어댑터를 끼우는 것과 같습니다. 서비스마다 어댑터를 하나씩 끼우면, 에이전트는 같은 방식으로 여러 서비스의 자료를 찾고 읽습니다. 이 어댑터를 <strong>MCP 서버</strong>(서비스 하나를 에이전트에 이어 주는 연결 부품)라고 부릅니다. 이름에 '서버'가 붙었지만 내가 컴퓨터를 따로 세우는 것이 아닙니다. 다른 앱에서는 같은 것을 **커넥터**(연결기)라고 부르기도 합니다.

연결에는 늘 네 가지가 따라옵니다.

- **① 어댑터** — 어떤 MCP 서버를 쓰는가.
- **② 설정 파일** — 에이전트가 그 어댑터를 어디서 알게 되는가. AGY에서는 앱 안의 목록(MCP 스토어, 연결할 수 있는 서버를 모아 둔 진열대)에서 고르면 AGY가 알아서 적어 둡니다.
- **③ 열쇠** — 내 계정으로 허락하는 절차. 보통 **OAuth**(오오스, 비밀번호를 AI에게 주지 않고 서비스 화면에서 "이 앱에 허락"을 누르는 로그인 방식)로 하고, 어떤 서버는 **토큰**(서비스가 발급하는 긴 비밀 문자열, 비밀번호와 같은 무게)을 씁니다.
- **④ 범위** — 어디까지 읽고 쓰게 할 것인가.

이 가운데 사람이 끝까지 쥐고 있어야 하는 것은 ③과 ④입니다. 주의할 점이 있습니다. 노션 공식 안내(`https://developers.notion.com/docs/mcp`)에 따르면, 노션 MCP는 OAuth로 허락하고 나면 **내가 노션에서 볼 수 있는 모든 내용을 읽고 고칠 수 있게** 됩니다. 페이지를 하나씩 골라 주는 방식이 아닙니다. 그래서 "무엇을 연결하지 않을지"는 연결하기 전에 정해야 합니다. 대신 AGY에는 안전장치가 하나 있습니다. 공식 도움말(`https://antigravity.google/docs/mcp`)에 따르면, 따로 정하지 않은 MCP 도구는 **Ask**(쓸 때마다 사람에게 묻는 방식)로 동작해, 에이전트가 노션을 읽거나 고칠 때마다 대화 안에 확인 카드가 뜹니다(C1 9강).

연결은 많을수록 좋은 것이 아닙니다. 연결된 서버마다 도구 목록이 에이전트의 작업 기억(한 번에 머릿속에 담을 수 있는 양)을 먼저 차지할 수 있습니다. 강사는 한 달 사용 기록을 세어 보고, 거의 쓰지 않던 연결들을 이 작업 공간에서 껐습니다.

## 실제 기록에서 배운 한 줄

강사의 워크스페이스에서 연결 설정을 고쳤는데 아무것도 달라지지 않은 일이 있었습니다. 에이전트 도구마다 **실제로 읽는 설정 파일이 달랐고**, 고친 파일은 어떤 도구도 읽지 않는 참고용 사본이었습니다. 또 초기 연결 안내문에는 배포처(npm, 프로그램 부품을 내려받는 공용 창고)에 존재하지 않는 서버 이름이 적혀 있었습니다. 그 뒤로 두 가지를 규칙으로 삼았습니다. 설정을 고치기 전에 "이 에이전트가 실제로 읽는 파일이 어디인가"부터 확인하고, 서버 이름은 공식 안내에서 확인한 것만 씁니다. 초보는 이 문제를 피하는 가장 쉬운 길이 있습니다. 설정 파일을 손으로 고치지 말고, 오늘처럼 앱 안의 MCP 스토어에서 고르는 것입니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다.

준비물: PC, C1에서 설치한 AGY, 노션 계정(없으면 <strong>가~나</strong>까지만 합니다). 노션 계정이 없어도 이 수업은 설계표만으로 완료할 수 있습니다.

**가. 연결 설계표 쓰기 (종이, 메모장, 또는 구글 문서)**

1. 윤하람 씨는 수업 출석과 진행 메모를 노션에, 강의 참고자료를 Gemini Notebook 노트북에 두고 있습니다. 하람 씨의 연결 설계표를 읽습니다.

   | 자료 | 있는 곳 | 연결이 필요한가 | 권한 | 열쇠 보관 |
   |---|---|---|---|---|
   | 수업 진행 메모 | 노션 '수업 기록' 페이지 | 필요 | 읽기만 | AGY의 OAuth 허락, 대화창에는 아무것도 붙이지 않음 |
   | 강의 참고자료 | Gemini Notebook 노트북 1개 | 보류 | — | AGY 스토어에 없음, 5강처럼 Gemini Notebook에서 직접 묻는다 |
   | 안내문 원본 | 작업 폴더 `10_sources` | 불필요(폴더로 읽음) | 해당 없음 | 해당 없음 |
   | 수강생 연락처 | 노션 '수강생 명단' 페이지 | **연결하지 않음** | 없음 | 없음 |

2. 넷째 줄을 다시 봅니다. 노션 MCP는 내 노션 전체를 봅니다. 그래서 하람 씨는 '수강생 명단'을 연결하지 않으려면 **노션 연결 자체를 하지 않거나**, 명단을 노션 밖(예: PC의 별도 폴더)으로 먼저 옮겨야 한다는 것을 설계표 아래에 적습니다. 하람 씨는 명단을 노션 밖으로 옮긴 뒤에 연결하기로 했습니다.
3. 내 자료로 같은 표를 씁니다. 폴더 안에서 읽을 수 있는 자료는 연결하지 않습니다. 민감 자료(남의 이름·연락처·상담 내용·돈 관련 기록)는 "연결하지 않음"으로 먼저 적고, 그 자료가 연결하려는 서비스 안에 있으면 2번처럼 어떻게 할지 한 줄 적습니다.
4. 연결할 자료 하나를 고릅니다. 처음 연결은 **읽기만** 하는 것부터 시작합니다.

**나. 어댑터가 누구 것인지 확인하기**

5. 어댑터를 고를 때 누가 만들었는지 확인합니다. 서비스 회사가 직접 낸 것인지, 개인·커뮤니티가 공개한 것인지에 따라 믿는 정도와 확인할 것이 달라집니다. AGY의 MCP 스토어에 올라 있는 서버는 AGY 공식 도움말에 목록이 있습니다(노션 포함). 강사가 쓰는 Gemini Notebook 연결은 공식 제품이 아니라 공개된 오픈소스 도구(누구나 내용을 볼 수 있게 공개한 프로그램)라서, 설치 전에 어떤 권한을 요구하는지 읽었습니다. 이 과정에서는 스토어에 있는 서버만 씁니다.

**다. AGY에서 노션 연결하기 (PC, AGY)**

6. '시작' 단추를 누르고 `Antigravity` 를 쳐서 AGY를 엽니다.
   → 이렇게 보이면 됩니다: 왼쪽에 세로로 긴 사이드바가 있는 첫 화면이 보입니다.
7. 화면 **왼쪽 아래**의 'Settings'(설정) 버튼을 누릅니다. 톱니바퀴 모양일 수 있습니다.
   → 이렇게 보이면 됩니다: 설정 화면이 열리고 여러 탭 이름이 보입니다.
8. 'Customizations'(맞춤 설정)를 누릅니다.
   → 이렇게 보이면 됩니다: 'Installed MCP Servers'(설치된 MCP 서버)라는 칸이 보입니다. 처음이면 비어 있습니다.
9. 'Add MCP' 버튼을 누릅니다.
   → 이렇게 보이면 됩니다: 연결할 수 있는 서버 목록(MCP 스토어)과 검색칸이 나타납니다.
10. 검색칸에 `Notion` 을 입력합니다.
    → 이렇게 보이면 됩니다: 목록에 'Notion'이 한 줄 보입니다.
11. 'Notion' 줄의 'Add'를 누릅니다.
    → 이렇게 보이면 됩니다: 'Installed MCP Servers' 칸에 'Notion'이 생기고, 옆에 켜고 끄는 스위치가 보입니다.
12. 'Notion' 옆에 'Authenticate'(인증) 버튼이 보이면 누릅니다. 버튼 없이 곧바로 크롬 창이 열릴 수도 있습니다.
    → 이렇게 보이면 됩니다: 크롬에 노션 화면이 열리고 "이 앱이 노션에 접근하도록 허락할지"를 묻습니다.
13. 노션 화면에서 **어떤 작업 공간(워크스페이스)에 연결하는지** 이름을 읽습니다. 2번에서 정리한 그 작업 공간이 맞을 때만 허락 버튼을 누릅니다.
14. 허락한 뒤 화면에 긴 확인 코드(인증 코드)가 나오면, 그 코드를 복사(`Ctrl + C`)해 AGY 설정 화면으로 돌아와 코드 칸에 붙여 넣고(`Ctrl + V`) 'Submit'(제출)을 누릅니다. 코드 없이 "완료" 화면만 나오면 크롬 탭을 닫고 AGY로 돌아옵니다.
    → 이렇게 보이면 됩니다: 'Notion' 줄에 연결됐다는 표시가 나오고 스위치가 켜져 있습니다.

✖ 'Settings'가 왼쪽 아래에 없으면: AGY 창이 작아 버튼이 가려졌을 수 있습니다. 창 오른쪽 위 네모(최대화) 버튼을 누릅니다. 그래도 없으면 `Ctrl + ,`(컨트롤과 쉼표)를 눌러 설정을 엽니다.

✖ 목록에 'Notion'이 없거나 'Add'가 눌리지 않으면: 여기서 멈춥니다. 설정 파일을 손으로 고치는 방법은 이 과정에서 하지 않습니다. 설계표까지를 완료로 적고, 화면을 캡처(`Win + Shift + S`)해 강사에게 보여 줍니다.

✖ 인증 뒤에도 연결 표시가 안 나오면: 'Installed MCP Servers' 칸의 새로 고침(둥근 화살표 모양) 버튼을 누릅니다. 그래도 안 되면 휴지통 모양으로 'Notion'을 지우고 9번부터 한 번만 다시 합니다. 두 번째도 실패하면 화면의 오류 문장을 그대로 옮겨 적고 멈춥니다.

**라. 범위 조회 — 무엇이 보이는가 (AGY 채팅)**

15. 설정 화면을 닫고, 왼쪽 사이드바에서 내 작업 폴더 프로젝트를 누릅니다.
16. 아래 "AI에게 건네는 말"의 **첫 번째 글**을 보냅니다. 오늘 첫 요청은 무엇이 보이는지만 묻는 **범위 조회**입니다.
    → 이렇게 보이면 됩니다: 노션 도구를 써도 되는지 묻는 확인 카드가 뜹니다. 카드에 적힌 도구 이름을 읽습니다. `notion-search`(찾기)처럼 찾기·읽기 도구면 허락합니다. `create`(만들기), `update`(고치기), `move`(옮기기)가 들어 있으면 허락하지 않습니다.
17. 답으로 나온 페이지 목록을 설계표 옆에 놓고 한 줄씩 대조합니다.
    → 이렇게 보이면 됩니다: '수업 기록' 같은 연결할 페이지는 보이고, 설계표에서 "연결하지 않음"으로 적은 자료는 보이지 않습니다.
18. 보이지 말아야 할 자료가 보이면, 곧바로 AGY 'Settings' → 'Customizations' → 'Installed MCP Servers'에서 'Notion' 옆 스위치를 끕니다. 그 자료를 노션 밖으로 옮기거나 연결을 지우기 전까지 다시 켜지 않습니다.
19. 쓰기(새 페이지 만들기, 내용 고치기)는 오늘 하지 않습니다. 쓰기를 허용하는 날에는 11강 헌장의 "사람이 정하는 것" 장에 무엇을 승인 없이 쓰게 할지 먼저 적습니다.
20. 오늘 실습이 끝나면 'Notion' 스위치를 끌지 켜 둘지 정해 설계표에 적습니다. 자주 쓰지 않을 연결은 끄는 쪽이 안전합니다.

(AGY 화면의 글자는 버전에 따라 조금 다를 수 있습니다. 이 카드의 메뉴 이름은 2026-09-28 기준 AGY 공식 도움말 `https://antigravity.google/docs/mcp`의 'Antigravity 2.0' 항목을 따릅니다.)

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

첫 번째 글 — 범위 조회(16번).

> 연결된 노션에서 네가 볼 수 있는 페이지 제목 목록만 조회해서 보여 줘. 페이지 내용은 읽지 말고, 새 페이지를 만들거나 고치거나 옮기지도 마. 이번에 쓴 노션 도구 이름도 함께 적어 줘.

두 번째 글 — 연결이 제대로 안 될 때, 원인을 함께 좁히기.

> 노션 연결이 되어 있는지 확인하고 싶어. 지금 네가 쓸 수 있는 MCP 서버와 도구 이름만 목록으로 알려 줘. 설정 파일을 고치거나 새로 설치하지 말고, 토큰이나 비밀번호를 대화창으로 달라고 하지도 마.

## 손에 남길 것과 완료 확인

**연결 설계표 1장 · 범위 조회 결과 1건**

설계표에 자료마다 권한과 열쇠 보관 방법이 적혀 있고, "연결하지 않음" 자료가 연결할 서비스 안에 있을 때 어떻게 할지 적혀 있는지 확인합니다. 연결을 마쳤다면 범위 조회 결과를 설계표와 나란히 놓고, 보이지 말아야 할 자료가 보이지 않는지 확인합니다. 계정이나 화면 문제로 연결을 마치지 못했다면 설계표까지만 완료로 적고, 막힌 단계 번호와 오류 문장을 그대로 남깁니다. 토큰이나 비밀번호를 채팅 입력칸에 붙여 넣었다면 완료가 아니라 사고입니다. 그 서비스에서 바로 비밀번호나 토큰을 새로 바꿉니다.
