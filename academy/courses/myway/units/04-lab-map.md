# 4강. 실습 ① 내 자료 지도 30개와 사전 검색 측정

유정근 · 마이웨이 아카데미 | C2 자료관리론

정본 교시: 1-3 실습 메타데이터와 양방향 태깅을 활용한 다차원 분류 체계 실습

## 오늘의 목표

정리를 시작하기 전에 진단표 12문항과 검색 5문제로 출발점을 재고, 업무 하나에 쓰이는 자료 30개의 지도를 만듭니다. 모두 구글 시트(칸과 줄로 된 표 프로그램, C0 19강) 파일 하나에 남깁니다.

## 먼저 이해하기

체중계에 오르기 전에 운동을 시작하면 무엇이 달라졌는지 알 수 없습니다. 자료관리도 같습니다. 오늘은 **정리하기 전에 먼저 잽니다.** 이것을 <strong>사전 측정</strong>(시작하기 전에 재 두는 것)이라고 합니다. 그래야 과정 마지막 수업(20강)에서 같은 난이도의 다른 문제로 다시 쟀을 때(사후 측정), 달라진 것이 기분인지 사실인지 말할 수 있습니다. 측정은 능력 평가가 아니라 출발점을 남기는 일입니다.

<strong>자료 지도</strong>는 3강의 여섯 항목(메타데이터 — 자료에 대한 설명 정보)을 자료마다 한 줄씩 적은 목록입니다. 오늘은 30개로 제한합니다. 서랍 전체를 비워야 일을 시작할 수 있는 구조는 오래 가지 못합니다. 지금 하는 업무 하나에 필요한 30개면 됩니다. 30은 수업을 위한 표본(전체를 다 보지 않고 일부만 떼어 살펴보는 묶음) 크기이지, 정리가 끝났다는 기준이 아닙니다.

## 실제 기록에서 배운 한 줄

강사의 워크스페이스에 색인을 설계할 때 폴더마다 파일 수를 먼저 실제로 세었습니다. 세어 보고 나서야 백업 규칙이 남긴 사본 파일이 원본 곁에 적지 않게 쌓여 있다는 사실이 드러났고, 이를 검색 대상에서 빼는 결정을 할 수 있었습니다. 짐작으로 그린 지도에는 이런 것이 나타나지 않습니다. **지도를 그리기 전에 세어 보고, 정리하기 전에 재어 봅니다.**

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다. 공유하기 어려운 자료만 있다면 원본을 보여 주지 말고 유형·수량·역할만 적습니다. 내 자료를 쓸 수 없으면 아래 가상 자료 S01~S03과 'AI에게 건네는 말'의 가상 목록으로 같은 절차를 밟습니다.

**가상 자료** — 윤하람 씨의 강의 자료입니다.
- S01 이전 강의계획: 기준일 2024-03-01, 성인 학습자, 90분, 개인 노트북, 개인 계정 연결 포함, 결과물은 자료 지도와 안내문.
- S02 이번 의뢰 조건: 기준일 2026-09-01, 성인 학습자, 60분, 공용 기기, 가상 자료 사용, 개인 계정 로그인 제외, 결과물은 자료 지도와 안내문.
- S03 과거 진행 메모: 기준일 2024-03-02, 개인 계정 연결에 시간이 걸렸고 핵심 실습은 자료 위치와 기준일 확인이었다는 가상 관찰.

**가. 실습 시트 준비 (PC, 크롬 → 구글 시트)**

1. 크롬 주소창에 `https://sheets.google.com` 을 입력해 들어갑니다.
   → 이렇게 보이면 됩니다: 위쪽에 '새 스프레드시트 시작' 줄과 '빈 스프레드시트'(색색의 '+' 네모)가 보입니다.
2. '빈 스프레드시트'를 누르고, 왼쪽 위 '제목 없는 스프레드시트'를 눌러 `날짜_자료지도_v01` 로 바꿉니다.
3. 화면 맨 아래 왼쪽의 '시트1' 탭 옆 '+' 를 두 번 눌러 시트를 세 장으로 만듭니다. 각 탭에서 마우스 오른쪽 단추 → '이름 바꾸기'로 이름을 `진단표` · `사전측정` · `자료목록` 으로 바꿉니다.
   → 이렇게 보이면 됩니다: 아래쪽에 탭 세 개가 나란히 있습니다.

**나. 끝낼 업무 선언과 사전 진단표**

4. `진단표` 탭의 A1 칸(맨 왼쪽 위 칸)부터 네 줄에 끝낼 업무를 적습니다: 만들 결과물, 사용할 사람, 마감, 완성 기준. 예: "10월 수업 안내문 / 수강 신청자 / 10월 1일 / 조건 다섯 가지가 모두 들어감".
5. 그 아래 A6 칸부터 아래 12문항을 한 줄에 하나씩 옮겨 적고, 바로 오른쪽 B칸에 '예 / 아니오 / 모르겠음' 중 하나를 적습니다. 점수를 매기지 않습니다. 20강에서 같은 문항에 다시 답해 달라진 곳을 봅니다.

   | # | 문항 |
   |---|---|
   | 1 | 지금 하는 업무의 자료가 어느 저장소 몇 곳에 있는지 말할 수 있다 |
   | 2 | 같은 자료가 여러 벌일 때 어느 것이 정본인지 표시해 두었다 |
   | 3 | 새 자료를 먼저 넣는 곳(인박스)이 한 곳으로 정해져 있다 |
   | 4 | 파일 이름에 날짜·무엇·상태를 넣는 규칙을 지키고 있다 |
   | 5 | 자료마다 원본 위치와 기준일을 적어 둔 목록이 있다 |
   | 6 | 백업이나 사본을 실제로 열어 복구해 본 적이 있다 |
   | 7 | 최근 한 달 안에 예전 자료를 못 찾아 다시 만든 일이 없다 |
   | 8 | 결정을 바꾼 이유를 기록으로 남기고 있다 |
   | 9 | 메모를 다음 일에 가져다 쓸 수 있는 형태로 다듬어 둔다 |
   | 10 | AI에게 일을 맡길 때 참고할 내 자료를 지정해 건넨다 |
   | 11 | AI가 쓴 초안의 근거를 원문과 대조해 확인한다 |
   | 12 | 공개해도 되는 자료와 지켜야 할 자료를 나누는 기준이 있다 |

   표를 한꺼번에 옮기려면: 이 페이지에서 표를 마우스로 끌어 선택 → `Ctrl + C` → 시트의 A6 칸 누르기 → `Ctrl + V`.

**다. 사전 검색 측정 5문제 (PC, 파일 탐색기 · 드라이브 · 휴대폰)**

6. `사전측정` 탭 첫 줄에 `문제` · `찾을 자료` · `걸린 시간(초)` · `찾음 여부` · `맞는 버전인가` 라고 적습니다.
7. 찾을 자료 다섯 개를 정해 2~6줄에 적습니다: 지난번에 보낸 제안서, 어떤 결정을 내리게 한 메모, 다시 쓰고 싶은 참고 자료, 사진이나 스캔 한 장, 그리고 "두 버전 중 지금 유효한 것" 하나. 없는 것은 같은 역할의 자료로 바꿉니다.
8. 시간을 잴 도구를 엽니다. PC 시작 단추를 누르고 `시계` 라고 입력해 '시계' 앱을 연 뒤 왼쪽의 '스톱워치'를 누릅니다(휴대폰 시계 앱의 스톱워치도 됩니다).
9. 첫 문제부터 스톱워치 시작 단추를 누르고 찾기 시작합니다. 찾는 곳은 평소 쓰는 방식 그대로입니다(탐색기 오른쪽 위 검색칸, 드라이브 '드라이브에서 검색' 칸, 메일 검색, 휴대폰 앱). 오늘은 새 방법을 쓰지 않습니다.
10. 찾았다고 끝내지 말고 파일을 열어 제목·내용·대상이 맞는지 확인한 뒤 스톱워치를 멈추고, 걸린 초를 적습니다.
   - 한 문제에 최대 2분(120초)입니다. 못 찾으면 0초가 아니라 <strong>'120초 초과·미발견'</strong>으로 적고 다음 문제로 갑니다.
   - 빨리 찾았어도 틀린 버전이면 '맞는 버전인가' 칸에 '아니오'를 적습니다. 이것은 실패로 셉니다.
11. 다섯 문제의 결과는 워크북(과정 전체에서 쓰는 기록장)의 전후 비교표 "시작 전" 줄에도 옮겨 적습니다.

**라. 저장소 지도와 자료 목록 (구글 시트 `자료목록` 탭)**

12. 3강의 저장소 지도 문서를 열어 저장소 3~5곳을 확인합니다. 곳마다 복구 수단(별도 사본, 버전 기록 등)과 마지막으로 확인한 날이 적혀 있지 않으면 지금 채웁니다.
13. `자료목록` 탭 첫 줄에 `ID` · `제목` · `원본 위치` · `출처` · `기준일` · `상태` · `내가 찾을 표현` 일곱 칸을 적습니다. ID는 S01, S02처럼 자료마다 붙이는 번호입니다.
14. 2줄부터 자료를 한 줄에 하나씩 10줄 이상 적습니다. 가상 자료라면 S01~S03부터 적습니다. S01과 S02의 기준일과 상태('이전 버전' / '현재 조건')가 다르다는 점이 한눈에 보여야 합니다.
   → 이렇게 보이면 됩니다: 일곱 칸짜리 표가 10줄 넘게 채워져 있습니다.
15. 출처나 기준일이 불확실하면 추측하지 않고 '모름'으로 적습니다. AI가 채워 준 값도 확인하기 전까지는 '모름'입니다.
16. **정본 표시.** 같은 자료가 여러 벌이면 2강에서 정한 대로 정본 한 줄의 '상태' 칸에 '정본'을 적고, 나머지는 역할(작업본·공유본·백업)만 적습니다. 지우지 않습니다.
17. **복구 확인.** 사본 하나를 다른 위치에서 실제로 열어 봅니다. 예: PC에 있는 파일의 사본을 드라이브에서 두 번 눌러 열기. 열리면 그 줄 끝 칸에 날짜와 함께 '복구 확인'이라고 씁니다.
18. **목록만 보고 찾아가기.** 짝이 있다면 내 시트를 건네고(C0 12강의 공유), 없다면 하루 뒤의 나라고 생각하고 목록의 '찾을 표현'만으로 드라이브·탐색기에서 검색해 자료 3개에 도달해 봅니다. 도달하지 못한 줄은 칸을 노란색으로 칠합니다(위쪽 도구 줄의 페인트 통 모양). 설명이 부족한 줄이라는 뜻입니다.
19. **남은 20줄 계획.** 30개 가운데 오늘 채우지 못한 줄을 언제 채울지 날짜를 적습니다. 모든 자료를 분류하거나 중복을 지우는 일은 과제가 아닙니다.

## AI에게 건네는 말

> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

내 자료를 쓸 수 없는 분은 첫 번째 글로 가상 목록을 받습니다. 답에 표가 나오면 표를 마우스로 끌어 선택해 복사한 뒤, 구글 시트 `자료목록` 탭의 A1 칸을 누르고 붙여 넣습니다.

> 학습용 가상 자료 목록 30개를 만들어 줘. 주인공은 성인 대상 기록·글쓰기 강의를 하는 1인 강사다. 강의계획·의뢰 조건·진행 메모·사진·참고 자료·공유본·오래된 초안이 섞이게 하고, 같은 자료의 버전 두 개가 있는 경우를 세 쌍 넣어 줘. 실존 인물·기관·연락처는 넣지 마. 칸은 'ID / 제목 / 원본 위치 / 출처 / 기준일 / 상태 / 찾을 표현'으로 하되, 출처나 기준일 몇 칸은 일부러 '모름'으로 남겨 줘.

두 번째 글은 새 대화에서 보내도 됩니다. 글을 붙여 넣은 뒤 `Shift + Enter` 로 줄을 바꾸고, 시트 `자료목록` 탭의 A1~G11 칸을 마우스로 끌어 선택 → `Ctrl + C` → 입력칸에 `Ctrl + V` 로 붙여 함께 보냅니다.

> 내 자료 목록 10행을 보고, 하루 뒤의 내가 '찾을 표현'만 보고는 도달하기 어려울 행을 골라 이유를 한 줄씩 알려 줘. 표현을 대신 고치지는 마.

## 손에 남길 것과 완료 확인

**사전 진단표 · 사전 측정표 1장과 자료 지도(30행 목표, 오늘 10행 이상)** — 구글 시트 `날짜_자료지도_v01` 의 세 탭

- [ ] 끝낼 업무와 완성 기준을 한 줄씩 적었다
- [ ] 진단표 12문항에 답했다
- [ ] 검색 5문제의 시간·성공 여부·정확한 버전 여부를 기록했다 (미발견은 '120초 초과·미발견'), 전후 비교표 "시작 전" 줄에 옮겼다
- [ ] 저장소 3~5곳과 각 복구 수단을 적었다
- [ ] 자료 목록을 10행 이상 채웠고, 모르는 칸은 '모름'으로 두었다
- [ ] 같은 자료가 여러 벌인 경우 정본 한 곳을 표시했다
- [ ] 사본 하나를 다른 위치에서 실제로 열어 보았다
- [ ] 목록만으로 자료 3개에 도달해 보았고, 도달하지 못한 행을 노란색으로 표시했다
- [ ] 남은 행을 채울 날짜를 적었다

사전 진단표와 사전 측정표는 20강에서 다시 꺼냅니다. 고치거나 다시 풀지 말고 그대로 보관합니다. 같은 문제를 다시 풀게 되면 기억 효과가 섞이므로, 사후 측정은 난이도가 비슷한 다른 문제로 합니다.
