# 6강. 챗봇에서 에이전트로: 지금 AI는 어디까지 왔나

유정근 · 마이웨이 아카데미 | T1 교사 연수 · 심화

## 오늘의 목표

지금 쓰이는 AI를 네 단계 지도로 봅니다. 대화형 챗봇 → 도구를 쓰는 AI → 코딩 에이전트 → 상주형 에이전트. 단계마다 무엇을 맡길 수 있는지, 비용과 학교 현실, 위험을 알고 "나는 지금 어디에 있고, 다음은 어디인가"를 정합니다.

## 오늘 손에 남는 것

<strong>4단계 지도</strong> 한 장 — 단계마다 내 업무 하나씩을 올려 둔 표. 그리고 "사람의 일은 지시서 쓰기·검수·승인으로 옮겨 간다"는 한 문장.

## 준비물

- 실습용 PC와 크롬, 개인 구글 계정
- 5강의 내 업무 자료 분류표
- 이 카드 아래의 4단계 지도 표

## 먼저 이해하기

**한 문장으로 요약하면 "묻는 AI → 맡기는 AI"입니다.** 2023년의 AI는 묻고 답하는 상대였습니다. 지금의 AI는 일을 받아 가서 파일을 만들고, 고치고, 다 되면 알려 주는 쪽으로 가고 있습니다. 요리에 비유하면 이렇습니다.

| 단계 | 비유 | 대표 도구 |
|---|---|---|
| ① 대화형 챗봇 | 매번 처음부터 설명해야 하는 요리사 | ChatGPT, 제미나이 |
| ② 도구를 쓰는 AI | 내가 건넨 장바구니 재료로만 요리하는 요리사 | Gemini Notebook(옛 이름 NotebookLM), 제미나이 Canvas·Deep Research |
| ③ 코딩 에이전트 | 내 부엌에 들어와 직접 칼을 잡는 조수 | Claude Code, Codex, Antigravity |
| ④ 상주형 에이전트 | 집에 함께 살며 냉장고를 기억하고 "장 볼 때 됐어요" 먼저 말하는 집사 | Hermes Agent |

**① 대화형 챗봇 — 매번 설명하는 요리사**

- 무엇을 맡기나: 문장 다듬기, 아이디어, 설명 요청. 기본 과정 2강에서 웹앱 코드를 받은 것도 여기입니다.
- 비용: 무료로 시작할 수 있습니다(사용량 한도 있음).
- 학교에서 현실성: 높음. 대부분의 선생님이 이미 여기에 있습니다.
- 위험: 지난 대화의 맥락을 매번 다시 설명해야 하고, 근거 없이 그럴듯한 답(부정확한 정보)을 냅니다. 학생 정보를 대화창에 붙여 넣는 습관이 가장 큰 위험입니다.

**② 도구를 쓰는 AI — 내 자료를 근거로**

- 무엇을 맡기나: 내가 올린 자료만 근거로 답하게 합니다. 예: 작년 사업계획서·교육청 지침 PDF를 Gemini Notebook에 올리고 "지침과 어긋나는 부분을 찾아 줘". 제미나이 Canvas(캔버스: 문서·코드를 옆 창에서 함께 고치는 기능)에서 가정통신문을 문단 단위로 고칩니다. Deep Research(여러 웹 자료를 찾아 읽고 보고서로 묶는 기능)로 정책 동향을 정리합니다.
- 비용: 무료로 쓸 수 있습니다(사용량 한도 있음).
- 학교에서 현실성: 높음. 5강의 분류표가 여기서 바로 쓰입니다 — SSOT만 올리고, 민감 자료는 올리지 않습니다.
- 위험: 근거를 붙여 주니 더 믿게 됩니다. 답의 인용 번호를 눌러 원문과 대조하는 습관이 필요합니다.

**③ 코딩 에이전트 — 내 PC 폴더에서 파일을 직접 만들고 고침**

- 무엇을 맡기나: 내 PC의 작업 폴더(AI가 읽고 쓸 수 있게 열어 둔 폴더)를 열어 주면, 에이전트(스스로 계획을 세우고 여러 단계를 실행하는 AI)가 파일을 읽고, 새로 만들고, 고치고, 명령을 실행합니다.
- 기본 과정과 비교하면 차이가 선명합니다. 기본 과정에서는 제미나이에게 코드를 받아 → Apps Script 편집기에 붙여 넣고 → 배포 버튼을 눌렀습니다. 코딩 에이전트와 `clasp`(Apps Script 코드를 내 PC에서 구글로 밀어 넣는 명령줄 도구)가 있으면 이 전부가 대화 한 번입니다. 아래는 그런 요청의 예입니다. <strong>오늘 입력하지 않습니다.</strong> 이런 세상이 있다는 것만 봅니다.

> <strong>어디에 입력하나요:</strong> 코딩 에이전트(Claude Code, Codex, Antigravity 등)를 내 PC에 설치하고 작업 폴더를 연 뒤, 그 프로그램의 채팅 입력칸에 넣습니다. 오늘은 입력하지 않고 읽기만 합니다.

```text
이 폴더의 Code.gs 와 index.html 은 '사업계획서 자판기' 웹앱이야.
1. 입력칸에 '협조 부서' 칸을 하나 추가하고, 초안의 Ⅱ 기본 방침에 반영해 줘.
2. 고친 뒤 clasp push 로 올리고, 기존 웹앱 배포를 '새 버전'으로 갱신해서 URL이 바뀌지 않게 해 줘.
3. 시트 '기록' 탭의 기존 줄은 지우거나 바꾸지 마.
4. 끝나면 바꾼 파일 목록과, 내가 폰에서 확인할 것 세 가지를 알려 줘.
```

- 비용: 제품마다 요금 조건이 다릅니다. 쓰기 전에 각 공식 안내에서 확인합니다.
- 학교에서 현실성: 낮음~중간. 프로그램 설치 권한이 있는 내 PC가 필요하고, 학교 보안 프로그램에 막히는 일이 많습니다. 관심 있는 선생님과 정보부 몫입니다.
- 위험: 실제 파일을 고치므로, 잘못 시키면 실제 파일이 망가집니다. 그래서 5강의 백업과 `01_원본` 구분이 먼저입니다. 에이전트가 계획이나 확인 창을 보여 주면 읽고 나서 승인합니다.

**④ 상주형 에이전트 — 계속 켜져 있는 집사**

- 무엇인가: Hermes Agent는 Nous Research가 2026년 2월 공개한 오픈소스(누구나 코드를 보고 쓸 수 있는 소프트웨어, MIT 허가서) 상주형 에이전트입니다. 내 컴퓨터나 서버에서 계속 돌며 기억을 쌓고, 일하면서 스스로 '스킬'(반복되는 일의 처리 방법)을 만들어 둡니다. 메신저나 터미널(글자로 명령을 주고받는 창)에서 말을 걸어 일을 시킵니다.
- 무엇을 맡기나: "매주 월요일 아침, 이번 주 마감 공문 정리해서 메신저로 보내 줘" 같은 반복·감시 업무가 이 단계가 향하는 모습입니다. 실제로 어디까지 되는지는 설치해 시험해 보고 판단합니다.
- 비용: 프로그램은 오픈소스지만, 계속 켜 둘 컴퓨터와 연결할 AI 모델이 필요합니다. 어떤 모델을 연결하느냐에 따라 비용이 달라집니다.
- 학교에서 현실성: 낮음. 지금은 "이런 방향으로 간다"를 아는 단계입니다.
- 위험: 오래 기억하고 스스로 움직이므로, 무엇을 기억하게 둘지(민감 자료 제외)와 무엇은 반드시 내 승인을 받게 할지를 처음에 정해야 합니다.

**솔직한 현실.** 대부분의 선생님은 ①과 ②에서 충분히 업무를 줄일 수 있습니다. ③④는 설치 권한이 있는 내 PC가 필요하고, 관심 있는 선생님과 정보부가 먼저 가 보는 길입니다. 다만 단계가 올라갈수록 <strong>사람의 일이 바뀝니다</strong>. 직접 쓰는 사람 → 지시서를 쓰고, 결과를 검수하고, 승인하는 사람. 이 변화는 ①②에 머무는 선생님에게도 똑같이 옵니다.

## 따라 하기

**가. 같은 일을 네 단계로 맡겨 보기 — 읽기 (약 10분)**

윤서진 선생님의 일 하나, "내년 디지털시민교육 사업계획서 쓰기"를 단계별로 맡기면 이렇게 달라집니다.

1. ① 챗봇: 제미나이 대화창에 사업명·대상·기간을 설명하고 초안을 받습니다. 다음 날 고치려면 맥락을 다시 설명합니다.
2. ② 도구: Gemini Notebook에 작년 결재본(SSOT)과 교육청 지침을 올리고 "지침의 필수 항목이 작년판에 빠졌는지 표로 보여 줘"라고 묻습니다. 답마다 근거 번호가 붙습니다.
3. ③ 코딩 에이전트: 위 `text` 예처럼 앱 자체를 고치게 합니다. 앱이 바뀌면 그 앱을 쓰는 동료 모두의 다음 초안이 함께 달라집니다.
4. ④ 상주형: "매년 2월 첫 주, 작년 사업계획서와 올해 지침을 비교한 메모를 보내 줘"라고 한 번 정해 두면 해마다 알아서 오게 하는 것이 이 단계가 겨냥하는 모습입니다.
   → 이렇게 보이면 됩니다: 아래로 갈수록 내가 하는 일이 "쓰기"에서 "정해 두고 확인하기"로 바뀐다는 것이 보입니다.

**나. ②를 지금 한 번 겪어 보기 (약 10분)**

5. PC 크롬 주소창에 `https://notebook.google.com` 을 입력해 들어갑니다(예전 주소 `https://notebooklm.google.com` 도 됩니다).
6. 새 노트북을 만드는 단추를 누르고, 자료 추가 창에서 5강 분류표의 '공개' 자료 하나를 올립니다. 손에 없으면 학교 홈페이지에 올라간 가정통신문 PDF 하나면 충분합니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)
   → 이렇게 보이면 됩니다: 왼쪽에 올린 자료 이름이 보이고, 가운데에 자료 요약과 채팅 칸이 나타납니다.
   ✖ 학교 계정으로 들어가지 않으면: 관리자 정책으로 막혀 있을 수 있습니다. 개인 구글 계정으로 다시 들어갑니다.

> **어디에 입력하나요:** PC 크롬에서 `https://notebook.google.com` (예전 주소 `https://notebooklm.google.com` 도 됩니다)에 들어가 해당 노트북을 엽니다. 화면 가운데 '채팅' 칸 맨 아래 입력칸에 아래 글을 붙여 넣고 보냅니다. 답의 문장 끝에 붙은 작은 번호(인용)에 마우스를 올리면 근거가 된 원문이 보이니, 중요한 문장은 번호를 눌러 원문과 대조하세요.

```text
이 자료만 근거로 답해 줘. 학부모가 이 안내문을 읽고 헷갈릴 만한 부분 세 곳을 찾아,
각각 '문장 / 헷갈리는 이유 / 고친 문장 예시' 표로 보여 줘.
자료에 없는 내용은 추측하지 말고 '자료에 없음'이라고 써.
```

7. 답의 번호 하나를 눌러 원문과 맞는지 확인합니다.
   → 이렇게 보이면 됩니다: 번호를 누르면 왼쪽 자료의 해당 문장이 표시됩니다. ①과 달리 "어디서 나온 말인지"가 보입니다.

**다. 내 업무를 지도에 올리기 (약 5분)**

8. 아래 '4단계 지도'의 '내 업무' 칸에 단계마다 하나씩 적습니다. 예: ① 학급 소식 문장 다듬기 ② 교육청 지침 대비 사업계획서 점검 ③ 학년 출결 확인 앱 고치기 ④ 매주 공문 마감 알림.
9. '지금 할 수 있나' 칸에 됨/준비 필요/아직 아님을 적습니다.

**라. 사람의 일 한 줄 적기 (약 5분)**

10. 표 아래 칸에 "이 일을 AI에게 맡기면 내 일은 ___가 된다"를 한 문장 적습니다. 예: "사업계획서를 맡기면 내 일은 지시서를 쓰고, 지침과 맞는지 검수하고, 결재 올리기 전 승인하는 일이 된다."

## 4단계 지도

| 단계 | 내 업무 | 맡길 때 줄 자료(SSOT) | 지켜야 할 선 | 지금 할 수 있나 |
|---|---|---|---|---|
| ① 대화형 챗봇 | | | | |
| ② 도구를 쓰는 AI | | | | |
| ③ 코딩 에이전트 | | | | |
| ④ 상주형 에이전트 | | | | |

이 일을 AI에게 맡기면 내 일은 ______________________ 가 된다.

## 막히면

- **"③④는 우리 학교에서 못 쓰는데 왜 배우나요?"** — 쓰려고가 아니라 방향을 알려고 배웁니다. 단계가 올라가도 필요한 것은 같습니다. 정리된 자료(5강)와 잘 쓴 지시서(7강). 이 둘은 ①②에서 지금 연습할 수 있습니다.
- **"Gemini Notebook에 자료가 안 올라가요."** — 파일 대신 안내문 본문을 복사해, 자료 추가 창에서 글을 직접 붙여 넣는 항목으로 넣어도 됩니다. 학생 이름이 든 자료는 올리지 않습니다.
- **"에이전트가 알아서 하면 위험하지 않나요?"** — 그래서 승인 단계를 둡니다. 맡기는 범위, 하지 말 일, 내 확인이 필요한 순간을 지시서에 적는 것이 7강의 내용입니다.

## 정리

AI는 묻는 상대에서 맡기는 상대로 옮겨 가고 있습니다. 매번 설명하는 요리사, 장바구니 재료로만 요리하는 요리사, 부엌에 들어온 조수, 함께 사는 집사. 어느 단계든 좋은 결과는 정리된 재료와 분명한 주문서에서 나옵니다. 그리고 사람의 자리는 "쓰는 사람"에서 "지시서를 쓰고, 검수하고, 승인하는 사람"으로 바뀝니다. 다음 7강에서 그 지시서를 직접 써서, 한 가지 일만 잘하는 에이전트를 무료로 만들어 봅니다.
