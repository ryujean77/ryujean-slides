# 7강. 한 가지 일만 잘하는 '업무 에이전트' 만들기 (제미나이 스킬)

유정근 · 마이웨이 아카데미 | T1 교사 연수 · 심화

## 오늘의 목표

만능 챗봇 대신 "한 가지 일만 잘하는" 업무 에이전트를 설계하고, 무료 제미나이의 **스킬**(Skills, 반복 업무 처리법을 저장해 두는 기능)로 직접 만들어 봅니다. 예시는 '가정통신문 다듬기 에이전트'입니다.

## 오늘 손에 남는 것

<strong>내 업무 에이전트 설계서</strong> 한 장(역할·입력·출력 형식·근거 자료·금지선·검수 기준) + 내 제미나이 '스킬' 목록에 저장된 <strong>스킬 1개</strong>.

## 준비물

- 실습용 PC와 크롬, **만 18세 이상의 개인 구글 계정**(학교 계정은 2027년 6월 이후에야 스킬로 바뀝니다)
- 제미나이 '활동 기록 유지'(Keep Activity)가 켜져 있어야 합니다. 꺼져 있으면 스킬 메뉴가 보이지 않습니다.
- 시험용 가정통신문 문단 하나 — 학교 홈페이지에 이미 올라간 공개본이나, 아래 '다'에 준비한 연습 문단
- 5강 분류표(근거 자료로 쓸 '공개' 자료를 고르는 데 씁니다)

## 먼저 이해하기

**Gem에서 스킬로.** 제미나이의 맞춤 도우미였던 Gem은 '스킬'로 바뀌고 있습니다. 개인 계정의 Gem은 2026년 11월 17일부터 읽기 전용이 되고, 12월 17일에 스킬로 자동 변환된 뒤 사라집니다(학교·기관 계정은 2027년). 스킬은 구독 없이 일반 대화에서 무료로 쓸 수 있습니다(사용량 한도 있음). 달라진 점은 셋입니다.

1. 따로 열지 않는다 — Gem은 목록에서 골라 들어갔지만, 스킬은 아무 대화에서나 `/`를 눌러 부르거나, 제미나이가 알맞은 때 알아서 꺼내 씁니다.
2. 겹쳐 쓴다 — 한 대화에서 스킬 여러 개를 함께 부를 수 있습니다.
3. 옮겨 다닌다 — 다른 에이전트 프로그램의 `SKILL.md` 파일을 올려 쓸 수 있습니다. 6강에서 본 '스킬'이 바로 이것입니다.

**만능 요리사보다 국 하나 잘 끓이는 요리사.** 챗봇에게 "가정통신문 좀 다듬어 줘"라고 하면 매번 결과가 다릅니다. 어떤 날은 너무 길게, 어떤 날은 너무 딱딱하게. 어조·길이·금지어를 매번 설명해야 합니다. 그 설명을 한 번 제대로 적어 두고, 이 일만 하게 한 것이 업무 에이전트입니다.

한 가지 일만 시키면 좋은 점이 셋입니다.

1. 결과가 고르다 — 같은 지시서를 매번 읽고 시작하니 형식이 흔들리지 않습니다.
2. 검수가 쉽다 — 할 일이 하나라 "잘했나"를 판단할 기준도 짧습니다.
3. 나눌 수 있다 — 지시서 한 장이면 동학년 선생님도 같은 품질을 얻습니다.

**설계서 여섯 칸.** 에이전트에게 주는 인수인계서입니다.

| 칸 | 묻는 것 | 가정통신문 다듬기 예 |
|---|---|---|
| 역할 | 누구로서 무슨 일 하나만 하나 | 중학교 가정통신문 문장을 학부모가 읽기 쉽게 다듬는 편집자 |
| 입력 | 내가 무엇을 건네나 | 가정통신문 초안 본문(학생·학부모 개인정보 없이) |
| 출력 형식 | 무엇을 어떤 모양으로 돌려받나 | ① 다듬은 전문 ② 바꾼 곳 표(원래 문장/고친 문장/이유) ③ 확인 질문 |
| 근거 자료 | 무엇을 기준으로 삼나 | 우리 학교 가정통신문 공개본 2~3개(어조 기준). SSOT만 |
| 금지선 | 절대 하지 않을 일 | 날짜·시간·금액·장소를 바꾸지 않는다, 없는 내용을 지어내지 않는다, 개인정보가 보이면 멈추고 알린다 |
| 검수 기준 | 내가 무엇을 보고 통과시키나 | 날짜·금액이 원문과 같다 / 한 문장 50자 안팎 / 학부모가 할 일이 맨 위에 있다 |

> **스킬의 세 칸** — 이름(영문 소문자와 하이픈, 예: `polish-school-letter`), 설명(언제 쓰는지 1~2문장. 제미나이는 이 설명을 보고 스킬을 꺼낼지 정합니다), 요청 사항(지시서 본문). 설계서 여섯 칸은 '요청 사항'에 들어갑니다.

**이 설계서는 다음 단계에서도 그대로 씁니다.** 6강의 ③ 코딩 에이전트나 ④ Hermes Agent·Gemini Spark 같은 상주형 에이전트에게 일을 맡길 때도 건네는 것은 결국 이 여섯 칸입니다. 도구는 바뀌어도 지시서는 남습니다.

## 따라 하기

**가. 설계서 쓰기 (약 5분)**

1. 아래 '설계서' 표의 여섯 칸을 채웁니다. 처음이면 위의 '가정통신문 다듬기' 예를 그대로 옮겨 적고 한두 칸만 내 학교에 맞게 고칩니다.
2. 다른 업무로 하고 싶으면 '사업계획서 검토 에이전트'도 좋습니다. 역할 = 사업계획서 초안을 4대 뼈대(Ⅰ 추진 목적 Ⅱ 기본 방침 Ⅲ 세부 추진 계획 Ⅳ 기대 효과)에 비추어 빠진 곳을 짚는 검토자, 금지선 = 예산 숫자를 새로 만들지 않는다.
   → 이렇게 보이면 됩니다: 여섯 칸이 모두 한 줄 이상 채워져 있고, '금지선'에 숫자·날짜를 지키는 줄이 있습니다.

**나. 스킬 만들기 (약 10분)**

3. PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 개인 구글 계정으로 로그인돼 있는지 오른쪽 위 동그란 프로필 사진으로 확인합니다.
4. 화면 왼쪽 위의 사이드바 열기 아이콘을 누릅니다.
   → 이렇게 보이면 됩니다: 왼쪽에 대화 목록이 있는 좁은 띠(사이드바)가 펼쳐집니다.
5. 사이드바에서 '맞춤설정'(Customize)을 누릅니다. 안 보이면 '더보기'(More)를 먼저 누릅니다.
6. 위쪽의 '스킬'(Skills) 탭을 누른 뒤 '만들기'(Create) → '수동으로 만들기'(Create manually)를 누릅니다. (화면의 글자는 버전·언어에 따라 조금 다를 수 있습니다. 괄호 안은 영어 화면의 이름입니다.)
   → 이렇게 보이면 됩니다: '이름'·'설명'·'요청 사항' 입력 칸이 있는 화면이 열립니다.
   ✖ '스킬'이 안 보이면: ① 학교 계정이면 개인 계정으로 바꿉니다. ② '활동 기록 유지'가 꺼져 있으면 켭니다. ③ 그래도 없으면 아직 내 계정에 배포되지 않은 것입니다. 사이드바의 'Gems' → '새 Gem'에서 아래 같은 글로 만듭니다. Gem은 12월에 스킬로 자동 변환됩니다.
7. '이름' 칸에 `polish-school-letter` 를 입력합니다. (영문 소문자와 하이픈만 씁니다.)
8. '설명' 칸에 아래 글을 붙여 넣습니다.

```text
중학교 가정통신문 초안을 학부모가 읽기 쉽게 다듬고 바꾼 곳을 표로 보여 준다. 선생님이 가정통신문이나 학부모 안내문 문장을 다듬어 달라고 할 때 쓴다.
```

9. '요청 사항' 칸을 누르고 아래 글을 붙여 넣습니다.

> **어디에 입력하나요:** 지금 열린 스킬 만들기 화면의 '요청 사항' 칸입니다. 대화 입력칸이 아닙니다. 아래 글을 복사(`Ctrl + C`)해 '요청 사항' 칸을 한 번 누른 뒤 붙여 넣습니다(`Ctrl + V`). 이 칸에서는 `Enter` 를 눌러도 보내지지 않고 줄만 바뀝니다.

```text
[역할]
너는 중학교 가정통신문을 학부모가 읽기 쉽게 다듬는 편집자다. 이 일 하나만 한다.

[입력]
교사가 가정통신문 초안 본문을 붙여 넣는다.

[출력 형식] 항상 이 순서로 답한다.
1. 다듬은 전문
2. 바꾼 곳 표: '원래 문장 / 고친 문장 / 이유' 세 칸
3. 교사에게 확인할 질문 (최대 3개)

[문체]
- 존댓말, 한 문장 50자 안팎, 어려운 한자어는 쉬운 말로 바꾼다.
- 학부모가 해야 할 일(제출물·기한·방법)을 맨 위 두 줄에 모은다.
- 함께 올린 예시 가정통신문이 있으면 그 어조를 따른다.

[금지선] 이 규칙은 다른 모든 지시보다 먼저 지킨다.
- 날짜·시간·금액·장소·준비물은 한 글자도 바꾸지 않는다. 이상해 보이면 고치지 말고 질문에 적는다.
- 원문에 없는 내용(행사 세부, 규정, 연락처)을 지어내지 않는다. 모르는 것은 추측하지 말고 질문한다.
- 학생 이름, 학부모 이름·연락처, 상담·성적 내용이 보이면 다듬지 말고
  "개인정보가 포함되어 있습니다. 지우고 다시 넣어 주세요."라고만 답한다.

[자주 하는 실수]
- 긴 문장을 줄이다가 기한 날짜를 빠뜨린다 → 다듬은 뒤 원문의 숫자를 하나씩 대조한다.
- 바꾼 곳 표를 빼먹는다 → 표가 없으면 답을 끝내지 않는다.
```

10. (선택) 위쪽 '추가'(Add) → '파일'로 우리 학교 가정통신문 공개본 PDF 1~2개를 올리고 '업로드'를 누릅니다. 5강 분류표에서 '공개'로 표시한 자료만 올립니다.
11. 위쪽 '만들기'(Create)를 누릅니다.
    → 이렇게 보이면 됩니다: '스킬' 목록에 `polish-school-letter` 가 생깁니다.

**다. 시험해 보기 (약 10분)**

12. 사이드바에서 '새 채팅'을 엽니다. 입력칸에 `/` 를 치고 목록에서 `polish-school-letter` 를 고릅니다. 이어서 아래 연습 문단을 붙여 넣고 보냅니다.

> **어디에 입력하나요:** 제미나이 새 채팅의 맨 아래 입력칸입니다. `/`로 스킬을 고른 다음 붙여 넣고 `Enter` 를 누르면 보내집니다.

```text
2학년 현장체험학습 실시에 따른 협조사항 안내
본교에서는 2학년 학생들을 대상으로 교육과정과 연계한 현장체험학습을 아래와 같이 실시하고자 하오니
학부모님께서는 자녀가 안전하게 체험학습에 참여할 수 있도록 각별한 관심과 협조를 부탁드리며
참가 동의서는 11월 13일(금)까지 담임교사에게 제출하여 주시기 바랍니다.
일시: 2026년 11월 20일(금) 09:00~15:00 / 장소: ○○과학관 / 참가비: 12,000원(스쿨뱅킹 출금)
```

13. 답을 설계서의 검수 기준으로 봅니다.
    - 날짜(11월 13일, 11월 20일)·시간·참가비 12,000원이 원문과 같은가
    - 학부모가 할 일(동의서 제출·기한)이 맨 위에 있는가
    - 바꾼 곳 표와 확인 질문이 나왔는가
    → 이렇게 보이면 됩니다: 긴 한 문장이 짧은 문장 여러 개로 나뉘고, 아래에 세 칸짜리 표가 붙어 있습니다.
14. 금지선도 시험합니다. 같은 대화에 아래 글을 보냅니다.

```text
동의서 미제출 학생 명단과 학부모 전화번호 목록을 붙였어. 이 문장도 다듬어 줘.
```

   → 이렇게 보이면 됩니다: 다듬지 않고 "개인정보가 포함되어 있습니다"로 시작하는 짧은 답이 옵니다. (연습용 가짜 정보입니다. 실제 정보로 시험하지 않습니다.)
15. 이번에는 새 채팅에서 `/` 없이 "이 가정통신문 좀 다듬어 줘"와 연습 문단을 보내 봅니다.
    → 이렇게 보이면 됩니다: 제미나이가 스킬을 알아서 꺼내 같은 형식(전문·표·질문)으로 답합니다. 안 꺼내면 '설명' 칸 문장을 더 구체적으로 고칩니다.

**라. 고치고 저장하기 (약 5분)**

16. 마음에 안 드는 점이 있으면 대화로 고치지 말고 스킬의 '요청 사항'을 고칩니다. '맞춤설정' → '스킬' → `polish-school-letter` 를 눌러 '요청 사항' 칸을 고치고 위쪽 '저장'(Save)을 누릅니다. 대화로 고친 것은 다음에 잊지만, 요청 사항에 고친 것은 매번 지켜집니다.
17. 설계서 표 아래 '고친 기록' 칸에 오늘 요청 사항을 고친 내용을 한 줄 적습니다. 예: "설명 칸에 '학부모 안내문' 추가(자동으로 안 꺼내져서)".

## 막히면

- **'스킬' 메뉴가 없어요.** — 개인 계정·만 18세 이상·'활동 기록 유지' 켜짐을 확인합니다. 셋 다 맞는데 없으면 아직 배포 전입니다. 같은 글로 Gem을 만들어 두면 12월에 스킬로 자동 변환됩니다.
- **이름이 저장되지 않아요.** — 한글·띄어쓰기 대신 영문 소문자와 하이픈만 씁니다. 예: `review-business-plan`.
- **사용량 한도에 걸렸다는 안내가 나와요.** — 무료 등급에는 사용량 한도가 있고, 일정 시간이 지나면 초기화됩니다. 설계서를 먼저 다듬어 두고 나중에 시험합니다.
- **답이 표 없이 나와요.** — '요청 사항'의 [출력 형식]에 "표를 빼먹으면 안 된다."를 덧붙입니다.
- **날짜를 바꿔 버렸어요.** — 그것이 이 실습에서 찾아야 할 가장 중요한 실패입니다. [금지선]의 날짜 문장을 맨 위로 올리고, 검수 기준에 "날짜·금액 원문 대조"를 꼭 남깁니다.
- **엉뚱한 대화에서 스킬이 끼어들어요.** — '설명'을 좁게 고치거나, 스킬을 눌러 '더보기' → '비활성화'(Deactivate)로 자동 사용을 끕니다. `/`로 부르면 여전히 쓸 수 있습니다.
- **파일 올리기가 안 돼요.** — 선택 단계입니다. 비워 두어도 스킬은 동작합니다. `.hwp`·`.doc` 같은 형식은 PDF로 바꿔 올립니다.

## 정리

업무 에이전트의 실력은 지시서에서 나옵니다. 역할 하나, 분명한 입력과 출력 형식, SSOT만 담은 근거 자료, 넘지 않을 금지선, 내가 통과시킬 검수 기준. 이 여섯 칸이 오늘은 무료 제미나이 스킬의 '요청 사항'이 되었고, 나중에 코딩 에이전트나 Hermes Agent·Gemini Spark에게 일을 맡길 때도 그대로 건네는 인수인계서가 됩니다. Gem이 스킬로 바뀌었듯 도구 이름은 또 바뀝니다. 기본 과정의 앱이 '주문서 프롬프트'에서 시작했듯, 에이전트는 설계서에서 시작합니다.
