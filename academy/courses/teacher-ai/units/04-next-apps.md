# 4강. 다음 앱과 안전 수칙 5가지

유정근 · 마이웨이 아카데미 | T1 교사 연수 · 기본

## 오늘의 목표

오늘 익힌 길(주문서 → 붙여 넣기 → 배포 → 새 버전 → 확인)로 만들 수 있는 다음 앱을 고릅니다. 1강에서 본 영상 속 앱 4개를 Apps Script용 주문서로 바꿔 두었습니다. 앱을 키우기 전에 지켜야 할 안전 수칙 5가지를 체크하고, 내 다음 앱 주문서 한 장을 씁니다.

## 오늘 손에 남는 것

- <strong>다음 앱 주문서</strong> 한 장(바로 제미나이에 넣을 수 있는 형태)
- <strong>안전 수칙 5가지</strong> 체크 결과

## 준비물

- 1강에서 쓴 앱 아이디어 한 줄
- PC 크롬, 개인 구글 계정, 무료 제미나이 탭
- 2~3강에서 만든 앱(배포 순서를 다시 볼 때)

## 먼저 이해하기

1강의 영상 속 선생님은 "만드는 건 쉬운데 테스트와 배포가 어렵다"고 했습니다. 오늘 여러분은 그 두 고개를 한 번씩 넘었습니다. 이제 남은 것은 무엇을 만들지 고르는 일과, 만들면서 다치지 않는 일입니다.

새 앱도 모두 같은 틀로 주문합니다. 주문서에 늘 들어가는 다섯 줄이 있습니다.

1. 파일은 `Code.gs` 와 `index.html` 두 개, 각각 전체 코드로
2. 저장은 이 스프레드시트의 시트에
3. 휴대폰에서 보기 좋게
4. 유료 서비스·외부 라이브러리 금지, AI는 선택(스크립트 속성 `GEMINI_API_KEY` 가 있을 때만, 없어도 동작)
5. 개인정보를 받지 않는 화면

이 다섯 줄이 있으면 2~3강의 배포·재배포 순서를 그대로 쓸 수 있습니다.

## 따라 하기

**가. 다음 앱 고르기: 영상 속 앱 4개의 주문서** (약 8분)

아래 주문서는 모두 같은 곳에 넣습니다.

> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.

앱마다 <strong>새 구글 시트</strong>를 하나씩 만들고(2강 '가'), 제미나이도 '새 채팅'에서 시작합니다. 앱 하나 = 시트 하나 = 대화 하나. 섞이지 않게 하는 가장 쉬운 방법입니다. 지금은 넷 중 하나만 골라 읽고, 실제 제작은 연수 뒤에 합니다.

### ① 바로기록 — 관찰·상담 기록

영상 속 바로기록처럼 원클릭으로 남기되, 학생은 <strong>번호</strong>로만 적습니다.

```text
너는 코딩을 모르는 중학교 교사를 돕는 Google Apps Script 개발자야.
구글 시트에 연결된 Apps Script 웹앱 '바로기록'을 만들어 줘.

[파일] Code.gs 와 index.html 두 개만. 각 파일 전체를 생략 없이 코드 블록 하나씩.
유료 서비스, 외부 라이브러리는 쓰지 마. AI 기능은 넣지 마.

[화면] 휴대폰에서 한 손으로 쓰기 좋게, 큰 단추.
- 학생 번호 입력칸(숫자만, 예: 7). 이름 입력칸은 만들지 마.
- 유형 단추 5개: 상담, 관찰, 생활, 학습, 기타. 누른 단추가 색으로 표시.
- 내용 입력칸(여러 줄). 유형을 누르면 그 유형의 짧은 템플릿 문장이 내용 칸에 미리 채워짐.
- '기록' 단추. 날짜·시각은 자동.
[저장] 이 스프레드시트의 '기록' 시트(없으면 만들기)에 시각, 번호, 유형, 내용 한 줄.
[통계] '월별 통계' 화면: 월 × 유형별 건수 표.
[내보내기] 'CSV 내려받기' 단추: 기록 시트 전체를 CSV 파일로 내려받기.
[안내] 화면 맨 위에 '학생 이름·연락처는 적지 마세요' 한 줄.
코드 뒤에 붙여 넣는 순서를 다섯 줄 이내로.
```

> **이 앱은 특히 조심합니다.** 번호만 적어도 학급 명렬표와 맞추면 누구인지 알 수 있습니다. 상담·관찰 기록은 그 자체로 민감한 개인정보입니다. 개인 계정으로는 <strong>연습용 가짜 기록</strong>만 넣어 보고, 실제 기록은 학교가 허용한 저장소와 계정에서만 씁니다. 배포할 때 접근 권한은 '나만'으로 합니다. 이 앱에는 AI를 붙이지 않습니다(무료 등급 입력은 Google 제품 개선에 쓰이기 때문입니다).

### ② 문항 → 구글폼 변환기

평가 문항을 붙여 넣으면 퀴즈형 구글폼이 바로 만들어지는 앱입니다.

```text
너는 코딩을 모르는 중학교 교사를 돕는 Google Apps Script 개발자야.
구글 시트에 연결된 Apps Script 웹앱 '문항→구글폼 변환기'를 만들어 줘.

[파일] Code.gs 와 index.html 두 개만. 각 파일 전체를 생략 없이 코드 블록 하나씩.
유료 서비스, 외부 라이브러리는 쓰지 마.

[화면] 휴대폰·PC 모두 보기 좋게.
- 폼 제목 입력칸
- 문항 붙여 넣기 칸(여러 줄). 형식 예시를 칸 안에 회색 글씨로 보여 줘:
  1. 질문 / ① 보기 ② 보기 ③ 보기 ④ 보기 / 정답: ②
- '폼 만들기' 단추
[동작] FormApp 으로 퀴즈 모드 구글폼을 새로 만들고, 객관식 문항과 정답·배점(기본 1점)을 넣는다.
형식을 못 읽은 문항은 건너뛰고, 몇 번 문항을 건너뛰었는지 화면에 알려 준다.
끝나면 '폼 편집 링크'와 '응답용 링크'를 화면에 보여 준다.
[기록] 이 스프레드시트의 '기록' 시트에 시각, 폼 제목, 문항 수, 두 링크를 한 줄.
[AI 선택] 스크립트 속성 GEMINI_API_KEY 가 있을 때만, 각 문항의 해설을 제미나이 API
(모델 gemini-flash-lite-latest)로 만들어 정답 피드백에 넣는다. 키가 없으면 해설 없이 만든다.
코드 뒤에 붙여 넣는 순서를 다섯 줄 이내로.
```

> **여기가 Apps Script의 홈그라운드입니다.** 영상 속 변환기도 마지막에는 Apps Script 코드로 폼을 만들었습니다. 우리는 처음부터 그 안에서 만듭니다. 구글 안에서 폼을 만들고 링크를 받으니, 학교 PC에 따로 설치할 것도, 보안 프로그램과 씨름할 일도 없습니다. 처음 배포할 때 구글 폼을 만들고 고칠 권한을 묻는 승인 화면이 새로 나옵니다. 2강 '라'처럼, 내가 만든 앱일 때만 허용합니다.

### ③ 우리 반 단어장·사전

```text
너는 코딩을 모르는 중학교 교사를 돕는 Google Apps Script 개발자야.
구글 시트에 연결된 Apps Script 웹앱 '우리 반 단어장'을 만들어 줘.

[파일] Code.gs 와 index.html 두 개만. 각 파일 전체를 생략 없이 코드 블록 하나씩.
유료 서비스, 외부 라이브러리는 쓰지 마.

[저장] 이 스프레드시트의 '단어' 시트(없으면 만들기): 단어, 뜻, 쉬운 예문, 단원.
[화면] 휴대폰에서 보기 좋게.
- 검색칸: 단어를 치면 시트에서 찾아 뜻과 예문을 카드로 보여 줌.
- '단원별 보기': 단원을 고르면 그 단원 단어 목록.
- '단어 추가' 칸(교사용): 단어·뜻·예문·단원 입력 → 시트에 저장.
[AI 선택] 스크립트 속성 GEMINI_API_KEY 가 있으면 '단어 추가'에서 단어만 넣고
'AI로 채우기'를 누르면 중학생 눈높이의 뜻과 예문 초안을 제미나이 API
(모델 gemini-flash-lite-latest)로 채워 준다. 교사가 읽고 고친 뒤 저장한다. 키가 없으면 단추를 숨긴다.
코드 뒤에 붙여 넣는 순서를 다섯 줄 이내로.
```

> AI 채우기는 교사만 씁니다. 학생에게 URL을 열어 줄 때는 검색·단원별 보기만 쓰게 하고, 학교 규정을 먼저 확인합니다. 학생이 입력한 글이 무료 등급 AI로 들어가지 않게 하려는 것입니다.

### ④ 개념 카드 — 이미지 API 없이

영상 속 컨셉덱은 AI 이미지 사용료가 부담이었습니다. 이 주문서는 그림 대신 이모지·색·짧은 글로 카드를 만들어 비용을 0원으로 둡니다.

```text
너는 코딩을 모르는 중학교 교사를 돕는 Google Apps Script 개발자야.
구글 시트에 연결된 Apps Script 웹앱 '개념 카드'를 만들어 줘.

[파일] Code.gs 와 index.html 두 개만. 각 파일 전체를 생략 없이 코드 블록 하나씩.
유료 서비스, 외부 라이브러리, 이미지 생성 API는 쓰지 마.

[저장] 이 스프레드시트의 '카드' 시트(없으면 만들기): 단원, 개념, 한 줄 정의, 예시, 이모지, 색.
[화면] 휴대폰에서 보기 좋게.
- 카드 한 장씩: 앞면 = 큰 이모지와 개념 이름, 누르면 뒷면 = 정의와 예시.
- 단원 고르기, '다음 카드', '섞어서 복습' 단추.
- '카드 추가' 칸(교사용): 단원·개념·정의·예시·이모지·색 입력 → 시트에 저장.
[AI 선택] 스크립트 속성 GEMINI_API_KEY 가 있으면 개념 이름만 넣고 'AI로 채우기'를 누르면
정의·예시·어울리는 이모지 초안을 제미나이 API(모델 gemini-flash-lite-latest)로 채운다.
키가 없으면 단추를 숨긴다. 그림은 만들지 않는다.
코드 뒤에 붙여 넣는 순서를 다섯 줄 이내로.
```

1. 넷 중 내 업무에 가장 가까운 것 하나에 동그라미를 칩니다.
   → 이렇게 보이면 됩니다: 1강에서 적은 아이디어와 같은 것이면 바로 '다'로, 다르면 1강 아이디어를 '다'에서 주문서로 바꿉니다.

**나. 안전 수칙 5가지 체크** (약 6분)

앱을 만드는 일보다 앱이 오래 무사한 일이 더 중요합니다. 아래 다섯 가지를 내 앱 기준으로 체크합니다.

| 번호 | 수칙 | 내 앱에서 지키는 방법 | 체크 |
|---|---|---|---|
| 1 | <strong>개인정보는 넣지 않는다</strong> | 학생 이름·연락처·성적·상담 내용을 화면에 받지 않는다. 꼭 필요하면 번호로, 실제 기록은 학교가 허용한 저장소에서만. 화면 맨 위에 "개인정보 금지" 안내를 둔다. | ☐ |
| 2 | <strong>비용과 무료 한도를 안다</strong> | 무료 등급 키만 쓴다. 키를 만든 프로젝트에 결제를 연결하지 않는다. 429(사용량 초과)가 나오면 기다린다. 이미지 생성처럼 비싼 AI는 쓰지 않는다. | ☐ |
| 3 | <strong>공유 범위와 권한을 정한다</strong> | 나 혼자 쓰면 '나만', 동료와 쓰면 'Google 계정이 있는 모든 사용자'. '모든 사용자'(익명)는 쓰지 않는다. '나'로 실행되는 앱은 누가 쓰든 <strong>내</strong> 드라이브·시트에 쌓인다는 것을 안다. 남이 보낸 앱의 권한 승인은 누르지 않는다. | ☐ |
| 4 | <strong>무료 등급 데이터 활용을 안다</strong> | 무료 등급 API에 넣은 글은 Google 제품 개선에 쓰인다. 학생이 직접 입력하는 칸은 AI로 보내지 않는다. 키는 코드가 아니라 스크립트 속성에. | ☐ |
| 5 | <strong>최종 판단은 교사, 확인은 습관</strong> | AI 초안은 초안이다. 숫자·일정·표현은 내가 고친다. 고칠 때는 한 번에 하나, 새 버전 배포, 휴대폰에서 눈으로 확인. | ☐ |

수칙 5는 현장 선생님들의 목소리이기도 합니다. 2026년 10월 보도된 한국교육과정평가원(KICE) 연구리포트에서 교사 2,740명 중 약 63%가 수업·평가에 생성형 AI를 쓰고 있었고, 걱정으로는 부정확한 정보, 개인정보 유출, 학생 사고력 저하를 꼽았습니다. 결론은 "최종 판단은 교사"였습니다.

1. 표의 체크 칸 다섯 개를 내 앱 기준으로 채웁니다.
   ✖ 지킬 수 없는 칸이 있으면: 그 기능을 주문서에서 빼거나, 학교 정보 담당 부서와 먼저 상의합니다.

**다. 다음 앱 주문서 1장 쓰기** (약 6분)

아래 틀을 그대로 채우면 제미나이에 바로 넣을 수 있는 주문서가 됩니다. 빈칸만 바꿉니다.

> <strong>어디에 입력하나요:</strong> 지금은 보내지 않습니다. 빈칸을 다 채운 뒤, 연수가 끝나고 '가'와 같은 곳(`https://gemini.google.com` 의 '새 채팅' 입력칸)에 붙여 넣어 보냅니다. 오늘은 아래 1~3번처럼 종이나 메모장에서 빈칸만 채웁니다.

```text
너는 코딩을 모르는 중학교 교사를 돕는 Google Apps Script 개발자야.
구글 시트에 연결된 Apps Script 웹앱 '[앱 이름]'을 만들어 줘.

[파일] Code.gs 와 index.html 두 개만. 각 파일 전체를 생략 없이 코드 블록 하나씩.
유료 서비스, 외부 라이브러리는 쓰지 마.

[누가 언제 쓰나] [예: 내가 수행평가 준비할 때 PC에서]
[화면] 휴대폰에서 보기 좋게.
- 입력칸: [칸 이름 1], [칸 이름 2], [칸 이름 3]
- 단추: [단추 이름]
```

## 정리

오늘 기본 과정에서 윤서진 선생님은 앱 하나를 만들고, AI를 달고, 한 번 고쳤습니다. 그리고 다음 앱의 주문서 한 장을 들고 갑니다. 영상 속 선생님이 말한 "에듀테크를 고르는 사람에서 직접 푸는 사람으로"의 첫걸음은 거창한 앱이 아니라, 내 반복 업무 하나를 자판기로 바꾸는 일입니다.

주문서는 정확하게, 수정은 하나씩, 확인은 눈으로. 그리고 개인정보는 앱 밖에.
