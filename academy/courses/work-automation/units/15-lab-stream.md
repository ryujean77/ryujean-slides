# 15강. 실습 ③ 나의 줄기 문서 한 장과 원장 첫 줄

유정근 · 마이웨이 아카데미 | C3 업무 자동화
척추: 12블럭 B10

## 오늘의 목표

내 일 가운데 가장 오래 이어질 줄기(한 사업의 연속선) 하나를 골라 **줄기 문서 한 장**(헌장 · 가지와 건 · 단계표 · 결정 · 충돌 대기 · 정책)을 씁니다. 그리고 덧붙이기만 하는 <strong>원장 시트</strong>에 첫 줄을 남깁니다. 마지막으로, AI가 초안을 쓰기 전에 이 두 문서를 먼저 읽게 만드는 요청문을 완성합니다.

## 먼저 이해하기

13강은 원장의 개념을, 14강은 단계표를 다뤘습니다. 오늘은 둘을 실제 문서로 세웁니다. 오늘 쓰는 말을 다시 짚어 둡니다.

- **줄기 문서**: 한 사업의 "지금 상태 요약"입니다. 상황이 바뀌면 고쳐 씁니다. 13강의 줄기 헌장을 담는 문서입니다.
- **원장**: "무슨 일이 있었는지의 증거"입니다. 지우거나 고치지 않고 아래에 한 줄씩 더하기만 합니다. 요약이 틀어지면 원장에서 다시 만들 수 있기 때문입니다.
- **가지와 건**: 가지는 줄기 안의 대상별 갈래, 건은 가지 안의 기관별 실제 과정 하나입니다(13강).
- **완료 조건**: 다음 단계로 가려면 채워져야 할 사실입니다(14강).
- **충돌 대기**: 서로 다른 말이 부딪혀 사람의 판단을 기다리는 목록입니다. 예: 한 메모는 "3회차", 다른 메모는 "4회차".
- **정책**: AI가 어디까지 자동으로 해도 되는지, 무엇은 반드시 사람이 하는지 적은 규칙입니다.

비유하자면 배의 해도와 항해일지입니다. 해도(줄기 문서)에는 지금 배가 어디 있는지 연필로 표시하고, 위치가 바뀌면 지우고 다시 찍습니다. 항해일지(원장)에는 몇 시에 무엇을 보았고 무엇을 결정했는지를 잉크로 한 줄씩 적습니다. 해도의 표시가 의심스러우면 항해일지를 거슬러 읽어 위치를 다시 계산합니다. 항해일지를 지우고 고쳐 쓰는 선장은 없습니다.

오늘 만드는 문서는 모두 <strong>비공개 폴더</strong>에만 둡니다. 사람 이름과 약속이 들어가기 때문입니다. 비공개 폴더란 공유 설정을 하지 않아 나만 열 수 있는 드라이브 폴더입니다. 공개와 비공개의 원칙은 C2 19강에서 배운 그대로입니다.

## 강사의 시스템에서

강사의 수로(강사가 만든 원장의 이름)는 줄기 하나에 파일 두 개로 시작했습니다. 줄기 문서 하나와 원장 하나. 가지를 파일로 쪼개지 않고 줄기 문서 안의 섹션으로 두었는데, 그래야 헌장과 가지를 AI가 한 번에 읽기 때문입니다. 첫 개설은 사람 손으로 약 40분을 잡았습니다. 코드는 한 줄도 바뀌지 않았고, 이 단계를 "수동 개시"라고 불렀습니다. 자동화는 그다음이었습니다.

줄기 문서 맨 아래에는 정책 네 줄이 있습니다. `true` 는 "켬(허용)", `false` 는 "끔(금지)"이라는 뜻이고, `#` 뒤는 사람이 읽으라고 붙인 설명입니다.

```
auto_draft: true        # 초안 자동 생성
auto_plan: true         # 산출물 기획까지 자동
auto_send: false        # 대외 발송은 항상 사람
needs_human: [강의료, 일정 확정, 계약, 이력서·개인정보]
```

이 네 줄이 자동화의 경계선입니다. 초안과 기획은 AI가 앞서 가도 되지만, 대외 발송(바깥 사람에게 보내는 일)과 돈·날짜·계약·개인정보는 어느 단계에서도 자동으로 넘지 않습니다. `needs_human` 은 "사람이 꼭 봐야 하는 것" 목록입니다. 19강에서 이 정책을 더 넓게 다룹니다.

원장 한 줄은 이런 모양입니다(가상 값). 컴퓨터가 읽기 좋도록 칸 이름과 값을 따옴표와 중괄호로 짝지어 적은 형식(JSON)입니다. 수강생은 이 형식 대신 시트의 칸으로 같은 내용을 적습니다.

```
{"ts":"2026-10-02T14:02","src":"음성메모_1002.m4a","people":["담당자A"],"case":"신입 보고서 과정","summary":"회차 수 문의","decisions":[],"todos":["예산 범위 질의"]}
```

(`ts` 는 시각, `src` 는 출처 파일, `people` 은 등장 인물, `case` 는 건, `summary` 는 요약, `decisions` 는 결정, `todos` 는 할 일입니다.)

그리고 경계가 하나 있습니다. 사람 카드(한 사람에 대해 한 장씩 적는 메모)에는 상담 원문이나 개인정보를 옮기지 않고, 필요하면 "어디에 있는지"만 적습니다. 원장은 공개 포털이나 공개 저장소로 가는 동기화(두 곳의 내용을 똑같이 맞추는 자동 복사) 대상에 넣지 않습니다. 강사는 이 경계를 설계 문서의 첫머리에 적어 두었습니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다. 내 일을 쓰기 어렵다면 윤하람 씨의 "강의 의뢰" 줄기로 같은 절차를 밟습니다. PC의 크롬에서 합니다. 약 60분이 걸립니다.

### 가. 줄기 고르고 비공개 폴더 만들기

1. **줄기를 고릅니다.** 앞으로 석 달 이상 이어질 일 하나입니다. 기준은 "같은 사람·같은 목적의 연락이 두 번 이상 왔거나 올 것"입니다. 종이에 줄기 이름을 한 줄로 적습니다. 하람 씨: `강의의뢰`.
2. 크롬 주소창에 `https://drive.google.com` 을 입력해 드라이브를 엽니다. 왼쪽 목록에서 '내 드라이브'를 누릅니다.
3. 왼쪽 위의 '+ 새로 만들기' 단추를 누르고 '새 폴더'를 고릅니다. 이름 칸에 `_줄기` 라고 적고 '만들기'를 누릅니다. 이름 앞의 `_`는 7강의 `_양식`처럼 흐름 밖에서 참고하는 폴더라는 표시입니다.
4. 방금 만든 `_줄기` 폴더를 두 번 눌러 들어갑니다. 3단계와 같은 방법으로 그 안에 `강의의뢰` 폴더를 만듭니다.
   - 이렇게 보이면 됩니다: 화면 위쪽 경로에 `내 드라이브 > _줄기` 가 보이고, 그 아래에 `강의의뢰` 폴더가 있습니다.
5. **공유 설정을 확인합니다.** `강의의뢰` 폴더를 마우스 오른쪽 단추로 누르고 '공유' → '공유'를 고릅니다. 뜨는 창에서 '액세스 권한이 있는 사용자'에 나(소유자) 한 명만 있는지, '일반 액세스'가 '제한됨'인지 봅니다. 맞으면 '완료'(또는 창 닫기)를 누릅니다.
   - ✖ '링크가 있는 모든 사용자'로 되어 있으면: 그 글자를 눌러 '제한됨'으로 바꾸고 저장합니다.
6. **14강의 시트를 옮깁니다.** 왼쪽 '내 드라이브'로 돌아가 `단계표_강의의뢰` 시트를 마우스 오른쪽 단추로 누르고 '정리' → '이동'을 고릅니다. 창에서 `_줄기` → `강의의뢰` 를 차례로 누른 뒤 '이동'을 누릅니다.
   - 이렇게 보이면 됩니다: `강의의뢰` 폴더 안에 `단계표_강의의뢰` 가 있습니다.

### 나. 줄기 문서 쓰기

7. `강의의뢰` 폴더 안에서 '+ 새로 만들기' → 'Google 문서'를 누릅니다. 새 탭에 빈 문서가 열립니다. 폴더 안에서 만들었으므로 문서도 그 폴더에 저장됩니다.
8. 왼쪽 위 '제목 없는 문서'를 누르고 `stream_강의의뢰` 라고 적습니다.
9. 제목 여섯 개를 한 줄에 하나씩 적습니다: `헌장`, `가지와 건`, `단계표`, `결정 사항`, `충돌 대기`, `정책`. 한 줄씩 커서를 두고, 위쪽 도구 막대의 '일반 텍스트'라고 적힌 칸을 눌러 '제목 1'을 고르면 큰 제목이 됩니다.
   - 이렇게 보이면 됩니다: 문서 왼쪽의 개요(문서 목차) 칸에 제목 여섯 개가 나타납니다. 보이지 않으면 문서 왼쪽 위의 줄 세 개 모양(개요 표시)을 누릅니다.
10. **헌장을 네 줄로 씁니다.** `헌장` 제목 아래에: 나의 역할, 영역, 관여자(역할로만 적어도 됩니다), 공통 원칙. 예) "공통 원칙: 실습 비중 절반 이상, 참가자 실제 문서는 받지 않고 가상 문서로 연습".
11. **가지와 건을 적습니다.** 13강의 `연습_줄기지도` 를 옆 탭에 열어 두고 옮겨 적습니다. 가지는 대상, 건은 기관별 실제 과정입니다. 건마다 세 줄만: 현재 단계 / 근거(날짜·출처) / 빠진 완료 조건.
12. **단계표를 붙입니다.** `단계표` 제목 아래에 14강 시트의 링크를 넣습니다. 시트를 연 탭의 주소창을 한 번 누르면 주소 전체가 파랗게 선택됩니다. `Ctrl + C` 로 복사하고 문서에 `Ctrl + V` 로 붙여 넣으면 링크가 됩니다. 그 옆에 `정본은 이 시트` 라고 적습니다. 표를 문서에 옮겨 붙이지 않습니다. 두 곳에 같은 표가 있으면 어느 쪽이 맞는지 헷갈리기 때문입니다.
13. **결정 사항과 충돌 대기는 비워 둡니다.** 설명 한 줄씩만 씁니다. `결정 사항` 아래: `날짜 · 출처 · 누가 정했는지를 함께 적는다`. `충돌 대기` 아래: `서로 다른 말이 부딪혀 내 판단을 기다리는 것`.
14. **정책 네 줄을 씁니다.** `정책` 제목 아래에 강사의 정책 네 줄 모양대로 적습니다. 하람 씨는 이렇게 적었습니다.

```
auto_draft: true        # 초안 자동 생성
auto_plan: true         # 산출물 기획까지 자동
auto_send: false        # 대외 발송은 항상 사람
needs_human: [강의료, 일정 확정, 계약, 참가자 개인정보]
```

### 다. 사람 카드 만들기

15. 다시 드라이브의 `강의의뢰` 폴더로 가서 '+ 새로 만들기' → 'Google 문서'로 문서를 하나 더 만들고, 제목을 `사람_담당자A` 로 적습니다.
16. 칸 여섯 개를 한 줄씩 적고 채웁니다: 소속 · 관계 · 관여 줄기 · 소통 선호 · 열린 약속 · 금지 영역. 예) 금지 영역: `강의료 협의 여부는 내가 판단`. 상담 내용이나 전화번호·이메일은 옮기지 않습니다.
17. 13강에서 제미나이로 초안을 써 본 담당자 B 카드가 있다면, 같은 방법으로 `사람_담당자B` 문서를 만들어 붙여 넣어 둡니다.

### 라. 원장 시트 만들고 첫 줄 남기기

18. `강의의뢰` 폴더에서 '+ 새로 만들기' → 'Google 스프레드시트'를 누르고, 제목을 `ledger_강의의뢰` 로 적습니다.
19. 첫 행에 칸 이름을 적습니다. A1부터 `Tab` 키로 넘어가며: `시각 / 출처 / 사람 / 건 / 요약 / 결정 / 할 일 / 단계 변화`.
20. A1 칸을 마우스 오른쪽 단추로 누르고 '메모 삽입'을 고릅니다. 뜨는 노란 상자에 `고치지 않는다. 틀렸으면 아래에 정정 줄을 더한다.` 라고 적고, 상자 밖을 누릅니다.
    - 이렇게 보이면 됩니다: A1 칸 오른쪽 위 모서리에 작은 검은 삼각형이 생기고, 마우스를 올리면 메모가 보입니다.
21. **첫 줄을 남깁니다.** 최근 자료 하나(메모·메일·녹음 요약)를 골라 2행을 채웁니다. 지금까지의 사정을 알려 주는 "개설" 줄이어도 좋습니다. 하람 씨의 예:
    - 시각 `2026-10-02 14:02` / 출처 `음성메모_1002` / 사람 `담당자A` / 건 `초록물산 신입사원 보고서 과정` / 요약 `회차 수 문의` / 결정 `없음` / 할 일 `예산 범위 질의` / 단계 변화 (비움 — 이번 줄에서는 단계가 바뀌지 않았습니다)
    - 단계가 바뀐 줄에는 `제안→확정` 처럼 적습니다.

### 마. AI에게 먼저 읽히기

22. 아래 "AI에게 건네는 말"의 첫 번째 요청문으로 새 자료 하나를 처리해 봅니다. 초안 맨 위에 건 · 단계 판정 · 새로 생긴 것 · 부딪히는 것 네 칸이 나왔는지 확인합니다. 나오지 않았다면 요청문을 고쳐 다시 보냅니다.
23. 초안이 `단계 제안` 을 했더라도, 내가 승인하기 전에는 원장에 적지 않습니다. 승인했다면 원장 시트 맨 아래 빈 줄에 새 줄을 더하고, 단계 변화 칸에 전이를 적습니다.

## AI에게 건네는 말

두 요청 모두 제미나이 웹에서 합니다. 문서의 내용은 복사해서 붙여 넣습니다. 문서 전체를 복사하려면, 그 문서 안을 한 번 누르고 `Ctrl + A` (모두 선택) → `Ctrl + C` 를 누릅니다. 원장은 마지막 5줄만 행 번호를 끌어 선택해 복사합니다.

> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

보낼 글 (첫 번째 요청): 네 개의 `[ … ]` 자리에 각각 해당 내용을 붙여 넣은 뒤 보냅니다. 붙여 넣는 동안 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다.

> 초안을 쓰기 전에 아래 세 문서를 먼저 읽어 줘. 줄기 문서: [stream_강의의뢰 내용] / 사람 카드: [사람_담당자A 내용] / 원장의 마지막 5줄: [ledger_강의의뢰 마지막 5줄]. 그다음 새 자료를 처리해: [새 자료]. 초안 맨 위에는 반드시 네 칸을 먼저 써 줘: ① 해당 건 ② 단계 판정(유지 또는 `단계 제안: 현재 → 다음`) ③ 이번에 새로 생긴 것 ④ 기존 결정과 부딪히는 것. 부딪히는 것은 판정하지 말고 드러내기만 해. 정책의 `needs_human`에 걸리는 내용은 결정처럼 쓰지 말고 "사람 확인 필요"로 표시해.

답을 읽는 법: 답의 맨 위 네 칸부터 봅니다. ②에 단계 제안이 있으면 그 근거가 새 자료의 어느 문장인지 찾아봅니다. 강의료나 날짜를 "정해졌다"고 쓴 곳이 있으면 "사람 확인 필요로 바꿔 줘"라고 이어서 보냅니다.

보낼 글 (두 번째 요청): 같은 대화 입력칸에 이어서 보냅니다. 문서를 다시 붙여 넣지 않아도 됩니다.

> 앞에서 준 줄기 문서와 사람 카드에서, 공개되면 안 되는 정보(실명·연락처·금액·상담 내용)가 들어간 줄을 찾아 줘. 지우지는 말고 줄 위치만 알려 줘.

답을 읽는 법: 짚은 줄을 내가 문서에서 찾아 직접 고칩니다. "없음"이라는 답이 나와도, 사람 카드의 '열린 약속' 줄은 한 번 더 눈으로 봅니다.
