# 3강. 흐름도 한 장 — 입력·처리·결재·출력·기록

유정근 · 마이웨이 아카데미 | C3 업무 자동화
척추: 12블럭 B10

## 오늘의 목표

1강의 자동화를 **입력 → 처리 → 결재 → 출력 → 기록** 다섯 칸짜리 <strong>흐름도</strong>(일이 어디서 들어와 어디로 나가는지 칸과 화살표로 그린 그림) 한 장으로 그리고, "승인하면 정확히 무엇이 일어나는가"에 답할 수 있게 합니다. 종이와 펜, 또는 구글 문서의 표로 그립니다.

## 먼저 이해하기

자동화가 무서운 이유는 대개 속이 보이지 않기 때문입니다. 흐름도는 그 속을 한 장에 펼쳐 놓는 일입니다. 다섯 칸이면 충분합니다.

- **입력**: 무엇이, 어디로 들어오는가 (예: 음성 메모가 드라이브 인박스 폴더로)
- **처리**: 누가 무엇을 만드는가 (예: AI가 진행 메모 초안을)
- **결재**: 어디서 사람이 멈추는가 (2강의 멈춤 지점)
- **출력**: 승인하면 무엇이 생기는가 (파일, 일정, 할 일, 알림)
- **기록**: 무엇이 언제 누구 판단으로 지나갔는지 어디에 남는가

앞의 네 칸은 누구나 그립니다. 다섯 번째 칸이 빠지기 쉽습니다. 기록이 없으면 자동화가 한 달 뒤에 무엇을 했는지 아무도 설명하지 못합니다. 실패를 고칠 수도, 잘 된 것을 잴 수도 없습니다.

비유하자면 택배 송장입니다. 물건이 접수되고, 분류되고, 배송 기사가 서명을 받고, 문 앞에 놓입니다. 그리고 그 모든 순간이 조회 화면에 한 줄씩 남습니다. 물건이 사라졌을 때 우리가 찾아가는 곳은 창고가 아니라 그 기록입니다.

## 강사의 시스템에서

강사의 통화 자동화는 드라이브 안의 번호 붙은 폴더 다섯 개로 흐름이 보입니다. 01 인박스(녹취 원문) → 02 기획 초안 → 03 결재 완료 → 04 최종 <strong>산출물</strong>(밖에 내놓는 완성 결과물) → 05 웹 문서. 파일이 어느 폴더에 있는지만 보면 그 일이 어디까지 왔는지 압니다. 실사 때 숫자는 인박스 62건, 초안 40건, 결재 완료 17건이었습니다. 흐름도가 있었기에 <strong>병목</strong>(일이 좁은 목에 걸려 쌓이는 곳)<strong>이 03번 관문 하나라는</strong> 진단이 한눈에 나왔습니다.

흐름도는 안전 점검에도 쓰였습니다. 대리 결재를 하기 전에 가장 먼저 확인한 질문은 "승인하면 통화 내용이 공개되는가"였습니다. 승인 경로를 끝까지 따라가 출력 칸을 모두 적었습니다. 최종 문서 생성, 초안을 결재 완료 폴더로 이동, 웹 문서 생성, 내부 목록에 등록, 캘린더·할 일 등록, 결재 <strong>스레드</strong>(메신저에서 한 주제의 글과 답글이 이어진 묶음) 회신. 여섯 가지 모두 비공개 영역 안이었습니다. 이름에 "Published"가 붙은 폴더도 실제로는 외부 배포가 아니었습니다. 공개 배포는 사람이 별도로 실행할 때만, 그것도 차단 장치를 통과해야만 일어났습니다. <strong>출력 칸을 빠짐없이 적어 보는 것이</strong> 곧 안전 점검이었습니다.

기록 칸에는 결재 상태를 적는 <strong>원장</strong>(일의 상태를 한 줄씩 적어 두는 기준 장부)과, 덧붙이기만 하는 <strong>감사 기록</strong>(나중에 되짚어 보려고 남기는, 지우거나 고치지 않는 기록)이 있습니다. 한 번 적힌 줄은 고치지 않고 아래에 새 줄을 더합니다. 그래서 무엇이 언제 누구 판단으로 지나갔는지 되짚을 수 있습니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다. 폴더 이름은 5강에서 실제로 만들 이름을 미리 씁니다. 오늘은 그리기만 하고 폴더는 만들지 않습니다.

**준비 — 다섯 칸 그리기**

1. A4 종이 한 장을 가로로 놓고, 왼쪽부터 네모 다섯 개를 그린 뒤 위에 입력 / 처리 / 결재 / 출력 / 기록이라고 씁니다.
   구글 문서로 하려면: `C3_자동화후보표` 문서 맨 아래를 누르고, 위쪽 메뉴 '삽입' → '표' 에 포인터를 올린 뒤 가로 5칸 × 세로 2칸이 파랗게 칠해질 때 누릅니다. 첫 줄에 다섯 칸 이름을 적습니다.
   → 이렇게 보이면 됩니다: 이름이 적힌 빈칸 다섯 개가 한 줄로 놓여 있습니다.

**칸 채우기**

2. 입력 칸. 윤하람 씨는 이렇게 씁니다. "수업 직후 휴대폰 받아쓰기로 남긴 메모 → 구글 드라이브 `C3_자동화` 폴더 안의 `00_inbox` 폴더." C2 8강에서 내 PC의 표준 폴더에 두었던 인박스를, 휴대폰에서도 넣을 수 있도록 드라이브(인터넷에 있는 구글의 저장 공간)에 하나 더 두는 것입니다.
3. 처리 칸. "AI가 메모를 읽고 진행 메모 초안을 만들어 `01_draft` 폴더에 넣는다. 원본 메모는 그대로 둔다."
4. 결재 칸. 2강의 멈춤 지점표에서 ■·▲ 줄을 옮겨 적습니다. "초안을 읽고 승인·수정·보류 중 하나를 고른다. 판단 기준: 날짜와 준비물이 원문과 맞는가."
5. 출력 칸. 승인했을 때 생기는 것을 <strong>하나도 빼지 않고</strong> 씁니다. "진행 메모를 `02_approved` 폴더로 옮김, 다음 수업 준비물을 할 일에 등록."
6. 출력 칸을 다시 읽으며, 2강의 "본인만" 목록에 걸리는 것이 있는지 봅니다. 윤하람 씨는 처음에 "수강생 요약 발송"도 적었다가 지웠습니다. 그것은 2강에서 "본인만"으로 정한 일이기 때문입니다.
   ✖ 출력 칸에 발송·공유·공개가 남아 있다면: 그 줄을 지우고 결재 칸 옆에 "이건 내가 직접"이라고 적습니다.
7. 기록 칸. "구글 시트 한 장에 한 줄씩 — 날짜, 원본 파일 이름, 초안 파일 이름, 판단(승인·수정·보류), 한 줄 사유." (시트는 9강에서 만듭니다.)

**화살표와 점검**

8. 네모와 네모 사이에 오른쪽 화살표를 그립니다. 구글 문서 표라면 칸 사이에 `→` 를 적습니다.
9. 결재 칸에서 처리 칸으로 되돌아가는 화살표를 하나 그리고 "수정"이라고 씁니다. 결재 칸 아래에는 제자리에 머무는 동그란 화살표를 그리고 "보류 — 이유와 다시 볼 조건을 적는다"라고 씁니다.
   → 이렇게 보이면 됩니다: 앞으로 가는 화살표 네 개와, 결재 칸에서 뒤로 가는 화살표 하나, 제자리 화살표 하나가 있습니다.
10. 완성한 흐름도를 보며 스스로 묻습니다. "승인 버튼을 누르면 정확히 무엇이 일어나는가?" 출력 칸만 읽고 답이 나오면 됩니다.
11. 흐름도를 휴대폰으로 사진 찍어 두거나, 구글 문서라면 표 전체를 끌어 선택해 `Ctrl + C` 로 복사해 둡니다. 아래 요청문의 재료입니다.

## AI에게 건네는 말

> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

종이에 그렸다면 흐름도 사진을 '+' 버튼으로 올리고, 구글 문서에서 복사했다면 글 아래에 붙여 넣은 뒤 보냅니다.

> 아래는 내 자동화를 설명한 글이다. 이것을 '입력 / 처리 / 결재 / 출력 / 기록' 다섯 칸 표로 정리해 줘. 내가 적지 않은 단계를 네가 채워 넣지 말고, 빠진 것 같은 칸에는 '확인 필요'라고만 써 줘. 특히 출력 칸에 밖으로 나가는 행동(발송·공유·공개)이 있으면 굵게 표시해 줘.

답을 읽는 법: 표에서 굵은 글씨가 있는지부터 봅니다. 있으면 6번으로 돌아가 그 줄을 결재 칸의 "내가 직접"으로 옮깁니다. '확인 필요' 칸은 내 흐름도에도 같은 말을 적어 둡니다.

그림으로도 보고 싶을 때 — 같은 대화창에서 이어서 보냅니다.

> 이 흐름도를 머메이드(mermaid) 흐름도 코드로 바꿔 줘. 결재 칸은 다른 모양으로 그리고, '수정'과 '보류'의 되돌이 화살표를 넣어 줘.

답을 읽는 법: <strong>머메이드</strong>는 글자 몇 줄로 흐름도를 그리는 표기법입니다. 답에 `flowchart` 로 시작하는 회색 코드 상자가 나오면, 상자 안 글을 모두 끌어 선택해 복사합니다. 새 탭(`Ctrl + T`)의 주소창에 `https://mermaid.live` 를 입력해 들어가, 화면 왼쪽의 코드 칸 내용을 모두 지우고(`Ctrl + A` 후 `Delete`) 붙여 넣습니다. 오른쪽에 네모와 화살표 그림이 나타나면 성공입니다. 그림이 안 나오고 빨간 오류 글자가 보이면, 그 글자를 복사해 제미나이에 "이 오류를 고친 코드로 다시 줘" 라고 보냅니다.

## 손에 남길 것과 완료 확인

**흐름도 한 장** (종이 사진 또는 구글 문서의 표)

- [ ] 다섯 칸이 모두 채워져 있다
- [ ] 결재 칸에 판단 기준이 한 줄 있다
- [ ] "수정"과 "보류"의 되돌이 화살표가 있다
- [ ] 출력 칸에 발송·공유·공개가 없다 (있다면 "내가 직접"으로 옮겼다)
- [ ] 출력 칸만 읽고 "승인하면 무엇이 일어나는가"에 답할 수 있다

기록 칸이 "나중에"로 비어 있으면 완료가 아닙니다. 시트 한 장, 문서 한 장이라도 위치를 정해 적습니다. 이 흐름도는 4강 설계서의 한가운데에 들어갑니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)
