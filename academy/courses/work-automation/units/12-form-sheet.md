# 12강. 설문지 → 시트 → 알림 — 앱스 스크립트를 AGY에게 맡기기

유정근 · 마이웨이 아카데미 | C3 업무 자동화

척추: 12블럭 B10

## 오늘의 목표

구글 설문지 응답이 시트에 쌓이면, 앱스 스크립트가 새 응답 한 줄을 읽어 나에게 요약 알림 메일을 보내는 흐름을 만듭니다. 코드는 AGY가 쓰고, 사람은 코드를 읽고 권한을 승인하고 결과를 확인합니다.

## 먼저 이해하기

앱스 스크립트(Apps Script)는 구글 문서·시트·설문지·Gmail·캘린더 안에서 도는 작은 프로그램입니다. 따로 서버를 두지 않아도 되고, 시트 메뉴의 [확장 프로그램] → [Apps Script]에서 바로 열립니다. 이 스크립트를 스스로 움직이게 하는 것이 **트리거입니다**. 설치형 트리거에는 "양식 제출 시"처럼 사건이 일어나면 도는 것과, "매일 오전 9시대"처럼 시간이 되면 도는 것이 있습니다. 편집기 왼쪽의 시계 모양 [트리거] 메뉴에서 만듭니다. 트리거는 우체국의 자동 분류기와 같습니다. 편지가 들어오면(양식 제출) 기계가 움직이지만, 어느 칸으로 보낼지는 사람이 미리 정해 둔 규칙대로만 움직입니다. 그래서 규칙, 곧 코드를 사람이 읽고 승인하는 단계를 건너뛰지 않습니다.

알아 둘 사실 몇 가지는 공식 문서로 확인했습니다.

- 설치형 트리거는 **그것을 만든 사람의 계정으로** 실행됩니다. 설문지를 누가 제출하든, 메일은 트리거를 만든 내 계정에서 나갑니다.
- 시트에 걸린 "양식 제출 시" 트리거는 제출된 응답을 질문 이름과 값의 묶음(`namedValues`)으로 넘겨줍니다.
- 시간 기반 트리거는 정확한 분에 돌지 않습니다. "오전 9시"로 정하면 9시부터 10시 사이 어느 시각이 정해져 매일 그 무렵에 돕니다.
- 5강에서 본 대로, 드라이브 폴더에 "파일이 들어오면" 도는 트리거는 없어 시간 기반 트리거로 주기적으로 확인합니다.
- 일반 구글 계정(gmail.com)의 하루 한도는 메일 수신자 100명, 트리거 실행 시간 합계 90분이고, 한 번 실행은 6분까지입니다. 한도는 예고 없이 바뀔 수 있으니 운영 전에 공식 한도 페이지를 다시 확인합니다.

## 강사의 시스템에서

강사는 한 협동조합 아카데미의 2회기 여섯 시간을 이 흐름 하나로 구성했습니다. 설문지 → 응답 시트 → 앱스 스크립트 → AI 요약 → Gmail 보고의 4단계입니다. 돌봄 일지 접수 폼이 제출되면 스크립트가 마지막 행을 읽고, AI가 요약과 이상 징후를 뽑고, 담당자에게 HTML 보고 메일을 보냅니다. 수강생은 코드를 직접 타이핑하지 않고, AI에게 역할을 주어 코드를 받고, 실행 기록(로그)을 보며 고쳤습니다.

현장에서 자주 막힌 곳은 늘 같았습니다.

1. **API 키를 코드에 그대로 붙여 넣는 일.** 키는 스크립트 속성(Properties)에 저장하고 코드에서는 이름으로만 불러야 합니다. 코드를 공유하는 순간 키도 같이 공유되기 때문입니다.
2. **처음 실행할 때 뜨는 권한 확인 창.** 내 계정이 내 스크립트에 메일 발송·시트 읽기 권한을 주는 단계입니다. 누가 만든 어떤 코드인지 내가 읽었을 때만 허용합니다.
3. **사용 한도 초과(429 오류).** 무료 한도를 넘으면 AI 호출이 거절됩니다. 강사의 음성 파이프라인에서도 같은 일이 있었고, 하루 처리 가능한 건수가 한도에 묶였습니다.
4. **트리거 중복.** 테스트하며 트리거를 두 번 만들면 응답 하나에 메일이 두 통 갑니다. 트리거 목록을 열어 하나만 남깁니다.
5. **메일이 스팸함으로 가는 일.** 받는 사람 쪽에서 확인해야 드러납니다.

오늘 수강생 실습은 AI 요약을 빼고 시작합니다. 응답을 그대로 정리해 나에게만 알리는 데까지가 첫 바퀴입니다. AI 요약과 외부 발송은 흐름이 안정된 뒤에 붙입니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다.

1. 윤하람 씨는 강의 신청 설문지를 만듭니다. 질문은 네 개입니다. `이름`, `소속`, `희망 날짜`, `하고 싶은 말`.
2. 설문지의 [응답] 탭에서 스프레드시트 연결 기능으로 새 응답 시트를 만듭니다.
3. 본인이 테스트 응답 한 건을 제출하고, 시트에 한 줄이 들어온 것을 확인합니다. 첫 열에 타임스탬프가 붙어 있습니다.
4. 시트에서 [확장 프로그램] → [Apps Script]를 열어 빈 편집기를 띄웁니다. 아직 코드를 쓰지 않습니다.
5. AGY에게 아래 첫 번째 요청을 보내 코드를 받습니다. 받는 사람은 반드시 나 자신으로 고정합니다.
6. 코드를 붙여 넣기 전에 AGY에게 두 번째 요청을 보내, 코드가 하는 일을 한 줄씩 설명받습니다. 설명에 "응답자에게 메일을 보낸다"나 "다른 파일을 지운다"가 있으면 붙여 넣지 않습니다.
7. 코드를 편집기에 붙여 넣고 저장한 뒤, 트리거 함수 대신 테스트용 함수를 한 번 실행합니다. 권한 확인 창이 뜨면 내 계정인지, 요청하는 권한이 시트 읽기와 메일 보내기뿐인지 확인하고 허용합니다.
8. 왼쪽 [트리거] 메뉴에서 [트리거 추가]를 누르고, 실행할 함수, 이벤트 소스 "스프레드시트에서", 이벤트 유형 "양식 제출 시"를 골라 저장합니다.
9. 설문지에 두 번째 테스트 응답을 제출하고, 내 메일함에 요약 알림이 한 통만 왔는지 확인합니다. 두 통이 왔다면 트리거 목록에서 중복을 지웁니다.
10. 편집기의 [실행] 기록에서 방금 실행이 성공했는지, 몇 초 걸렸는지 봅니다. 실패했다면 오류 문구를 그대로 복사해 AGY에게 보여 줍니다.
11. 결재판(9강)에 이 자동화 한 줄을 올립니다. 9강처럼 순번이 아닌 ID로 적습니다. "S-0929-신청알림 · 신청 알림 스크립트 · 받는 사람 나 · 트리거 양식 제출 시 · 승인". 응답자에게 자동 회신을 붙이는 일은 이 줄을 다시 결재한 뒤에 합니다.

## AI에게 건네는 말

> 구글 시트에 연결된 설문지 응답(열: 타임스탬프, 이름, 소속, 희망 날짜, 하고 싶은 말)이 들어오면, 새 응답 한 줄을 정리해 [내 이메일]로만 알림 메일을 보내는 Apps Script 코드를 써 줘. 시트의 '양식 제출 시' 설치형 트리거에 연결할 함수와, 트리거 없이 마지막 행으로 시험할 테스트 함수를 따로 만들어 줘. 응답자에게는 메일을 보내지 말고, 시트의 기존 데이터를 고치거나 지우지 마. 비밀 값이 필요하면 코드에 쓰지 말고 스크립트 속성에서 읽게 해 줘.

> 방금 준 코드가 하는 일을 사람이 읽을 수 있게 한 줄씩 설명해 줘. 특히 ① 어떤 권한이 필요한지 ② 메일이 누구에게 가는지 ③ 같은 응답에 메일이 두 번 갈 수 있는 경우가 있는지 따로 적어 줘.

## 손에 남길 것과 완료 확인

**움직이는 흐름 1개: 설문지 → 시트 → 나에게 알림**

- [ ] 설문지 응답이 시트에 쌓인다
- [ ] 테스트 함수로 한 번, 실제 제출로 한 번, 알림 메일이 나에게만 왔다
- [ ] 트리거 목록에 "양식 제출 시" 트리거가 하나만 있다
- [ ] 코드에 API 키·비밀번호가 없다
- [ ] 코드 설명을 읽고 승인한 기록이 결재판에 있다

모두 체크되면 완료입니다.
