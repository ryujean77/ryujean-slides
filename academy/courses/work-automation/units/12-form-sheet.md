# 12강. 설문지 → 시트 → 알림 — 앱스 스크립트를 AGY에게 맡기기

유정근 · 마이웨이 아카데미 | C3 업무 자동화

척추: 12블럭 B10

## 오늘의 목표

구글 설문지 응답이 시트에 쌓이면, 앱스 스크립트가 새 응답 한 줄을 읽어 나에게 요약 알림 메일을 보내는 흐름을 만듭니다. 코드는 AGY가 쓰고, 사람은 코드를 읽고, 권한을 승인하고, 결과를 확인합니다.

## 먼저 이해하기

오늘은 구글 서비스 세 개와 AGY를 잇습니다. 나오는 말부터 풀어 둡니다.

- **구글 설문지(Google Forms)**: 질문을 만들어 링크로 나눠 주고 답을 받는 도구입니다.
- **설문지·시트 연결**: 설문지에 들어온 응답이 구글 시트(칸으로 나뉜 온라인 계산 표)에 한 줄씩 자동으로 쌓이게 이어 두는 설정입니다. 응답 한 건이 시트의 한 행(가로 한 줄)이 되고, 맨 앞 칸에는 제출 시각(타임스탬프)이 자동으로 붙습니다.
- **앱스 스크립트(Apps Script)**: 구글 문서·시트·설문지·Gmail·캘린더 안에서 도는 작은 프로그램입니다. 따로 서버(인터넷 너머에서 늘 켜져 있는 컴퓨터)를 빌리지 않아도 구글의 컴퓨터에서 돌아갑니다. 시트 위쪽 메뉴의 '확장 프로그램' → 'Apps Script'에서 엽니다.
- **함수**: 코드 안에서 이름을 붙여 둔 일 묶음입니다. 예를 들어 `sendTest` 라는 함수는 "마지막 줄을 읽어 메일 한 통 보내기"라는 일 하나를 뜻합니다. 편집기에서 함수 이름을 골라 실행합니다.
- **트리거**: 정해진 때가 되면 함수를 자동으로 실행되게 하는 설정입니다. 오늘 쓰는 것은 설치형 트리거(내가 편집기에서 직접 만들어 켜는 트리거)로, "양식 제출 시"처럼 사건이 일어나면 도는 것과 "매일 오전 9시대"처럼 시간이 되면 도는 것이 있습니다.
- **권한 승인**: 스크립트가 내 계정으로 시트를 읽고 메일을 보내도 된다고 허락하는 절차입니다. 처음 실행할 때 한 번 창이 뜹니다.
- **실행 로그**: 스크립트가 돌 때마다 언제 시작해서 어떻게 끝났는지(성공·실패, 오류 문구)를 적어 두는 기록입니다.

트리거는 우체국의 자동 분류기와 같습니다. 편지가 들어오면(양식 제출) 기계가 움직이지만, 어느 칸으로 보낼지는 사람이 미리 정해 둔 규칙대로만 움직입니다. 그래서 규칙, 곧 코드를 사람이 읽고 승인하는 단계를 건너뛰지 않습니다.

알아 둘 사실 몇 가지는 공식 문서(developers.google.com/apps-script)로 확인했습니다.

- 설치형 트리거는 **그것을 만든 사람의 계정으로** 실행됩니다. 설문지를 누가 제출하든, 메일은 트리거를 만든 내 계정에서 나갑니다.
- 시트에 걸린 "양식 제출 시" 트리거는 제출된 응답을 질문 이름과 값의 묶음(`namedValues`)으로 함수에 넘겨줍니다. "이름: 박○○, 소속: ○○" 같은 짝입니다.
- 트리거가 실패하면 구글이 실패 요약 메일을 보내 줍니다. 트리거를 만들 때 이 알림을 얼마나 자주 받을지 고릅니다.
- 편집기의 실행 로그는 개발하는 동안 보는 가벼운 기록이라 오래 남지 않습니다. 오래 남겨야 할 기록은 18강에서 시트에 따로 적습니다.
- 시간 기반 트리거는 정확한 분에 돌지 않습니다. "오전 9시대"로 정하면 9시부터 10시 사이 어느 시각에 돕니다.
- 5강에서 본 대로, 드라이브 폴더에 "파일이 들어오면" 도는 트리거는 없어 시간 기반 트리거로 주기적으로 확인합니다.
- 일반 구글 계정(gmail.com)의 하루 한도는 메일 수신자 100명, 트리거 실행 시간 합계 90분이고, 한 번 실행은 6분까지입니다. 한도는 바뀔 수 있으니 운영 전에 공식 한도 페이지(`https://developers.google.com/apps-script/guides/services/quotas`)를 다시 확인합니다.

## 강사의 시스템에서

강사는 한 협동조합 아카데미의 2회기 여섯 시간을 이 흐름 하나로 구성했습니다. 설문지 → 응답 시트 → 앱스 스크립트 → AI 요약 → Gmail 보고의 4단계입니다. 돌봄 일지 접수 설문지가 제출되면 스크립트가 시트의 마지막 행을 읽고, AI가 요약과 이상 징후를 뽑고, 담당자에게 HTML 보고 메일(글자 크기·색·표를 넣어 꾸민 메일)을 보냅니다. 수강생은 코드를 직접 타이핑하지 않고, AI에게 역할을 주어 코드를 받고, 실행 로그를 보며 고쳤습니다.

현장에서 자주 막힌 곳은 늘 같았습니다.

1. **API 키를 코드에 그대로 붙여 넣는 일.** API 키는 유료 AI 서비스 같은 외부 서비스를 쓸 수 있게 해 주는 비밀 열쇠 글자입니다. 키는 스크립트 속성(프로젝트 설정 화면에 따로 보관하는 비밀 값 칸)에 저장하고, 코드에서는 이름으로만 불러야 합니다. 코드를 공유하는 순간 키도 같이 공유되기 때문입니다.
2. **처음 실행할 때 뜨는 권한 확인 창.** 내 계정이 내 스크립트에 메일 발송·시트 읽기 권한을 주는 단계입니다. 누가 만든 어떤 코드인지 내가 읽었을 때만 허용합니다.
3. **사용 한도 초과(429 오류).** 429는 "요청이 너무 많다"는 뜻의 오류 번호입니다. 무료 한도를 넘으면 AI 호출이 거절됩니다. 강사의 음성 파이프라인에서도 같은 일이 있었고, 하루 처리 가능한 건수가 한도에 묶였습니다.
4. **트리거 중복.** 시험하면서 트리거를 두 번 만들면 응답 하나에 메일이 두 통 갑니다. 트리거 목록을 열어 하나만 남깁니다.
5. **메일이 스팸함으로 가는 일.** 받는 사람 쪽에서 확인해야 드러납니다.

오늘 수강생 실습은 AI 요약을 빼고 시작합니다. 응답을 그대로 정리해 나에게만 알리는 데까지가 첫 바퀴입니다. AI 요약과 외부 발송은 흐름이 안정된 뒤에 붙입니다.

## 가상 예시로 직접 해 보기

아래 인물·자료·기관은 학습용 가상 설정입니다. PC의 크롬에서, 구글 계정에 로그인한 상태로 합니다. 전체 약 60분이 걸립니다.

### 가. 설문지 만들기 (약 10분)

1. 크롬 주소창에 `https://forms.google.com` 을 입력해 들어갑니다.
   - 이렇게 보이면 됩니다: 위쪽에 '새 양식 시작하기' 줄이 있고, 그 안에 '+' 가 그려진 '빈 양식' 칸이 보입니다.
2. '빈 양식'을 누릅니다.
   - 이렇게 보이면 됩니다: 맨 위에 '제목 없는 설문지'라고 적힌 새 설문지 편집 화면이 열립니다.
3. '제목 없는 설문지' 글자를 누르고 지운 뒤 `강의 신청 (연습)` 이라고 입력합니다.
4. 아래 첫 질문 상자에서 '제목없는 질문' 글자를 누르고 `이름` 이라고 입력합니다.
5. 그 질문 상자 오른쪽의 질문 유형 칸(처음에는 '객관식 질문')을 누르고 '단답형'을 고릅니다.
6. 화면 오른쪽에 세로로 떠 있는 작은 도구 막대에서 동그라미 안의 '+' 모양(질문 추가)을 누릅니다. 새 질문 상자가 생기면 `소속` 이라고 적고 유형을 '단답형'으로 바꿉니다.
7. 같은 방법으로 `희망 날짜`(단답형), `하고 싶은 말`('장문형')을 더합니다.
   - 이렇게 보이면 됩니다: 질문 상자 네 개가 이름 → 소속 → 희망 날짜 → 하고 싶은 말 순서로 있습니다. 설문지는 자동 저장됩니다.

### 나. 설문지를 시트에 연결하기 (약 5분)

8. 설문지 편집 화면 위쪽 가운데의 '응답' 탭을 누릅니다. 그 아래 '요약'이 선택돼 있는지 봅니다.
9. 응답 화면 오른쪽 위의 점 세 개(더보기)를 누르고 '응답 저장 위치 선택'을 누릅니다.
10. 나타난 창에서 '새 스프레드시트 만들기'가 골라져 있는지 확인하고 '만들기'를 누릅니다.
    - 이렇게 보이면 됩니다: 새 탭에 구글 시트가 열립니다. 첫 행에 `타임스탬프 / 이름 / 소속 / 희망 날짜 / 하고 싶은 말` 이 칸 이름으로 들어가 있고, 아래쪽 시트 탭 이름은 '설문지 응답 시트1'입니다.
    - ✖ '응답 저장 위치 선택'이 보이지 않으면: 응답 탭에 있는 초록색 시트 모양 단추('Sheets에 연결' 또는 'Sheets에서 보기')를 눌러도 같은 창이 뜹니다.
11. 이 시트 탭은 그대로 열어 둡니다. 나중에 여기서 앱스 스크립트를 엽니다.

### 다. 게시하고 테스트 응답 넣기 (약 5분)

12. 설문지 탭으로 돌아가 오른쪽 위의 '게시'를 누르고, 뜨는 창에서 다시 '게시'를 누릅니다.
    - 이렇게 보이면 됩니다: 오른쪽 위 단추가 '게시됨'으로 바뀝니다. 게시해야 응답을 받을 수 있습니다.
13. '게시됨'을 누르고 '응답자 링크 복사'를 누릅니다.
14. 크롬에서 새 탭을 열고(`Ctrl + T`) 주소창에 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누릅니다. 응답자가 보는 설문지 화면이 열립니다.
15. 가짜 값으로 채웁니다. 이름 `테스트1`, 소속 `연습`, 희망 날짜 `10월 중`, 하고 싶은 말 `첫 시험 응답입니다`. 맨 아래 '제출'을 누릅니다.
16. 시트 탭으로 가서 2행에 방금 응답이 들어왔는지 봅니다.
    - 이렇게 보이면 됩니다: A2 칸에 제출 시각, B2 칸부터 테스트1 · 연습 · 10월 중 · 첫 시험 응답입니다가 보입니다.

### 라. 앱스 스크립트 편집기 열기 (약 3분)

17. 시트 탭 위쪽 메뉴에서 '확장 프로그램'을 누르고 'Apps Script'를 누릅니다.
    - 이렇게 보이면 됩니다: 새 탭에 앱스 스크립트 편집기가 열립니다. 왼쪽 위에 '제목 없는 프로젝트', 가운데 코드 칸에 `function myFunction() {` 로 시작하는 몇 줄이 있습니다.
18. 편집기 화면을 한 번 둘러봅니다.
    - 맨 왼쪽의 세로 아이콘 줄: 위에서부터 '개요'(i 모양), '편집기'(< > 모양), '트리거'(알람 시계 모양), '실행'(줄 세 개에 재생 표시가 붙은 목록 모양), '프로젝트 설정'(톱니바퀴 모양)입니다. 아이콘 위에 마우스를 올리면 이름이 나옵니다.
    - 코드 칸 바로 위 도구 줄: 디스크 모양(프로젝트 저장), '▷ 실행', '디버그', 그리고 실행할 함수 이름이 적힌 칸, 오른쪽 끝의 '실행 로그'가 있습니다.
19. 왼쪽 위 '제목 없는 프로젝트'를 누르고 `신청알림_v01` 이라고 적은 뒤 '이름 바꾸기'를 누릅니다. 아직 코드는 건드리지 않습니다. 이 탭도 열어 둡니다.

### 마. AGY에게 코드 받기 (약 10분)

20. AGY를 열고 아래 "AI에게 건네는 말"의 첫 번째 요청을 보냅니다. 받는 사람은 반드시 나 자신으로 고정되게 되어 있습니다.
21. AGY가 계획을 보여 주면, 그 안에 "작업 폴더에 `신청알림_v01.gs` 파일을 만든다" 한 가지만 있는지 봅니다. 다른 파일을 지우거나 옮기는 단계가 있으면 승인하지 말고 "파일 하나만 만들어 줘"라고 답합니다.
22. 파일이 만들어지면 곧바로 두 번째 요청을 보내, 코드가 하는 일을 한 줄씩 설명받습니다.
23. 설명을 읽습니다. 다음 중 하나라도 있으면 붙여 넣지 않고 AGY에게 고쳐 달라고 합니다.
    - "응답자에게 메일을 보낸다"
    - "시트의 값을 고치거나 지운다"
    - 필요한 권한에 시트 읽기·메일 보내기 말고 다른 것(드라이브 전체, 캘린더 등)이 있다
    - 받는 사람 주소가 코드 안에 글자로 적혀 있다

### 바. 코드를 편집기에 붙여 넣고 저장하기 (약 5분)

24. 윈도우 작업 표시줄의 노란 폴더 모양(파일 탐색기)을 눌러, AGY 작업 폴더 안의 `신청알림_v01.gs` 파일을 찾습니다.
25. 그 파일을 마우스 오른쪽 단추로 누르고 '연결 프로그램' → '메모장'을 고릅니다.
    - 이렇게 보이면 됩니다: 메모장에 `function` 으로 시작하는 코드가 열립니다.
26. 메모장 안을 한 번 누르고 `Ctrl + A`(모두 선택) → `Ctrl + C`(복사)를 누릅니다. 메모장은 저장하지 않고 닫습니다.
27. 앱스 스크립트 편집기 탭으로 돌아가 코드 칸 안을 한 번 누르고, `Ctrl + A` 로 원래 있던 `myFunction` 몇 줄을 모두 선택한 뒤 `Ctrl + V` 로 붙여 넣습니다.
28. 도구 줄의 디스크 모양(프로젝트 저장)을 누르거나 `Ctrl + S` 를 누릅니다.
    - 이렇게 보이면 됩니다: 도구 줄의 함수 이름 칸을 눌렀을 때 AGY가 알려 준 함수 이름 두 개가 목록에 나타납니다.
    - ✖ 저장할 때 빨간 오류 문구가 뜨면: 문구를 그대로 복사해 AGY에게 "앱스 스크립트 저장 중 이 오류가 났어"라고 보냅니다. 붙여 넣을 때 앞뒤가 잘린 경우가 많습니다.

### 사. 테스트 함수를 한 번 실행하고 권한 승인하기 (약 7분)

29. 도구 줄의 함수 이름 칸을 누르고, 테스트용 함수(예: `sendTestForLastRow` — AGY가 붙인 이름을 씁니다)를 고릅니다. 트리거용 함수는 지금 고르지 않습니다. 트리거용 함수는 설문지 제출 정보를 받아야 해서, 손으로 실행하면 오류가 납니다.
30. '▷ 실행'을 누릅니다. 처음이면 '승인 필요'라는 창이 뜹니다. 여기서부터가 권한 승인입니다.
31. 창의 '권한 검토'를 누릅니다.
32. 새 창에 구글 계정 목록이 나오면, 이 시트를 만든 내 계정을 누릅니다.
33. "Google에서 확인하지 않은 앱"이라는 경고 화면이 나올 수 있습니다. 내가 직접 만든 스크립트는 구글의 심사를 받지 않았으므로 이 경고가 뜨는 것이 정상입니다. 왼쪽 아래의 '고급'을 누르고, 아래에 나타나는 '신청알림_v01(으)로 이동(안전하지 않음)'을 누릅니다.
    - 이 단계는 **내가 23단계에서 코드 설명을 읽고 확인한 경우에만** 진행합니다. 남이 보내 준 코드, 설명을 읽지 않은 코드라면 여기서 창을 닫습니다.
34. "신청알림_v01에서 내 Google 계정에 액세스하려고 합니다" 같은 제목 아래 권한 목록이 나옵니다. 스프레드시트를 보는 권한과 내 이름으로 메일을 보내는 권한, 이 두 가지인지 읽습니다. 항목 옆에 체크 상자가 있다면 두 가지를 모두 체크합니다.
35. 맨 아래 '허용'(화면에 따라 '계속')을 누릅니다.
    - 이렇게 보이면 됩니다: 편집기 아래쪽에 '실행 로그' 칸이 열리고, '실행 시작됨' 다음 줄에 '실행 완료됨'이 나옵니다.
    - ✖ '오류'와 빨간 글자가 나오면: 그 줄을 마우스로 끌어 선택하고 복사해 AGY에게 "실행 로그에 이 오류가 나왔어"라고 보냅니다. 코드를 고쳐 받으면 25~28단계를 다시 하고, 29단계부터 다시 실행합니다.
36. 크롬 새 탭에서 `https://mail.google.com` 을 열어 내 받은편지함을 봅니다. "강의 신청 알림" 같은 제목의 메일이 한 통 와 있고, 본문에 테스트1 · 연습 · 10월 중 · 첫 시험 응답입니다가 정리돼 있으면 성공입니다.

### 아. 트리거 설정하기 (약 5분)

### 자. 실제 제출로 확인하고 실행 기록 보기 (약 5분)

## AI에게 건네는 말

두 요청 모두 AGY에게 보냅니다.

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

보낼 글 (첫 번째 요청 — 코드 받기):

> 구글 시트에 연결된 설문지 응답(열: 타임스탬프, 이름, 소속, 희망 날짜, 하고 싶은 말)이 들어오면, 새 응답 한 줄을 정리해 나에게만 알림 메일을 보내는 Apps Script 코드를 써 줘. 받는 사람 주소는 코드에 글자로 적지 말고, 스크립트를 실행하는 내 계정 주소를 코드가 스스로 읽게 해 줘. 시트의 '양식 제출 시' 설치형 트리거에 연결할 함수와, 트리거 없이 시트의 마지막 행으로 시험할 테스트 함수를 따로 만들어 줘. 응답자에게는 메일을 보내지 말고, 시트의 기존 데이터를 고치거나 지우지 마. 비밀 값이 필요하면 코드에 쓰지 말고 스크립트 속성에서 읽게 해 줘. 코드는 작업 폴더에 `신청알림_v01.gs` 파일 하나로만 저장하고, 두 함수의 이름을 대화에 따로 알려 줘.

답을 읽는 법: 대화에 함수 이름 두 개(트리거용, 테스트용)가 적혀 나오면 종이에 옮겨 둡니다. 29단계와 39단계에서 이 이름을 고릅니다.

보낼 글 (두 번째 요청 — 설명 받기):

> 방금 준 코드가 하는 일을 사람이 읽을 수 있게 한 줄씩 설명해 줘. 특히 ① 어떤 권한이 필요한지 ② 메일이 누구에게 가는지 ③ 같은 응답에 메일이 두 번 갈 수 있는 경우가 있는지 따로 적어 줘.

답을 읽는 법: ①에 "스프레드시트 보기"와 "메일 보내기"만 있고, ②에 "스크립트를 실행한 사람(나)"이라고 적혀 있으면 23단계를 통과합니다. ③에 "트리거를 두 번 만들면"이 나오면 42단계에서 확인할 것이라고 메모해 둡니다.
