# 7강. 자료를 줬다면 정말 읽었는지 묻기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

`practice` 폴더의 자료 두 개를 AGY에게 읽게 하고, AGY가 실제로 읽은 파일과 읽지 못한(또는 내용이 없는) 파일을 구분해 표로 적습니다. 파일 이름만 보고 내용을 짐작한 답을 가려내는 눈을 기릅니다.

## 먼저 이해하기

AI와 자료 사이에는 네 단계가 있습니다. 앞 단계가 됐다고 뒤 단계까지 된 것은 아닙니다.

| 단계 | 뜻 | 예 |
| --- | --- | --- |
| 설치 | 프로그램이 내 PC에 들어옴 | 2강의 AGY 설치 |
| 로그인 | 내 계정으로 들어감 | 2강의 구글 로그인 |
| 연결 | 폴더나 바깥 서비스를 AI가 볼 수 있게 이어 둠 | 3강의 `practice` 연결 |
| 읽기 | AI가 파일을 열어 내용을 실제로 봄 | 오늘 확인하는 것 |

읽었는지 확인하는 가장 쉬운 방법은 **파일 속 핵심 문장을 말해 보게** 하는 것입니다. 파일에 실제로 있는 문장을 그대로 말하면 읽은 것이고, 그럴듯하지만 파일에 없는 말을 하면 짐작한 것입니다.

구글 드라이브·노션 같은 바깥 문서 도구를 AI에 붙이는 방법도 있습니다. MCP(Model Context Protocol, AI가 바깥 서비스와 연결되는 통로의 규격)라는 방식입니다. 그런데 "연결됨"이라고 표시돼도 인증(내 계정으로 허락하는 절차)이나 읽기 조건이 남아 있어 실제로는 못 읽는 경우가 있습니다. 드라이브 속 `.gdoc` 파일은 문서 본문이 아니라 바로가기라서, 폴더에 있어도 AI가 내용을 읽지 못합니다(C0 11강). 그래서 이번 수업에서는 바깥 도구를 새로 연결하지 않고, 내 PC에 있고 내가 내용을 아는 텍스트 파일만 씁니다.

비유하자면 책을 빌려준 뒤 "재미있었어?"가 아니라 "주인공 이름이 뭐였어?"라고 묻는 것입니다. 앞의 질문에는 읽지 않아도 대답할 수 있습니다.

## 실제 기록에서 배운 한 줄

실제 대화에서 AI는 열지 못한 문서 대신, 있을 법한 내용을 스스로 만들어 작업을 이어 갔습니다. 사용자가 이를 알아채고 지적한 뒤, 문서를 Word 사본으로 내보내 다시 주고 "원문 기준으로 다시 만들어 달라"고 요청해서야 바로잡혔습니다. 오늘은 그 지적을 처음부터 하는 법을 연습합니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

**가. 확인용 자료 준비하기**

1. 탐색기에서 `practice` 를 엽니다. 4강의 `memo.txt` 가 있는지 봅니다. `memo.txt` 에는 "참가자는 성인", "실습은 종이로 진행" 두 줄이 들어 있습니다.
2. `practice` 의 빈 곳에서 마우스 오른쪽 버튼 → '새로 만들기' → '텍스트 문서'를 누릅니다. 이름 칸이 파랗게 선택된 상태가 되면 `schedule` 만 쓰고 `Enter` 를 누릅니다. 뒤의 `.txt` 는 그대로 둡니다. 안에는 아무것도 쓰지 않습니다.
   → 이렇게 보이면 됩니다: `practice` 에 `schedule.txt` 가 생깁니다(탐색기가 '자세히' 보기라면 크기가 `0KB` 로 보입니다). 일부러 비워 둔 파일입니다. AI가 이 파일을 "일정표"라는 이름만 보고 내용을 지어내는지 보려는 것입니다.

✖ 이름이 `schedule.txt.txt` 가 되면: `.txt` 를 한 번 더 쓴 것입니다. 파일을 한 번 누르고 `F2` 를 눌러 끝의 `.txt` 하나를 지웁니다.

**나. 읽었는지 묻기**

3. AGY를 열고 `Ctrl + N` 으로 새 대화를 엽니다.
4. 아래 "AI에게 건네는 말"의 글을 보냅니다.
   → 이렇게 보이면 됩니다: 답에 `memo.txt` 의 핵심 사실 두 가지("성인", "종이 실습")가 나오고, `schedule.txt` 는 "비어 있음" 또는 "내용 없음"으로 따로 적힙니다.
5. 종이에 표를 그리고 채웁니다.

| 파일 | AGY가 말한 핵심 사실 | 파일에 실제로 있나 (메모장으로 열어 확인) | 판정 |
| --- | --- | --- | --- |
| memo.txt | | | 읽음 / 짐작 |
| schedule.txt | | | 읽음 / 짐작 / 비어 있음 |

6. "파일에 실제로 있나" 칸은 AGY의 말을 믿지 말고, 탐색기에서 파일을 오른쪽 클릭 → '연결 프로그램' → '메모장'으로 직접 열어 채웁니다. 다 보면 고치지 않고 닫습니다.

✖ AGY가 `schedule.txt` 에 날짜나 일정이 있다고 말하면: 짐작한 것입니다. 입력칸에 "schedule.txt를 다시 열어서 첫 줄을 그대로 옮겨 적어 줘. 비어 있으면 비어 있다고 말해 줘" 라고 보냅니다. 그래도 내용을 말하면, 표의 판정 칸에 "짐작"이라고 적고 그 답은 쓰지 않습니다.

✖ AGY가 파일을 찾지 못한다고 하면: 3강에서 연결한 폴더가 `practice` 인지, 파일이 `practice` 바로 안에 있는지 탐색기에서 봅니다. 읽지 못하는 파일이 있을 때는 짐작 작업을 멈추게 하고, 내가 내용을 아는 텍스트 파일로 바꿔서 다시 줍니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

보낼 글:

> practice 폴더의 memo.txt와 schedule.txt를 실제로 열어서 읽어 줘. 읽은 파일마다 파일 이름과, 그 파일에 적힌 핵심 사실 두 가지를 원문 그대로 적어 줘. 못 읽은 파일이나 내용이 비어 있는 파일은 따로 알려 줘. 파일 이름만 보고 내용을 짐작하지 말고, 파일을 새로 만들거나 고치지도 마.

답은 입력칸 위쪽 대화 영역에 나타납니다. 읽기만 하는 부탁이므로 파일을 쓰는 권한 창이 뜨면 허용하지 않습니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## 손에 남길 것과 완료 확인

**읽음·읽지 못함 확인표**

- □ `practice` 에 빈 `schedule.txt` 를 만들었다.
- □ 확인표 두 줄이 채워져 있고, "파일에 실제로 있나" 칸은 메모장으로 직접 열어 보고 채웠다.
- □ `schedule.txt` 에 대해 AGY가 "비어 있음"이라고 했는지, 내용을 지어냈는지 판정했다.
- □ 짐작한 답이 있었다면 다시 묻는 말을 보냈고, 그 결과를 적었다.
- □ `memo.txt` 는 고치지 않았다.
