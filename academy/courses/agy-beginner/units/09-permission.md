# 9강. 권한 창을 읽고 범위를 정하기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

권한 요청의 동작·대상·범위를 설명하고 승인 여부를 판단한다.

## 먼저 이해하기

계획 동의, 도구 실행 허용, 결과 만족은 서로 다르다. 무인 실행에서는 승인 요청을 받을 사람이 있는지도 중요하다.

| 연습용 권한 요청 | 이번 과제에서의 판단 |
| --- | --- |
| 지정한 연습 파일 하나 작성 | 목적·위치·변경 내용을 읽고 필요한 범위만 판단 |
| 컴퓨터 전체 파일 수정 | 과제 범위를 벗어나므로 보류하고 이유 질문 |
| 안내문을 외부 서비스로 전송 | 이번 과제에 없으므로 승인하지 않음 |

제품의 Ask는 실행 전 확인을 요청하는 상태입니다. 모든 작업이 매번 창을 띄우는 것은 아니며, 운영체제·설정에 따라 다릅니다. [공식 권한 안내](https://antigravity.google/docs/permissions)

오늘 사례의 재실행 성공은 제공된 기록에 없습니다. 수업에서는 ‘파일이 없었다’는 사실과 ‘다음에 시험할 대응’을 구별합니다. 무인 실행의 권한 사전 설계는 C1+·C3에서 다루며, 여기서는 확인 가능한 화면에서 최소 작업을 시험합니다.

## 실제 기록에서 배운 한 줄

오늘 무인 실행에서 에이전트가 권한 확인을 받지 못해 파일을 하나도 만들지 못했다. 원인은 승인 경로에서 찾았으며, 대화형 실행에서 좁은 범위를 확인하는 재시도 절차를 이번 실습으로 익힌다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. 가상 권한 카드 ‘연습 폴더 파일 쓰기’, ‘전체 드라이브 수정’, ‘외부로 보내기’를 보고 동작과 대상을 표시한다.
2. 이번 실습에 필요한 한 파일 작성만 판단하고 모르는 명령은 설명을 요청한다. 전체 허용을 해결책으로 삼지 않는다.
3. 오늘의 사례를 읽고 사람에게 확인 창이 보이는 실행 방식에서 최소 작업을 먼저 시험하는 재시도 계획을 적는다.

## AI에게 건네는 말

> 지금 필요한 권한의 동작, 대상 파일, 이번 작업에 필요한 이유를 설명해 줘. 내가 응답할 수 없는 승인 대기라면 상태를 알리고 멈춰. 모든 권한을 한꺼번에 늘리지 마.

## 손에 남길 것과 완료 확인

**권한 판단표와 재시도 전 점검**

권한 요청의 동작·대상·범위를 설명하고 승인 여부를 판단한다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
