# 9강. 권한 창을 읽고 범위를 정하기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

AGY가 "이것을 해도 될까요?" 하고 묻는 권한 확인 창을 끝까지 읽고, 무엇을(동작) 어디에(대상) 하려는지 말로 설명한 뒤 허용할지 거절할지 스스로 정합니다.

## 먼저 이해하기

AGY는 내 컴퓨터에서 직접 파일을 만들고 명령을 실행할 수 있습니다. 그래서 위험할 수 있는 일을 하기 전에 멈추고 사람에게 묻습니다. 이때 나타나는 것이 권한 확인 창(에이전트가 일을 하기 전에 사람의 허락을 받으려고 띄우는 작은 카드)입니다.

공식 도움말은 권한을 세 가지로 나눕니다.

| 이름 | 뜻 | 화면에서 일어나는 일 |
| --- | --- | --- |
| Allow(허용) | 묻지 않고 바로 해도 됨 | 창 없이 그냥 진행됩니다 |
| Ask(확인 요청) | 할 때마다 사람에게 물어봄 | 채팅 화면에 확인 카드가 나타나고 AGY가 멈춰 기다립니다 |
| Deny(거부) | 하지 못하게 막음 | 그 동작은 즉시 막힙니다 |

확인 카드는 보통 채팅 대화 안에 끼어 들어온 네모 칸 모양입니다. 안에는 세 가지가 적혀 있습니다.

- 동작: 무엇을 하려는지. 예) 명령 실행, 파일 읽기, 파일 쓰기, 인터넷 주소 열기
- 대상: 어디에 하려는지. 예) `practice` 폴더 안의 `today.md`, 또는 명령 한 줄(`dir` 같은 영어 글자)
- 버튼: 허락하는 버튼과 거절하는 버튼. 허락 쪽은 'Allow' 또는 'Accept'처럼, 거절 쪽은 'Deny' 또는 'Reject'처럼 보입니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

버튼을 누르기 전에 스스로 세 가지를 묻습니다.

1. 이 동작이 오늘 내가 부탁한 일에 꼭 필요한가?
2. 대상이 `practice` 폴더 안인가?
3. 무슨 뜻인지 모르는 영어 명령이 있는가? 있다면 누르지 말고 먼저 묻는다.

| 연습용 권한 요청 | 이번 과제에서의 판단 |
| --- | --- |
| `practice` 폴더 안에 파일 하나 쓰기 | 부탁한 일이 맞고 대상도 연습 폴더 안이므로 허용 |
| 바탕화면이나 컴퓨터 전체의 파일 읽기·수정 | 과제 범위를 벗어나므로 거절하고 "왜 필요한지" 묻기 |
| 안내문을 인터넷의 다른 서비스로 보내기 | 이번 과제에 없는 일이므로 거절 |
| 뜻을 모르는 영어 명령 실행 | 누르지 말고 "이 명령이 무엇을 하는지 쉬운 말로 설명해 줘" 라고 묻기 |

알아 둘 점이 두 가지 있습니다.

- 모든 작업마다 창이 뜨지는 않습니다. 창이 뜨는 일과 그냥 진행되는 일은 설정에 따라 다릅니다. 공식 도움말에 따르면 새 권한 방식은 맥·리눅스용이고, 윈도우에서는 이전 방식이 쓰입니다. 윈도우의 설정(Settings) 화면 'Agent' 쪽에는 'Terminal Command Auto Execution(터미널 명령을 자동으로 실행할지)'이라는 항목이 있고, 고를 수 있는 값은 'Request Review(매번 사람에게 확인)', 'Proceed in Sandbox(보호된 구역 안에서는 묻지 않고 실행)', 'Always Proceed(묻지 않고 항상 실행)' 입니다. 입문 과정에서는 'Request Review'를 권합니다. 터미널(글자로 명령을 입력해 컴퓨터를 움직이는 검은 화면)은 C1+에서 배웁니다.
- '모두 허용'이나 'Always Proceed'는 창을 없애 주지만 멈출 기회도 없앱니다. 창이 귀찮다는 이유로 넓게 허용하지 않습니다.

공식 자료: [권한 안내](https://antigravity.google/docs/permissions), [에이전트 설정](https://antigravity.google/docs/agent-settings)

## 실제 기록에서 배운 한 줄

실제 무인 실행(사람이 자리에 없을 때 AI 혼자 일하게 한 실행)에서 에이전트가 권한 확인을 받지 못해 파일을 하나도 만들지 못했습니다. 확인 창을 눌러 줄 사람이 없었던 것이 원인이었습니다. 그래서 이 수업은 사람이 화면 앞에 있는 상태에서 작은 일부터 허락하는 순서를 연습합니다. 무인 실행의 권한을 미리 설계하는 방법은 C1+·C3에서 다룹니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

준비: PC에서 AGY를 열고, 3강에서 연결한 `practice` 폴더(경로 예: `C:\사용자\(내 계정 이름)\my_work\practice`)가 화면 왼쪽 목록에 보이는지 확인합니다.

**연습 1 — 폴더 안의 파일 하나 만들기**

1. 화면 아래쪽 채팅 입력칸에 아래 "AI에게 건네는 말"의 첫 번째 글을 붙여 넣고 보냅니다.
2. 확인 카드가 나타나면 바로 누르지 않습니다. 카드 안에서 동작(파일 쓰기)과 대상(`practice` 안의 `permission_test.md`)을 찾아 소리 내어 읽습니다.
3. 대상이 `practice` 안이 맞으면 허락 버튼을 누릅니다. 카드가 없이 바로 파일이 생겼다면, 이 동작은 지금 설정에서 묻지 않아도 되는 일로 정해져 있다는 뜻입니다.

이렇게 보이면 됩니다: 화면 왼쪽 파일 목록에 `permission_test.md` 가 새로 보이고, 눌러 열면 "권한 연습" 한 줄이 들어 있습니다.

**연습 2 — 명령 실행을 묻는 카드 읽기**

1. 두 번째 글을 보냅니다. AGY가 파일 목록을 보려고 명령(영어 한 줄)을 실행하려 할 수 있습니다.
2. 카드에 명령이 나오면 그 글자를 종이에 그대로 적습니다. 예) `dir`
3. 뜻을 모르면 거절 버튼을 누르지도 허락하지도 말고, 채팅 입력칸에 "방금 그 명령이 무엇을 하는지 쉬운 말로 설명해 줘" 라고 보냅니다.
4. 설명이 "폴더 안의 파일 이름만 보여 준다"처럼 읽기만 하는 일이면 허락합니다. 지우기·옮기기·설치가 들어 있으면 거절합니다.

이렇게 보이면 됩니다: 채팅에 `practice` 폴더의 파일 이름 목록(`today.md`, `permission_test.md` 등)이 나타납니다.

✖ 카드가 떴는데 아무것도 누르지 않고 다른 창으로 가 버리면, AGY는 계속 기다린 채 멈춰 있습니다. 채팅 화면으로 돌아와 카드를 찾아 결정하세요.

**연습 3 — 범위 밖 요청을 거절하기**

1. 세 번째 글을 보냅니다. 바탕화면은 작업 폴더 밖이라서, AGY가 확인을 요청하거나 "접근할 수 없다"고 답합니다.
2. 확인 카드가 나오면 대상이 `practice` 밖인 것을 확인하고 거절 버튼을 누릅니다.
3. 채팅 입력칸에 "거절했어. 이 작업은 practice 폴더 안에서만 해 줘." 라고 보냅니다.

이렇게 보이면 됩니다: AGY가 바탕화면 파일을 읽지 않고, 폴더 밖에는 손대지 않겠다고 답합니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

연습 1:

> practice 폴더 안에 permission_test.md 파일을 만들고 "권한 연습" 한 줄만 적어 줘. 다른 폴더나 파일은 건드리지 마. 권한 확인이 필요하면 무엇을 어디에 하려는지 먼저 알려 줘.

연습 2:

> practice 폴더에 어떤 파일이 있는지 목록으로 보여 줘. 명령을 실행해야 하면 실행 전에 그 명령이 무엇을 하는지 쉬운 말로 한 줄 설명해 줘.

연습 3:

> 바탕화면에 있는 파일을 읽어서 목록을 만들어 줘.

(연습 3은 거절을 연습하려고 일부러 범위를 벗어나게 쓴 글입니다.)

답을 읽는 법: AGY의 답은 채팅 입력칸 위쪽에 쌓입니다. 확인 카드도 그 사이에 나타납니다. 답 끝에 "완료"라고 쓰여 있어도 왼쪽 파일 목록에서 파일을 직접 눌러 열어 확인합니다.
