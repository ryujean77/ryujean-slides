# 10강. 계획부터 할까, 바로 실행할까

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

AGY의 두 가지 일하는 방식인 Planning(계획 먼저)과 Fast(바로 실행)의 차이를 알고, 화면에서 직접 바꿔 본 뒤 일의 크기에 맞게 고릅니다.

## 먼저 이해하기

같은 부탁이라도 AGY가 일하는 순서를 두 가지 중에서 고를 수 있습니다.

| 방식 | 공식 도움말의 설명을 쉬운 말로 | 어울리는 일 |
| --- | --- | --- |
| Planning(계획 모드) | 먼저 자료를 살펴보고, 할 일을 정리한 계획서를 만든 뒤 일합니다 | 새 안내문 만들기, 파일 여러 개를 다루는 일, 처음 해 보는 일 |
| Fast(빠른 모드) | 따로 계획 단계 없이 바로 일합니다 | 한 줄 고치기, 파일 이름 하나 바꾸기처럼 작고 금방 끝나는 일 |

Planning에서 AGY가 만드는 계획서를 공식 이름으로 Implementation Plan(구현 계획서, AI가 "이런 순서로 이 파일을 이렇게 하겠다"고 적은 문서)이라고 부릅니다. 이런 결과 문서를 통틀어 Artifact(아티팩트, AI가 일하면서 남기는 확인용 문서)라고 합니다.

계획서가 나온 뒤 AGY가 멈춰서 기다릴지는 또 다른 설정이 정합니다. 설정(Settings) 화면의 'Agent' 쪽에 있는 검토 방식입니다.

| 검토 방식 | 뜻 |
| --- | --- |
| Request Review(검토 요청, 공식 권장) | 계획서를 보여 준 뒤 반드시 멈추고 사람의 승인을 기다립니다 |
| Always Proceed(항상 진행) | 계획서를 만들고 멈추지 않고 곧바로 실행합니다 |

입문 과정에서는 Planning + Request Review 조합을 기본으로 씁니다. 두 가지를 꼭 기억합니다.

- Planning을 골랐다고 해서 늘 멈추는 것은 아닙니다. 검토 방식이 Always Proceed면 계획서만 보여 주고 그냥 진행합니다.
- Fast를 골랐다고 권한 확인(9강)이 사라지는 것은 아닙니다. 둘은 서로 다른 설정입니다.

3강에서 본 Local(내 폴더에서 바로 작업)과 New Worktree(별도 작업 사본에서 작업)는 어디서 일할지를 고르는 것으로, 오늘 배우는 모드와는 다른 선택입니다. 입문 과정은 Local로 연습 폴더에서만 합니다.

공식 자료: [계획·실행 방식과 검토 설정](https://antigravity.google/docs/artifact-review), [계획 명령 /plan](https://antigravity.google/docs/plan)

## 실제 기록에서 배운 한 줄

실제 사용자 화면의 보안 메뉴가 설명서와 달라 진행이 막혔고, 사용자가 화면 문구를 되물은 뒤 폴더 연결을 확인했습니다. 모드도 설명서의 이름만 믿지 말고 내 화면에 보이는 글자와 맞춰 보며 고릅니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

**1단계 — 지금 어떤 모드인지 찾기**

1. PC에서 AGY를 열고 `practice` 폴더가 연결되어 있는지 봅니다.
2. 화면 아래쪽 채팅 입력칸 주변(입력칸 바로 아래나 옆)을 봅니다. 'Planning' 또는 'Fast'라는 글자가 적힌 작은 선택 단추가 있습니다. 옆에는 AI 모델 이름(예: Gemini …)이 적힌 단추가 따로 있을 수 있는데, 그것은 모드가 아니라 모델 선택입니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)
3. 지금 보이는 글자를 종이에 적습니다.

이렇게 보이면 됩니다: 입력칸 근처에 'Planning' 또는 'Fast' 중 하나가 보입니다.

✖ 어디에도 보이지 않으면: 이 수업에서는 대신 메시지 맨 앞에 `/plan` 을 붙여 보냅니다. `/plan` 은 "먼저 계획부터 세워 줘"라는 공식 명령입니다. 입력칸에 `/` 를 치면 쓸 수 있는 명령 목록이 뜹니다.

**2단계 — 모드 바꿔 보기**

1. 그 선택 단추를 한 번 누릅니다. 작은 목록이 펼쳐집니다.
2. 'Fast'를 누릅니다. 단추의 글자가 'Fast'로 바뀌는지 봅니다.
3. 다시 눌러 'Planning'으로 돌려놓습니다.

이렇게 보이면 됩니다: 누를 때마다 단추의 글자가 바뀝니다.

**3단계 — 검토 방식 확인하기 (선택)**

1. AGY의 설정(Settings) 화면을 엽니다. 화면 가장자리에 톱니바퀴 모양 아이콘이나 'Settings'라는 글자가 보이면 그것을 누릅니다.
2. 'Agent' 쪽에서 검토 방식이 'Request Review'인지 봅니다. 아니면 'Request Review'로 바꿉니다.
3. 설정 화면을 찾기 어려우면 이 단계는 건너뛰어도 됩니다. 대신 채팅 요청에 "계획만 보여 주고 내 승인을 기다려"를 꼭 넣습니다(아래 두 번째 글).

**4단계 — 같은 날 두 가지 일을 모드에 맞게 시키기**

1. 모드를 'Fast'로 바꿉니다. 아래 첫 번째 글(작은 일: `today.md` 에 한 줄 추가)을 보냅니다.
2. 왼쪽 파일 목록에서 `today.md` 를 눌러 열고 줄이 하나 늘었는지 봅니다.
3. 모드를 'Planning'으로 바꿉니다. 아래 두 번째 글(큰 일: 모임 안내문 준비)을 보냅니다.
4. 계획서가 나타나면 읽기만 하고, 오늘은 승인하지 않습니다. 계획서를 고치고 승인하는 법은 11강에서 배웁니다.

이렇게 보이면 됩니다: Fast에서는 곧바로 파일이 바뀌고 짧은 보고가 옵니다. Planning에서는 파일이 바로 바뀌지 않고, 제목이 붙은 계획 문서(Implementation Plan)가 채팅 옆이나 안에 열립니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

Fast 모드에서 보낼 글:

> practice 폴더의 today.md 맨 아래에 "모드 연습하기" 한 줄만 추가해 줘. 다른 줄은 바꾸지 마.

Planning 모드에서 보낼 글:

> 가상의 작은 배움 모임 안내문을 practice 폴더에 만들려고 해. 먼저 계획만 보여 줘. 읽을 자료, 만들 파일 이름, 끝나고 확인할 항목을 세 줄로 적고 내 승인을 기다려. 아직 파일은 만들지 마.

답을 읽는 법: Fast의 답은 "추가했습니다" 같은 짧은 보고입니다. 보고만 믿지 말고 파일을 열어 봅니다. Planning의 답은 계획 문서입니다. 읽을 자료·만들 파일·확인 항목 세 가지가 들어 있는지 찾아 봅니다.
