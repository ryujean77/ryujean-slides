# 6강. 말로 적고, AI에게 되물어 달라 하기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

거친 메모를 바탕으로 필요한 질문에 답해 요청서를 완성한다.

## 먼저 이해하기

음성 입력은 선택이다. 핵심은 AI가 추정해서 채우기 전에 필요한 정보를 하나씩 묻게 하는 것이다.

## 실제 기록에서 배운 한 줄

실제 계획서 대화에서는 내용 자료·서식·일정 근거를 따로 지정해 요청했다. 필요한 조건을 먼저 모으는 방식으로 대응했으며, 이번에는 이를 짧은 역질문으로 연습한다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. ‘작은 배움 모임을 하려는데 준비 안내가 필요해’라는 가상 메모를 타이핑하거나 기기의 음성 입력으로 적는다.
2. 인식된 글을 읽고 잘못된 단어를 고친다. 실제 고객·상담 이야기는 넣지 않는다.
3. 대상·결과 형식·제약을 하나씩 질문하게 하고 답을 모아 요청서를 만든다.

## AI에게 건네는 말

> 아직 계획서를 쓰지 마. 아래 가상 메모를 읽고 대상, 결과 형식, 지켜야 할 조건을 한 번에 하나씩 물어봐 줘. 내가 모르는 정보는 비워 둬.

## 손에 남길 것과 완료 확인

**질문·답 3쌍과 요청서**

거친 메모를 바탕으로 필요한 질문에 답해 요청서를 완성한다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
