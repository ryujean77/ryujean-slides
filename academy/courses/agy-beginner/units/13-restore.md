# 13강. 잘못 고쳤다면 사본으로 돌아가기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

변경 전 사본으로 내용을 복구하고 다시 요청한다.

## 먼저 이해하기

생성·수정·복구를 한 묶음으로 연습한다. 원문이 잘못되었으면 수정 몇 줄로 덮지 않고 출발 자료부터 바꾼다.

되돌리기는 사본을 기준으로 별도 복구 파일을 만들어 내용을 대조하는 방식으로 연습합니다. 특정 단축키나 버튼이 모든 파일 변경을 복구한다고 가정하지 않습니다.

## 실제 기록에서 배운 한 줄

실제 대화에서 추정 자료로 만든 결과가 목적과 다르자 사용자가 원문 사본을 확보하고 재작성을 요청했다. 당시의 삭제 요청은 그대로 따르지 않고 수업에서는 사본을 보존하며 다시 만드는 방법으로 바꿨다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. 가상 안내문을 수정하기 전에 before.txt 사본을 남긴다.
2. 실습용 사본의 준비물을 일부러 잘못 바꾸고 원문과 차이를 찾는다.
3. 오류본은 비교용으로 보관하고 before.txt를 기준으로 별도 복구본을 만든 뒤 내용을 대조한다. Git 명령과 이력 관리는 C1+에서 배운다.

## AI에게 건네는 말

> 잘못 수정된 파일을 더 고치지 말고 멈춰 줘. before.txt를 기준으로 restored.txt를 따로 만들 계획을 보여 줘. 기존 파일은 삭제하지 말고 복구 뒤 차이를 확인하자.

## 손에 남길 것과 완료 확인

**수정 전·오류본·복구본**

변경 전 사본으로 내용을 복구하고 다시 요청한다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
