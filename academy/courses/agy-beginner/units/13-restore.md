# 13강. 잘못 고쳤다면 사본으로 돌아가기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

AI에게 파일을 고치게 하기 전에 사본(복사해 둔 원래 파일)을 먼저 만들고, 고친 결과가 잘못되었을 때 그 사본으로 원래 내용을 되찾습니다.

## 먼저 이해하기

AGY는 파일을 직접 고칩니다. 잘못 고친 뒤에 "되돌려 줘"라고 부탁하면 AI는 기억을 더듬어 되살리려 하는데, 원래 문장과 다르게 되살릴 수 있습니다. 가장 확실한 되돌리기는 고치기 전에 내 손으로 만들어 둔 사본입니다.

이 수업에서 쓰는 세 파일:

| 파일 | 역할 |
| --- | --- |
| `notice.txt` | 고칠 대상(작업본) |
| `before.txt` | 고치기 전에 내가 탐색기에서 복사해 둔 사본. 절대 고치지 않습니다 |
| `restored.txt` | `before.txt` 를 기준으로 새로 만든 복구본 |

잘못 고쳐진 `notice.txt` 는 지우지 않고 "무엇이 틀렸는지" 비교하는 데 씁니다.

편집기에서 `Ctrl + Z`(되돌리기)를 누르면 내가 직접 친 글자는 되돌아가지만, AI가 바꾼 파일 전체가 되돌아간다고 믿지 않습니다. 버튼 하나로 모든 변경이 되돌아간다고 가정하지 않고, 사본으로 확인합니다. 파일의 변경 이력을 자동으로 남기는 방법(Git)은 C1+에서 배웁니다.

## 실제 기록에서 배운 한 줄

실제 대화에서 추정 자료로 만든 결과가 목적과 다르자, 사용자가 원문 사본을 구해 다시 만들어 달라고 요청했습니다. 당시에는 기존 결과를 지워 달라는 요청도 있었지만, 이 수업에서는 지우지 않고 사본을 보존한 채 다시 만드는 방법으로 바꿨습니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

**1단계 — 작업본 만들기**

1. AGY를 열고 `practice` 폴더가 연결되어 있는지 봅니다.
2. 아래 "AI에게 건네는 말"의 첫 번째 글을 보내 `notice.txt` 를 만듭니다.
3. 왼쪽 파일 목록에서 `notice.txt` 를 눌러 열고, 준비물 줄에 "필기도구"가 있는지 봅니다.

이렇게 보이면 됩니다: 세 줄(모임 이름, 대상, 준비물)이 들어 있는 `notice.txt` 가 보입니다.

**2단계 — 고치기 전에 사본 만들기 (내 손으로)**

1. PC에서 파일 탐색기를 엽니다(작업 표시줄의 노란 폴더 모양, 또는 `Win + E`).
2. `my_work` → `practice` 폴더로 들어갑니다.
3. `notice.txt` 를 한 번 눌러 선택하고 `Ctrl + C` 를 누릅니다.
4. 폴더 안 빈 곳을 한 번 누르고 `Ctrl + V` 를 누릅니다. `notice - 복사본.txt` 가 생깁니다.
5. 그 파일을 한 번 누르고 `F2` 를 눌러 이름을 `before.txt` 로 바꾼 뒤 `Enter` 를 누릅니다.

이렇게 보이면 됩니다: `practice` 폴더에 `notice.txt` 와 `before.txt` 가 나란히 있습니다. AGY 왼쪽 파일 목록에도 `before.txt` 가 나타납니다.

✖ 이름이 `before.txt.txt` 처럼 보이면: 확장자(파일 이름 끝의 `.txt` 같은 꼬리표)가 두 번 붙은 것입니다. `F2` 를 다시 눌러 `.txt` 하나를 지웁니다(C0 4강).

**3단계 — 일부러 잘못 고치게 하기**

1. 두 번째 글을 보내 준비물을 "노트북"으로 바꾸게 합니다. 모임은 종이로 실습하므로 이것은 틀린 수정입니다.
2. `notice.txt` 를 다시 열어 준비물이 바뀐 것을 확인합니다.

**4단계 — 멈추고, 사본으로 복구하기**

1. 세 번째 글을 보냅니다. 더 고치지 말고 `before.txt` 를 기준으로 `restored.txt` 를 새로 만들게 하는 글입니다.
2. 확인 카드나 계획이 나오면 대상이 `restored.txt` 새 파일인지 읽고 승인합니다. `notice.txt` 나 `before.txt` 를 지우거나 고치는 내용이 있으면 거절합니다(9강).
3. 왼쪽 파일 목록에 `restored.txt` 가 생겼는지 봅니다.

**5단계 — 세 파일을 나란히 비교하기**

1. 파일 탐색기에서 `before.txt`, `notice.txt`, `restored.txt` 를 하나씩 더블클릭해 메모장으로 엽니다.
2. 창 세 개를 나란히 놓고 준비물 줄을 비교합니다.
3. `before.txt` 와 `restored.txt` 가 글자 하나까지 같은지 봅니다. `notice.txt` 에는 "노트북"이 남아 있어야 합니다.

이렇게 보이면 됩니다: `before.txt` 와 `restored.txt` 는 똑같고, `notice.txt` 만 준비물이 다릅니다.

✖ `restored.txt` 가 `before.txt` 와 다르면: AGY가 사본이 아닌 기억으로 만든 것입니다. 메모장에서 `before.txt` 의 내용을 전부 복사(`Ctrl + A`, `Ctrl + C`)해 `restored.txt` 에 붙여 넣고 저장(`Ctrl + S`)해도 됩니다. 사람이 직접 복구하는 것도 올바른 방법입니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

1단계:

> practice 폴더에 notice.txt 를 만들어 줘. 내용은 세 줄이야. "모임: 작은 배움 모임", "대상: 성인", "준비물: 필기도구". 다른 파일은 만들지 마.

3단계 (일부러 틀리게 고치는 연습):

> notice.txt 의 준비물을 "노트북"으로 바꿔 줘. 다른 줄은 그대로 둬.

4단계:

> 방금 수정은 잘못됐어. notice.txt 를 더 고치지 말고 멈춰 줘. before.txt 의 내용을 그대로 복사해서 restored.txt 라는 새 파일을 만들어 줘. before.txt 와 notice.txt 는 지우지도 고치지도 마. 만든 뒤 before.txt 와 restored.txt 가 같은지 확인한 결과를 알려 줘.

답을 읽는 법: 보고에 "같습니다"라고 쓰여 있어도 5단계처럼 내 눈으로 세 파일을 비교합니다.

## 손에 남길 것과 완료 확인

**수정 전·오류본·복구본**

`practice` 폴더에 `before.txt`(수정 전), `notice.txt`(잘못 고친 오류본), `restored.txt`(복구본) 세 파일이 모두 남아 있어야 합니다.

완료 기준: 사본은 AGY가 아니라 내가 탐색기에서 만들었고, 세 파일을 메모장으로 열어 `before.txt` 와 `restored.txt` 가 같다는 것을 직접 확인했습니다. 어느 파일도 지우지 않았습니다.
