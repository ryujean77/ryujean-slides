# 16강. 혼자 한 번 더 하고 다음 과정 고르기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

새 주제 하나로 요청 → 승인 → 실행 → 검수 → 복구의 다섯 단계를 도움 없이 처음부터 끝까지 해 보고, 막힌 곳을 보고 다음에 들을 과정을 고릅니다.

## 먼저 이해하기

C1은 AGY에게 작은 일을 맡기고, 결과를 내 눈으로 확인하는 입문 과정입니다. 지금까지 배운 것을 다섯 단계로 묶으면 다음과 같습니다.

| 단계 | 내가 하는 일 | 배운 수업 |
| --- | --- | --- |
| 요청 | 누가·무엇을·어떤 형식·어떤 조건으로를 넣어 부탁한다. 빠진 정보는 AI가 되묻게 한다 | 5·6강 |
| 승인 | 계획과 권한 확인 카드를 읽고, 필요한 것만 허락한다 | 9·10·11강 |
| 실행 | 'Proceed' 뒤 AGY가 일하는 동안 멈춤·오류를 살핀다 | 12강 |
| 검수 | 파일을 직접 열어 원문과 대조하고 내 말로 판단한다 | 7·8·14·15강 |
| 복구 | 고치기 전 사본을 만들고, 잘못되면 사본으로 되돌린다 | 13강 |

이번에는 새 가상 주제 "책 나눔 모임"으로 합니다. 앞의 수업을 다시 펴 보지 않고 해 보는 것이 목표입니다. 막히면 그 자리에서 해당 수업으로 돌아가 복습하고, 어디서 막혔는지 점검표에 적습니다. 막힌 곳이 곧 다음에 배울 곳입니다.

## 실제 기록에서 배운 한 줄

실제 대화에서 코드 파일이 생긴 뒤 "이제 무엇을 해야 하나"를 다시 물었고, 이어서 실행·브라우저 확인 문제로 넘어갔습니다. 파일이 생긴 것과 그 파일이 제대로 쓰이는 것은 다른 단계입니다. 그래서 이 수업은 파일 생성과 사용 확인을 나누어 마무리합니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

**1단계 — 요청 (5·6강)**

1. AGY를 열고 `practice` 폴더가 연결되어 있는지, 모드가 'Planning'인지 봅니다.
2. 아래 "AI에게 건네는 말"의 첫 번째 글을 보냅니다. AGY가 대상·형식·조건을 하나씩 물어 옵니다.
3. 질문마다 짧게 답합니다. 예) 대상: 동네 성인 / 형식: 네 줄 안내문 / 조건: 날짜는 미정, 새 파일 하나만.

이렇게 보이면 됩니다: 질문이 끝나면 AGY가 요청을 한 문단으로 정리해 보여 줍니다.

**2단계 — 승인 (9·10·11강)**

1. 계획이 나오면 단계마다 ○/×를 표시합니다.
2. 만들 파일이 `20261010_책나눔안내_v01.md` 한 개(날짜는 오늘 날짜)인지, 게시·전송·폴더 정리가 없는지 봅니다.
3. ×가 있으면 빼 달라고 보내고, 고친 계획을 확인한 뒤 'Proceed'를 누릅니다. 권한 확인 카드가 나오면 동작과 대상을 읽고 정합니다.

**3단계 — 실행 (12강)**

1. AGY가 일하는 동안 채팅 화면을 지켜봅니다.
2. 멈춘 것 같으면 먼저 확인 카드가 남아 있는지 봅니다.
3. 오류가 나면 기대·실제·오류 문구·마지막 성공 단계를 메모장에 적고 되묻습니다.

**4단계 — 검수 (8·14강)**

1. 왼쪽 파일 목록에서 새 파일을 눌러 엽니다.
2. 내가 답한 대상·형식·조건과 맞는지 봅니다. 없는 날짜가 들어가 있지 않은지 봅니다.
3. 틀린 곳 두 곳을 찾아 적습니다. 틀린 곳이 없으면 "없음"이라고 적습니다.

**5단계 — 복구 (13강)**

1. 파일 탐색기(`Win + E`)에서 `practice` 폴더를 열고 `_v01.md` 를 복사해 `before_book.md` 라는 사본을 만듭니다(`Ctrl + C`, `Ctrl + V`, `F2`).
2. AGY에게 `_v01.md` 의 한 줄을 일부러 틀리게 고치게 합니다.
3. 두 번째 글을 보내 `before_book.md` 를 기준으로 `_v02.md` 를 새로 만들게 합니다.
4. 메모장으로 `before_book.md` 와 `_v02.md` 를 열어 같은지 봅니다.

이렇게 보이면 됩니다: `practice` 폴더에 `_v01.md`(틀리게 고친 판), `before_book.md`(사본), `_v02.md`(복구본)가 모두 있고, 사본과 복구본이 같습니다.

**6단계 — 점검표 채우고 다음 과정 고르기**

1. 아래 점검표의 다섯 칸을 채웁니다.
2. "도움 받음"이 있는 칸을 보고, 위 "다음 학습 경로" 표에서 그 칸과 가장 가까운 과정을 고릅니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

1단계:

> 가상의 "책 나눔 모임" 안내문을 practice 폴더에 새 파일 하나로 만들고 싶어. 아직 만들지 말고, 대상·결과 형식·지켜야 할 조건을 한 번에 하나씩 물어봐 줘. 답을 다 모으면 요청을 한 문단으로 정리하고, 실행 전 계획과 끝난 뒤 내가 확인할 항목을 보여 줘. 확인하지 않은 일을 완료라고 쓰지 마.

5단계:

> 방금 수정은 잘못됐어. 더 고치지 말고, before_book.md 의 내용을 그대로 복사해서 20261010_책나눔안내_v02.md 를 새로 만들어 줘. 다른 파일은 지우지도 고치지도 마.

(글 속 날짜 `20261010` 은 예시입니다. 2단계에서 정한 날짜와 똑같이 씁니다.)

답을 읽는 법: 이번에는 AGY의 답을 읽고 다음 행동을 스스로 정합니다. 계획·카드·보고 중 어느 것이든, 읽고 나서 "이것은 요청·승인·실행·검수·복구 중 어느 단계인가"를 먼저 떠올립니다.
