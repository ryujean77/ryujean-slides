# 16강. 혼자 한 번 더 하고 다음 과정 고르기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

요청→승인→실행→검수→복구의 흐름을 혼자 재현한다.

## 먼저 이해하기

C1은 AGY에게 작은 일을 맡기는 입문이다. 다음 학습은 C1+ 검은 화면, C2 자료관리론, C3 업무 자동화로 이어진다.

## 다음 학습 경로

C0 컴퓨터 왕기초 → **C1 AGY 입문** → C1+ 검은 화면 → C2 자료관리론 → C3 업무 자동화.

C1+에서는 터미널·CLI·스킬을, C2에서는 자료 지도·정본·헌장·산출물 운영을, C3에서는 인박스→초안→결재 파이프라인을 배웁니다. 이 수업의 파일 생성 경험과 검수 기록을 다음 과정으로 가져갑니다.

## 실제 기록에서 배운 한 줄

실제 대화에서 코드 파일이 생긴 뒤 다음에 무엇을 할지 다시 질문했다. 이후 실행·브라우저 확인 문제로 이어진 기록을 바탕으로, 파일 생성과 사용 검증을 나누어 마무리한다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. 새 가상 주제 ‘책 나눔 모임’으로 4요소 요청을 쓰고 파일 하나를 받는다.
2. 파일을 다시 열어 오류 두 곳을 찾는 연습과 수정 전 사본 복구를 보조 없이 수행한다.
3. 폴더 조작이 막히면 C0, 명령·스킬은 C1+, 자료 체계는 C2, 반복 운영은 C3로 학습할 항목을 적는다.

## AI에게 건네는 말

> 새 연습에서 내가 직접 판단하도록 해 줘. 요청의 빠진 정보만 물어보고, 실행 전 범위와 이후 확인할 항목을 제시해 줘. 확인하지 않은 일을 완료라고 쓰지 마.

## 손에 남길 것과 완료 확인

**독립 수행 점검표와 다음 과정 선택**

요청→승인→실행→검수→복구의 흐름을 혼자 재현한다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
