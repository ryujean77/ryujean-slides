# 14강. 초안을 받고 내 말로 승인하기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

AGY 안에서 초안을 읽고 수정·승인·보류를 구별한다.

## 먼저 이해하기

한 번의 대화에서 초안을 받아 판단하는 감각을 익힌다. 접수함·예약·연동·결재 파이프라인은 C3에서 배운다.

## 실제 기록에서 배운 한 줄

실제 계획서 대화에서 초안 보고를 받은 뒤 사용자가 필요한 파일 제작을 다시 지정했고 생성 완료 보고를 받았다. 수업에서는 보고를 듣는 데서 끝내지 않고 파일을 열어 판단한다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. 6강 요청서와 8강 원문으로 가상 안내문 초안을 받는다.
2. 대상·준비물·미정 항목을 읽고 한 곳을 수정 요청한다.
3. ‘내용 검수 완료, 외부 전송은 요청하지 않음’ 또는 ‘일정 미정으로 보류’ 중 판단을 기록한다.

## AI에게 건네는 말

> 이 요청서로 안내 초안을 새 파일로 만들어 줘. 자료에 없는 일정은 미입력으로 남겨. 내가 내용을 확인할 때까지 초안 상태로 두고 외부로 보내지 마.

## 손에 남길 것과 완료 확인

**검수한 모임 안내 초안**

AGY 안에서 초안을 읽고 수정·승인·보류를 구별한다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
