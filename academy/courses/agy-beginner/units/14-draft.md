# 14강. 초안을 받고 내 말로 승인하기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

AGY에게 모임 안내문 초안(처음 만들어 본, 아직 확정하지 않은 글)을 받아 직접 열어 읽고, "승인·수정 요청·보류" 셋 중 하나를 내 말로 정해 남깁니다.

## 먼저 이해하기

AGY가 "완료했습니다"라고 보고하는 것과, 내가 그 결과를 "이대로 좋다"고 승인하는 것은 다른 일입니다. 보고는 AI가 하고, 승인은 사람이 합니다.

| 판단 | 언제 고르나 | 남기는 말의 예 |
| --- | --- | --- |
| 승인 | 원문 메모와 맞고 빠진 것이 없다 | "내용 검수 완료. 외부 전송은 요청하지 않음" |
| 수정 요청 | 한두 곳이 틀리거나 어색하다 | "준비물 줄만 원문대로 고쳐 v02로 저장해 줘" |
| 보류 | 내가 아직 모르는 정보가 있다 | "일정 미정으로 보류. 날짜가 정해지면 다시 요청" |

파일 이름은 C0에서 배운 `날짜_내용_v01` 규칙을 씁니다. 예: `20261010_모임안내_v01.md`. 고칠 때마다 원래 파일은 두고 `_v02`, `_v03` 으로 새로 저장하면, 13강처럼 이전 판으로 돌아갈 수 있습니다.

`.md` 파일(마크다운 파일, 제목·목록 같은 간단한 표시를 넣을 수 있는 글 파일)은 AGY 왼쪽 파일 목록에서 이름을 누르면 가운데 화면에 열립니다. 메모장으로 열어도 됩니다.

AGY에는 이번 대화에서 바뀐 파일을 모아 보여 주는 'Review Changes'(변경 사항 검토) 기능도 있습니다. 공식 도움말에 따르면 에이전트 창 아래쪽 도구 줄에서 열 수 있고, 바뀐 부분에 댓글을 달아 AGY에게 전할 수 있습니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.) 이번 수업은 파일을 직접 열어 읽는 방법을 기본으로 합니다.

접수함·예약·결재 흐름을 자동으로 돌리는 방법은 C3에서 배웁니다.

공식 자료: [변경 사항 검토](https://antigravity.google/docs/ide/review-changes-editor)

## 실제 기록에서 배운 한 줄

실제 계획서 대화에서 초안 보고를 받은 뒤 사용자가 필요한 파일 제작을 다시 지정했고, 생성 완료 보고를 받았습니다. 이 수업에서는 보고를 듣는 데서 끝내지 않고 파일을 열어 읽은 뒤 판단합니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

준비: `practice` 폴더에 `memo.txt`(가상 메모: 작은 배움 모임, 대상 성인, 종이로 실습, 날짜 미정)가 있는지 봅니다. 6강에서 만든 요청서가 있으면 옆에 띄워 둡니다.

**1단계 — 초안 받기**

1. AGY를 열고, 모드를 'Planning'으로 둡니다(10강).
2. 아래 "AI에게 건네는 말"의 첫 번째 글을 보냅니다. 글 속 파일 이름의 `20261010` 은 예시이므로 오늘 날짜(예: 10월 10일이면 `20261010`)로 바꿔 씁니다. 3·4단계 글에서도 같은 날짜로 바꿉니다.
3. 계획이 나오면 11강처럼 읽습니다. 만들 파일이 한 개이고 외부로 보내는 단계가 없으면 'Proceed'를 누릅니다.

이렇게 보이면 됩니다: 왼쪽 파일 목록에 `(오늘 날짜)_모임안내_v01.md` 가 생깁니다.

**2단계 — 직접 열어 읽기**

1. 왼쪽 파일 목록에서 새 파일 이름을 누릅니다. 가운데에 내용이 열립니다.
2. 메모장에 아래 세 칸을 만들고 하나씩 대조합니다.
   - 대상이 "성인"인가?
   - 준비물이 원문과 같은가? (종이 실습이니 필기도구)
   - 날짜가 "미정" 또는 "미입력"으로 남아 있는가? 원문에 없는 날짜가 적혀 있으면 틀린 것입니다(8강).
3. 틀리거나 어색한 곳에 밑줄을 긋듯 메모합니다.

**3단계 — 한 곳만 수정 요청하기**

1. 가장 중요한 한 곳을 고릅니다. 한 번에 여러 곳을 고치게 하면 무엇이 바뀌었는지 확인하기 어렵습니다.
2. 두 번째 글에서 괄호 부분을 내 메모대로 바꿔 보냅니다.
3. `_v02` 파일이 새로 생기면 열어서 그 한 곳이 고쳐졌는지, 다른 곳은 그대로인지 봅니다. `_v01` 파일도 그대로 남아 있어야 합니다.

**4단계 — 내 말로 판단 남기기**

1. 표의 세 판단 중 하나를 고릅니다. 이 연습에서는 날짜가 미정이므로 "승인" 또는 "보류" 둘 다 올바를 수 있습니다. 이유를 스스로 정합니다.
2. 세 번째 글의 괄호에 내 판단과 이유를 넣어 보냅니다.
3. AGY가 판단을 파일 맨 아래에 적었는지 열어서 봅니다.

이렇게 보이면 됩니다: `_v02` 파일 맨 아래에 "검수:" 로 시작하는 한 줄이 있고, 외부로 무엇을 보냈다는 보고는 없습니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

1단계:

> practice 폴더의 memo.txt 만 근거로 가상 모임 안내 초안을 써서 20261010_모임안내_v01.md 새 파일로 저장해 줘. 목적·대상·준비물·일정 네 줄로 쓰고, 메모에 없는 일정은 "미입력"으로 남겨. 내가 확인할 때까지 초안 상태로 두고, 어디에도 보내지 마.

3단계:

> 20261010_모임안내_v01.md 에서 (고칠 곳: 예) 준비물 줄)만 (이렇게: 예) memo.txt 대로 "필기도구") 고쳐 줘. v01 은 그대로 두고 20261010_모임안내_v02.md 로 새로 저장해 줘. 다른 줄은 바꾸지 마.

4단계:

> v02 를 읽었어. 내 판단은 (승인 / 수정 요청 / 보류 중 하나)이고, 이유는 (한 줄)이야. v02 맨 아래에 "검수: " 로 시작하는 한 줄로 이 판단을 적어 줘. 외부 전송은 요청하지 않아.

답을 읽는 법: AGY가 "좋은 초안입니다" 같은 칭찬을 덧붙여도 판단은 내가 내린 것만 인정합니다. 보고를 읽은 뒤 반드시 파일을 다시 열어 봅니다.

## 손에 남길 것과 완료 확인

**검수한 모임 안내 초안**

- `(날짜)_모임안내_v01.md`(처음 초안)와 `_v02.md`(한 곳 고친 판)
- `_v02.md` 맨 아래의 "검수:" 한 줄

완료 기준: 두 파일을 모두 직접 열어 보았고, 고친 곳이 한 곳뿐인지 대조했으며, 판단과 이유를 내 말로 남겼습니다. 판단을 정하지 못했다면 "보류"로 적고 무엇을 알아야 정할 수 있는지 한 줄 씁니다.
