# 2강. 내 컴퓨터에 맞는 AGY 준비하기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

C0 24강에서 받아 둔 설치 파일로 AGY 2.0 데스크톱 앱을 내 PC에 설치하고, 내 개인 구글 계정으로 로그인까지 마칩니다. 마지막에 앱 이름·버전·로그인 상태를 종이에 적습니다.

## 먼저 이해하기

**AGY가 무엇인가요.** AGY는 구글이 만든 Google Antigravity(구글 안티그래비티)의 줄임말입니다. 제미나이 웹처럼 대화만 하는 AI가 아니라, 내가 열어 준 폴더 안의 파일을 직접 읽고 만드는 에이전트(내 대신 여러 단계를 스스로 해 나가는 AI 조수) 프로그램입니다. 그래서 인터넷 창이 아니라 내 PC에 프로그램으로 설치합니다.

**오늘 설치하는 것은 하나뿐입니다.** 공식 다운로드 페이지(`https://antigravity.google/download`)에는 제품이 여러 개 있습니다. 이 과정에서 쓰는 것은 맨 위의 'Antigravity 2.0' 데스크톱 앱(바탕화면에서 마우스로 쓰는 프로그램) 하나입니다.

| 페이지에 보이는 이름 | 무엇인가 | 이 과정에서 |
| --- | --- | --- |
| Antigravity 2.0 | 마우스로 쓰는 데스크톱 앱 | 오늘 설치 |
| Antigravity CLI | CLI(Command Line Interface, 검은 글자 창에 명령어를 쳐서 쓰는 방식) 버전 | 설치하지 않음 (C1+에서) |
| Antigravity IDE | IDE(Integrated Development Environment, 프로그래머가 코드를 쓰고 실행하는 통합 작업 프로그램) | 설치하지 않음 |
| Antigravity SDK | SDK(Software Development Kit, 다른 프로그램에 끼워 넣는 개발 도구 묶음) | 설치하지 않음 |

**설치 전에 알아 둘 세 가지**

- 설치 파일은 C0 24강에서 이미 받아 두었습니다. 파일 이름은 `Antigravity-x64.exe` 또는 `Antigravity-arm64.exe` 와 비슷합니다. `.exe` 는 두 번 누르면 실행되는 프로그램 파일이라는 뜻의 확장자(파일 이름 끝의 점 뒤 글자)입니다.
- 윈도우는 64비트 Windows 10 이상이어야 합니다. 첫 실행 때는 인터넷이 연결돼 있어야 합니다.
- 로그인(내가 누구인지 계정으로 확인하는 일)은 내가 직접 합니다. 비밀번호와 인증번호는 AI에게도, 옆 사람에게도 알려 주지 않습니다. 요금제(무료·유료)는 로그인한 계정에 붙습니다. 이 과정은 무료 요금제로 충분합니다.

비유하자면 오늘은 이런 날입니다. **새로 산 가전제품을 설치하고 전원을 켜는 날.** 포장(설치 파일)은 C0에서 이미 받아 송장(디지털 서명)까지 확인했습니다. 오늘은 상자를 열어 제자리에 놓고, 내 이름으로 등록합니다.

공식 자료: [다운로드](https://antigravity.google/download) · [시작하기](https://antigravity.google/docs/getting-started). 설치 화면의 글자는 대부분 영어입니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## 실제 기록에서 배운 한 줄

강사가 직접 설치할 때 가장 오래 멈춘 곳은 두 군데였습니다. 하나는 설치 중 여러 개의 체크 항목과 'IDE 설치' 안내가 나와 "무엇을 골라야 하나, 다 골라도 되나"를 되물은 순간이고, 다른 하나는 다운로드가 "사이트에 연결할 수 없음"으로 끝없이 실패한 순간입니다. 이 카드는 두 곳에서 무엇을 누르면 되는지를 미리 적어 둡니다. 강사의 120분 특강 교안에도 "설치가 안 돼요"의 대부분은 x64·ARM64 파일을 잘못 고른 경우라고 적혀 있습니다.

## 가상 예시로 직접 해 보기

준비물: C0 23강의 "시스템 종류" 메모, C0 24강에서 받아 둔 설치 파일, 내 개인 구글 계정의 비밀번호(내 머릿속에).

**가. 설치 파일 찾기와 다시 확인하기**

1. PC에서 키보드의 `Windows 키 + E` 를 눌러 파일 탐색기를 엽니다.
   → 이렇게 보이면 됩니다: 왼쪽에 '홈', '바탕 화면', '다운로드' 같은 목록이 있는 창이 열립니다.
2. 탐색기 왼쪽 목록에서 '다운로드'를 한 번 누릅니다.
   → 이렇게 보이면 됩니다: 오른쪽에 최근 받은 파일이 보이고, 그중 `Antigravity-x64.exe` 또는 `Antigravity-arm64.exe` 와 비슷한 이름이 있습니다.
3. 파일 이름의 `x64` / `arm64` 가 C0 23강 메모와 맞는지 봅니다. 메모가 `x64 기반 프로세서` 이면 `x64`, `ARM 기반 프로세서` 이면 `arm64` 여야 합니다.
   → 이렇게 보이면 됩니다: 메모와 파일 이름이 같은 쪽입니다.
4. 파일을 마우스 오른쪽 버튼으로 누르고 '속성'을 누릅니다(윈도우 11에서는 '추가 옵션 표시' 안에 있을 수 있습니다). 위쪽 '디지털 서명' 탭을 엽니다.
   → 이렇게 보이면 됩니다: 서명자 이름에 `Google LLC` 가 보입니다. 확인했으면 '확인'을 눌러 창을 닫습니다.

✖ 파일이 없거나 메모와 다른 쪽이면: C0 24강 1~10번을 다시 해 맞는 파일을 받습니다. 다운로드 페이지가 "사이트에 연결할 수 없음"으로 계속 실패하면, 크롬에서 `Ctrl + J` 를 눌러 다운로드 목록을 열고 실패한 항목을 지운 뒤 다시 받습니다. 그래도 안 되면 기관·회사 인터넷이 막고 있을 수 있으니 집 인터넷이나 휴대폰 핫스팟(휴대폰의 인터넷을 PC에 나눠 주는 기능)으로 바꿔 시도합니다. 인터넷 답변에 나오는 "명령어로 설치하기"는 이 과정에서 쓰지 않습니다.

**나. 설치하기**

5. 설치 파일을 마우스 왼쪽 버튼으로 두 번 빠르게 누릅니다.
   → 이렇게 보이면 됩니다: 잠시 뒤 설치 창이 나타나거나, 화면이 어두워지며 "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"라는 확인 창이 나옵니다.
6. 그 확인 창(사용자 계정 컨트롤, 프로그램이 PC를 바꾸기 전에 윈도우가 허락을 묻는 창)이 나오면, 창에 적힌 게시자가 `Google LLC` 인지 보고 '예'를 누릅니다.
   → 이렇게 보이면 됩니다: 설치가 진행되는 막대나 안내 화면이 나타납니다.
7. 전에 AGY를 설치한 적이 있다면 'Keep Both'(둘 다 두기)와 'Replace'(바꾸기) 중 하나를 고르라는 알림이 나올 수 있습니다. 공식 안내대로 'Replace'를 누릅니다. 처음 설치라면 이 알림은 나오지 않습니다.
   → 이렇게 보이면 됩니다: 알림이 닫히고 설치가 이어집니다.
8. IDE를 다시 설치할지 묻는 안내가 나올 수 있습니다. 공식 안내에서도 "원하면" 하는 선택입니다. 이 과정에서는 IDE를 쓰지 않으므로, 설치하지 않는 쪽 버튼(Skip, Later, No처럼 "하지 않음·나중에"를 뜻하는 글자)을 누릅니다.
   → 이렇게 보이면 됩니다: IDE 안내가 닫히고 AGY 2.0 설치만 이어집니다. IDE는 나중에 필요해지면 따로 설치할 수 있습니다.
9. 설치 중에 여러 개의 체크 상자(네모 칸에 ✓ 표시를 하는 선택지)가 붙은 목록이 나올 수 있습니다. 플러그인(앱에 기능을 덧붙이는 추가 부품)이나 스킬 묶음을 고르는 화면입니다. 이미 체크돼 있는 기본값을 그대로 두고 다음으로 넘어갑니다(Next, Continue, Finish처럼 "다음·계속·마침"을 뜻하는 버튼). 이 과정의 실습은 기본값으로 충분합니다.
   → 이렇게 보이면 됩니다: 다음 화면이나 설치 진행 막대로 넘어갑니다.
10. 설치가 끝날 때까지 기다립니다. 인터넷 속도에 따라 몇 분 걸릴 수 있습니다. 창을 닫거나 PC를 끄지 않습니다.
   → 이렇게 보이면 됩니다: 설치 창이 닫히고 AGY가 저절로 열리거나, 끝났다는 안내가 나옵니다.

✖ 설치 창이 아무것도 안 나오면: 30초쯤 기다린 뒤, 화면 맨 아래 작업 표시줄에 새 아이콘이 생겼는지 봅니다. 그래도 없으면 5번을 한 번만 다시 합니다. 여러 번 누르면 설치가 겹칠 수 있습니다.

✖ 파란 창에 "Windows의 PC 보호"가 뜨면: 바로 '실행'을 누르지 말고 창을 닫은 뒤, 4번의 디지털 서명을 다시 확인합니다. 서명이 `Google LLC` 가 아니면 파일을 지우고 C0 24강부터 다시 받습니다. 서명이 맞는데도 막히면 기관 PC의 보안 설정일 수 있으니 강사에게 알립니다.

**다. 처음 열고 로그인하기**

11. AGY가 저절로 열리지 않았다면, 화면 왼쪽 아래 '시작' 단추(윈도우 모양)를 누르고 키보드로 `Antigravity` 라고 칩니다. 위에 나온 'Antigravity'를 누릅니다.
    → 이렇게 보이면 됩니다: AGY 창이 열리고, 첫 화면에 구글로 로그인하라는 버튼이 보입니다. 강사의 기록에서는 'Sign in with Google'(구글로 로그인)이라고 적혀 있었습니다.
12. 그 로그인 버튼을 누릅니다.
    → 이렇게 보이면 됩니다: 크롬(또는 PC의 기본 인터넷 창)이 새로 열리며 구글 계정을 고르는 화면이 나옵니다.
13. C0 6강에서 만든 개인 크롬 프로필의 내 개인 구글 계정을 누릅니다. 비밀번호나 2단계 인증을 물으면 내가 직접 입력합니다.
14. AGY가 내 계정 정보를 써도 되는지 묻는 화면이 나오면, 화면 위쪽에 'Antigravity' 또는 'Google'이 적혀 있는지 확인하고 허용 버튼을 누릅니다.
    → 이렇게 보이면 됩니다: 인터넷 창에 로그인이 끝났다는 안내가 나오거나, "Antigravity를 열까요?" 같은 작은 창이 뜹니다. 작은 창이 뜨면 여는 쪽 버튼을 누릅니다.
15. 작업 표시줄에서 AGY 창을 눌러 다시 AGY로 돌아옵니다.
    → 이렇게 보이면 됩니다: 로그인 버튼이 사라지고 AGY의 첫 화면(왼쪽에 사이드바가 있는 화면)이 보입니다. 처음에는 준비 과정 때문에 2~3분 걸릴 수 있습니다.
16. 테마(화면 색)나 단축키 같은 첫 설정을 묻는 화면이 나오면, 바꾸지 않고 기본값 그대로 'Continue'(계속) 같은 버튼을 누릅니다. 브라우저 확장 프로그램 설치를 권하는 안내가 나와도 이 과정에서는 필요 없으니 나중으로 미룹니다.

✖ 로그인 버튼을 눌러도 인터넷 창이 안 열리면: AGY를 오른쪽 위 `X` 로 완전히 닫았다가 11번부터 다시 엽니다. 그래도 안 되면 PC의 기본 인터넷 창이 크롬이 아닐 수 있습니다. '시작' → '설정' → '앱' → '기본 앱'에서 'Google Chrome'을 찾아 '기본값 설정'을 누른 뒤 다시 합니다.

✖ 인터넷 창에서는 로그인이 끝났는데 AGY는 계속 로그인 화면이면: AGY를 완전히 닫고 다시 열어 봅니다. 사용자 포럼에도 같은 증상이 보고돼 있습니다. 두 번 해도 같으면 화면을 캡처해(C0 22강) 강사에게 보냅니다.

✖ "이 계정에서는 사용할 수 없습니다"와 비슷한 글이 뜨면: 학교·회사·기관이 관리하는 계정은 외부 앱을 막아 둔 경우가 많습니다. 개인 구글 계정으로 다시 로그인합니다.

**라. 확인하고 적기**

17. 설치 기록을 남깁니다. '시작' → '설정' → '앱' → '설치된 앱'을 열고, 위쪽 검색칸에 `Antigravity` 를 칩니다.
    → 이렇게 보이면 됩니다: 'Antigravity'가 목록에 있고, 이름 아래에 버전 숫자·게시자·날짜가 작은 글씨로 보입니다.
18. 종이에 세 줄을 적습니다: 앱 이름(보이는 그대로), 버전 숫자(보이는 그대로, 안 보이면 "안 보임"), 로그인한 계정이 개인 계정인지(예/아니오). 이메일 주소 전체는 적지 않아도 됩니다.
19. AGY를 오른쪽 위 `X` 로 닫고, 11번 방법으로 다시 열어 봅니다.
    → 이렇게 보이면 됩니다: 다시 로그인하라고 묻지 않고 바로 첫 화면이 나옵니다. 이것이 "로그인 상태가 유지된다"는 뜻입니다.

## AI에게 건네는 말

설치가 막혔을 때 씁니다. 아직 AGY가 열리지 않으니 제미나이 웹에 묻습니다. 휴대폰이 편하면 휴대폰 'Gemini' 앱에 같은 글을 보내도 됩니다.

> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
