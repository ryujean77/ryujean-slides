# 15강. 짧은 요청서로 한 페이지 만들기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

목적·기능·검사 기준을 적어 로컬 안내 페이지를 만든다.

## 먼저 이해하기

학습 사이트 제작 브리프의 ‘먼저 계획, 한 화면씩, 열어 확인’을 한 파일 실습으로 줄인다.

## 실제 기록에서 배운 한 줄

실제 대화에 브라우저 도구 오류가 보고되자 로컬 브라우저로 직접 여는 대안이 제시됐다. 이 수업은 사람이 파일을 열어 검사하는 방식을 사용하며 당시 대안의 성공까지 단정하지 않는다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. 14강의 검수 문장으로 제목·대상·준비물·미입력 일정을 보여 주는 페이지를 요청한다.
2. 계획을 승인한 뒤 외부 라이브러리 없이 하나의 HTML 파일로 만들게 한다.
3. 본인이 브라우저로 열어 문구와 글자 크기를 확인한다. 생성 중 막히면 9·12강 순서로 상태를 묻는다.

## AI에게 건네는 말

> 검수한 가상 모임 안내문으로 단일 HTML을 만들어 줘. 먼저 화면 구성과 확인 방법을 설명해 줘. 승인 뒤 한 파일만 만들고 외부 연결·게시 없이 브라우저로 읽게 해 줘.

## 손에 남길 것과 완료 확인

**모임 안내 HTML 1개**

목적·기능·검사 기준을 적어 로컬 안내 페이지를 만든다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
