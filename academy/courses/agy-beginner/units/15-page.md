# 15강. 짧은 요청서로 한 페이지 만들기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

14강에서 검수한 안내문으로, 크롬에서 열어 볼 수 있는 한 장짜리 안내 페이지(HTML 파일)를 만들고, 내가 정한 기준으로 직접 확인합니다.

## 먼저 이해하기

HTML(에이치티엠엘, 웹 페이지를 만드는 글 파일 형식)로 저장한 파일은 인터넷에 올리지 않아도 내 PC의 크롬에서 바로 열립니다. 주소창에는 `https://…` 대신 `file:///C:/…` 처럼 내 컴퓨터 안의 위치가 보입니다. 그래서 이 수업의 페이지는 나만 볼 수 있고, 어디에도 게시되지 않습니다.

한 페이지를 부탁할 때는 짧은 요청서에 세 가지를 적습니다.

| 칸 | 뜻 | 이번 예 |
| --- | --- | --- |
| 목적 | 누가 무엇을 하려고 보는가 | 성인 참가자가 모임 안내를 읽는다 |
| 담을 내용 | 화면에 무엇이 보여야 하나 | 제목, 대상, 준비물, 일정(미입력 표시) |
| 확인 기준 | 무엇을 보면 됐다고 할까 | 휴대폰 크기로 줄여도 글자가 읽힌다, 원문에 없는 날짜가 없다, 인터넷 연결 없이 열린다 |

"외부 라이브러리 없이"라는 조건도 넣습니다. 라이브러리(다른 사람이 만들어 인터넷에 올려 둔 기능 묶음)를 쓰면 인터넷이 끊겼을 때 화면이 깨질 수 있기 때문입니다.

순서는 늘 같습니다. 먼저 계획 → 한 파일만 만들기 → 내가 열어 확인.

## 실제 기록에서 배운 한 줄

실제 대화에서 브라우저 도구 오류가 보고되자, 만든 파일을 내 PC의 브라우저로 직접 여는 대안이 제시됐습니다. 이 수업은 AI의 확인 보고 대신 사람이 파일을 열어 검사하는 방식을 씁니다. 당시 대안이 성공했는지는 기록에 없어 단정하지 않습니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

준비: `practice` 폴더에 14강의 `(날짜)_모임안내_v02.md` 가 있는지 봅니다. 아래 글에서는 예시로 `20261010_모임안내_v02.md` 라고 썼으니, 내 파일 이름으로 바꿔 씁니다.

**1단계 — 요청서 세 칸 적기**

1. 메모장을 열고 위 표의 목적·담을 내용·확인 기준을 내 말로 적습니다.
2. 확인 기준은 눈으로 확인할 수 있는 것만 씁니다. "예쁘게"는 확인할 수 없으니 "글자가 크고 줄 간격이 넓다"처럼 바꿉니다.

**2단계 — 계획 먼저 받기**

1. AGY를 열고 모드를 'Planning'으로 둡니다(10강).
2. 아래 "AI에게 건네는 말"을 붙여 넣습니다. 괄호 부분에 1단계의 세 칸을 붙여 넣고 보냅니다.
3. 계획을 11강처럼 읽습니다. 만들 파일이 `moim_page.html` 하나인지, 게시·전송 단계가 없는지, 인터넷 주소(`https://…`)에서 무엇을 불러오는 단계가 없는지 봅니다.
4. 문제가 없으면 'Proceed'를 누릅니다. 있으면 "그 단계는 빼 줘"라고 먼저 보냅니다.

이렇게 보이면 됩니다: 왼쪽 파일 목록에 `moim_page.html` 이 생깁니다.

✖ 중간에 멈췄다면: 채팅에 확인 카드가 남아 있는지 먼저 보고(9강), 오류가 있으면 12강의 네 줄로 묻습니다.

**3단계 — 크롬으로 직접 열기**

1. 파일 탐색기(`Win + E`)에서 `my_work` → `practice` 로 들어갑니다.
2. `moim_page.html` 을 마우스 오른쪽 버튼으로 누르고 '연결 프로그램' → 'Google Chrome'을 누릅니다. 아이콘이 크롬 모양이면 더블클릭해도 됩니다.
3. 크롬이 열리면 주소창이 `file:///` 로 시작하는지 봅니다.

이렇게 보이면 됩니다: 크롬 화면에 모임 제목, 대상, 준비물, "일정: 미입력"이 보입니다.

✖ 글자 대신 `<html>` 같은 기호가 가득 보이면: 메모장으로 열린 것입니다. 2번의 '연결 프로그램' 방법으로 다시 엽니다.

**4단계 — 확인 기준으로 검사하기**

1. 원문 대조: 화면의 글을 14강 `_v02.md` 와 한 줄씩 비교합니다. 원문에 없는 날짜·장소·연락처가 있으면 틀린 것입니다.
2. 글자 크기: `Ctrl` 을 누른 채 `-` 를 두세 번 눌러 작게, `Ctrl + 0` 으로 원래대로 돌려 봅니다.
3. 휴대폰 크기: 크롬 창 오른쪽 가장자리를 마우스로 끌어 창을 좁게 만듭니다. 글이 화면 밖으로 잘리지 않는지 봅니다.
4. 인터넷 없이: 작업 표시줄 오른쪽 아래의 와이파이 모양을 눌러 잠깐 끈 뒤, 크롬에서 `F5`(새로 고침)를 누릅니다. 같은 화면이 나오면 통과입니다. 확인 뒤 와이파이를 다시 켭니다.
5. 틀린 곳이 있으면 한 곳만 골라 "moim_page.html 에서 (무엇)을 (어떻게) 고쳐 줘. 다른 곳은 바꾸지 마." 라고 보낸 뒤 `F5` 로 다시 확인합니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

> practice 폴더의 20261010_모임안내_v02.md 를 근거로 안내 페이지 하나를 만들려고 해. 요청서는 아래와 같아.
> 목적: (1단계에서 적은 것)
> 담을 내용: (1단계에서 적은 것)
> 확인 기준: (1단계에서 적은 것)
> 먼저 화면 구성과 내가 확인할 방법을 계획으로 보여 주고 승인을 기다려. 승인 뒤에는 외부 라이브러리나 인터넷 주소를 쓰지 않는 moim_page.html 파일 하나만 practice 폴더에 만들어 줘. 게시하거나 어디로 보내지 마. 원문에 없는 날짜·장소·연락처는 넣지 마.

답을 읽는 법: 계획에 "화면 구성"(위에서 아래로 무엇이 놓이는지)과 "확인 방법"이 둘 다 있는지 봅니다. 완료 보고가 와도 3·4단계를 내 손으로 합니다.

## 손에 남길 것과 완료 확인

**모임 안내 HTML 1개**

- `practice` 폴더의 `moim_page.html` 한 개
- 메모장의 요청서 세 칸과, 확인 기준마다 통과/실패 표시

완료 기준: 크롬 주소창이 `file:///` 로 시작하는 상태에서 페이지를 직접 열었고, 원문 대조·글자 크기·좁은 창·인터넷 없이 네 가지를 확인해 결과를 적었습니다. 실패한 항목은 실패로 적고, 고쳐 달라고 보낸 글을 함께 남깁니다.
