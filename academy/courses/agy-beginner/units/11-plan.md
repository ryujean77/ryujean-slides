# 11강. AI의 계획에서 과한 일을 덜어내기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

작업 계획을 읽고 필요한 단계만 구체적으로 승인한다.

## 먼저 이해하기

‘알아서 전부’ 대신 입력·출력·제외 범위·완료 기준을 확인한다.

## 실제 기록에서 배운 한 줄

실제 계획서 대화에서는 파일 작성 뒤 게시·저장소 작업을 별도 요청으로 이어 갔다. 한 번의 초안 요청에 후속 작업까지 묶지 않고 범위를 나누는 방식으로 대응했다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. 가상 계획 ‘안내문 생성 → 웹 게시 → 전체 폴더 정리’를 읽고 요청 범위를 벗어난 두 단계를 표시한다.
2. 안내문 새 파일 1개와 원문 대조만 남긴 계획을 받는다.
3. 승인 문장에 할 일과 멈출 지점을 적는다.

## AI에게 건네는 말

> 계획 중 새 안내문 파일 작성과 원문 대조만 승인해. 웹 게시와 기존 폴더 정리는 제외해. 결과 파일을 보여 주고 내 검수에서 멈춰 줘.

## 손에 남길 것과 완료 확인

**수정한 계획과 범위 승인문**

작업 계획을 읽고 필요한 단계만 구체적으로 승인한다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
