# 4강. 자료와 작업 약속은 한 번만 맛보기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

`practice` 폴더에 연습 자료 `memo.txt` 와 작업 약속 파일 `law.md`, 결과물을 모을 `deliverables` 폴더를 직접 만듭니다. 자료의 역할(원본·초안·기준본)을 한 줄로 적고, AGY가 약속 파일을 실제로 읽었는지 확인합니다.

## 먼저 이해하기

AI와 일할 때는 파일마다 역할이 있습니다. 오늘은 네 가지 말만 구별합니다.

| 말 | 뜻 | 오늘의 예 |
| --- | --- | --- |
| 원본 | 처음부터 있던 자료. AI가 고치면 안 되는 재료 | `memo.txt` |
| 초안 | AI나 내가 새로 만든, 아직 검수 전인 글 | 5강부터 AI가 만드는 안내문 |
| 기준본 | 사람이 검수를 마치고 "이것을 기준으로 삼는다"고 정한 판 | 이 과정 뒤쪽(14강)에서 정함 |
| 약속 파일 | AI에게 매번 지키라고 적어 둔 규칙 글 | `law.md` |

**결과물**(AI가 새로 만든 파일)은 한곳에 모읍니다. 오늘은 `practice` 안에 `deliverables`(결과물이라는 뜻의 영어) 폴더를 하나 만들어 그 자리를 정합니다. 실제 업무에서는 그 안에 `20260926_1500_meeting_practice` 처럼 날짜·시각·영어 주제 이름으로 폴더를 나누는데, 이 방법은 C2 자료관리론에서 자세히 배웁니다.

`law.md` 라는 이름의 파일을 두기만 하면 AI가 알아서 읽는 것은 아닙니다. 그래서 오늘은 "law.md를 읽어 줘"라고 분명히 말하고, 읽은 내용을 AI가 제대로 말하는지 확인합니다.

비유하자면 이렇습니다. 부엌에 새 도우미가 왔을 때, 냉장고 속 재료(원본)는 함부로 버리지 말라고 하고, 만든 반찬(결과물)은 정해 둔 선반에 올려 달라고 하고, 그 약속을 냉장고 문에 붙여 둡니다(약속 파일). 붙여 둔 뒤에는 "읽어 보셨어요?" 하고 한 번 물어봅니다.

자료 목록 확장·이름 규칙·기준본 운영·약속 파일 연결은 C2에서, 스킬(반복하는 일을 AI가 따라 할 절차서로 저장한 것) 제작은 C1+에서 배웁니다. 오늘은 맛보기입니다.

## 실제 기록에서 배운 한 줄

강사의 실제 작업 기록에는 여기저기 흩어진 결과물 폴더를 날짜·시각 규칙으로 한 번에 정리했다는 보고가 남아 있습니다. 처음부터 자리를 정했다면 필요 없던 일입니다. 이 수업은 그 운영 전체 대신, 재료와 결과물의 자리를 처음부터 나눠 두는 것만 해 봅니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

**가. 원본 자료 `memo.txt` 만들기**

1. PC에서 '시작' 단추를 누르고 `메모장` 이라고 쳐서 메모장을 엽니다.
   → 이렇게 보이면 됩니다: 빈 흰 창이 열립니다.
2. 아래 다섯 줄을 그대로 적습니다(복사해 붙여 넣어도 됩니다).

   ```
   가상 배움 모임 메모
   참가자는 성인
   실습은 종이로 진행
   준비물: 필기도구
   날짜: 미정
   ```

3. 메모장 위쪽 '파일' → '저장'을 누릅니다(또는 `Ctrl + S`).
   → 이렇게 보이면 됩니다: 저장할 곳을 고르는 창이 열립니다.
4. 창 왼쪽 목록에서 `practice` 를 누릅니다(C0 23강에서 고정해 두었습니다). 창 위쪽 경로 끝이 `practice` 인지 봅니다.
5. 아래쪽 '파일 이름' 칸에 `memo` 라고 쓰고 '저장'을 누릅니다. 확장명 `.txt` 는 메모장이 붙입니다.
   → 이렇게 보이면 됩니다: 메모장 창 위쪽 제목이 `memo.txt` 로 바뀝니다.

**나. 약속 파일 `law.md` 만들기**

6. 메모장 위쪽 '파일' → '새 탭'(또는 '새로 만들기')을 눌러 빈 문서를 엽니다.
7. 아래 네 줄을 적습니다.

   ```
   # 이번 연습의 약속

   1. 원본 memo.txt는 고치지 않는다.
   2. 자료에 없는 사실은 만들지 않고 "미입력"으로 남긴다.
   3. 새로 만드는 파일은 practice 안 deliverables 폴더에 저장한다.
   ```

8. '파일' → '다른 이름으로 저장'을 누르고, 저장할 곳이 `practice` 인지 봅니다.
9. 아래쪽 '파일 형식' 칸을 눌러 '모든 파일 (*.*)'로 바꿉니다. 이것을 바꾸지 않으면 `law.md.txt` 라는 엉뚱한 이름이 됩니다.
10. '파일 이름' 칸에 `law.md` 라고 쓰고 '저장'을 누릅니다.
    → 이렇게 보이면 됩니다: 메모장 제목이 `law.md` 로 바뀝니다.
11. 메모장을 닫습니다.

**다. 결과물 폴더 만들기와 확인**

12. `Windows 키 + E` 로 탐색기를 열고 `practice` 를 누릅니다.
13. 빈 곳에서 마우스 오른쪽 버튼 → '새로 만들기' → '폴더'를 누르고, 이름을 `deliverables` 로 씁니다.
    → 이렇게 보이면 됩니다: `practice` 안에 `deliverables` 폴더, `law.md`, `memo.txt`, 3강의 `today.md` 가 보입니다.

✖ `law.md.txt` 로 보이면: 파일을 한 번 누르고 `F2` 를 눌러 끝의 `.txt` 를 지우고 `Enter` 를 누릅니다. 확장명을 바꾸겠느냐고 물으면 '예'를 누릅니다. 확장명이 아예 안 보이면 C0 4강대로 '보기' → '표시' → '파일 이름 확장명'을 켭니다.

**라. 자료 1행 적기**

14. 종이에 아래 표를 그리고 한 줄을 채웁니다.

| 파일 이름 | 위치 | 쓰임 | 역할 |
| --- | --- | --- | --- |
| memo.txt | practice | 모임 안내문의 재료 | 원본 (고치지 않음) |

**마. AGY가 약속을 읽었는지 확인하기**

15. 아래 "AI에게 건네는 말"을 AGY에 보냅니다.
16. 답을 읽고, 7번에 적은 세 줄과 하나씩 맞춰 봅니다.
    → 이렇게 보이면 됩니다: 답에 "원본을 고치지 않는다", "없는 사실은 미입력", "deliverables에 저장" 세 가지가 내 글과 같은 뜻으로 적혀 있습니다.

✖ 내가 쓰지 않은 약속이 답에 섞여 있으면: AGY가 파일을 읽지 않고 짐작했을 수 있습니다. "law.md에 실제로 적힌 문장을 한 글자도 바꾸지 말고 그대로 옮겨 적어 줘" 라고 이어서 보냅니다.

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

보낼 글:

> practice 폴더의 law.md를 읽고, 적힌 약속 세 줄을 쉬운 말로 하나씩 설명해 줘. 파일을 새로 만들거나 고치지 말고, 다른 파일의 목록 정리도 하지 마. law.md를 읽지 못했다면 짐작하지 말고 못 읽었다고 알려 줘.

이 부탁은 읽기만 하는 일이라 파일을 쓰는 권한 창은 나오지 않는 것이 정상입니다. 파일을 만들거나 고치겠다는 권한 창이 뜨면 허용하지 말고, 입력칸에 "읽기만 해 줘" 라고 다시 보냅니다.

## 손에 남길 것과 완료 확인

**자료 1행과 작업 약속 3줄**

- □ `practice` 안에 `memo.txt`, `law.md`, `deliverables` 폴더가 있다(탐색기로 확인).
- □ `law.md` 가 `law.md.txt` 가 아니다.
- □ 종이에 `memo.txt` 의 이름·위치·쓰임·역할 한 줄을 적었다.
- □ AGY의 설명이 내가 적은 약속 세 줄과 같은 뜻이었다. 다르면 다른 부분을 적어 두었다.

`memo.txt` 는 5~8강에서 계속 쓰는 원본입니다. 앞으로 어떤 수업에서도 이 파일은 고치지 않습니다.
