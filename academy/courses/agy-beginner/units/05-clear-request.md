# 5강. 막연한 부탁을 좋은 요청으로 바꾸기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

같은 요청을 세 번 고쳐 결과의 차이를 확인한다.

## 먼저 이해하기

누가·무엇을·어떤 형식·어떤 조건의 네 요소를 넣는다. ‘잘해 줘’ 대신 눈으로 확인할 기준을 쓴다.

| 요청 | 무엇을 확인할까요? |
| --- | --- |
| 모임 계획 잘 써 줘 | 대상·형식·자료 범위가 빠져 있다 |
| 성인 모임 안내를 3행 표로 써 줘 | 대상과 형식은 있지만 근거·제약이 빠져 있다 |
| 제공 메모만 사용해 목적·대상·준비물 3행 표로 쓰고 없는 정보는 미입력으로 남겨 줘 | 결과를 원문과 대조할 수 있다 |

## 실제 기록에서 배운 한 줄

실제 계획서 대화에서는 초안 보고 뒤 사용자가 파일로 만들어 달라고 다시 요청했다. 말로 나온 결과와 원하는 파일 형식을 처음부터 구별하는 계기로 삼는다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. 첫 요청 ‘모임 계획 잘 써 줘’에 무엇이 빠졌는지 표시한다.
2. 둘째 요청에 대상과 3행 표 형식을 넣는다.
3. 셋째 요청에 제공 메모만 사용하고 날짜는 지어내지 말라는 조건을 추가해 결과를 비교한다.

## AI에게 건네는 말

> 가상의 성인 배움 모임 참가자에게 보여 줄 안내 초안을 써 줘. 제공 메모만 사용하고 목적·대상·준비물의 3행 표로 만들어 줘. 없는 일정은 미입력으로 남겨 줘.

## 손에 남길 것과 완료 확인

**요청 3판과 비교 메모**

같은 요청을 세 번 고쳐 결과의 차이를 확인한다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
