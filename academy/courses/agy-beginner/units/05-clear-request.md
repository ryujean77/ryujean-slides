# 5강. 막연한 부탁을 좋은 요청으로 바꾸기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

같은 부탁을 세 번 고쳐 AGY에 보내고, 세 답이 어떻게 달라지는지 비교합니다. 마지막 요청은 결과를 원본 `memo.txt` 와 한 줄씩 맞춰 볼 수 있을 만큼 구체적으로 씁니다.

## 먼저 이해하기

좋은 요청(프롬프트, AI에게 보내는 요청 글)에는 네 가지가 들어갑니다.

| 요소 | 묻는 것 | 예 |
| --- | --- | --- |
| 누구를 위해 | 이 글을 읽을 사람은? | 성인 참가자 |
| 무엇을 | 무엇을 만들까? | 모임 안내 초안 |
| 어떤 형식으로 | 어떤 모양으로? | 목적·대상·준비물 3행 표 |
| 어떤 조건으로 | 지켜야 할 것은? | `memo.txt` 만 사용, 없는 정보는 "미입력" |

"잘해 줘", "깔끔하게" 같은 말은 눈으로 확인할 수 없습니다. 대신 "3행 표", "`memo.txt` 에 있는 내용만"처럼 결과를 보고 맞았는지 틀렸는지 판단할 수 있는 기준을 씁니다.

| 요청 | 무엇이 빠졌나 |
| --- | --- |
| ① 모임 계획 잘 써 줘 | 대상·형식·자료 범위가 모두 빠져 있다 |
| ② 성인 모임 안내를 3행 표로 써 줘 | 대상과 형식은 있지만, 무엇을 근거로 쓸지와 지킬 조건이 빠져 있다 |
| ③ memo.txt만 사용해 목적·대상·준비물 3행 표로 쓰고, 없는 정보는 미입력으로 남겨 줘 | 결과를 원문과 한 줄씩 대조할 수 있다 |

비유하자면 택시 기사에게 "좋은 데로 가 주세요"라고 하는 것과 "시청역 3번 출구 앞에 내려 주세요"라고 하는 것의 차이입니다. 앞의 말로는 도착해도 맞게 왔는지 알 수 없습니다.

## 실제 기록에서 배운 한 줄

실제 계획서 대화에서 AI가 초안을 대화창에 글로 보고하자, 사용자는 "파일로 만들어 달라"고 다시 부탁해야 했습니다. 원하는 결과가 "대화 속 글"인지 "파일"인지를 처음 요청에 적었다면 한 번에 끝났을 일입니다. 오늘은 결과를 "대화 속 답으로만" 받는다고 정하고 시작합니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다. 준비물: 4강에서 만든 `practice\memo.txt`, 1강의 종이.

**가. 첫 번째 요청 보내기**

1. AGY를 열고, 왼쪽 사이드바에서 3강의 프로젝트가 선택돼 있는지 봅니다.
2. 새 대화를 엽니다. 키보드로 `Ctrl + N` 을 누릅니다(공식 단축키: 새 대화).
   → 이렇게 보이면 됩니다: 대화 영역이 비고, 아래쪽 채팅 입력칸만 남습니다.
3. 입력칸에 ①번 문장 `모임 계획 잘 써 줘` 를 그대로 쓰고 보냅니다.
4. 파일을 만들겠다는 권한 창이 뜨면 이번에는 허용하지 않습니다(허용하지 않는 쪽 버튼을 누릅니다). 오늘은 답만 받습니다.
5. 답을 끝까지 읽고, 종이에 "① 답에서 memo.txt에 없는 내용"을 모두 적습니다.
   → 이렇게 보이면 됩니다: 날짜·장소·목적처럼 내가 준 적 없는 내용이 들어 있을 가능성이 큽니다. 이것이 막연한 요청의 결과입니다.

**나. 두 번째 요청 보내기**

6. `Ctrl + N` 으로 새 대화를 엽니다. 앞 대화의 영향을 받지 않게 하기 위해서입니다.
7. ②번 문장 `성인 모임 안내를 3행 표로 써 줘. 파일은 만들지 말고 답으로만 보여 줘.` 를 보냅니다.
8. 답을 읽고, 종이에 "② 답에서 memo.txt에 없는 내용"을 적습니다.
   → 이렇게 보이면 됩니다: 표 모양은 맞지만, 칸을 채우려고 지어낸 내용이 아직 섞여 있을 수 있습니다.

**다. 세 번째 요청 보내기**

9. `Ctrl + N` 으로 새 대화를 엽니다.
10. 아래 "AI에게 건네는 말"의 글(③번 요청)을 보냅니다.
11. 답을 `memo.txt` 와 한 줄씩 맞춰 봅니다. 탐색기에서 `memo.txt` 를 오른쪽 클릭 → '연결 프로그램' → '메모장'으로 열어 옆에 둡니다.
    → 이렇게 보이면 됩니다: 대상 칸은 "성인", 준비물 칸은 "필기도구", 목적 칸은 "미입력"입니다. `memo.txt` 에는 목적이 적혀 있지 않기 때문입니다.
12. 메모장은 아무것도 고치지 않고 닫습니다. 원본이기 때문입니다.

✖ ③의 답에도 목적이 그럴듯하게 채워져 있으면: 같은 대화 입력칸에 "목적은 memo.txt 어느 줄에 있어? 없으면 미입력으로 바꿔 줘" 라고 보냅니다. 이런 일은 8강에서 자세히 다룹니다.

**라. 비교 메모 쓰기**

13. 종이에 세 줄을 적습니다: ①·②·③ 각각의 답에서 지어낸 내용이 몇 개였는지.
14. 한 줄을 더 적습니다: "③이 나았던 이유는 ○○을 넣었기 때문이다." (예: 자료 범위, 없는 정보 처리 방법)

✖ 권한 창이 무엇을 묻는지 모르겠으면: 아무것도 누르지 말고 그 창을 캡처해 두었다가 9강에서 함께 읽습니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

보낼 글 (③번 요청):

> 가상의 성인 배움 모임 참가자에게 보여 줄 안내 초안을 써 줘. practice 폴더의 memo.txt에 적힌 내용만 사용하고, 목적·대상·준비물 세 줄의 표로 만들어 줘. memo.txt에 없는 정보는 지어내지 말고 "미입력"으로 남겨 줘. 파일은 만들지 말고 대화 속 답으로만 보여 줘.

답은 입력칸 위쪽 대화 영역에 나타납니다. 표의 칸마다 `memo.txt` 의 어느 줄에서 왔는지 떠올리며 읽습니다.

## 손에 남길 것과 완료 확인

**요청 3판과 비교 메모**

- □ 세 요청을 각각 새 대화(`Ctrl + N`)에서 보냈다.
- □ 종이에 ①·②·③ 답에서 지어낸 내용의 개수를 적었다.
- □ ③의 표가 `memo.txt` 와 맞았다(대상 성인, 준비물 필기도구, 목적 미입력). 맞지 않았다면 틀린 칸을 적었다.
- □ "③이 나았던 이유" 한 줄을 적었다.
- □ `memo.txt` 는 고치지 않았다.
