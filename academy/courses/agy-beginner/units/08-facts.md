# 8강. 없는 사실을 채우지 못하게 하기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

일부러 틀린 문장이 섞인 초안을 원본 `memo.txt` 와 대조해, 근거가 있는 문장·원문과 다른 문장·원문에 없는 문장을 나눕니다. AGY의 대조 결과를 그대로 믿지 않고, 마지막 판단은 내가 적습니다.

## 먼저 이해하기

AI는 빈칸을 싫어합니다. 자료에 없는 날짜·대상·숫자를 그럴듯하게 채워 넣는 일이 자주 있습니다. 이런 지어낸 내용을 흔히 환각(AI가 사실이 아닌 것을 사실처럼 말하는 현상)이라고 부릅니다.

그래서 초안의 문장마다 **근거**(그 문장이 원본의 어느 줄에서 왔는지)를 따집니다.

| 분류 | 뜻 | 할 일 |
| --- | --- | --- |
| 근거 있음 | 원본에 같은 내용이 있다 | 그대로 둔다 |
| 원문과 다름 | 원본에 있지만 내용이 바뀌었다 | 원본대로 고친다 |
| 원문에 없음 | 원본 어디에도 없다 | 지우거나 "미입력"으로 바꾼다 |

자료가 부족할 때 "모름", "미입력"으로 남기는 것은 실패가 아니라 올바른 결과입니다. 4강에서 `law.md` 에 적은 두 번째 약속이 바로 이것입니다. 또 이 과정의 모임·이름은 모두 가상 설정입니다. 가상 설정을 실제 사실처럼 쓰지 않는 것도 같은 원칙입니다.

비유하자면 교정 담당자가 신문 기사를 취재 수첩과 한 줄씩 맞춰 보는 일입니다. 수첩에 없는 숫자는 아무리 그럴듯해도 기사에 싣지 않습니다.

## 실제 기록에서 배운 한 줄

실제 대화에서 AI는 자료를 읽지 못하자 가상의 요구사항을 만들어 작업을 계속했고, 사용자가 이를 중간에 멈추게 했습니다. 그 뒤 읽을 수 있는 원문 사본을 구해 "원문대로 다시 써 달라"고 요청했습니다. 오늘은 멈추게 하는 눈, 곧 대조하는 습관을 연습합니다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

**가. 틀린 문장이 섞인 초안 만들기**

1. '시작' → `메모장` 으로 메모장을 엽니다.
2. 아래 세 문장을 그대로 적습니다. 강사가 일부러 틀린 곳 두 개를 넣어 둔 연습용 초안입니다.

   ```
   이 모임은 어린이 대상입니다.
   모임은 10월 1일에 열립니다.
   실습은 종이로 합니다.
   ```

3. '파일' → '저장'을 누르고, 저장할 곳을 `practice` 안 `deliverables` 폴더로 고릅니다. '파일 이름' 칸에 `draft_test` 라고 쓰고 '저장'을 누릅니다.
   → 이렇게 보이면 됩니다: 메모장 제목이 `draft_test.txt` 로 바뀝니다. 메모장을 닫습니다.

**나. 내가 먼저 찾아보기**

4. 탐색기에서 `practice\memo.txt` 를 메모장으로 엽니다(오른쪽 클릭 → '연결 프로그램' → '메모장'). "참가자는 성인", "실습은 종이로 진행", "날짜: 미정"을 확인하고, 고치지 않고 닫습니다.
5. 종이에 초안 세 문장을 적고, 각 문장 옆에 '근거 있음' / '원문과 다름' / '원문에 없음' 중 하나를 내 판단으로 먼저 적습니다.
   → 이렇게 보이면 됩니다: "어린이 대상"은 원문과 다름(원본은 성인), "10월 1일"은 원문에 없음(원본은 날짜 미정), "종이로 합니다"는 근거 있음.

**다. AGY에게 대조시키기**

6. AGY를 열고 `Ctrl + N` 으로 새 대화를 엽니다.
7. 아래 "AI에게 건네는 말"의 글을 보냅니다.
   → 이렇게 보이면 됩니다: 답에 세 문장이 세 분류로 나뉘어 나오고, 문장마다 `memo.txt` 의 어느 줄이 근거인지 적혀 있습니다.
8. AGY의 분류를 5번의 내 판단과 나란히 적습니다. 같으면 ○, 다르면 ×를 표시합니다.
9. ×가 있으면 `memo.txt` 를 다시 열어 누구 판단이 맞는지 봅니다. 최종 판단 칸은 내가 원본을 보고 채웁니다.

✖ AGY가 "10월 1일"을 근거 있음으로 분류하거나, 고친 초안에 새 날짜를 넣으면: 입력칸에 "그 날짜는 memo.txt의 몇째 줄에 있어? 없으면 미입력으로 바꿔 줘" 라고 보냅니다.

✖ AGY가 `draft_test.txt` 를 바로 고치겠다는 권한 창을 띄우면: 이번에는 허용하지 않습니다. 오늘은 분류만 받고, 고치는 일은 13강(되돌리기)과 14강(초안 수정)에서 합니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

보낼 글:

> practice 폴더의 memo.txt를 원문으로, deliverables 폴더의 draft_test.txt를 초안으로 삼아 비교해 줘. 초안의 문장을 하나씩 "근거 있음 / 원문과 다름 / 원문에 없음"으로 나누고, 문장마다 원문의 어느 줄이 근거인지 적어 줘. 원문에 없는 날짜·대상·숫자를 새로 만들지 말고, 두 파일 모두 고치지 마.

답은 입력칸 위쪽 대화 영역에 나타납니다. 분류마다 근거 줄이 적혀 있는지 보고, 근거 줄이 없는 판단은 믿지 않습니다.

## 손에 남길 것과 완료 확인

**근거 대조표와 오류 2개**

- □ `practice\deliverables\draft_test.txt` 를 만들었다.
- □ AGY에게 묻기 전에, 세 문장을 내 판단으로 먼저 분류했다.
- □ 틀린 곳 두 개("어린이 대상", "10월 1일")를 찾았고, 각각 원본의 어느 줄과 다른지 적었다.
- □ AGY의 분류와 내 판단을 ○·×로 비교했고, 최종 판단은 원본을 보고 내가 채웠다.
- □ `memo.txt` 와 `draft_test.txt` 는 고치지 않았다.

오류를 두 개 다 찾지 못했다면 성공으로 적지 않고, 찾지 못한 문장을 적어 둡니다. 5~8강에서 만든 종이들은 9강부터 권한과 계획을 읽을 때 다시 씁니다.
