# 3강. 연습 폴더를 열고 첫 파일 받기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

C0 23강에서 만든 빈 `practice` 폴더 하나를 AGY에 작업 폴더로 연결하고, AGY에게 첫 파일 `today.md` 를 만들게 합니다. 그 파일을 파일 탐색기에서 내 눈으로 찾아 열고, AGY를 껐다 켠 뒤에도 다시 찾습니다.

## 먼저 이해하기

**작업 폴더**(AI가 읽고 쓸 수 있게 열어 둔 폴더)는 AGY의 작업대입니다. AGY는 이 폴더 안에서만 파일을 읽고 만들게 하는 것이 기본 안전장치입니다. 그래서 바탕화면 전체나 C 드라이브 전체가 아니라, 비어 있는 `practice` 폴더 하나만 줍니다.

**프로젝트**(AGY 안에서 작업 폴더에 붙이는 이름표 겸 묶음)를 하나 만들고, 그 안에 폴더를 넣습니다. 공식 안내의 순서는 이렇습니다: 왼쪽 사이드바의 '+'가 붙은 폴더 아이콘 → 'New Project'(새 프로젝트) → 'Add Folder'(폴더 추가) → 'Create'(만들기).

**프롬프트**(AI에게 보내는 요청 글)는 화면 아래쪽 채팅 입력칸에 씁니다. 보내면 AGY가 작업 방식을 묻기도 합니다. 공식 안내에는 두 가지가 있습니다.

| 이름 | 뜻 | 이번 수업 |
| --- | --- | --- |
| Local Mode | 연결한 폴더의 파일을 그 자리에서 직접 만들고 고치는 방식 | 이것을 고릅니다 |
| New Worktree Mode | Git(파일의 변경 이력을 관리하는 도구)으로 따로 떼어 낸 사본에서 작업하는 방식 | 쓰지 않습니다 (10강·C1+) |

Local Mode는 진짜 폴더를 바로 바꿉니다. 그래서 연결한 폴더가 비어 있는 연습 폴더인지 먼저 확인하는 것이 중요합니다.

**`today.md` 는 어떤 파일인가요.** `.md` 는 마크다운(`#` 이나 `-` 같은 기호로 제목과 목록을 표시하는 간단한 글 파일)이라는 뜻의 확장자입니다. 메모장으로 열어 읽을 수 있습니다.

비유하자면 오늘은 이런 날입니다. **새 조수에게 빈 책상 하나를 내주고, 첫 쪽지 한 장을 받아 보는 날.** 쪽지를 받았다는 말만 믿지 않고, 책상 위에 정말 쪽지가 있는지 직접 봅니다.

공식 자료: [시작하기](https://antigravity.google/docs/getting-started). 파일 열기·저장이 아직 어렵다면 C0 3~4강을 먼저 복습합니다. (화면의 글자는 버전에 따라 조금 다를 수 있습니다.)

## 실제 기록에서 배운 한 줄

실제 대화에서 사용자는 "프로젝트"와 "폴더 선택"이 무엇을 말하는지 몰라 되물었습니다. 설명 대신 화면에 실제로 보이는 메뉴 이름을 하나씩 따라가자 진행이 됐고, 사용자가 "프로젝트에 폴더가 보인다"고 확인한 뒤에야 다음 단계로 갔습니다. 이 카드도 같은 방식으로, 누를 곳과 그다음 보일 화면을 한 단계씩 적습니다.

## 가상 예시로 직접 해 보기

준비물: 2강에서 설치하고 로그인한 AGY, C0 23강에서 만든 빈 `practice` 폴더.

**가. 연결할 폴더가 맞는지 먼저 보기**

1. PC에서 `Windows 키 + E` 로 파일 탐색기를 엽니다.
   → 이렇게 보이면 됩니다: 탐색기 왼쪽 목록에 C0 23강에서 고정한 `practice` 가 보입니다.
2. 왼쪽의 `practice` 를 한 번 누릅니다.
   → 이렇게 보이면 됩니다: 오른쪽이 텅 비어 있고 "이 폴더는 비어 있습니다" 같은 글이 보입니다.
3. 위쪽 주소 표시줄의 빈 곳을 한 번 누릅니다.
   → 이렇게 보이면 됩니다: 경로가 `C:\사용자\(내 계정 이름)\my_work\practice` 처럼 글자로 바뀝니다. `G:` 로 시작하거나 `OneDrive` 가 들어 있으면 멈추고 C0 23강 6번으로 돌아갑니다. (C3 업무 자동화에서는 드라이브 폴더를 일부러 여는 수업이 따로 있습니다. C1에서는 내 PC 폴더만 씁니다.)
4. 탐색기는 닫지 말고 둡니다. 11번에서 다시 씁니다.

**나. AGY에 프로젝트 만들고 폴더 넣기**

5. '시작' 단추를 누르고 `Antigravity` 를 쳐서 AGY를 엽니다.
   → 이렇게 보이면 됩니다: 로그인된 첫 화면이 나오고, 화면 왼쪽에 세로로 긴 사이드바(메뉴가 모인 띠)가 있습니다.
6. 왼쪽 사이드바에서 '+' 표시가 붙은 폴더 모양 아이콘을 찾아 누릅니다. 아이콘 위에 마우스를 잠시 올려 두면 이름이 작게 뜹니다.
   → 이렇게 보이면 됩니다: 작은 메뉴가 열리고 'New Project'가 보입니다.
7. 'New Project'를 누릅니다.
   → 이렇게 보이면 됩니다: 새 프로젝트를 만드는 창이 열리고 'Add Folder' 버튼이 보입니다.
8. 'Add Folder'를 누릅니다.
   → 이렇게 보이면 됩니다: 윈도우의 폴더 고르기 창(탐색기와 비슷하게 생긴 창)이 열립니다.
9. 그 창의 왼쪽 목록에서 `practice` 를 한 번 누릅니다. 왼쪽에 없으면 `my_work` 를 두 번 눌러 연 뒤 그 안의 `practice` 를 한 번 누릅니다. `practice` 안으로 들어가지 말고, 이름을 한 번 눌러 파랗게 선택만 합니다.
10. 창 아래쪽의 '폴더 선택' 버튼을 누릅니다.
    → 이렇게 보이면 됩니다: 폴더 고르기 창이 닫히고, 새 프로젝트 창에 `practice` 가 한 줄 들어가 있습니다.
11. 들어간 폴더가 `practice` 하나뿐인지 봅니다. 다른 폴더가 함께 들어갔다면 그 줄을 빼는 표시(보통 `X` 나 휴지통 모양)를 눌러 뺍니다.
12. 'Create'를 누릅니다.
    → 이렇게 보이면 됩니다: 왼쪽 사이드바에 새 프로젝트가 생기고, 그 안에 `practice` 가 보입니다.

✖ 이 폴더를 믿는지(신뢰하는지) 묻는 확인 창이 나오면: 창에 적힌 폴더 이름이 `practice` 인지 읽고, 맞으면 믿는다는 쪽 버튼을 누릅니다. 다른 폴더 이름이면 누르지 말고 창을 닫은 뒤 6번부터 다시 합니다.

✖ '+' 폴더 아이콘이 안 보이면: AGY 창이 작아서 사이드바가 접혔을 수 있습니다. 창 오른쪽 위의 네모(최대화) 버튼을 눌러 창을 크게 합니다. 그래도 없으면 화면을 캡처해 아래 "AI에게 건네는 말"과 함께 제미나이 웹에 묻습니다.

✖ 'Create'가 눌리지 않으면: 폴더가 아직 한 줄도 들어가지 않은 것입니다. 8번부터 다시 합니다.

**다. 첫 파일 만들게 하기**

13. 왼쪽 사이드바에서 방금 만든 프로젝트를 한 번 누릅니다.
    → 이렇게 보이면 됩니다: 화면 아래쪽에 글을 쓰는 긴 채팅 입력칸이 보입니다.
14. 아래 "AI에게 건네는 말"의 글을 복사(`Ctrl + C`)해 채팅 입력칸을 한 번 누르고 붙여 넣습니다(`Ctrl + V`).
15. `Enter` 를 누릅니다.
16. 작업 방식을 고르라는 선택지가 나오면 'Local Mode'를 누릅니다. 계획 먼저(Planning)와 바로 실행(Fast) 중 고르라고 하면 'Planning'을 고릅니다(자세한 차이는 10강).
    → 이렇게 보이면 됩니다: 입력칸 위쪽 대화 영역에 AGY의 답이나 계획이 한 줄씩 나타납니다.
17. 파일을 만들어도 되는지 묻는 확인 창(권한 요청)이 나오면, 바로 누르지 말고 두 가지를 읽습니다. 만들 파일 이름이 `today.md` 인가? 위치가 `practice` 안인가? 둘 다 맞으면 허용 버튼을 누릅니다. 다른 폴더나 다른 파일이 적혀 있으면 허용하지 않고, 입력칸에 "practice 폴더의 today.md 하나만 만들어 줘" 라고 다시 보냅니다(권한 창 읽는 법은 9강).
18. AGY가 끝났다고 답하면, 답에 적힌 파일 이름을 읽습니다.
    → 이렇게 보이면 됩니다: 답에 `today.md` 라는 이름과 두 항목이 적혀 있습니다.

**라. 내 눈으로 확인하기**

19. 4번에서 열어 둔 파일 탐색기로 갑니다(작업 표시줄에서 탐색기 아이콘을 누릅니다). `practice` 폴더 화면에서 `F5` 를 눌러 새로 고칩니다.
    → 이렇게 보이면 됩니다: 비어 있던 `practice` 에 `today.md` 가 한 개 보입니다.
20. `today.md` 를 마우스 오른쪽 버튼으로 누르고 '연결 프로그램' → '메모장'을 누릅니다.
    → 이렇게 보이면 됩니다: 메모장이 열리고 "안내문 초안 쓰기", "내용 확인하기" 두 줄이 보입니다. 앞에 `-` 나 `#` 같은 기호가 붙어 있어도 정상입니다(마크다운 표시).
21. 메모장을 오른쪽 위 `X` 로 닫습니다. 아무것도 고치지 않았으니 저장을 묻지 않습니다.

✖ AGY는 만들었다고 하는데 탐색기에 파일이 없으면: 성공으로 적지 않습니다. 먼저 `F5` 를 한 번 더 누릅니다. 그래도 없으면 AGY 입력칸에 "today.md를 어느 폴더에 저장했는지 전체 경로를 알려 줘" 라고 보내고, 그 경로를 3번의 경로와 비교합니다. 다르면 12번에서 다른 폴더를 연결한 것입니다.

✖ 파일 이름이 `today` 로만 보이면: 확장명이 숨겨진 상태입니다. C0 4강대로 탐색기 '보기' → '표시' → '파일 이름 확장명'을 켭니다.

**마. 껐다 켜도 남아 있는지 보기**

22. AGY를 오른쪽 위 `X` 로 닫습니다.
23. '시작' → `Antigravity` 로 다시 엽니다.
    → 이렇게 보이면 됩니다: 왼쪽 사이드바에 오늘 만든 프로젝트와 `practice` 가 그대로 있습니다.
24. 탐색기에서도 `practice` 안의 `today.md` 가 그대로 있는지 봅니다.
25. 종이에 적습니다: 연결한 폴더 경로(3번에서 본 그대로, 내 이름 부분은 ○○○로 가려도 됨), 만든 파일 이름, 다시 열었을 때 있었는지(예/아니오).

## AI에게 건네는 말

> **어디에 입력하나요:** 바탕화면이나 시작 메뉴에서 'Antigravity'를 눌러 AGY를 엽니다. 작업 폴더가 열려 있는지 먼저 봅니다(C1 3강). 화면 아래쪽의 채팅 입력칸(에이전트에게 말을 거는 칸)을 누르고, 아래 글을 붙여 넣은 뒤 `Enter` 로 보냅니다. AGY가 대화 안에 계획이나 확인 카드를 먼저 보여 주면, 바로 승인하지 말고 무엇을 하겠다는지 읽은 뒤 결정합니다(C1 9강).

보낼 글:

> 연결된 practice 폴더 안에 today.md 파일 하나를 만들어 줘. 내용은 "안내문 초안 쓰기"와 "내용 확인하기" 두 항목의 목록이야. 다 만들면 저장한 파일 이름과 폴더 위치를 알려 줘. 다른 폴더는 추가하지 말고, 다른 파일도 만들지 마.

답은 입력칸 위쪽 대화 영역에 나타납니다. 끝까지 읽고, 파일 이름과 위치가 적혀 있는지 봅니다. 모르는 말이 나오면 같은 입력칸에 "○○가 무슨 뜻이야? 쉬운 말로 알려 줘" 라고 이어서 보냅니다.

## 손에 남길 것과 완료 확인

**today.md와 다시 열기 기록**

- □ AGY 프로젝트에 연결된 폴더가 `practice` 하나뿐이다.
- □ 파일 권한 창이 나왔다면, 파일 이름과 위치를 읽은 뒤 허용했다.
- □ 탐색기에서 `practice\today.md` 를 찾아 메모장으로 열고 두 줄을 읽었다.
- □ AGY를 껐다 켠 뒤에도 프로젝트와 파일이 그대로 있었다.
- □ 종이에 경로·파일 이름·다시 열기 결과 세 줄을 적었다.

AGY의 "만들었습니다"라는 말은 확인이 아닙니다. 탐색기에서 파일을 직접 열어 본 것만 완료로 적습니다. 막힌 칸은 번호와 화면의 글자를 그대로 적어 둡니다.
