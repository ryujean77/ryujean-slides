# 3강. 연습 폴더를 열고 첫 파일 받기

유정근 · 마이웨이 아카데미 | C1 AGY 입문

## 오늘의 목표

폴더 하나를 프로젝트에 연결하고 생성 파일을 다시 연다.

## 먼저 이해하기

C0에서 준비한 폴더를 AGY에 연결하는 데만 집중한다. 저장·확장자·클라우드 기초는 C0에서 복습한다.

공식 자료: [프로젝트 시작](https://antigravity.google/docs/getting-started). 파일 열기·저장 자체가 어렵다면 C0 컴퓨터 왕기초에서 먼저 연습합니다.

## 실제 기록에서 배운 한 줄

실제 대화에서 프로젝트와 폴더 선택을 몰라 되물었고, 화면에 표시된 메뉴를 기준으로 진행한 뒤 사용자가 프로젝트에 폴더가 보인다고 확인했다.

## 가상 예시로 직접 해 보기

아래 모임·자료·파일 이름은 학습용 가상 설정입니다. 실제 고객 자료나 이력을 넣지 않습니다.

1. C0에서 만든 빈 practice 폴더를 탐색기로 연다. 어렵다면 C0 파일·폴더 수업을 먼저 복습한다.
2. New Project → Add Folder → Create로 그 폴더 하나를 연결한다. Local Mode는 연결한 폴더에서 직접 작업하는 방식이므로 연습 폴더인지 확인한다.
3. today.md에 ‘안내문 초안 쓰기, 내용 확인하기’ 두 항목을 만들게 한다. 앱을 닫았다 다시 열어 같은 파일을 찾는다.

## AI에게 건네는 말

> 연결된 practice 폴더에 today.md를 만들어 줘. 내용은 안내문 초안 쓰기와 내용 확인하기 두 항목이야. 저장한 파일명을 알려 줘. 다른 폴더는 추가하지 마.

## 손에 남길 것과 완료 확인

**today.md와 다시 열기 기록**

폴더 하나를 프로젝트에 연결하고 생성 파일을 다시 연다. 이 행동을 직접 수행했는지 확인합니다. 결과 파일이 있는 수업은 파일을 열어 확인하고, 판단 수업은 선택한 이유를 한 문장으로 적습니다. 하지 못한 단계는 성공한 것처럼 기록하지 않고 보완할 행동을 남깁니다.
