# 14강. 시스템 구축 ⑩: 사람 승인과 실행 로그

유정근 · 마이웨이 아카데미 | C4 단일 강좌

## 오늘의 목표

Human-in-the-loop 승인·반려 단계와 처리 이력 기록. 산출물 ⑦ 실행 가능한 업무 프로세스 완성

## 왜 이 단계가 필요한가

AI가 다음 단계를 제안해도 최종 승인과 반려는 사람이 남깁니다.

## 따라 하기

1. 검토 화면에 승인·반려 버튼과 이유 입력칸을 둡니다.
2. 실행 로그에 시간·자료 ID·단계·사람의 판단을 기록합니다.
3. 샘플 1건을 승인, 1건을 반려해 산출물 대기 상태가 맞는지 확인합니다.

## 실행 로그 한 줄의 형태

`시각 | 가상 자료 ID | 이전 상태 | 새 상태 | 승인/반려 이유`

같은 자료를 승인하고 다시 열어 봅니다. 누가 왜 승인했는지 읽을 수 있어야 다음 단계인 산출물 생성으로 보냅니다.


## AI에게 건네는 말

> 업무 흐름에 사람 승인 단계를 넣어 줘. 승인 또는 반려 전에는 산출물을 확정하지 마. 두 동작 모두 시간·자료 id·이유를 로그에 남기고 자동 삭제는 하지 마.

AI의 완료 보고만 믿지 말고 화면·파일·저장 결과를 직접 확인합니다.

## 완료 확인

- [ ] 산출물 ⑦ 실행 가능한 흐름에서 승인·반려를 시연한다
- [ ] 두 결정의 로그가 남는다

이 과정의 예시 자료는 모두 학습용 가상 자료입니다. 실제 고객 기록·연락처·비밀번호를 공개 AI나 시연본에 넣지 않습니다.
