# 16강. 시스템 구축 ⑫: AI 초안 생성·검수

유정근 · 마이웨이 아카데미 | C4 단일 강좌

## 오늘의 목표

프롬프트 템플릿과 구조화 출력으로 초안을 만들고 근거·검토자·승인 상태 확인. 산출물 ⑧ 근거 표시 문서 1건 완성

## 왜 이 단계가 필요한가

AI가 만든 문장은 초안입니다. 원본과 대조하고 사람이 승인한 뒤에 산출물이 됩니다.

## 따라 하기

1. 지식 카드 1~2건의 비식별 내용만 AI에 건네 초안을 받습니다.
2. 원본에 없는 문장을 표시하고 수정·삭제합니다.
3. 출처·검토자·승인 상태를 채운 뒤 `.md` 파일로 내보냅니다.

## 산출물 최소 양식

```markdown
# 문서 제목
상태: 초안 / 승인
검토자: 본인
근거 카드: K01, K02
작성일: YYYY-MM-DD

## 요약
## 본문
## 확인 필요
```

AI가 `확인 필요`를 비워 두더라도 원본을 열어 대조합니다. 승인 전 파일은 최종본으로 부르지 않습니다.


## AI에게 건네는 말

> 아래 지식 카드 내용만 근거로 문서 템플릿을 채워 줘. 카드에 없는 사실은 `확인 필요`로 표시해 줘. 출처 카드 id를 문장 옆에 적고 승인 상태는 `초안`으로 남겨 줘.

AI의 완료 보고만 믿지 말고 화면·파일·저장 결과를 직접 확인합니다.

## 완료 확인

- [ ] 산출물 ⑧ 근거 표시 문서 1건이 저장된다
- [ ] 원본에 없는 주장은 확정 사실로 남지 않는다

이 과정의 예시 자료는 모두 학습용 가상 자료입니다. 실제 고객 기록·연락처·비밀번호를 공개 AI나 시연본에 넣지 않습니다.
