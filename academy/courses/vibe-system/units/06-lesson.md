# 6강. 시스템 구축 ②: Inbox 입력 화면

유정근 · 마이웨이 아카데미 | C4 단일 강좌

## 오늘의 목표

제목·유입일·원본 위치·상태 입력과 재조회. 산출물 ③ Inbox 화면 완성

## 왜 이 단계가 필요한가

Inbox는 아직 처리되지 않은 자료의 접수대입니다. 첫 기능은 파일 자체보다 자료의 메타데이터를 안전하게 기록하는 것입니다.

## 따라 하기

1. 제목·유입일·원본 위치·상태 입력칸을 추가합니다.
2. 샘플 1건을 등록하고 페이지를 새로고침한 뒤 다시 찾습니다.
3. 빈 제목을 저장하려 하면 안내가 나오는지 확인합니다.

## 첫 입력 예시

학습용 가상 자료 `가상_강의안_v01`을 등록합니다. 제목은 `가상 강의안`, 유입일은 오늘 날짜, 상태는 `신규`, 원본 위치는 `연습 자료`로 둡니다. 새로고침 뒤 목록에 다시 나타나면 저장 기능이 작동합니다. 안 보이면 브라우저 개발자 도구의 오류 메시지를 AI 코딩 도구에 그대로 전달해 원인을 찾습니다.


## AI에게 건네는 말

> 기존 프로젝트에 Inbox 등록만 추가해 줘. 브라우저 localStorage에 메타데이터를 저장하고 파일 내용이나 경로의 실제 파일은 업로드하지 마. 제목 필수 검증과 등록 목록을 만들고, 저장 후 새로고침해도 유지되게 해 줘.

AI의 완료 보고만 믿지 말고 화면·파일·저장 결과를 직접 확인합니다.

## 완료 확인

- [ ] 산출물 ③ Inbox 화면에서 샘플 1건 등록·재조회가 된다
- [ ] 빈 제목은 저장되지 않는다

이 과정의 예시 자료는 모두 학습용 가상 자료입니다. 실제 고객 기록·연락처·비밀번호를 공개 AI나 시연본에 넣지 않습니다.
