# 7강. 시스템 구축 ③: 메타데이터·분류 기준

유정근 · 마이웨이 아카데미 | C4 단일 강좌

## 오늘의 목표

유형·태그·민감도·중복 여부 메타데이터와 AI 분류 기준 설정

## 왜 이 단계가 필요한가

분류를 AI가 제안하더라도 어떤 근거로 분류했는지 사람이 확인할 수 있어야 합니다.

## 따라 하기

1. Inbox 항목에 유형·태그·민감도·중복 의심 칸을 정의합니다.
2. 가상 자료 3건을 서로 다른 유형으로 입력합니다.
3. AI 분류 제안은 실제 값과 구별해 `제안` 표시로만 보여 주도록 요청합니다.

## AI에게 건네는 말

> Inbox 메타데이터에 type, tags, sensitivity, duplicateHint를 추가해 줘. AI 분류는 결정이 아닌 제안으로 표시하고, 확정 버튼을 누르기 전에는 보관 상태로 이동하지 않게 해 줘.

AI의 완료 보고만 믿지 말고 화면·파일·저장 결과를 직접 확인합니다.

## 완료 확인

- [ ] 샘플 3건의 분류 항목이 구별된다
- [ ] 제안과 확정 상태가 다르게 보인다

이 과정의 예시 자료는 모두 학습용 가상 자료입니다. 실제 고객 기록·연락처·비밀번호를 공개 AI나 시연본에 넣지 않습니다.
