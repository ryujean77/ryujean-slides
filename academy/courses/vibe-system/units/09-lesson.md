# 9강. 시스템 구축 ⑤: 출처가 보이는 지식 카드

유정근 · 마이웨이 아카데미 | C4 단일 강좌

## 오늘의 목표

승인 자료를 Markdown 카드로 등록하고 원본 출처·버전·태그 연결

## 왜 이 단계가 필요한가

지식저장소에는 검토가 끝난 자료만 들어갑니다. 검색 결과가 원본으로 되돌아갈 수 있어야 합니다.

## 따라 하기

1. 보관된 항목 하나를 선택해 제목·요약·출처·버전·태그를 가진 지식 카드로 만듭니다.
2. 원본 링크 또는 로컬 위치는 개인용 화면에만 보이도록 표시합니다.
3. 가상 자료 카드 3개를 만들고 각 카드의 출처를 확인합니다.

## AI에게 건네는 말

> 보관 상태의 Inbox 항목만 지식 카드로 옮기는 기능을 추가해 줘. 원본 출처·버전·태그를 필수 항목으로 두고, 공개용 데이터에는 개인 로컬 경로가 들어가지 않게 분리해 줘.

AI의 완료 보고만 믿지 말고 화면·파일·저장 결과를 직접 확인합니다.

## 완료 확인

- [ ] 지식 카드 3개에 출처가 있다
- [ ] 신규 상태 항목은 지식 카드로 옮겨지지 않는다

이 과정의 예시 자료는 모두 학습용 가상 자료입니다. 실제 고객 기록·연락처·비밀번호를 공개 AI나 시연본에 넣지 않습니다.
