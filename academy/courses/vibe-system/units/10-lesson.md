# 10강. 시스템 구축 ⑥: 지식 검색과 근거 확인

유정근 · 마이웨이 아카데미 | C4 단일 강좌

## 오늘의 목표

키워드 검색과 RAG 기본 원리 실습, 원본 출처 확인. 산출물 ⑤ 지식저장소 완성

## 왜 이 단계가 필요한가

RAG는 답을 만들기 전에 관련 자료를 찾고, 찾은 자료를 근거로 답하는 순서입니다. 이 실습에서는 검색과 근거 확인부터 구현합니다.

## 따라 하기

1. 지식 카드 제목·태그·요약을 찾는 키워드 검색을 만듭니다.
2. 검색 결과를 누르면 출처와 버전이 보이게 합니다.
3. AI에게 답을 요청할 때는 검색 결과 1~2건을 붙이고 `근거에 없는 내용은 모른다고 말하라`고 지시합니다.

## 검색 결과를 AI에 물을 때

> 아래는 내가 승인한 지식 카드 두 건이다. 카드에 적힌 내용만 사용해 질문에 답하고, 답의 근거로 카드 ID를 적어 줘. 두 카드에 없는 사실은 `자료에서 확인되지 않음`이라고 써 줘.

이 단계의 앱은 **로컬 키워드 검색**을 합니다. 외부 AI와 자동 연결되는 RAG 서비스로 설명하지 않습니다. 검색 결과를 골라 근거와 함께 묻는 순서를 연습합니다.


## AI에게 건네는 말

> 지식 카드 검색을 추가해 줘. 제목·태그·요약에서 찾고, 결과마다 출처와 버전을 표시해 줘. 브라우저에 AI API 키를 넣거나 자동으로 외부 서비스에 자료를 보내는 기능은 만들지 마.

AI의 완료 보고만 믿지 말고 화면·파일·저장 결과를 직접 확인합니다.

- [ ] 자료 밖의 질문에는 근거가 없음을 구별한다
