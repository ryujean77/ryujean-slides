# 11강. 구축 ⑦: 자동화 대시보드 설계

유정근 · 마이웨이 아카데미 | C4 단일 강좌

## 오늘의 목표

대기 Inbox·업무·산출물·검색을 한 화면에 배치하고 데이터 원천 지정

## 왜 이 단계가 필요한가

대시보드는 예쁜 표지보다 지금 처리할 일을 먼저 보여 주는 작업 화면입니다.

## 따라 하기

1. 종이에 Inbox 대기 건수·진행 업무·최근 산출물·지식 검색 네 영역을 배치합니다.
2. 각 숫자와 목록의 데이터 원천을 써 둡니다.
3. 가장 먼저 누를 버튼을 `검토 대기 보기`로 정하고 화면 순서를 검토합니다.

## AI에게 건네는 말

> 현재 앱의 데이터 구조를 읽고 대시보드 화면 설계안을 먼저 글로 제시해 줘. 각 카드의 데이터 원천과 클릭했을 때 이동할 곳을 적고 코드는 아직 바꾸지 마.

AI의 완료 보고만 믿지 말고 화면·파일·저장 결과를 직접 확인합니다.

## 완료 확인

- [ ] 네 영역과 데이터 원천이 대응된다
- [ ] 검토 대기 자료로 한 번에 이동하는 길이 있다

이 과정의 예시 자료는 모두 학습용 가상 자료입니다. 실제 고객 기록·연락처·비밀번호를 공개 AI나 시연본에 넣지 않습니다.
