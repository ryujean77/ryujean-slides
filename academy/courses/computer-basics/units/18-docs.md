# 18강. 구글 문서 — 자동 저장, 댓글, 버전 기록

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표

구글 문서를 하나 만들어 댓글을 달고, 버전 기록에서 예전 내용으로 되돌립니다.

## 왜 여기서 막히나

한글이나 워드에 익숙한 분은 구글 문서에서 "저장" 버튼부터 찾습니다. 구글 문서에는 따로 누를 저장 버튼이 없어서, 오히려 "저장이 안 된 것 같다"는 불안이 생깁니다. 잘못 지운 문단을 되살리는 길(버전 기록)을 모르면 문서를 고치는 일 자체가 두려워집니다.

## 먼저 이해하기

- 구글 문서: 크롬 안에서 쓰는 워드 같은 문서 프로그램. 파일은 내 드라이브에 저장됩니다.
- 자동 저장: 인터넷에 연결돼 있는 동안 쓰는 대로 저절로 저장되는 것. 저장 버튼이 없습니다.
- 댓글: 문서 옆 여백에 붙이는 메모. 본문을 바꾸지 않고 의견만 남깁니다.
- 버전 기록: 문서가 바뀌어 온 과정을 시간 순으로 보관한 목록. 예전 모습으로 되돌릴 수 있습니다.

비유하자면 버전 기록은 <strong>일기장 사진첩</strong>입니다. 오늘 페이지를 잘못 칠해도, 어제 찍어 둔 사진을 보고 그대로 되돌릴 수 있습니다.

## 따라 해 보기

모두 PC에서 합니다.

**가. 새 문서 만들고 자동 저장 확인하기**

1. PC에서 크롬을 열고 주소창에 `https://docs.google.com` 을 입력한 뒤 `Enter` 를 누릅니다.
   → 이렇게 보이면 됩니다: 위쪽에 '새 문서 시작' 줄이 있고, 그 맨 왼쪽에 여러 색 '+' 가 그려진 빈 종이 모양이 보입니다.
2. 오른쪽 위 프로필 사진을 눌러 내 개인 계정인지 봅니다. 맞으면 빈 곳을 눌러 닫습니다.
3. 여러 색 '+' 가 그려진 빈 종이('내용 없음')를 누릅니다.
   → 새 탭에 흰 종이 화면이 열리고, 왼쪽 위에 '제목 없는 문서'라고 적혀 있습니다.
4. 왼쪽 위 '제목 없는 문서' 글자를 한 번 누릅니다.
   → 글자가 칸으로 바뀌며 선택됩니다.
5. 4강 규칙대로 `20261001_요가원안내문_v01` 을 입력하고 `Enter` 를 누릅니다.
6. 흰 종이 부분을 한 번 누르고, 아래 세 줄을 씁니다. 줄을 바꿀 때 `Enter` 를 누릅니다.
   `10월 수업 안내`
   `화·목 저녁 7시`
   `준비물: 매트`
   → 제목 오른쪽에 구름 모양 아이콘이나 '저장 중…' → 'Drive에 저장됨' 같은 표시가 잠깐 보입니다. 이것이 자동 저장입니다.
7. 저장 버튼을 찾지 말고, 이 탭 위쪽의 'X'를 눌러 탭을 닫습니다.
8. 다시 `https://docs.google.com` 을 열면 '최근 문서' 목록에 `20261001_요가원안내문_v01` 이 있습니다. 눌러 엽니다.
   → 세 줄이 그대로 있습니다.

**나. 댓글 달기**

9. "화·목 저녁 7시" 글자의 맨 앞에 마우스를 대고, 왼쪽 버튼을 누른 채 글자 끝까지 끌어 선택합니다.
   → 글자 뒤가 파랗게 칠해지고, 종이 오른쪽 여백에 작은 아이콘 몇 개가 나타납니다.
10. 그중 말풍선에 '+' 가 붙은 '댓글 추가' 아이콘을 누릅니다.
    → 오른쪽 여백에 댓글 입력칸이 열립니다.
11. `시간 확인 필요` 라고 쓰고 파란 '댓글' 버튼을 누릅니다.
    → 선택했던 글자가 노랗게 표시되고, 오른쪽 여백에 댓글이 붙습니다.

**다. 지우고 버전 기록으로 되돌리기**

12. 셋째 줄 "준비물: 매트"를 9번처럼 끌어 선택한 뒤 `Delete` 키를 눌러 지웁니다.
13. 같은 자리에 `준비물: 수건` 을 씁니다. 1~2분 기다립니다(기록이 남을 시간).
14. 화면 오른쪽 위, '공유' 버튼 왼쪽에 있는 시계 모양 '버전 기록' 아이콘을 누릅니다.
    ✖ 아이콘이 안 보이면 → 위쪽 메뉴 줄의 '파일'을 누르고, '버전 기록' → '버전 기록 보기'를 누릅니다.
    → 화면 오른쪽에 날짜·시각이 적힌 목록이 나타납니다. 가운데 문서에는 바뀐 부분이 색으로 표시됩니다.
15. 오른쪽 목록에서 12번 전의 시각(예: 몇 분 전 시각)을 한 번 누릅니다.
    → 가운데 문서에 "준비물: 매트"가 있는 예전 모습이 보입니다. 보기만 하는 것이라 아직 아무것도 바뀌지 않습니다.
16. 화면 위쪽 파란 '이 버전 복원하기'를 누릅니다.
    → '이 버전을 복원하시겠습니까?' 같은 확인 창이 뜹니다.
17. 확인 창에서 '복원'을 누릅니다.
    → 버전 기록 화면이 닫히고 "준비물: 매트"가 되살아난 문서가 보입니다.

**라. 댓글 정리하기**

18. 오른쪽 여백의 `시간 확인 필요` 댓글을 한 번 누르고, 댓글 위쪽의 체크 표시('해결됨으로 표시' 또는 '완료')를 누릅니다.
    → 댓글이 여백에서 사라집니다(지워진 것이 아니라 정리된 것입니다).

(화면의 글자는 버전에 따라 조금 다를 수 있습니다)

✔ 잘 됐는지 확인: "준비물: 매트" 줄이 되살아났고, 댓글은 여백에서 사라졌습니다. 버전 기록을 다시 열면 "복원"한 기록도 목록에 남아 있습니다.

✖ 안 될 때:
- 버전 기록 목록이 비어 보이면 → 문서를 고친 뒤 몇 분 기다렸다 다시 엽니다.
- '댓글 추가' 아이콘이 안 보이면 → 글자를 먼저 선택했는지 확인합니다. 선택해야 나타납니다. 위쪽 메뉴 '삽입' → '댓글'로도 됩니다.
- 되돌리기가 겁나면 → 버전을 누르고 보기만 해도 됩니다. '복원'을 누르지 않으면 아무것도 바뀌지 않습니다. 복원한 뒤에도 방금 전 내용은 목록에 남아 있어서 다시 되돌릴 수 있습니다.
- 버전 기록 화면에서 나오고 싶으면 → 왼쪽 위 화살표(←)를 누릅니다.

## AI에게 물어보기

**어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11, 크롬에서 구글 문서를 쓴다. 한 시간 전 내용으로 되돌리고 싶다. 지금 문서 화면이 열려 있고, 오른쪽 위에 시계 모양 아이콘이 보인다. 파일 메뉴는 열어 봤다. 버전 기록에서 되돌리는 순서를 알려 주고, 되돌려도 지금 내용이 사라지지 않는지도 설명해 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 문서 내용을 붙여 넣어 물을 때는 다른 사람의 이름·연락처를 먼저 지웁니다.

## 혼자 다시 해 보기

1. 안내문 문서에서 '파일' → '버전 기록' → '버전 이름 지정'을 누르고, `10월 초안` 이라고 쓴 뒤 '저장'을 누릅니다. 버전 기록 목록에서 이 이름을 찾아봅니다.
2. 아무 문장이나 지우고, 버전 기록에서 `10월 초안` 을 눌러 '이 버전 복원하기' → '복원'으로 되돌립니다.

완료 기준: 이름 붙은 버전이 목록에 보이고, 지운 문장이 되살아났습니다.
