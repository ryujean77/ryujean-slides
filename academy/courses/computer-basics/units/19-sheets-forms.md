# 19강. 구글 시트와 설문지 — 표, 정렬·필터, 합계, 응답 받기

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표

구글 설문지로 신청을 받아 시트에 모으고, 그 표를 정렬·필터하고 합계를 구합니다.

## 왜 여기서 막히나

신청을 전화나 문자로 받아 손으로 옮겨 적으면, 옮기다 틀리고 합계도 다시 셉니다. 구글 설문지와 시트가 연결된다는 사실을 모르면 이 수고가 계속됩니다. 시트는 칸이 많아 처음엔 겁이 나지만, 오늘 쓰는 기능은 네 가지뿐입니다.

## 먼저 이해하기

- 구글 설문지: 질문지를 만들고 링크로 돌려 답을 받는 도구.
- 구글 시트(스프레드시트): 칸으로 나뉜 표에 숫자와 글을 넣고 계산하는 문서. 엑셀과 비슷합니다.
- 셀: 시트의 네모 칸 하나. 이름은 '열 글자 + 행 번호'입니다. 예: `D2` 는 D열(위쪽 글자 D 아래 세로줄)의 2행(왼쪽 숫자 2의 가로줄) 칸.
- 헤더 행: 표 맨 위의 제목 줄(예: 이름, 희망 요일). 정렬할 때 섞이지 않게 따로 표시합니다.
- 정렬: 줄 순서를 바꾸는 것. 필터: 조건에 맞는 줄만 잠시 보여 주는 것. 필터는 줄을 지우지 않습니다.
- 함수: 칸에 `=` 로 시작해 쓰는 계산 명령. 합계는 `=SUM(시작칸:끝칸)` 한 줄로 구합니다.

응답을 시트에 연결해 두면 한 사람이 답할 때마다 표에 한 줄씩 쌓입니다.

비유하자면 설문지는 **접수 창구**, 시트는 <strong>접수 대장</strong>입니다. 창구에 온 사람의 이름이 저절로 대장에 적히는 셈입니다.

## 따라 해 보기

예시: 김은숙 씨가 요가원 특강 신청을 받습니다. 연습 응답은 모두 가짜 이름으로 넣습니다. 모두 PC 크롬에서 합니다.

**가. 설문지 만들기**

1. 크롬 주소창에 `https://forms.google.com` 을 입력하고 `Enter` 를 누릅니다. 처음이면 소개 화면이 나올 수 있습니다. 그럴 땐 가운데 '설문지로 이동' 같은 버튼을 누릅니다.
   → 이렇게 보이면 됩니다: 위쪽 '새 양식 시작' 줄 맨 왼쪽에 여러 색 '+' 가 그려진 빈 칸이 보입니다.
2. 여러 색 '+' 가 그려진 빈 칸을 누릅니다.
   → 보라색 띠가 있는 새 설문지가 열리고, 맨 위에 '제목 없는 설문지'라고 적혀 있습니다.
3. '제목 없는 설문지' 글자를 누르고 지운 뒤 `10월 특강 신청` 을 씁니다.
4. 그 아래 첫 번째 질문 상자의 '제목없는 질문'을 누르고 `이름` 을 씁니다.
5. 같은 상자 오른쪽의 질문 유형 칸(처음엔 '객관식 질문'으로 보임)을 누르고, 목록에서 '단답형'을 고릅니다.
6. 화면 오른쪽의 세로 도구 막대에서 동그라미 속 '+'('질문 추가')를 누릅니다.
   → 새 질문 상자가 생깁니다.
7. 질문 제목에 `희망 요일` 을 쓰고, 유형은 '객관식 질문' 그대로 둡니다. '옵션 1'을 눌러 `화` 로 바꾸고, 아래 '옵션 추가'를 눌러 `목` 을 씁니다.
8. 6번처럼 질문을 하나 더 추가하고, 제목 `함께 올 인원`, 유형 '단답형'으로 만듭니다.

**나. 응답을 시트에 연결하기**

9. 설문지 맨 위 가운데의 '응답' 탭을 누릅니다.
   → '응답 0개' 같은 글자와 '요약' 탭이 보입니다.
10. 오른쪽 위의 초록색 'Sheets에 연결'(또는 'Sheets에서 보기') 버튼을 누릅니다. 이 버튼이 안 보이면 오른쪽 위 점 세 개('더보기') → '응답 저장 위치 선택'을 누릅니다.
    → '응답 저장 위치 선택' 창이 뜹니다.
11. '새 스프레드시트 만들기'가 선택된 상태에서 이름 칸을 지우고 `20261001_특강신청_v01` 을 쓴 뒤 '만들기'를 누릅니다.
    → 새 탭에 시트가 열리고, 맨 윗줄에 '타임스탬프', '이름', '희망 요일', '함께 올 인원' 제목이 보입니다. 확인했으면 설문지 탭으로 돌아옵니다(크롬 위쪽 탭 줄에서 보라색 설문지 아이콘 탭을 누름).

**다. 연습 응답 넣기**

12. 설문지 오른쪽 위의 눈 모양 '미리보기'를 누릅니다.
    → 새 탭에 실제로 받을 사람이 보게 될 설문지 화면이 열립니다.
13. 이름 `가나다`, 희망 요일 `화`, 인원 `2` 를 넣고 아래 '제출'을 누릅니다. 인원 칸에는 숫자만 씁니다.
14. '다른 응답 제출'을 누르고, 같은 방법으로 세 번 더 제출합니다. 예: `라마바 / 목 / 1`, `사아자 / 화 / 3`, `차카타 / 목 / 2`. 13강에서 맞춘 휴대폰에서도 한 번 제출해 봐도 좋습니다(링크를 나에게 메일로 보내 휴대폰 Gmail 앱에서 열기).

**라. 시트에서 정리하기**

15. 크롬 위쪽 탭 줄에서 초록색 시트 아이콘 탭(11번에서 열린 `20261001_특강신청_v01`)을 누릅니다.
    → 2행부터 5행까지 응답 네 줄이 들어와 있습니다. A열은 제출 시각(타임스탬프: 언제 제출했는지 자동으로 적힌 시각)입니다.
16. 표의 왼쪽 위 `A1` 칸을 누르고, 마우스 왼쪽 버튼을 누른 채 마지막 응답의 인원 칸(예: `D5`)까지 끌어 표 전체를 선택합니다.
    → 선택한 칸들이 옅은 파란색으로 칠해집니다.
17. 위쪽 메뉴 줄의 '데이터' → '범위 정렬' → '고급 범위 정렬 옵션'을 차례로 누릅니다.
18. 뜬 창에서 '데이터에 헤더 행 있음'의 네모 칸에 체크합니다.
19. '정렬 기준' 칸을 눌러 '희망 요일'을 고르고, 파란 '정렬'을 누릅니다.
    → 화요일 신청과 목요일 신청이 모여서 보입니다. 맨 윗줄 제목은 그대로입니다.
20. 표 안의 아무 칸이나 누른 뒤, '데이터' → '필터 만들기'를 누릅니다.
    → 맨 윗줄 제목마다 오른쪽에 깔때기 모양(또는 세 줄 모양) 필터 아이콘이 생깁니다.
21. '희망 요일' 제목 옆의 필터 아이콘을 누릅니다. 아래 목록에서 '목' 앞의 체크를 눌러 끄고 '확인'을 누릅니다.
    → '화'인 줄만 남고, 왼쪽 행 번호가 건너뛰어 보입니다(숨은 줄이 있다는 뜻).
22. 21번과 같은 필터 아이콘을 다시 누르고 '모두 선택'을 누른 뒤 '확인'을 누릅니다.
    → 네 줄이 모두 다시 보입니다.
23. 표 오른쪽으로 한 칸 떨어진 빈 칸 `F2` 를 누릅니다(E열은 비워 둡니다). 응답 줄 바로 아래에 쓰면 새 응답이 들어올 자리와 부딪힐 수 있어서 옆에 둡니다.
24. `=SUM(D2:D)` 를 입력하고 `Enter` 를 누릅니다. `D2:D` 는 "D2부터 D열 맨 아래까지"라는 뜻이라, 응답이 늘어도 식을 고칠 필요가 없습니다. 인원이 다른 열에 있으면 그 열 글자로 바꿉니다.
    → 칸에 인원의 합(예: 8)이 나옵니다.

(화면의 글자는 버전에 따라 조금 다를 수 있습니다)

✔ 잘 됐는지 확인: 제출한 네 건이 시트에 있고, 합계 칸에 인원 수의 합이 나옵니다. 필터를 풀면 숨었던 줄이 모두 돌아옵니다.

✖ 안 될 때:
- 합계가 0이면 → 인원 칸에 숫자 대신 "2명"처럼 글자가 들어갔을 수 있습니다. 그 칸을 눌러 숫자만 남깁니다.
- 합계 칸이 `#NAME?` 이면 → `SUM` 철자와 괄호, 쌍점(`:`)을 확인합니다.
- 정렬했더니 제목 줄이 섞였다면 → `Ctrl + Z` 로 되돌리고 '데이터에 헤더 행 있음'을 체크해 다시 합니다.
- 필터를 켠 뒤 줄이 사라졌다고 놀라지 마세요. 숨은 것이지 지워진 것이 아닙니다.
- 시트 탭을 닫아 버렸다면 → 설문지 '응답' 탭의 'Sheets에서 보기'를 누르면 다시 열립니다.

## AI에게 물어보기

**어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11, 크롬에서 구글 시트를 쓴다. D열의 인원 합계를 구하려 한다. 지금 F2 칸에 =SUM(D2:D)를 넣었는데 0이 나온다. D열 칸을 눌러 보니 "2명"처럼 적혀 있다. 왜 0이 나오는지, 어떻게 고치는지 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 실제 신청자 명단은 AI에 붙여 넣지 말고, 가짜 이름으로 바꾼 표로 묻습니다.

## 혼자 다시 해 보기

1. 설문지 '미리보기'로 가짜 응답을 두 건 더 넣고, 시트에 줄이 늘었는지 봅니다. `F2` 의 합계가 새 응답만큼 저절로 늘었는지 확인합니다.
2. 필터로 "목"만 남겨 봅니다.

완료 기준: 여섯 건이 보이고, 합계가 여섯 건의 인원 합과 같습니다.
