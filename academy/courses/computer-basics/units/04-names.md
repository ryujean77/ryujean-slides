# 4강. 확장자와 이름 짓기 — 날짜로 다시 찾을 수 있게

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표
파일 확장명이 보이게 켜고, `날짜_내용_버전` 규칙으로 파일 이름을 지어 저장한 뒤, 검색으로 다시 찾아냅니다.

## 왜 여기서 막히나
현장 제출물에서 `Index.html.html`처럼 **꼬리표가 두 번 붙은 파일**이 여러 번 나왔습니다. 윈도우가 확장명을 숨긴 상태에서 이름을 바꾸다 보니, 보이지 않는 꼬리표 뒤에 같은 꼬리표를 하나 더 붙인 것입니다. 또 "최종", "최종2", "진짜최종"이 한 폴더에 쌓여 어느 것이 마지막인지 아무도 모르게 되는 일도 흔합니다. 이름 짓는 규칙 하나가 이 둘을 함께 풉니다.

## 먼저 이해하기
- **확장명**은 파일 이름 끝 마침표 뒤의 꼬리표입니다. 컴퓨터는 이것을 보고 어떤 프로그램으로 열지 정합니다. 옷에 붙은 **세탁 표시 라벨**과 같습니다 — 라벨을 떼어도 옷감은 그대로이듯, Microsoft 도움말도 **확장명만 바꾼다고 파일 형식이 바뀌지는 않는다**고 설명합니다.
- 자주 만나는 꼬리표: `.txt`(서식 없는 글), `.docx`(워드 문서), `.pdf`(PDF 문서), `.jpg`·`.png`(사진·그림), `.zip`(압축 파일), `.exe`(실행 프로그램), `.msi`(설치 관리자 파일).
- **날짜를 이름 맨 앞에** 붙이면(`20260926_…`) 이름순으로 정렬만 해도 시간 순서가 됩니다. 연도-월-일 순서로, 월과 일은 두 자리(`09`, `05`)로 씁니다.
- 파일 이름에 쓸 수 없는 글자가 있습니다: `\ / : * ? " < > |`. 이름 끝을 공백이나 마침표로 끝내지도 않습니다.
- 윈도우는 영문 대문자와 소문자를 같은 이름으로 봅니다. 하지만 인터넷에 올리는 파일은 구별하는 곳도 있으니, 영문은 **소문자로 통일**하는 편이 안전합니다.

**이 과정의 이름 규칙**

```
날짜_내용_버전.확장명
20260926_회원명단_v01.xlsx
20260926_회원명단_v02.xlsx   ← 고치면 번호만 올립니다
```

## 따라 해 보기

1. `Win + E`로 파일 탐색기를 엽니다.
2. 위쪽 메뉴에서 **보기** → **표시** → **파일 이름 확장명**을 눌러 체크합니다. (화면에는 "파일 확장명"으로 보일 수 있습니다)
3. 3강에서 만든 `my_work` 폴더로 들어갑니다. 이제 파일 이름 뒤에 `.zip`, `.txt` 같은 꼬리표가 보입니다.
4. 메모장을 열고 `김은숙 요가원 — 10월 수업 준비 메모`라고 한 줄 씁니다.
5. `Ctrl + S`를 누릅니다. 저장 창이 뜨면 왼쪽에서 `my_work`를 찾아 누릅니다.
6. **파일 이름** 칸에 `20260926_수업준비메모_v01`이라고 쓰고 **저장**을 누릅니다. 확장명 `.txt`는 메모장이 알아서 붙입니다.
7. 탐색기로 돌아가 `20260926_수업준비메모_v01.txt`가 생겼는지 봅니다.
8. 이 파일을 우클릭 → **복사**, 빈 곳에서 우클릭 → **붙여넣기**로 복사본을 만듭니다.
9. 복사본을 우클릭 → **이름 바꾸기**를 누릅니다. (윈도우 11에서는 메뉴 위쪽 아이콘 줄에 있을 수 있습니다) 마침표 앞부분만 지우고 `20260926_수업준비메모_v02`로 바꿉니다. **`.txt`는 건드리지 않습니다.**
10. 탐색기 오른쪽 위 **검색 상자**에 `수업준비`를 입력합니다. 두 파일이 모두 찾아집니다.

✔ 잘 됐는지 확인: `my_work` 안에 `…_v01.txt`, `…_v02.txt` 두 파일이 나란히 있고, 이름 끝에 `.txt`가 한 번만 붙어 있습니다.

✖ 안 될 때:
- 이름을 바꿀 때 "확장명을 변경하면 파일을 사용하지 못할 수 있다"는 경고가 뜨면 **아니요**를 누르고, 마침표 뒤를 지웠는지 확인합니다.
- `…_v02.txt.txt`처럼 꼬리표가 두 번 붙었다면 2번 설정이 꺼진 상태에서 이름을 바꾼 것입니다. 설정을 켜고 뒤쪽 `.txt` 하나만 지웁니다.
- "파일 이름에 다음 문자를 사용할 수 없습니다" 창이 뜨면 `/`나 `:` 같은 금지 글자를 썼는지 봅니다. 날짜는 `2026/09/26`이 아니라 `20260926`으로 씁니다.

## AI에게 물어보기
> 나는 윈도우 11 파일 탐색기를 쓴다. 파일 이름 뒤의 확장명(.txt 같은 것)이 보이게 하려고 한다. 지금 위쪽 메뉴에 "보기"는 보이는데 "표시" 안에 무엇을 눌러야 하는지 모르겠다. 이미 보기 메뉴를 한 번 열어 봤다. 정확한 순서를 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 파일 이름에도 주민번호나 전화번호는 넣지 않습니다.

## 혼자 다시 해 보기
- 바탕 화면이나 다운로드 폴더에 흩어진 파일 다섯 개를 골라 `날짜_내용_v01` 규칙으로 이름을 바꾸고 `my_work`로 옮깁니다. 날짜는 파일을 만든 날로 씁니다.
- 완료 기준: 다음 날, 탐색기 검색 상자만으로 다섯 개 가운데 강사가 부르는 파일 하나를 30초 안에 찾아냅니다.
