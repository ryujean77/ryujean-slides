# 4강. 확장자와 이름 짓기 — 날짜로 다시 찾을 수 있게

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표
파일 확장명이 보이게 켜고, `날짜_내용_버전` 규칙으로 파일 이름을 지어 저장한 뒤, 검색으로 다시 찾아냅니다.

## 왜 여기서 막히나
현장 제출물에서 `Index.html.html`처럼 **꼬리표가 두 번 붙은 파일**이 여러 번 나왔습니다. 윈도우가 확장명을 숨긴 상태에서 이름을 바꾸다 보니, 보이지 않는 꼬리표 뒤에 같은 꼬리표를 하나 더 붙인 것입니다. 또 "최종", "최종2", "진짜최종"이 한 폴더에 쌓여 어느 것이 마지막인지 아무도 모르게 되는 일도 흔합니다. 이름 짓는 규칙 하나가 이 둘을 함께 풉니다.

## 먼저 이해하기
- <strong>확장명</strong>(확장자라고도 부름)은 파일 이름 끝 마침표 뒤의 꼬리표입니다. 컴퓨터는 이것을 보고 어떤 프로그램으로 열지 정합니다. 옷에 붙은 **세탁 표시 라벨**과 같습니다 — 라벨을 떼어도 옷감은 그대로이듯, Microsoft 도움말도 **확장명만 바꾼다고 파일 형식이 바뀌지는 않는다**고 설명합니다.
- 자주 만나는 꼬리표: `.txt`(서식 없는 글), `.docx`(워드 문서), `.pdf`(PDF 문서 — 어느 컴퓨터에서 열어도 모양이 똑같이 보이는 문서), `.jpg`·`.png`(사진·그림), `.zip`(압축 파일), `.exe`(실행 프로그램), `.msi`(설치 관리자 파일).
- **날짜를 이름 맨 앞에** 붙이면(`20260926_…`) 이름순으로 정렬만 해도 시간 순서가 됩니다. 연도-월-일 순서로, 월과 일은 두 자리(`09`, `05`)로 씁니다.
- <strong>버전</strong>은 몇 번째 고친 판인지 적는 번호입니다. `v01`, `v02` 처럼 씁니다. "최종"이라는 말 대신 번호만 올립니다.
- 파일 이름에 쓸 수 없는 글자가 있습니다: `\ / : * ? " < > |`. 이름 끝을 공백이나 마침표로 끝내지도 않습니다.
- 윈도우는 영문 대문자와 소문자를 같은 이름으로 봅니다. 하지만 인터넷에 올리는 파일은 구별하는 곳도 있으니, 영문은 **소문자로 통일**하는 편이 안전합니다.

**이 과정의 이름 규칙**

```
날짜_내용_버전.확장명
20260926_회원명단_v01.xlsx
20260926_회원명단_v02.xlsx   ← 고치면 번호만 올립니다
```

## 따라 해 보기
**가. 꼬리표가 보이게 켜기**

1. `Win + E` 로 파일 탐색기를 엽니다.
2. 탐색기 창 위쪽의 아이콘 줄에서 '보기'(네모 칸이 겹친 모양 옆에 "보기" 글자)를 누릅니다.
   → 이렇게 보이면 됩니다: '큰 아이콘', '자세히' 같은 목록이 아래로 펼쳐지고, 맨 아래쪽에 '표시'가 있습니다.
3. '표시'에 포인터를 올리거나 누릅니다.
   → 이렇게 보이면 됩니다: 옆으로 작은 목록이 하나 더 열리고 '파일 이름 확장명'(화면에는 "파일 확장명"으로 보일 수 있음)이 있습니다.
4. '파일 이름 확장명'을 누릅니다.
   → 이렇게 보이면 됩니다: 목록이 닫힙니다. 다시 열어 보면 그 글자 왼쪽에 체크 표시(✓)가 붙어 있습니다.
5. 왼쪽 목록에서 3강에서 만든 `my_work` 를 누릅니다.
   → 이렇게 보이면 됩니다: 파일 이름 뒤에 `.zip`, `.txt` 같은 꼬리표가 보입니다.

**나. 규칙대로 이름 지어 저장하기**

6. 시작 단추 → `메모장` 입력 → '메모장'을 눌러 엽니다(2강).
7. `김은숙 요가원 — 10월 수업 준비 메모` 라고 한 줄 씁니다.
8. `Ctrl + S` 를 누릅니다.
   → 이렇게 보이면 됩니다: "다른 이름으로 저장" 창이 뜹니다. 왼쪽에는 폴더 목록, 아래쪽에는 '파일 이름' 칸과 '저장' 단추가 있습니다.
9. 창 왼쪽 목록에서 `my_work` 를 한 번 누릅니다. 목록에 없으면 '내 PC' → '로컬 디스크 (C:)' → '사용자' → (내 계정 이름) → `my_work` 순서로 들어갑니다.
   → 이렇게 보이면 됩니다: 창 위쪽 주소 칸 끝에 `my_work` 가 보입니다.
10. 아래 '파일 이름' 칸을 한 번 누르고, 원래 들어 있던 글자(`*.txt` 나 "제목 없음")를 `Backspace` 로 모두 지웁니다.
11. `20260926_수업준비메모_v01` 이라고 치고 '저장' 단추를 누릅니다. 확장명 `.txt` 는 메모장이 알아서 붙입니다.
    → 이렇게 보이면 됩니다: 메모장 창 맨 위 제목(또는 탭 이름)이 `20260926_수업준비메모_v01` 로 바뀝니다. 메모장은 닫습니다.
12. 탐색기로 돌아가 `my_work` 안에 `20260926_수업준비메모_v01.txt` 가 생겼는지 봅니다.

**다. 새 판 만들고 다시 찾기**

13. 그 파일을 한 번 눌러 고르고 `Ctrl + C`, 빈 곳을 한 번 누르고 `Ctrl + V` 를 누릅니다.
    → 이렇게 보이면 됩니다: `20260926_수업준비메모_v01 - 복사본.txt` 같은 파일이 하나 더 생깁니다.
14. 복사본을 한 번 눌러 고른 뒤 키보드 맨 윗줄의 `F2` 키를 누릅니다. (오른쪽 단추 메뉴에서 '이름 바꾸기'를 눌러도 됩니다. 윈도우 11에서는 메뉴 맨 위 작은 아이콘 줄에 있을 수 있습니다)
    → 이렇게 보이면 됩니다: 이름 글자 중 마침표 앞부분만 파랗게 칠해집니다.
15. 파란 부분만 새로 씁니다. `20260926_수업준비메모_v02` 라고 치고 `Enter` 를 누릅니다. <strong>`.txt` 는 건드리지 않습니다.</strong>
16. 탐색기 창 오른쪽 위의 **검색 상자**(돋보기 모양, "my_work 검색"처럼 적힌 칸)를 한 번 누르고 `수업준비` 를 칩니다.
    → 이렇게 보이면 됩니다: 잠시 뒤 `…_v01.txt`, `…_v02.txt` 두 파일이 목록에 나옵니다.

✔ 잘 됐는지 확인: `my_work` 안에 `…_v01.txt`, `…_v02.txt` 두 파일이 나란히 있고, 이름 끝에 `.txt`가 한 번만 붙어 있습니다.

✖ 안 될 때:
- 이름을 바꿀 때 "확장명을 변경하면 파일을 사용하지 못할 수 있다"는 경고가 뜨면 '아니요'를 누르고, 마침표 뒤를 지웠는지 확인합니다.
- `…_v02.txt.txt`처럼 꼬리표가 두 번 붙었다면 2~4번 설정이 꺼진 상태에서 이름을 바꾼 것입니다. 설정을 켜고 뒤쪽 `.txt` 하나만 지웁니다.
- "파일 이름에 다음 문자를 사용할 수 없습니다" 창이 뜨면 `/`나 `:` 같은 금지 글자를 썼는지 봅니다. 날짜는 `2026/09/26`이 아니라 `20260926`으로 씁니다.
- 노트북에서 `F2` 가 안 먹으면 키보드 왼쪽 아래 `Fn` 키를 누른 채 `F2` 를 누릅니다.

## AI에게 물어보기

> AI 앱(질문에 글로 답해 주는 프로그램)은 21강에서 함께 준비합니다. 크롬에서 이미 구글 계정으로 로그인해 두었다면 지금 아래 방법으로 묻고, 아직이라면 이 칸은 건너뛰었다가 21강 뒤에 돌아와 해 봅니다.
>
> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11 파일 탐색기를 쓴다. 파일 이름 뒤의 확장명(.txt 같은 것)이 보이게 하려고 한다. 지금 위쪽 메뉴에 "보기"는 보이는데 "표시" 안에 무엇을 눌러야 하는지 모르겠다. 이미 보기 메뉴를 한 번 열어 봤다. 정확한 순서를 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 파일 이름에도 주민번호나 전화번호는 넣지 않습니다.

## 혼자 다시 해 보기
- 바탕 화면이나 다운로드 폴더에 흩어진 파일 다섯 개를 골라 `날짜_내용_v01` 규칙으로 이름을 바꾸고 `my_work`로 옮깁니다. 날짜는 파일을 만든 날로 씁니다.
- 완료 기준: 다음 날, 탐색기 검색 상자만으로 다섯 개 가운데 강사가 부르는 파일 하나를 30초 안에 찾아냅니다.
