# 5강. 크롬 기본과 'Google로 로그인'의 원리

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표
크롬의 탭·검색주소창·북마크를 다루고, 'Google 계정으로 로그인' 버튼을 누르기 전에 **어느 계정으로, 무엇을 넘기는지** 확인합니다.

## 왜 여기서 막히나
1강에서 말한 로그인에 대한 두려움은 상당 부분 **지금 어느 계정으로 들어와 있는지 모르는 데서** 옵니다. 국제 조사(FIDO Alliance, 2024)에서도 응답자의 56%가 최근 한 달 사이 로그인 문제로 서비스 이용을 포기한 적이 있다고 답했습니다. 우리 수강생이 정확히 어느 단계에서 멈추는지는 아직 모아 둔 기록이 적습니다 — 그래서 1강의 사전 진단으로 직접 모으고 있습니다.

## 먼저 이해하기
- **크롬**(Chrome)은 구글이 만든 인터넷 보기 프로그램(브라우저)입니다. 바탕 화면이나 작업 표시줄에서 빨강·노랑·초록 고리 가운데 파란 점이 있는 동그란 아이콘을 누르면 열립니다.
- <strong>구글 계정</strong>은 `○○○@gmail.com` 같은 이메일 주소 하나로 지메일·드라이브·유튜브를 함께 쓰게 해 주는 내 회원 자격입니다.
- **탭**은 한 책상 위에 펼쳐 둔 여러 권의 책입니다. 크롬 창 맨 위에 이름표처럼 나란히 붙습니다. 창을 여러 개 띄우지 않아도 됩니다.
- **검색주소창**(탭 바로 아래 가로로 긴 칸)은 주소를 넣는 곳이자 검색창입니다. `google.com`처럼 주소를 쳐도, `요가 매트 세탁법`처럼 말을 쳐도 됩니다.
- **북마크**는 자주 가는 곳에 꽂아 두는 책갈피입니다. **북마크바**는 그 책갈피를 주소창 바로 아래에 늘 보이게 하는 선반입니다.
- <strong>'Google 계정으로 로그인'</strong>(흔히 "SSO" — Single Sign-On, 한 번 로그인으로 여러 서비스에 들어가는 방식)은 가게마다 회원 카드를 새로 만들지 않고 **신분증 하나를 보여 주는 것**과 같습니다. Google 도움말에 따르면 이때 그 사이트에 **이름, 이메일 주소, 프로필 사진**이 전달됩니다. 비밀번호는 전달되지 않습니다.
- 그래서 중요한 것은 "어느 신분증을 꺼내느냐"입니다. 구글 계정이 두 개 이상이면 계정을 고르는 창이 뜹니다. 여기서 잘못 고르면, 나중에 그 사이트에 다른 계정으로 들어가 "내 자료가 없어졌다"고 느끼게 됩니다.

| 단축키 | 하는 일 |
|---|---|
| `Ctrl + T` | 새 탭 열기 |
| `Ctrl + W` | 지금 탭 닫기 |
| `Ctrl + Shift + T` | 방금 닫은 탭 다시 열기 |
| `Ctrl + L` | 검색주소창으로 가기 |
| `Ctrl + D` | 지금 페이지 북마크 |
| `Ctrl + Shift + B` | 북마크바 보이기/숨기기 |

## 따라 해 보기
**가. 탭과 검색주소창**

1. PC에서 크롬 아이콘을 두 번 눌러(작업 표시줄에 있으면 한 번) 크롬을 엽니다.
   → 이렇게 보이면 됩니다: 맨 위에 탭 하나, 그 아래 긴 주소창이 있는 창이 뜹니다.
2. `Ctrl + T` 를 세 번 누릅니다.
   → 이렇게 보이면 됩니다: 맨 위 이름표(탭)가 세 개 늘어납니다. 새 탭에는 "새 탭"이라고 적혀 있습니다.
3. `Ctrl + W` 를 한 번 누릅니다. 지금 보던 탭 하나가 닫힙니다.
4. `Ctrl + Shift + T` 를 누릅니다(`Ctrl` 과 `Shift` 를 함께 누른 채 `T`). 닫은 탭이 되살아납니다.
5. `Ctrl + L` 을 누릅니다.
   → 이렇게 보이면 됩니다: 주소창의 글자가 파랗게 칠해집니다. 이 상태에서 치면 원래 글자가 지워지고 새로 들어갑니다.
6. `google.com` 을 치고 `Enter` 를 누릅니다.
   → 이렇게 보이면 됩니다: 가운데에 알록달록한 "Google" 글자와 검색 칸이 있는 페이지가 열립니다.

**나. 북마크**

7. 주소창 안쪽 오른쪽 끝의 **별 모양**(☆) 아이콘을 누릅니다.
   → 이렇게 보이면 됩니다: 별이 파랗게 채워지고, "북마크 추가됨" 같은 작은 창이 뜹니다.
8. 그 작은 창의 '완료'를 누릅니다.
9. 크롬 창 오른쪽 위 끝, 세로로 점 세 개(⋮)가 있는 **더보기** 단추를 누릅니다.
10. 펼쳐진 목록에서 '북마크 및 목록'에 포인터를 올립니다. 옆에 작은 목록이 열리면 '북마크바 표시'를 누릅니다.
    → 이렇게 보이면 됩니다: 주소창 바로 아래에 가는 줄이 생기고, 방금 꽂은 "Google" 책갈피가 보입니다.

**다. 지금 어느 계정인가**

11. google.com 페이지 오른쪽 위의 동그란 <strong>프로필 사진(또는 이름 첫 글자)</strong>을 누릅니다. 사진 대신 파란 '로그인' 단추가 보이면 아직 로그인하지 않은 상태입니다.
    → 이렇게 보이면 됩니다: 작은 창이 열리고 맨 위에 이메일 주소가 보입니다. 이것이 지금 로그인된 계정입니다. 종이에 **주소만** 적어 둡니다.
12. 계정이 여러 개라면 그 아래 목록에 함께 보입니다. 몇 개인지 세어 봅니다. (1강 진단 5번 문항과 이어집니다) 창 바깥 빈 곳을 누르면 닫힙니다.

**라. 'Google 계정으로 로그인' 버튼 앞에서**

13. 강사가 안내한 실습 사이트 주소를 주소창에 치고 들어갑니다.
14. 그 사이트의 'Google 계정으로 로그인'(또는 G 글자가 있는 'Google로 계속하기') 버튼을 누릅니다.
    → 이렇게 보이면 됩니다: "계정 선택"이라는 제목의 작은 창이나 새 페이지가 뜨고, 내 계정 주소들이 줄지어 보입니다.
15. 여기서 **멈추고** 두 가지를 읽습니다 — ① 내가 고를 계정 주소 ② 창에 적힌 "이름, 이메일 주소, 프로필 사진을 공유" 같은 안내.
16. 11번에서 적은 계정 주소를 한 번 누릅니다. 쓰려는 계정이 목록에 없으면 '다른 계정 사용'(또는 "다른 계정 추가")을 누릅니다.
17. '계속' 같은 확인 단추가 나오면 안내 글을 읽고 누릅니다.
    → 이렇게 보이면 됩니다: 실습 사이트로 돌아오고, 오른쪽 위 등에 내 이름이나 사진이 보입니다.
18. 나중에 이 연결을 끊고 싶을 때는 Google 계정의 '서드 파티 연결'(다른 회사 사이트와 이어 둔 목록) 페이지에서 해당 사이트를 골라 'Google 계정으로 로그인 사용 중지'를 누릅니다. 찾는 법: 11번 창에서 'Google 계정 관리' → 화면 위쪽 검색 칸에 `서드 파티 연결` 입력. (화면의 글자는 버전에 따라 조금 다를 수 있습니다)

✔ 잘 됐는지 확인: 북마크바에 책갈피가 하나 보이고, 지금 로그인된 구글 계정 주소를 보지 않고 말할 수 있으며, 실습 사이트에 **내가 고른 계정**으로 들어가 있습니다.

✖ 안 될 때:
- 북마크바가 보이지 않으면 `Ctrl + Shift + B`를 한 번 누릅니다.
- 계정 선택 창에 모르는 계정이 보이면 누르지 말고 창을 닫습니다. 공용 PC라면 8강에서 배울 게스트 창으로 다시 합니다.
- "조직 정책" 또는 "관리자"라는 말이 들어간 오류가 뜨면 회사·학교 계정을 고른 경우가 많습니다. 크롬 왼쪽 위 뒤로 가기 화살표(`←`)를 눌러 개인 계정으로 다시 고릅니다. 두 계정을 아예 나누는 법은 6강에서 합니다.

## AI에게 물어보기

> AI 앱(질문에 글로 답해 주는 프로그램)은 21강에서 함께 준비합니다. 크롬에서 이미 구글 계정으로 로그인해 두었다면 지금 아래 방법으로 묻고, 아직이라면 이 칸은 건너뛰었다가 21강 뒤에 돌아와 해 봅니다.
>
> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11과 크롬을 쓴다. 어떤 사이트에 'Google 계정으로 로그인'으로 들어가려고 한다. 지금 계정 선택 창에 계정이 세 개 보이는데 어느 것을 골라야 할지 모르겠다. 이미 google.com 오른쪽 위 프로필에서 지금 계정 주소를 확인했다. 계정을 고를 때 무엇을 기준으로 보면 되는지 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 계정 주소를 물을 때도 앞부분은 `○○○@gmail.com`처럼 가려서 씁니다.

## 혼자 다시 해 보기
- 자주 가는 사이트 세 곳을 북마크바에 꽂고, 북마크바에서 하나씩 열었다가 `Ctrl + W`로 닫습니다.
- 내 구글 계정이 몇 개인지, 각각 무엇에 쓰는지 종이에 한 줄씩 적습니다(주소만, 비밀번호는 적지 않음).
- 완료 기준: 새 탭 → 주소 입력 → 북마크 → 닫은 탭 되살리기를 카드 없이 하고, 계정 목록 종이를 6강에 가져옵니다.
