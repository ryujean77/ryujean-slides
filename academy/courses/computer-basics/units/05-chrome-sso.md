# 5강. 크롬 기본과 'Google로 로그인'의 원리

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표
크롬의 탭·검색주소창·북마크를 다루고, 'Google 계정으로 로그인' 버튼을 누르기 전에 **어느 계정으로, 무엇을 넘기는지** 확인합니다.

## 왜 여기서 막히나
1강에서 말한 로그인에 대한 두려움은 상당 부분 **지금 어느 계정으로 들어와 있는지 모르는 데서** 옵니다. 국제 조사(FIDO Alliance, 2024)에서도 응답자의 56%가 최근 한 달 사이 로그인 문제로 서비스 이용을 포기한 적이 있다고 답했습니다. 우리 수강생이 정확히 어느 단계에서 멈추는지는 아직 모아 둔 기록이 적습니다 — 그래서 1강의 사전 진단으로 직접 모으고 있습니다.

## 먼저 이해하기
- **탭**은 한 책상 위에 펼쳐 둔 여러 권의 책입니다. 창을 여러 개 띄우지 않아도 됩니다.
- **검색주소창**(맨 위 긴 칸)은 주소를 넣는 곳이자 검색창입니다. `google.com`처럼 주소를 쳐도, `요가 매트 세탁법`처럼 말을 쳐도 됩니다.
- **북마크**는 자주 가는 곳에 꽂아 두는 책갈피입니다. **북마크바**는 그 책갈피를 주소창 바로 아래에 늘 보이게 하는 선반입니다.
- **'Google 계정으로 로그인'**(흔히 "SSO", 한 번 로그인으로 여러 서비스에 들어가는 방식)은 가게마다 회원 카드를 새로 만들지 않고 **신분증 하나를 보여 주는 것**과 같습니다. Google 도움말에 따르면 이때 그 사이트에 **이름, 이메일 주소, 프로필 사진**이 전달됩니다. 비밀번호는 전달되지 않습니다.
- 그래서 중요한 것은 "어느 신분증을 꺼내느냐"입니다. 구글 계정이 두 개 이상이면 계정을 고르는 창이 뜹니다. 여기서 잘못 고르면, 나중에 그 사이트에 다른 계정으로 들어가 "내 자료가 없어졌다"고 느끼게 됩니다.

| 단축키 | 하는 일 |
|---|---|
| `Ctrl + T` | 새 탭 열기 |
| `Ctrl + W` | 지금 탭 닫기 |
| `Ctrl + Shift + T` | 방금 닫은 탭 다시 열기 |
| `Ctrl + L` | 검색주소창으로 가기 |
| `Ctrl + D` | 지금 페이지 북마크 |
| `Ctrl + Shift + B` | 북마크바 보이기/숨기기 |

## 따라 해 보기
**가. 탭과 검색주소창**

1. 크롬을 열고 `Ctrl + T`를 세 번 눌러 탭을 세 개 엽니다.
2. `Ctrl + W`로 하나를 닫고, `Ctrl + Shift + T`로 되살립니다.
3. `Ctrl + L`을 누르고 `google.com`을 입력한 뒤 `Enter`를 누릅니다.

**나. 북마크**

4. 주소창 오른쪽 끝의 **별 모양(북마크)** 아이콘을 누르고 **완료**를 누릅니다.
5. 오른쪽 위 **더보기**(점 세 개) → **북마크 및 목록** → **북마크바 표시**를 누릅니다. 주소창 아래에 방금 꽂은 책갈피가 보입니다.

**다. 지금 어느 계정인가**

6. google.com 오른쪽 위의 동그란 <strong>프로필 사진(또는 이니셜)</strong>을 누릅니다. 맨 위에 보이는 이메일 주소가 지금 로그인된 계정입니다. 종이에 **주소만** 적어 둡니다.
7. 계정이 여러 개라면 그 아래 목록에 함께 보입니다. 몇 개인지 세어 봅니다. (1강 진단 5번 문항과 이어집니다)

**라. 'Google 계정으로 로그인' 버튼 앞에서**

8. 강사가 안내한 실습 사이트에서 **Google 계정으로 로그인** 버튼을 누릅니다.
9. 계정 선택 창이 뜨면 **멈추고** 두 가지를 읽습니다 — ① 내가 고를 계정 주소 ② 창에 적힌 "이름, 이메일 주소, 프로필 사진을 공유" 같은 안내.
10. 6번에서 적은 계정을 골라 들어갑니다. 쓰려는 계정이 목록에 없으면 **다른 계정 추가**를 누릅니다.
11. 나중에 이 연결을 끊고 싶을 때는 Google 계정의 **서드 파티 연결** 페이지에서 해당 사이트를 골라 **Google 계정으로 로그인 사용 중지**를 누릅니다. (Google 계정 관리 화면 위쪽 검색창에 "서드 파티 연결"을 쳐도 찾아집니다. 메뉴 이름은 버전에 따라 다를 수 있습니다)

✔ 잘 됐는지 확인: 북마크바에 책갈피가 하나 보이고, 지금 로그인된 구글 계정 주소를 보지 않고 말할 수 있으며, 실습 사이트에 **내가 고른 계정**으로 들어가 있습니다.

✖ 안 될 때:
- 북마크바가 보이지 않으면 `Ctrl + Shift + B`를 한 번 누릅니다.
- 계정 선택 창에 모르는 계정이 보이면 누르지 말고 창을 닫습니다. 공용 PC라면 8강에서 배울 게스트 창으로 다시 합니다.
- "조직 정책" 또는 "관리자"라는 말이 들어간 오류가 뜨면 회사·학교 계정을 고른 경우가 많습니다. 뒤로 가서 개인 계정으로 다시 고릅니다. 두 계정을 아예 나누는 법은 6강에서 합니다.

## AI에게 물어보기
> 나는 윈도우 11과 크롬을 쓴다. 어떤 사이트에 'Google 계정으로 로그인'으로 들어가려고 한다. 지금 계정 선택 창에 계정이 세 개 보이는데 어느 것을 골라야 할지 모르겠다. 이미 google.com 오른쪽 위 프로필에서 지금 계정 주소를 확인했다. 계정을 고를 때 무엇을 기준으로 보면 되는지 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 계정 주소를 물을 때도 앞부분은 `○○○@gmail.com`처럼 가려서 씁니다.

## 혼자 다시 해 보기
- 자주 가는 사이트 세 곳을 북마크바에 꽂고, 북마크바에서 하나씩 열었다가 `Ctrl + W`로 닫습니다.
- 내 구글 계정이 몇 개인지, 각각 무엇에 쓰는지 종이에 한 줄씩 적습니다(주소만, 비밀번호는 적지 않음).
- 완료 기준: 새 탭 → 주소 입력 → 북마크 → 닫은 탭 되살리기를 카드 없이 하고, 계정 목록 종이를 6강에 가져옵니다.
