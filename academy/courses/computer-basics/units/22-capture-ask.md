# 22강. 막히면 캡처해서 묻기 — 네 줄 질문 틀

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표

모르는 창이 뜨면 필요한 부분만 캡처해 Gemini에 올리고, 네 줄 질문 틀로 다음 행동을 묻습니다.

## 왜 여기서 막히나

낯선 창이 뜨면 "뭔가 떴어요"라고밖에 설명하지 못해 도움을 받기 어렵습니다. 말로 옮기다 보면 버튼 이름이 틀리고, 창을 닫아 버리면 무엇이 떴는지 다시 볼 수도 없습니다. 이 과정의 모든 카드에 있던 "AI에게 물어보기" 칸을 오늘은 스스로 만드는 연습을 합니다.

## 먼저 이해하기

- 캡처(스크린샷): 지금 화면에 보이는 모습을 사진처럼 찍어 두는 것.
- 클립보드: 복사한 것을 잠시 담아 두는 보이지 않는 바구니. `Ctrl + V` 를 누르면 여기 담긴 것이 붙습니다. 캡처도 이 바구니에 담깁니다.
- 첨부: 질문에 사진이나 파일을 함께 붙여 보내는 것.

윈도우 11에서는 `Windows 로고 키 + Shift + S` 를 누르면 캡처 도구가 열립니다. '사각형'을 고르고 마우스로 필요한 부분만 끌면, 그 사진이 클립보드에 복사되고 '사진' 폴더 안 '스크린샷' 폴더에도 저장됩니다. 사진만 보내는 것보다 <strong>네 줄 질문 틀</strong>을 함께 쓰면 답이 내 화면에 더 가까워집니다.

> ① 나는 [윈도우 11 / 크롬]을 쓴다
> ② 하려는 것: …
> ③ 지금 보이는 화면: … (캡처 첨부)
> ④ 이미 해 본 것: …

비유하자면 <strong>병원 문진표</strong>입니다. "아파요"보다 "어디가, 언제부터, 무엇을 해 봤는지"를 적어 가면 진료가 빨라집니다.

## 따라 해 보기

연습 상황: 크롬 설정 화면에서 "다운로드 파일이 저장되는 폴더를 바꾸고 싶다"고 해 봅니다. 모두 PC에서 합니다.

**가. 연습할 화면 열기**

1. 크롬을 열고 주소창에 `chrome://settings` 를 입력한 뒤 `Enter` 를 누릅니다.
   → 이렇게 보이면 됩니다: 왼쪽에 '설정' 메뉴 목록, 가운데에 여러 설정 항목이 보입니다.

**나. 필요한 부분만 캡처하기**

2. 키보드 왼쪽 아래의 `Windows 로고 키`(창문 모양)와 `Shift` 를 함께 누른 채, `S` 를 누릅니다.
   → 화면 전체가 살짝 어두워지고, 화면 <strong>맨 위 가운데</strong>에 작은 도구 막대(아이콘 몇 개)가 나옵니다.
3. 도구 막대에서 네모 모양 아이콘('사각형')이 선택돼 있는지 봅니다. 아니면 그 아이콘을 누릅니다.
4. 설정 화면에서 보여 주고 싶은 부분의 왼쪽 위 모서리에 마우스를 대고, 왼쪽 버튼을 누른 채 오른쪽 아래 모서리까지 끈 다음 손을 뗍니다. 이름·이메일 주소·프로필 사진이 보이는 곳은 빼고 그립니다.
   → 화면이 원래대로 밝아지고, 화면 오른쪽 아래에 '캡처가 클립보드에 복사됨'과 비슷한 알림이 잠깐 뜹니다. 캡처가 클립보드에 들어간 것입니다.

**다. Gemini에 캡처 붙이기**

5. 크롬 창 맨 위 탭 줄에서, 지금 탭 오른쪽의 '+'(새 탭)를 누릅니다.
6. 새 탭 주소창에 `https://gemini.google.com` 을 입력하고 `Enter` 를 누릅니다(로그인은 21강 방법).
   → 화면 아래쪽 가운데에 입력칸이 보입니다.
7. 입력칸을 한 번 누르고 `Ctrl + V` 를 누릅니다.
   → 입력칸 위쪽(또는 안쪽)에 캡처 사진의 작은 그림이 붙습니다.
   ✖ 사진이 안 붙으면 → 입력칸 <strong>왼쪽</strong>의 '+' 버튼('파일 추가')을 누르고 '파일 업로드'를 누릅니다. 열린 창의 왼쪽 목록에서 '사진' → '스크린샷' 폴더로 들어가, 가장 최근 파일을 한 번 누르고 '열기'를 누릅니다.

**라. 네 줄 질문 쓰고 보내기**

8. 사진이 붙은 입력칸 안을 한 번 누르고, 아래 네 줄을 씁니다. 줄을 바꿀 때는 `Enter` 대신 `Shift + Enter` 를 누릅니다(`Enter` 만 누르면 바로 보내집니다).
   `나는 윈도우 11, 크롬을 쓴다.`
   `하려는 것: 다운로드 파일이 저장되는 폴더를 바꾸고 싶다.`
   `지금 보이는 화면: 첨부한 크롬 설정 화면이다.`
   `이미 해 본 것: 설정 화면까지는 열었다. 다음에 어디를 눌러야 할지 모르겠다.`

9. 입력칸 오른쪽의 보내기 버튼(종이비행기 모양)을 누르거나 `Enter` 를 누릅니다.
   → 내 질문과 사진이 위로 올라가고, 그 아래에 답이 나타납니다.
10. 답의 **첫 단계 하나만** 해 봅니다. `chrome://settings` 탭으로 돌아가(크롬 위쪽 탭 줄에서 '설정' 탭을 누름) 답이 말한 메뉴를 찾습니다.
11. 된 뒤에 Gemini 탭으로 돌아와 다음 단계를 읽고 해 봅니다. 실제로 위치를 바꾸지 않아도 됩니다. 어디서 바꾸는지만 찾으면 성공입니다.

**마. 휴대폰으로 PC 화면을 찍어 묻기 (PC 캡처가 어려울 때)**

12. 휴대폰에서 'Gemini' 앱(21강에서 준비)을 엽니다.
13. 아래쪽 입력칸 옆의 카메라 모양 버튼(또는 '+' 버튼 → '카메라')을 누릅니다. 처음이면 카메라 사용 허용을 묻습니다. '허용'을 누릅니다.
14. PC 화면 중 막힌 부분이 가득 차게 비추고, 가운데 동그란 촬영 버튼을 누릅니다. 찍기 전에 화면에 비밀번호나 개인정보가 보이지 않는지 먼저 봅니다.
15. 사진이 입력칸에 붙으면, 네 줄 질문을 쓰고 보내기 버튼을 누릅니다.

(화면의 글자는 버전에 따라 조금 다를 수 있습니다)

✔ 잘 됐는지 확인: 캡처에 개인정보가 보이지 않고, AI가 알려 준 곳을 실제 화면에서 찾았습니다.

✖ 안 될 때:
- 단축키를 눌러도 아무 일이 없으면 → 세 키를 동시에 누른 채 1초 기다립니다. 그래도 안 되면 작업 표시줄의 시작 단추(창문 모양)를 누르고 `캡처 도구` 를 입력해 열고, '새로 만들기'를 누릅니다.
- AI 답의 버튼 이름이 내 화면과 다르면 → 그 사실을 그대로 적어 다시 묻습니다: "네가 말한 ○○ 버튼이 안 보인다. 내 화면에는 △△가 있다."
- 캡처한 사진이 어디 갔는지 모르겠으면 → `Win + E` 로 탐색기를 열고 왼쪽 목록의 '사진' → '스크린샷' 폴더를 봅니다.

## AI에게 물어보기

**어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11, 크롬을 쓴다. 모르는 창이 뜰 때 캡처해서 너에게 묻고 싶다. 지금 Windows 키 + Shift + S를 눌러 사각형으로 캡처했다. 그런데 캡처한 사진을 어디에 붙여 넣는지 모르겠다. Ctrl + V는 메모장에서 해 봤는데 안 붙었다. 이 대화창에 사진을 넣는 방법을 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 로그인 창, 인증번호 문자, 은행 화면은 캡처하지 않습니다. 오류 창이라면 오류 문구 부분만 잘라 냅니다.

## 혼자 다시 해 보기

1. 이번 과정에서 한 번이라도 막혔던 화면(예: 압축 풀기, 드라이브 공유 창)을 다시 열어 캡처하고, 네 줄 질문 틀로 묻습니다.
2. 같은 질문을 틀 없이 "이거 어떻게 해?"로만 물어 보고, 두 답을 비교합니다.

완료 기준: 네 줄 질문 틀을 보지 않고 쓸 수 있고, 캡처 두 장 모두 개인정보가 없습니다.
