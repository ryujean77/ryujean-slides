# 3강. 파일 탐색기와 내 작업 폴더 — 받은 파일 찾기와 압축 풀기

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표
인터넷에서 받은 파일을 **다운로드** 폴더에서 찾아 압축을 풀고, 앞으로 모든 실습 파일을 모아 둘 **내 작업 폴더**를 만들어 옮깁니다.

## 왜 여기서 막히나
현장 수업 녹취를 다시 들어 보면, 가장 많은 시간이 새는 곳은 AI가 아니라 **"방금 받은 파일이 어디 갔지?"** 입니다. 그리고 파일을 찾더라도 압축을 풀지 않은 채 안에 든 파일을 바로 열어, 고친 내용이 저장되지 않거나 프로그램이 제대로 돌지 않는 일이 반복됩니다. 둘 다 원리만 알면 1분이면 끝나는 일입니다.

## 먼저 이해하기
- <strong>파일</strong>은 글·사진·표 하나하나, <strong>폴더</strong>는 그 파일을 담는 노란 서류철입니다. 폴더 안에 폴더를 또 넣을 수 있습니다.
- **파일 탐색기**는 내 컴퓨터 안의 방과 서랍을 보여 주는 지도입니다. `Win + E`(창문 키를 누른 채 `E`)로 엽니다. 창 왼쪽에는 자주 가는 곳 목록, 오른쪽 넓은 곳에는 지금 연 폴더의 내용이 보입니다.
- <strong>다운로드</strong>(인터넷에서 내 컴퓨터로 파일을 받아 오는 일)한 파일이 들어가는 **다운로드 폴더**는 아파트 **택배 보관함**입니다. 크롬(구글이 만든 인터넷 보기 프로그램)으로 받은 파일은 따로 정하지 않으면 모두 여기로 옵니다.
- **압축 파일**(`.zip`)은 여러 물건을 한 상자에 넣고 테이프로 봉한 **택배 상자**입니다. 상자 안을 들여다볼 수는 있지만, 물건을 쓰려면 **상자를 뜯어 꺼내야** 합니다. 이것이 "압축 풀기"(윈도우 메뉴에서는 '추출')입니다.
- **내 작업 폴더**는 택배 보관함에서 꺼낸 물건을 정리해 두는 **내 책상 서랍**입니다. 보관함은 매일 쌓이고 비워지는 곳이라, 오래 쓸 파일은 서랍으로 옮깁니다. 23강에서는 이 서랍 안에 AI 작업 도구(AGY, 안티그래비티 — 내 폴더의 파일을 읽고 고치는 AI 프로그램)에게 내줄 `practice` 폴더를 만듭니다.

## 따라 해 보기
**가. 받은 파일 찾기**

1. 크롬에서 강사가 안내한 실습용 압축 파일 링크(누르면 다른 곳으로 이동하는 글자나 단추)를 한 번 누릅니다.
   → 이렇게 보이면 됩니다: 크롬 오른쪽 위에 아래쪽 화살표 모양(다운로드) 아이콘이 나타나거나, 작은 창에 파일 이름과 "완료"가 보입니다. 파일 이름을 종이에 적어 둡니다.
2. 크롬에서 `Ctrl + J` 를 누릅니다.
   → 이렇게 보이면 됩니다: '다운로드'라는 새 탭이 열리고, 맨 위에 방금 받은 파일 이름이 있습니다.
3. `Win + E` 로 파일 탐색기를 엽니다.
   → 이렇게 보이면 됩니다: 노란 폴더 모양 아이콘이 달린 창이 뜨고, 왼쪽에 '홈', '바탕 화면', '다운로드', '문서' 같은 목록이 보입니다.
4. 왼쪽 목록에서 '다운로드'(아래쪽 화살표가 그려진 폴더)를 한 번 누릅니다.
   → 이렇게 보이면 됩니다: 오른쪽에 받은 파일들이 나오고, 1번에서 적은 이름이 보입니다. 지퍼가 달린 폴더 모양 아이콘이 압축 파일입니다.

**나. 압축 풀기**

5. 그 압축 파일 위에 포인터를 놓고 마우스 **오른쪽** 단추를 누릅니다.
   → 이렇게 보이면 됩니다: 파일 옆에 메뉴가 펼쳐집니다.
6. 메뉴에서 <strong>'모두 추출…'</strong>을 누릅니다. (PC에 따라 "압축 풀기"로 보일 수 있습니다. 화면의 글자는 버전에 따라 조금 다를 수 있습니다)
   → 이렇게 보이면 됩니다: "압축(ZIP) 폴더 풀기" 같은 제목의 창이 뜨고, 풀어 놓을 위치가 적힌 칸이 보입니다. 칸은 그대로 둡니다.
7. 창 오른쪽 아래 '추출'(또는 "압축 풀기") 단추를 누릅니다.
   → 이렇게 보이면 됩니다: 초록 막대가 잠깐 차오른 뒤, 같은 이름의 **일반 폴더**(지퍼 없는 노란 폴더)가 새로 생기고 자동으로 열립니다. 안의 파일은 이제 바로 써도 됩니다.

**다. 내 작업 폴더 만들기**

8. 탐색기 왼쪽 목록을 아래로 내려 '내 PC'(모니터 모양)를 누릅니다.
9. 오른쪽에 보이는 '로컬 디스크 (C:)'를 두 번 빠르게 누릅니다. (`C:` 는 컴퓨터 안의 기본 저장 장치 이름입니다)
10. '사용자' 폴더를 두 번 누릅니다. 영문 화면이면 `Users` 로 보입니다.
11. 내 계정 이름이 붙은 폴더(로그인할 때 보인 이름)를 두 번 누릅니다.
    → 이렇게 보이면 됩니다: '다운로드', '문서', '바탕 화면', '사진' 같은 폴더가 모여 있습니다. 위쪽 주소 칸에는 `C:\사용자\(내 계정 이름)` 처럼 보입니다.
12. 오른쪽 폴더들 사이 빈 흰 곳에서 마우스 오른쪽 단추를 누르고, '새로 만들기' → '폴더'를 차례로 누릅니다.
    → 이렇게 보이면 됩니다: "새 폴더"라는 이름의 폴더가 생기고, 이름 글자가 파랗게 칠해져 있습니다.
13. 파란 글자 상태 그대로 `my_work` 라고 치고 `Enter` 를 누릅니다. 영문으로 짓는 까닭은, 나중에 쓸 AI 작업 도구와 여러 프로그램이 폴더 주소를 다룰 때 문제를 덜 일으키기 때문입니다. 밑줄 `_` 은 `Shift` 를 누른 채 숫자 `0` 오른쪽 `-` 키를 누르면 나옵니다.
14. 7번에서 생긴 폴더로 옮길 차례입니다. 왼쪽 목록에서 '다운로드'를 누르고, 압축을 푼 폴더(지퍼 없는 것)를 한 번 눌러 고른 뒤 `Ctrl + X`(잘라내기)를 누릅니다.
15. 다시 8~11번처럼 들어가 `my_work` 폴더를 두 번 눌러 연 뒤, 안의 빈 곳을 한 번 누르고 `Ctrl + V` 를 누릅니다.
    → 이렇게 보이면 됩니다: `my_work` 안에 실습 폴더가 들어와 있고, 다운로드 폴더에서는 사라졌습니다.
16. 뒤로 가기 화살표(창 왼쪽 위 `←`)로 한 칸 나와 `my_work` 폴더를 오른쪽 단추로 누르고 '즐겨찾기에 추가'(또는 "빠른 액세스에 고정")를 누릅니다.
    → 이렇게 보이면 됩니다: 탐색기 왼쪽 목록 위쪽에 `my_work` 가 늘 보입니다.

✔ 잘 됐는지 확인: 탐색기 왼쪽 목록에서 `my_work`를 누르면, 압축이 풀린 실습 폴더와 그 안의 파일이 보입니다.

✖ 안 될 때:
- 파일이 어디 있는지 모르겠다면 크롬에서 `Ctrl + J` → 파일 이름 아래의 "폴더 열기"(또는 파일 옆 폴더 모양 아이콘)를 누르면 그 파일이 있는 곳이 바로 열립니다.
- 압축 파일을 더블클릭해서 열었는데 안의 파일이 이상하게 동작한다면, 상자를 뜯지 않고 들여다보기만 한 상태입니다. 5~7번을 다시 합니다.
- 오른쪽 단추 메뉴가 짧고 '모두 추출'이 없으면 메뉴 맨 아래 '추가 옵션 표시'를 누르면 긴 메뉴가 나옵니다.
- 압축을 풀 때 비밀번호를 묻는다면 멈춥니다. 보낸 사람에게 확인하기 전에는 열지 않습니다. (Chrome 도움말도 비밀번호 걸린 압축 파일은 악성 코드 — 컴퓨터를 망가뜨리거나 정보를 빼 가는 프로그램 — 를 숨기는 데 쓰일 수 있다고 안내합니다)

## AI에게 물어보기

> AI 앱(질문에 글로 답해 주는 프로그램)은 21강에서 함께 준비합니다. 크롬에서 이미 구글 계정으로 로그인해 두었다면 지금 아래 방법으로 묻고, 아직이라면 이 칸은 건너뛰었다가 21강 뒤에 돌아와 해 봅니다.
>
> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11과 크롬을 쓴다. 인터넷에서 받은 zip 파일의 압축을 풀어 내 작업 폴더로 옮기려고 한다. 지금 파일 탐색기의 다운로드 폴더에 파일이 보이는데, 우클릭 메뉴에 "모두 추출"이 보이지 않는다. 이미 파일을 한 번 눌러 선택하고 우클릭해 봤다. 다른 방법을 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다.

## 혼자 다시 해 보기
- 아무 공공기관 누리집(홈페이지)에서 서식 파일 하나를 받아 `Ctrl + J`로 위치를 확인하고, `my_work` 안에 `01_forms` 폴더를 만들어 옮깁니다. (`practice`라는 이름은 23강에서 AGY용으로 따로 쓰니 여기서는 쓰지 않습니다)
- 완료 기준: 파일을 받은 뒤 `my_work` → `01_forms` 안에 넣기까지 카드를 보지 않고 3분 안에 끝냅니다.
