# 3강. 파일 탐색기와 내 작업 폴더 — 받은 파일 찾기와 압축 풀기

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표
인터넷에서 받은 파일을 **다운로드** 폴더에서 찾아 압축을 풀고, 앞으로 모든 실습 파일을 모아 둘 **내 작업 폴더**를 만들어 옮깁니다.

## 왜 여기서 막히나
현장 수업 녹취를 다시 들어 보면, 가장 많은 시간이 새는 곳은 AI가 아니라 **"방금 받은 파일이 어디 갔지?"** 입니다. 그리고 파일을 찾더라도 압축을 풀지 않은 채 안에 든 파일을 바로 열어, 고친 내용이 저장되지 않거나 프로그램이 제대로 돌지 않는 일이 반복됩니다. 둘 다 원리만 알면 1분이면 끝나는 일입니다.

## 먼저 이해하기
- **파일 탐색기**는 내 컴퓨터 안의 방과 서랍을 보여 주는 지도입니다. `Windows 로고 키 + E`로 엽니다.
- **다운로드 폴더**는 아파트 **택배 보관함**입니다. 크롬으로 받은 파일은 따로 정하지 않으면 모두 여기로 옵니다.
- **압축 파일**(`.zip`)은 여러 물건을 한 상자에 넣고 테이프로 봉한 **택배 상자**입니다. 상자 안을 들여다볼 수는 있지만, 물건을 쓰려면 **상자를 뜯어 꺼내야** 합니다. 이것이 "압축 풀기"입니다.
- **내 작업 폴더**는 택배 보관함에서 꺼낸 물건을 정리해 두는 **내 책상 서랍**입니다. 보관함은 매일 쌓이고 비워지는 곳이라, 오래 쓸 파일은 서랍으로 옮깁니다. 23강에서는 이 서랍 안에 AI 작업 도구(AGY)에게 내줄 `practice` 폴더를 만듭니다.

## 따라 해 보기
**가. 받은 파일 찾기**

1. 강사가 알려 준 주소에서 실습용 압축 파일을 크롬으로 받습니다.
2. 크롬에서 `Ctrl + J`를 누릅니다. 방금 받은 파일 목록이 새 탭에 열립니다. 파일 이름을 기억해 둡니다.
3. `Win + E`로 파일 탐색기를 엽니다. 왼쪽 목록에서 **다운로드**를 누릅니다.
4. 2번에서 본 이름의 파일이 보입니다. 지퍼가 달린 폴더 모양 아이콘이 압축 파일입니다.

**나. 압축 풀기**

5. 압축 파일 위에서 **우클릭**합니다.
6. 메뉴에서 <strong>모두 추출…</strong>을 누릅니다. (PC에 따라 "압축 풀기"로 보일 수 있습니다. 메뉴 이름은 버전에 따라 다를 수 있습니다)
7. 창이 뜨면 아래쪽 **추출**(또는 "압축 풀기") 단추를 누릅니다.
8. 같은 이름의 **일반 폴더**(지퍼 없는 노란 폴더)가 새로 생기고 자동으로 열립니다. 안의 파일은 이제 바로 써도 됩니다.

**다. 내 작업 폴더 만들기**

9. 탐색기 왼쪽에서 **내 PC** → **로컬 디스크 (C:)** → **사용자** → (내 계정 이름) 순서로 들어갑니다. 영문 화면이면 "사용자"가 `Users`로 보입니다.
10. 빈 곳에서 우클릭 → **새로 만들기** → **폴더**를 누릅니다.
11. 이름을 `my_work`로 입력하고 `Enter`를 누릅니다. 영문으로 짓는 까닭은, 나중에 쓸 AI 작업 도구와 여러 프로그램이 폴더 주소를 다룰 때 문제를 덜 일으키기 때문입니다.
12. 8번에서 생긴 폴더를 마우스로 끌어 `my_work` 폴더 위에 놓습니다. (끌어서 옮기기가 어렵다면 폴더를 누르고 `Ctrl + X`, `my_work`에 들어가 `Ctrl + V`)
13. `my_work` 폴더를 우클릭하고 **즐겨찾기에 추가**(또는 "빠른 액세스에 고정")를 누르면 왼쪽 목록에 늘 보입니다.

✔ 잘 됐는지 확인: 탐색기 왼쪽 목록에서 `my_work`를 누르면, 압축이 풀린 실습 폴더와 그 안의 파일이 보입니다.

✖ 안 될 때:
- 파일이 어디 있는지 모르겠다면 크롬에서 `Ctrl + J` → 파일 옆의 폴더 모양 아이콘(또는 "폴더 열기")을 누르면 그 파일이 있는 곳이 바로 열립니다.
- 압축 파일을 더블클릭해서 열었는데 안의 파일이 이상하게 동작한다면, 상자를 뜯지 않고 들여다보기만 한 상태입니다. 5~8번을 다시 합니다.
- 압축을 풀 때 비밀번호를 묻는다면 멈춥니다. 보낸 사람에게 확인하기 전에는 열지 않습니다. (Chrome 도움말도 비밀번호 걸린 압축 파일은 악성 코드를 숨기는 데 쓰일 수 있다고 안내합니다)

## AI에게 물어보기
> 나는 윈도우 11과 크롬을 쓴다. 인터넷에서 받은 zip 파일의 압축을 풀어 내 작업 폴더로 옮기려고 한다. 지금 파일 탐색기의 다운로드 폴더에 파일이 보이는데, 우클릭 메뉴에 "모두 추출"이 보이지 않는다. 이미 파일을 한 번 눌러 선택하고 우클릭해 봤다. 다른 방법을 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다.

## 혼자 다시 해 보기
- 아무 공공기관 누리집에서 서식 파일 하나를 받아 `Ctrl + J`로 위치를 확인하고, `my_work` 안에 `01_forms` 폴더를 만들어 옮깁니다. (`practice`라는 이름은 23강에서 AGY용으로 따로 쓰니 여기서는 쓰지 않습니다)
- 완료 기준: 파일을 받은 뒤 `my_work` → `01_forms` 안에 넣기까지 카드를 보지 않고 3분 안에 끝냅니다.
