# 24강. AGY 설치 파일 안전하게 받기, 사후 진단과 수료

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표

공식 사이트에서 내 PC에 맞는 AGY 설치 파일을 받아 진짜인지 확인하고, 사후 진단으로 첫날과 오늘을 비교합니다. **오늘은 받기와 확인까지만 합니다. 설치는 C1 2강에서 합니다.**

## 왜 여기서 막히나

강사의 AGY 특강 교안에는 가장 많이 막히는 지점이 하나로 적혀 있습니다. **x64냐 ARM64냐.** 윈도우용 다운로드 버튼이 두 개라, 내 PC와 다른 쪽을 받으면 설치가 되지 않습니다. 게다가 같은 페이지 아래쪽에 개발자용 제품의 버튼도 같은 이름('Download for x64')으로 또 있어서, 엉뚱한 제품을 받기 쉽습니다. 검색창에 "안티그래비티 다운로드"를 치면 공식이 아닌 사이트가 섞여 나올 수 있고(8강 가짜 다운로드 구별), 버튼을 눌렀는데 아무 일도 안 일어나 당황했다는 실제 질문도 있었습니다.

## 먼저 이해하기

- AGY: 구글이 만든 Google Antigravity(구글 안티그래비티)의 줄임말. 내가 열어 준 작업 폴더(23강의 `practice`) 안에서 파일을 읽고 만드는 AI 프로그램입니다.
- 설치 파일: 프로그램을 PC에 까는 데 쓰는 파일. 윈도우에서는 이름 끝이 `.exe` 입니다. 두 번 누르면 설치가 시작되므로, 오늘은 누르지 않습니다.
- x64 / ARM64: 프로세서(컴퓨터의 두뇌 부품) 방식에 따라 나뉜 설치 파일 종류. 23강에서 적은 '시스템 종류'로 고릅니다.
- 디지털 서명: 파일을 만든 회사가 붙이는 위조 방지용 전자 도장. 서명자가 `Google LLC` 이면 구글이 만든 진짜 파일입니다.
- CLI·IDE·SDK: 같은 페이지에 있는 개발자용 제품들. CLI(명령줄 도구, 글자 명령으로 쓰는 프로그램), IDE(통합 개발 환경, 프로그래머의 코드 편집 프로그램), SDK(소프트웨어 개발 키트, 프로그램을 만드는 부품 모음)입니다. 이 과정에서는 받지 않습니다.

공식 다운로드 주소는 `https://antigravity.google/download` 하나입니다. 이 페이지 맨 위의 **'Antigravity 2.0'** 이 이 과정과 다음 과정 C1에서 쓰는 데스크톱 앱(PC에 설치해 쓰는 프로그램)입니다. 윈도우는 64비트 Windows 10 이상이어야 합니다.

비유하자면 <strong>택배 송장 확인</strong>입니다. 문 앞 상자를 뜯기 전에 보낸 사람 이름부터 봅니다. 오늘은 상자를 받아 송장까지만 확인하고, 뜯어서 설치하는 일은 C1 2강에서 강사와 함께 합니다.

## 따라 해 보기

준비물: 23강에서 적어 둔 '시스템 종류' 메모. 모두 PC에서 합니다.

**가. 공식 페이지 열기**

1. PC에서 크롬을 엽니다.
2. 맨 위 주소창을 한 번 누르고, `https://antigravity.google/download` 를 **직접** 입력한 뒤 `Enter` 를 누릅니다. 검색 결과나 광고를 누르지 않습니다.
   → 이렇게 보이면 됩니다: 영어로 된 페이지가 열리고, 위쪽에 'Antigravity 2.0' 제목과 운영 체제별(macOS·Windows·Linux) 다운로드 칸이 보입니다.
3. 주소창을 다시 보고, `antigravity.google` 이 한 글자도 다르지 않게 그대로 있는지 확인합니다. `antigravity-download` 나 `.com` 처럼 다른 글자가 붙어 있으면 그 페이지를 닫습니다.

**나. 맞는 버튼 고르기**

4. 맨 위 'Antigravity 2.0' 부분에서 'Windows' 칸을 찾습니다. 페이지를 아래로 내리지 않습니다. 아래쪽의 'Antigravity CLI', 'Antigravity for IDEs', 'Antigravity SDK' 부분은 개발자용입니다. 특히 'Antigravity for IDEs' 에도 같은 이름의 버튼이 있으니 누르지 않습니다.
5. Windows 칸의 두 버튼 중 메모와 맞는 것을 **한 번만** 누릅니다.
   - 메모가 `x64 기반 프로세서` → 'Download for x64'
   - 메모가 `ARM 기반 프로세서` → 'Download for ARM64'
   → 크롬 오른쪽 위(주소창 오른쪽 끝)에 아래쪽 화살표 모양 '다운로드' 아이콘이 나타나고, 작은 창에 파일 이름과 받는 중인 표시가 보입니다.
6. 받는 동안 기다립니다. 인터넷 속도에 따라 몇 초에서 몇 분 걸립니다. 버튼을 여러 번 누르지 않습니다.
   → 작은 창의 파일 이름 아래 글자가 크기 표시(예: ○○MB)로 바뀌면 다 받은 것입니다.

**다. 받은 파일 찾기**

7. 크롬 오른쪽 위의 아래쪽 화살표 '다운로드' 아이콘을 누릅니다. 아이콘이 안 보이면 키보드에서 `Ctrl + J` 를 누릅니다(크롬의 다운로드 목록이 새 탭으로 열립니다).
8. 파일 이름을 확인합니다. x64를 골랐다면 `Antigravity-x64.exe`, ARM64를 골랐다면 `Antigravity-arm64.exe` 입니다. 같은 파일을 두 번 받았다면 `Antigravity-x64 (1).exe` 처럼 숫자가 붙습니다.
9. 파일 이름 옆(또는 아래)의 폴더 모양 아이콘('폴더에 표시' 또는 '폴더 열기')을 누릅니다. **파일 이름 자체는 누르지 않습니다**(누르면 설치가 시작될 수 있습니다).
   → 파일 탐색기가 열리고 '다운로드' 폴더 안에 방금 받은 파일이 파랗게 선택돼 보입니다. 확장자(`.exe`)가 안 보이고 `Antigravity-x64` 로만 보여도 같은 파일입니다.
10. **아직 두 번 누르지 않습니다.**

**라. 진짜인지 확인하기 (디지털 서명)**

11. 탐색기에서 그 설치 파일을 마우스 **오른쪽** 버튼으로 한 번 누릅니다.
12. 뜬 메뉴에서 '속성'을 누릅니다. 메뉴에 '속성'이 없으면 맨 아래 '추가 옵션 표시'를 누른 뒤 나오는 긴 메뉴 맨 아래에서 '속성'을 누릅니다.
    → '(파일 이름) 속성' 창이 뜹니다. 위쪽에 '일반', '호환성', '디지털 서명' 같은 탭(이름표처럼 생긴 칸)이 있습니다.
13. 위쪽 '디지털 서명' 탭을 누릅니다.
    → '서명 목록' 표가 보이고, 첫 칸 '서명자 이름'에 이름이 적혀 있습니다.
14. '서명자 이름'이 `Google LLC` 인지 한 글자씩 확인합니다.
    ✖ 다른 이름이거나 '디지털 서명' 탭 자체가 없으면 → 그 파일은 쓰지 않습니다. 창을 닫고, 파일을 오른쪽 버튼 → '삭제'(휴지통 모양)로 지운 뒤 1번부터 다시 받습니다.
15. 속성 창 아래 '확인'을 누르거나 오른쪽 위 'X'를 눌러 닫습니다.
16. 오늘은 여기서 멈춥니다. 파일은 '다운로드' 폴더에 그대로 둡니다. C1 2강에서 이 파일로 설치하고 로그인합니다.

(화면의 글자는 버전에 따라 조금 다를 수 있습니다)

**마. 사후 진단과 수료**

17. [점검표 모음](../checklists.md)의 "사전·사후 진단표"를 열어, 첫날(1강)과 같은 12문항의 '사후' 칸에 답합니다. 이름은 적지 않습니다.
18. 진단표 아래 "사후 실제 과제"(받은 파일 다섯 개를 찾아 `my_work` 로 옮기기)를 제한 시간 안에 해 봅니다.
19. '아니오'나 '모르겠음'으로 남은 문항은 "이 수업에서 풉니다" 칸의 수업으로 돌아가 다시 합니다.

✔ 잘 됐는지 확인: 내 시스템 종류와 같은 이름의 설치 파일이 '다운로드' 폴더에 있고, 디지털 서명이 `Google LLC` 입니다. 설치는 하지 않았습니다. 사후 진단표 12문항과 실제 과제의 결과 칸이 채워져 있습니다.

✖ 안 될 때:
- 버튼을 눌렀는데 아무 일도 없으면 → 10초쯤 기다린 뒤 `Ctrl + J` 로 다운로드 목록을 봅니다. 그래도 없으면 크롬의 광고 차단 같은 확장 프로그램(크롬에 덧붙여 설치한 작은 기능)이 막았을 수 있습니다. `Ctrl + Shift + N` 으로 시크릿 창을 열어 같은 주소에서 다시 눌러 봅니다. 회사·기관 인터넷이면 방화벽(외부 파일을 막는 보안 장치) 때문일 수 있으니 강사에게 알립니다.
- 버튼이 영어라 겁이 나면 → 22강처럼 페이지를 캡처해 AI에게 "x64 버튼이 어느 것인지" 묻습니다.
- 크롬이 '위험한 파일'이나 '일반적으로 다운로드되지 않는 파일'이라며 막거나 파일이 사라지면 → 주소를 다시 확인합니다. 공식 주소에서 받았는데도 반복되면 기관 PC의 보안 설정일 수 있으니 억지로 풀지 말고 강사에게 알립니다.
- x64를 받았는데 메모가 ARM이었다면 → 파일을 지우고 맞는 쪽을 다시 받습니다. 잘못 받는 것은 흔한 일이고, 다시 받으면 그만입니다.
- 실수로 파일을 두 번 눌러 설치 창이 떴다면 → 당황하지 말고 창 오른쪽 위 'X' 또는 '취소'를 눌러 닫습니다. 설치는 C1 2강에서 처음부터 함께 합니다.

## AI에게 물어보기

**어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11, 크롬을 쓴다. 구글 안티그래비티 설치 파일을 공식 사이트에서 받으려 한다. 지금 다운로드 페이지에 Download for x64와 Download for ARM64 버튼이 보인다. 설정 > 시스템 > 정보에서 시스템 종류를 확인했더니 "64비트 운영 체제, x64 기반 프로세서"라고 나온다. 어느 버튼을 눌러야 하는지, 그리고 받은 파일이 진짜인지 디지털 서명으로 확인하는 방법을 알려 줘. 설치는 아직 하지 않을 것이다.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 나중에 설치 중 구글 로그인 창이 나오더라도 비밀번호는 내가 직접 입력하고, AI나 다른 사람에게 알려 주지 않습니다.

## 혼자 다시 해 보기

1. `Win + E` → 왼쪽 목록 '다운로드'에서 설치 파일을 다시 찾아, 11~14번대로 디지털 서명을 한 번 더 확인합니다.
2. 다음 체크리스트를 스스로 표시합니다: 개인 크롬 프로필 □ 드라이브 링크 메일 □ 버전 기록 복원 □ 설문지→시트 □ 네 줄 질문 틀 □ 빈 `practice` 폴더 □ 서명 확인한 설치 파일 □

완료 기준: 일곱 칸이 모두 채워졌다면 C0 수료입니다. 다음 과정 **C1 AGY 입문** 은 2강에서 이 설치 파일로 AGY를 설치하고, 3강에서 `practice` 폴더를 연결해 첫 파일 `today.md` 를 만듭니다. 첫날 진단표와 오늘 진단표를 나란히 놓고, 달라진 칸을 세어 보세요. 그것이 이 과정의 성적표입니다.
