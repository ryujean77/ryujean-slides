# 17강. Gmail — 쓰기, 드라이브 링크 첨부, 검색과 라벨

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표

드라이브 파일을 링크로 붙인 메일을 나에게 보내고, 검색과 라벨로 그 메일을 다시 찾습니다.

## 왜 여기서 막히나

메일에 큰 파일을 그대로 붙이다가 크기 제한에 걸려 멈추거나, 받은 사람이 "파일이 안 열린다"고 되묻는 일이 흔합니다. 링크로 보낸 파일은 공유 권한까지 맞아야 열립니다. 또 받은편지함이 쌓이면 지난달 받은 서류 한 통을 찾느라 한참을 스크롤(화면을 위아래로 밀어 넘기기)합니다.

## 먼저 이해하기

- 첨부파일: 메일에 파일 자체를 실어 보내는 것.
- 링크: 누르면 그 파일이 있는 인터넷 주소로 바로 데려가는 글자. 파일은 드라이브에 그대로 있고, 주소만 보냅니다.
- 공유 권한: 링크를 받은 사람이 그 파일을 볼 수 있는지, 고칠 수 있는지 정한 것(12강·20강).
- 라벨: 메일에 붙이는 이름표. 폴더와 비슷하지만, 한 메일에 여러 개를 붙일 수 있습니다.

개인 Gmail은 한 통에 붙일 수 있는 첨부파일이 25MB(사진 여러 장 정도의 크기)까지입니다. 그보다 크면 Gmail이 파일을 드라이브 링크로 바꿔 넣습니다. 처음부터 <strong>드라이브 링크</strong>로 보내면 크기 걱정이 없고, 받는 사람은 늘 최신 파일을 봅니다.

비유하자면 첨부파일은 **물건을 상자에 담아 부치는 것**, 드라이브 링크는 <strong>창고 열쇠 번호를 알려 주는 것</strong>입니다. 열쇠를 줄 때는 누가 창고에 들어올 수 있는지(공유 권한)를 함께 정해야 합니다.

## 따라 해 보기

준비물: 드라이브에 올려 둔 파일 하나(12강에서 쓴 파일이면 좋습니다). 예시는 김은숙 씨가 드라이브에 올려 둔 `20261001_수업시간표_v01` 파일을 보내는 상황입니다. 모두 PC에서 합니다.

**가. 드라이브 링크를 넣은 메일 보내기**

1. PC에서 개인 크롬 프로필(6강) 창을 엽니다.
2. 주소창에 `https://mail.google.com` 을 입력하고 `Enter` 를 누릅니다.
   → 이렇게 보이면 됩니다: 왼쪽 위에 'Gmail' 글자와 '편지쓰기' 버튼, 가운데에 받은 메일 목록, 맨 위 가운데에 '메일 검색' 칸이 보입니다.
3. 오른쪽 위 끝 프로필 사진을 눌러 내 개인 계정 주소인지 봅니다. 맞으면 빈 곳을 눌러 닫습니다.
4. 왼쪽 위 연필 모양 '편지쓰기'를 누릅니다.
   → 화면 오른쪽 아래에 '새 메일' 창이 뜹니다. 위에서부터 '받는사람', '제목', 넓은 본문 칸, 맨 아래에 파란 '보내기' 버튼과 작은 아이콘 줄이 있습니다.
5. '받는사람' 칸을 누르고 <strong>내 이메일 주소</strong>를 씁니다. 연습은 늘 나에게 먼저 보냅니다.
6. '제목' 칸을 누르고 `10월 수업 시간표 보냅니다` 처럼 무엇이 들었는지 알 수 있게 씁니다.
7. 본문 칸을 누르고 `10월 시간표 링크입니다.` 한 줄을 씁니다.
8. 창 맨 아래 아이콘 줄에서 드라이브 모양(삼각형) 아이콘 'Drive에 저장된 파일 삽입'을 누릅니다. 아이콘 위에 마우스를 잠깐 올리면 이름이 뜹니다.
   → 드라이브 파일을 고르는 큰 창이 열립니다.
9. 창 위쪽 '내 드라이브'를 누르고, `20261001_수업시간표_v01` 파일을 한 번 눌러 고릅니다.
   → 파일에 파란 테두리나 체크가 생깁니다.
10. 창 <strong>아래쪽</strong>에서 '드라이브 링크'가 선택돼 있는지 보고(안 돼 있으면 누름), '삽입'을 누릅니다.
    → 본문에 파일 이름이 파란 링크로 들어갑니다.
11. 공유 설정을 바꾸라는 창이 뜨면, 받는 사람이 열 수 있도록 권한을 고르는 창입니다. 나에게 보내는 연습에서는 '보내기'를 누르거나 설정을 그대로 둡니다.
12. 파란 '보내기'를 누릅니다.
    → 화면 왼쪽 아래에 '메일을 보냈습니다.'가 잠깐 뜹니다. 잠시 뒤 받은편지함 맨 위에 방금 보낸 메일이 들어옵니다.

**나. 검색으로 다시 찾기**

13. 맨 위 가운데 '메일 검색' 칸(돋보기 모양)을 누릅니다.
14. `from:me 시간표` 를 입력하고 `Enter` 를 누릅니다. `from:me` 는 "내가 보낸 메일"이라는 뜻의 검색 표시입니다.
    → 목록에 방금 보낸 메일만 남습니다.

**다. 라벨 붙이기**

15. 찾은 메일 줄 맨 왼쪽의 작은 네모 칸을 눌러 체크합니다.
    → 목록 위쪽에 아이콘 줄이 새로 나타납니다.
16. 그 아이콘 줄에서 꼬리표 모양의 '라벨' 아이콘을 누릅니다.
    → 라벨 목록이 작은 창으로 뜹니다.
17. 창 아래쪽 '새로 만들기'를 누르고, 이름 칸에 `요가원` 을 쓰고 '만들기'를 누릅니다.
    → 화면 왼쪽 목록에 `요가원` 라벨이 생기고, 메일 제목 옆에 `요가원` 꼬리표가 붙습니다.

(화면의 글자는 버전에 따라 조금 다를 수 있습니다)

✔ 잘 됐는지 확인: 왼쪽 목록에서 `요가원` 라벨을 누르면 방금 보낸 메일이 보이고, 메일을 열어 본문의 링크를 누르면 드라이브 파일이 새 탭에서 열립니다.

✖ 안 될 때:
- 'Drive에 저장된 파일 삽입' 아이콘이 안 보이면 → 새 메일 창이 작아서 숨었을 수 있습니다. 새 메일 창 오른쪽 위의 대각선 화살표('전체화면')를 눌러 창을 키운 뒤 아래 아이콘 줄을 천천히 훑어봅니다.
- 검색이 안 되면 → 띄어쓰기를 확인합니다. `from:me` 는 붙여 쓰고, 뒤 단어와는 한 칸 띄웁니다.
- 왼쪽에 `요가원` 라벨이 안 보이면 → 왼쪽 목록 아래쪽 '더보기'를 누르면 나옵니다.
- 자주 쓰는 검색어: `has:attachment`(첨부 있는 메일), `label:요가원`(라벨 안에서), `after:2026/10/01`(그 날짜 이후).

## AI에게 물어보기

**어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11, 크롬에서 개인 Gmail을 쓴다. 드라이브에 있는 파일을 링크로 메일에 넣으려고 한다. 지금 편지쓰기 창은 열었는데 드라이브 모양 아이콘을 찾지 못했다. 창 아래 클립 모양 첨부 버튼은 눌러 봤다. 다음에 무엇을 눌러야 하는지 한 단계씩 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 메일 화면을 캡처해 물을 때는 다른 사람의 이름과 주소가 보이지 않게 잘라 냅니다.

## 혼자 다시 해 보기

1. 다른 드라이브 파일 하나를 <strong>드라이브 링크</strong>로 나에게 보내고, 같은 `요가원` 라벨을 붙입니다.
2. '메일 검색' 칸에 `label:요가원 has:attachment` 와 `label:요가원` 을 각각 넣어 결과가 어떻게 다른지 봅니다.

완료 기준: 라벨 안에 메일이 두 통 있고, 두 링크가 모두 열립니다.
