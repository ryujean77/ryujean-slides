# 2강. 마우스와 키보드 — 복사·붙여넣기·되돌리기

유정근 · 마이웨이 아카데미 | C0 컴퓨터 왕기초

## 오늘의 목표
마우스의 세 가지 누르기와 단축키 `Ctrl + C`·`Ctrl + V`·`Ctrl + Z`로 글을 복사하고, 붙이고, 실수를 되돌립니다.

## 왜 여기서 막히나
실습 현장에서 가장 자주 들리는 말은 "버튼이 없잖아요", "조금만 천천히요"입니다. 화면에 보이는 단추만 찾다 보면, 정작 오른쪽 단추 메뉴나 단축키로 한 번에 되는 일을 놓칩니다. 그리고 실수 한 번에 글이 사라질까 봐 손을 떼 버립니다. 오늘 배우는 `Ctrl + Z` 하나가 그 두려움을 가장 많이 덜어 줍니다.

## 먼저 이해하기
- **마우스 포인터**는 화면 위를 움직이는 작은 흰 화살표입니다. 마우스를 책상 위에서 밀면 따라 움직입니다. 노트북은 키보드 아래 네모난 판(터치패드)을 손가락으로 문질러 움직이고, 판 아래쪽 왼쪽·오른쪽을 누르면 마우스 왼쪽·오른쪽 단추와 같습니다.
- **왼쪽 한 번 누르기(클릭)**: 고르기. **왼쪽 두 번 빠르게(더블클릭)**: 열기. **오른쪽 한 번(우클릭)**: "여기서 할 수 있는 일" 메뉴 부르기.
- **끌기(드래그)**: 왼쪽 단추를 누른 채로 움직이기. 글자 위를 끌면 파랗게 <strong>선택</strong>(지금부터 이 글을 다루겠다고 표시한 상태)됩니다.
- <strong>커서</strong>는 글 쓰는 칸 안에서 깜빡이는 가느다란 세로 막대입니다. 글자는 늘 이 막대가 있는 자리에 들어갑니다.
- **클립보드**는 복사한 것을 잠시 담아 두는 보이지 않는 쟁반입니다. `Ctrl + C`(복사)로 쟁반에 올리고, `Ctrl + V`(붙여넣기)로 원하는 곳에 내려놓습니다. 몇 번이고 내려놓을 수 있습니다.
- <strong>`Ctrl + Z`(실행 취소)</strong>는 방금 한 일을 한 걸음 되돌립니다. 되돌린 것을 다시 하려면 `Ctrl + Y`입니다.
- <strong>단축키</strong>는 메뉴를 찾지 않고 키 두 개를 함께 눌러 바로 명령하는 방법입니다. `Ctrl`(키보드 맨 아랫줄 왼쪽 끝)을 **먼저 누른 채로** 다른 키를 톡 누르고, 둘 다 뗍니다.

오늘 익힐 열 개 — 이것만 반복합니다.

| 단축키 | 하는 일 |
|---|---|
| `Ctrl + C` | 복사 |
| `Ctrl + V` | 붙여넣기 |
| `Ctrl + X` | 잘라내기 (옮기기) |
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + A` | 모두 선택 |
| `Ctrl + S` | 저장 |
| `Ctrl + F` | 찾기 |
| `Alt + Tab` | 열린 창 사이 옮겨 가기 |
| `Win + E` | 파일 탐색기 열기 (3강) |
| `한/영` | 한글·영문 바꾸기 (`Space` 오른쪽 옆 키) |

## 따라 해 보기

1. 화면 맨 아래 작업 표시줄의 **시작** 단추(파란 창문 모양)를 한 번 누릅니다.
   → 이렇게 보이면 됩니다: 시작 메뉴가 열리고 맨 위에 검색 칸이 보입니다.
2. 아무 데도 누르지 말고 바로 키보드로 `메모장` 이라고 칩니다. 글자는 자동으로 검색 칸에 들어갑니다.
   → 이렇게 보이면 됩니다: 맨 위 결과에 파란 수첩 모양 아이콘과 "메모장"이 나옵니다.
3. 그 "메모장"을 한 번 누릅니다.
   → 이렇게 보이면 됩니다: 하얀 빈 종이 같은 창이 열리고, 왼쪽 위에 커서가 깜빡입니다.
4. `오늘 날짜 요가 수업 준비물: 매트, 물병` 이라고 칩니다. 영어(`dhsmf`처럼)가 나오면 `Backspace`(키보드 오른쪽 위, 왼쪽 화살표가 그려진 키)로 지우고 `한/영` 키를 한 번 누른 뒤 다시 씁니다.
5. 마우스 포인터를 "매트"의 "매" 바로 앞에 놓고, 왼쪽 단추를 누른 채로 "물병" 끝까지 오른쪽으로 끈 뒤 손을 뗍니다.
   → 이렇게 보이면 됩니다: "매트, 물병" 부분만 파란 바탕으로 칠해집니다.
6. `Ctrl` 을 누른 채 `C` 를 톡 누르고 둘 다 뗍니다. 겉으로는 아무 변화가 없는 것이 정상입니다. 쟁반에 올라갔을 뿐입니다.
7. 키보드 `End` 키를 누르거나 글 끝을 한 번 클릭해 커서를 맨 끝으로 옮긴 뒤 `Enter` 로 줄을 바꿉니다.
8. `Ctrl + V` 를 세 번 누릅니다.
   → 이렇게 보이면 됩니다: 새 줄에 "매트, 물병매트, 물병매트, 물병"이 붙습니다.
9. `Ctrl + A` 를 누릅니다.
   → 이렇게 보이면 됩니다: 창 안의 글 전체가 파랗게 칠해집니다.
10. `Delete` 키(키보드 오른쪽 위쪽, `Del` 로 적힌 키도 있음)를 누릅니다. 글이 모두 사라집니다.
11. 당황하지 말고 `Ctrl + Z` 를 한 번 누릅니다.
    → 이렇게 보이면 됩니다: 지운 글이 모두 돌아옵니다.
12. 이번에는 글자 위에 포인터를 놓고 마우스 **오른쪽** 단추를 한 번 누릅니다.
    → 이렇게 보이면 됩니다: 작은 메뉴에 '복사', '붙여넣기' 같은 글자가 보입니다. 단축키가 기억나지 않을 때의 비상구입니다. 아무 데도 누르지 않으려면 `Esc`(키보드 왼쪽 맨 위)를 누릅니다.
13. 다른 창과 오가는 연습을 위해 `Win + E` 로 파일 탐색기(3강에서 배움)를 하나 엽니다.
14. `Alt`(`Space` 왼쪽 옆 키)를 누른 채로 손을 떼지 말고 `Tab`(키보드 왼쪽, `Q` 왼쪽 키)을 톡 누릅니다.
    → 이렇게 보이면 됩니다: 화면 가운데에 열린 창들의 작은 그림이 나란히 뜹니다. `Tab` 을 한 번 더 누를 때마다 테두리가 옆으로 옮겨 갑니다.
15. 메모장 그림에 테두리가 있을 때 `Alt` 에서 손을 뗍니다. 메모장이 앞으로 나옵니다. 파일 탐색기는 오른쪽 위 `X` 로 닫습니다.
16. 메모장 오른쪽 위 `X` 를 눌러 닫습니다. 저장할지 묻는 창이 뜨면 '저장 안 함'을 누릅니다. 묻지 않고 그냥 닫혀도 괜찮습니다 — 메모장 버전에 따라 다릅니다. (저장은 4강에서 이름을 정해서 합니다)

✔ 잘 됐는지 확인: 10번에서 지운 글이 11번의 `Ctrl + Z` 한 번으로 돌아왔다면 성공입니다.

✖ 안 될 때:
- 붙여넣기를 했는데 아무것도 안 나오면 6번의 복사가 안 된 것입니다. 글이 파랗게 선택된 상태에서 다시 `Ctrl + C`를 누릅니다.
- 끌다가 파란색이 사라지면 중간에 왼쪽 단추에서 손이 떨어진 것입니다. 5번부터 다시, 천천히 끕니다.
- `Ctrl + Z`가 안 먹는 것 같으면 `Ctrl`을 먼저 꾹 누르고 있는지 확인합니다. 두 키를 동시에 "탁" 치면 잘 안 됩니다.
- 한글이 "ㅇㅛㄱㅏ"처럼 풀어져 나오면 입력 중에 `한/영`이 바뀐 경우가 많습니다. 지우고 천천히 다시 씁니다.

## AI에게 물어보기

> AI 앱(질문에 글로 답해 주는 프로그램)은 21강에서 함께 준비합니다. 크롬에서 이미 구글 계정으로 로그인해 두었다면 지금 아래 방법으로 묻고, 아직이라면 이 칸은 건너뛰었다가 21강 뒤에 돌아와 해 봅니다.
>
> **어디에 입력하나요:** PC에서 크롬을 열고 주소창에 `https://gemini.google.com` 을 입력해 들어갑니다. 구글 계정으로 로그인돼 있으면 화면 아래쪽에 글을 쓰는 입력칸이 보입니다. 그 칸을 한 번 누르고, 아래 글을 복사(`Ctrl + C`)해 붙여 넣은(`Ctrl + V`) 뒤 `Enter` 를 누르거나 오른쪽의 보내기(제출) 버튼을 누르세요. (여러 줄을 쓸 때는 `Enter` 대신 `Shift + Enter` 로 줄을 바꿉니다 — `Enter` 만 누르면 바로 보내집니다.) 답이 위쪽에 나타나면 끝까지 읽고, 모르는 말이 있으면 "○○가 무슨 뜻이야?" 라고 이어서 물으면 됩니다.
> 화면을 보여 주고 싶으면: 입력칸 왼쪽의 '+' 또는 파일 추가 버튼으로 캡처 이미지(C0 22강의 `Win + Shift + S`)를 올린 뒤 질문을 씁니다.

> 나는 윈도우 11에서 메모장을 쓴다. 쓴 글을 다른 곳에 복사해서 붙이려고 한다. 지금 글을 선택하고 Ctrl + C, Ctrl + V를 눌렀는데 아무것도 붙지 않는다. 이미 글이 파랗게 선택됐는지 확인했다. 무엇을 다시 확인해야 하는지 알려 줘.

⚠ 비밀번호·인증번호·주민번호는 AI에 넣지 않습니다. 복사한 내용에 이런 정보가 섞여 있지 않은지도 한 번 봅니다.

## 혼자 다시 해 보기
- 메모장에 아무 문장 한 줄을 쓰고, **복사 → 붙여넣기를 20번** 반복합니다. 마지막에 `Ctrl + A` → `Delete` → `Ctrl + Z`로 되살립니다.
- 완료 기준: 표의 단축키 열 개 가운데 여덟 개 이상을 카드를 보지 않고 말하고 써 볼 수 있습니다.
