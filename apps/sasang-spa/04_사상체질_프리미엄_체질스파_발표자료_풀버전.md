## [Slide 02] Problem Statement : 기존 일반 스파와 디톡스의 3대 치명적 한계 (문제 정의)
* **문제 1. 획일적 처방의 부작용 ('One-Size-Fits-All' Risk)**:
  - "만인에게 좋은 것은 누구에게도 맞지 않는다."
  - 열이 많은 사람에게 고온 사우나/진저 오일 적용 시 두통·안구충혈·불면 악화, 몸이 찬 사람에게 찬 탄산스파/페퍼민트 적용 시 복통·냉증 악화.
* **문제 2. 1회성 마사지의 한계 (Temporary Relief)**:
  - 피부/근육 표면만 만져주는 마사지는 다음 날 피로가 100% 원상복귀됨. 체내 장부(간·폐·비·신)의 불균형과 심부 독소 정체 방치.
* **문제 3. 무분별한 디톡스·식이요법의 역효과**:
  - 체질을 무시한 샐러드/녹즙 디톡스는 소음인의 비위를 파괴하고, 고단백 육류 과다는 태양인의 간에 치명적 과부하 유발.

---

## [Slide 03] Our Solution : 사상체질 스파가 제시하는 3대 근본 해결책 (해결 방법)
* **해결 1. 장부대소(臟腑大小)에 기반한 0% 부작용 초개인화 처방**:
  - 1894년 이제마 『동의수세보원』의 과학적 해부생리학과 생체 데이터를 결합하여 오직 내 몸에만 맞는 오일·수온·약재 100% 선별.
* **해결 2. 3중 융합 신체 리셋 (스파 외용 + 12h 단식 섭생 + 비언어 의전)**:
  - 80분 이원화 바디(한의 수기+순수 오일)와 12시간 단식(자가포식)으로 세포 단위 찌꺼기 청소 후 맞춤 미역국으로 장부 영양 재건.
* **해결 3. 평생 지속 가능한 바이오 라이프스타일 (DTC 유전자 / 마이크로바이옴 / LRP 구독)**:
  - 1회성 힐링을 넘어 일상 복귀 후에도 체질 맞춤 섭생과 최고급 순수 에센셜 오일 구독을 통해 만성 불균형 재발 원천 차단.

## [Slide 04] 체질별 4대 고질적 병리 문제 & 1:1 맞춤 해결 프로토콜
* **태음인 (문제: 노폐물/림프 정체, 호흡기 건조, 비만 경향)**
  - ➔ **해법**: 디톡스 림프 배농 + 유칼립투스/샌달우드 호흡기 보습 + 소고기 양지 들깨 미역국 + 은반지 엄지손가락(1지) / 금반지 넷째손가락(4지).
* **소양인 (문제: 상체 열감, 두통, 가슴 답답, 불면증, 신장 음기 고갈)**
  - ➔ **해법**: 38.5℃ 쿨링 하이드로 + 페퍼민트/라벤더 뇌파 진정 + 돼지고기 수육/조개 미역국 + 은반지 가운데손가락(3지) / 금반지 새끼손가락(5지).
* **소음인 (문제: 수족냉증, 위장 냉증, 만성 소화불량, 만성 피로)**
  - ➔ **해법**: 41℃ 한방 온열 족욕 + 42~45℃ 심부 온열 챔버(체온 1℃ 상승) + 온가드/진저 + 닭가슴살 황기 미역국 + 은반지 새끼손가락(5지) / 금반지 가운데손가락(3지).
* **태양인 (문제: 기운 상기, 목덜미 강직, 간 해독력 저하, 하체 무력)**
  - ➔ **해법**: 단전 호흡 태극선법 기체조(그라운딩) + 베티버/프랑킨센스 + 완도산 전복 홍합 해물 미역국 + 은반지 넷째손가락(4지) / 금반지 엄지손가락(1지).
