마이크로비트와 함께 문제해결 시작하기 (나는야 해바라기)

운영안 서보 0점을 먼저 맞춘다 → 조도센서·서보 연결 → 밝기 > 800 조건문 → 빛·소리·기울기 데이터 수집해 교재에 기록 → 우리 팀 아이템에 필요한 센서 토의

⏱ 2차시에서 미룬 센서 측정·기록을 여기서 소화 ▶ 연수 영상 3차시 시작 지점

교육할 내용

  • 교안하드웨어: 확장보드 1번 = 조도센서, 2번 = 서보모터(해바라기 부착)
  • 교안조도값 확인: 손가락으로 가렸을 때·뗐을 때 숫자를 메모
  • 교안조건문: 밝기 > 800 이면 서보 45° + 웃는 얼굴, 아니면 0° + 찡그린 얼굴
  • 교안데이터 가설 설정과 수집 환경 설계, 팀 발표

주의점

  • 주영욱 대표서보모터는 조립하기 전에 0점을 맞춘다. 접속해서 각도 값을 한 번 줘 본다. 순서를 놓치면 전부 분해해서 다시 해야 한다
  • 주영욱 대표교안에는 서보 0점 맞추기 설명이 없다. 강사가 직접 짚어 줘야 한다
  • 연수 영상조도값을 메모한 뒤 반드시 다운로드를 누르고 새 프로젝트로 넘어간다 (여기서 가장 헷갈린다)
  • 연수 영상확장보드에 꽂은 번호와 코드 속 핀 번호(P1·P2)가 같아야 한다

중요한 점

  • 주영욱 대표800은 고정값이 아니다. 학생이 직접 잰 ‘손을 뗐을 때 값’을 기준으로 넣는다
  • 주영욱 대표2차시에서 미룬 빛·소리·기울기 측정은 여기서 한다. 교재에 기록한다
  • 주영욱 대표토의 질문 ‘우리 제품에는 어떤 센서가 필요할까?’ — 여기서 최종 디바이스 방향을 잡아야 뒤가 산다

주영욱 대표 코멘트

주영욱 대표3차시에 하나 유의하실 게, 먼저 조립을 하면 안 돼요. 서보모터는 항상 0점을 맞춰야 돼요. 그래야 결과값이 안 틀려요. 통화 34:53
주영욱 대표삑 하고 돌아갈 수도 있거든요. 그럼 그게 0점인 거예요. 아니면 이거 다 다시 분해해서 새로 해야 되거든요. 통화 35:20
