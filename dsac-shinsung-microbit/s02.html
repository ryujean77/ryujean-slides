마이크로비트 실시간 데이터 수집과 모니터링 (바람이 조절되는 선풍기)

운영안 시연 영상 → 확장보드·배터리홀더 결착 → 교재 15쪽 → 사이트 가입·로그인 → A/B/A+B 버튼, 아날로그 출력 400/1023, 정지, LED 아이콘. 센서 측정은 3차시 뒤로

⏱ 하드웨어 세팅에만 2~3시간 예상. 수업이 처음으로 어려워지는 지점 ▶ 연수 영상 2차시 시작 지점

교육할 내용

  • 교안하드웨어: 마이크로비트 → 확장보드 → 배터리홀더 → 3핀 케이블 → DC모터 → 날개
  • 교안소프트웨어: makecode.microbit.org → 새 프로젝트 ‘바람이 조절되는 선풍기’
  • 교안코드: A 버튼 = P0 아날로그 400, B 버튼 = 1023, A+B = 0(정지), 상태마다 아이콘 출력
  • 교안업로드: 5핀 USB 연결 → 쌍(페어) → Connect → 배터리 ON

주의점

  • 주영욱 대표가장 큰 관건은 마이크로비트 접속. 연결이 정말 잘 안 된다. 인내심을 갖고 연결한다
  • 주영욱 대표페어링이 안 되면 ‘파일로 다운로드’로 넘어간다
  • 주영욱 대표인터넷이 나빠 끝내 안 되면 오래 붙들지 말고 시연 영상을 보여 주고 넘어간다. 선풍기에 집착하면 하루 종일 선풍기만 만든다
  • 주영욱 대표배터리홀더 선은 한 번 꽂히면 잘 안 빠지고, 힘을 주면 툭 끊어진다. 조심히 꽂고 조심히 빼게 한다
  • 주영욱 대표선풍기 날개를 끝까지 꽉 끼우지 않는다. 뺄 때 모터 축이 부러질 수 있다
  • 주영욱 대표시키지 않은 LED 배선 등을 앞서 하는 학생을 막는다. 선이 떨어지면 수업이 무너진다
  • 주영욱 대표교안의 센서 측정·기록(데이터 수집 기록표)은 이 차시에서 하지 않는다. 센서를 어디 꽂는지도 안 배운 상태다

중요한 점

  • 주영욱 대표강사가 블록을 일일이 설명할 필요 없다. 교재대로 하면 학생들이 만든다. 강사가 할 일은 ‘연결’을 풀어 주는 것
  • 주영욱 대표“안 돼요”의 대부분은 배터리를 안 꽂았거나 배터리 케이스에 건전지가 없는 경우
  • 주영욱 대표모터가 멈추지 않고 계속 돈다 → 출력 포트가 아닌 입력 포트에 꽂았거나 프로그램이 계속 전송 중. 끊었다가 다시 연결
  • 주영욱 대표배선: 노랑 = 신호, 빨강 = +, 검정 = −. 안 되면 뒤집어 꽂아 보고, 반대쪽(모터 쪽)도 확인
  • 주영욱 대표첫 시간 고지: “멀쩡한 교구를 줬다. 다 점검해 봐라. 망가뜨리면 이후 실습은 못 한다”
  • 연수 영상USB 케이블은 마이크로비트 위쪽, 배터리홀더는 옆쪽 단자. 배터리가 약하면 USB를 옆 단자에 꽂아 전원으로 쓴다
  • 연수 영상3핀 케이블은 밋밋한 면이 확장보드 쪽, 케이블 색과 확장보드 색을 맞춰 꽂는다
