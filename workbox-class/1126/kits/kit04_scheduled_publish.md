# ④ 1년치 예약 발행 스타터 키트

> **분류:** KIT 04 · 발행 · 예약 콘텐츠
> **목적:** 시즌 계획을 세우고 초안 하나를 검수한 뒤, 승인한 것만 예약으로 올라가게 합니다.

---

## 1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

- **계획을 말하면 순서가 나온다:** 주제 수, 대본 길이, 올리는 주기, 채널을 말하면 에이전트가 주제 검색 → 제작 스킬 → 초안 → 연결 순서로 계획을 냅니다.
- **초안 하나를 먼저 검수한다:** 에이전트는 초안을 하나 만들어 검수받은 뒤 같은 방식으로 반복합니다. 첫 초안에서 기준을 잡아야 나머지가 내 입맛대로 나옵니다.
- **승인한 것만 올라간다:** 예약 작업이 끝나면 메신저로 “검수해 주세요”가 오고, 내가 승인한 것만 예약됩니다. 시즌(졸업·입학·명절·휴가)은 미리 걸어 두고 트렌드는 그 시기에 다시 봅니다.

### 📁 작업 폴더(`workbox/`) 투입 원형 자료

- `01_채널_정보.md` — 채널 이름, 대상 시청자, 지금까지 올린 것
- `02_시즌_달력.md` — 1년 중 놓치면 안 되는 시기
- `03_샘플_대본.md` — (선택) 마음에 들었던 대본이나 글

---

## 2. 예약 발행 시즌 설계서

### 1. 채널과 대상
- 가이드: 누가 보나
- 작성(예시): 유튜브 쇼츠 / 60·70대

### 2. 형식과 길이
- 가이드: 영상·글, 몇 분
- 작성(예시): 1분 쇼츠, 내 목소리 나레이션

### 3. 주기
- 가이드: 매일·격일·주 1회
- 작성(예시): 이틀에 하나

### 4. 시즌
- 가이드: 꼭 걸어 둘 시기
- 작성(예시): 졸업·입학, 설, 추석, 여름휴가, 크리스마스

### 5. 승인 방법
- 가이드: 어디서 무엇을 보고 승인하나
- 작성(예시): 초안 링크를 받아 보고 "승인"이라고 답함

---

## 사람이 승인하는 단계

이 칸에서는 에이전트가 멈추고 묻게 합니다.

| 단계 | 내가 확인할 것 |
| --- | --- |
| 주제 목록 | 빼거나 더할 주제 |
| 첫 초안 | 고칠 점과 유지할 점 |
| 예약 직전 | 날짜·제목·공개 상태 |

---

## 3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

### 요청문 1. 1년 예약 발행 계획 요청문 (에이전트 · 계획)
- **언제 쓰나요:** 채널 운영을 맡기기 시작할 때

```text
나는 [채널]에 [대상]이 좋아할 [형식]을 [주기]로 올리고 싶어.
1. 주제 후보 20개를 찾아 표로 보여 주고, 근거가 된 검색 결과를 붙여 줘.
2. [시즌 목록]에 맞춰 1년 달력 초안을 만들어 [달력 이름.md]로 저장해 줘.
3. 필요한 제작 스킬이 있으면 설치하기 전에 무엇인지 알려 줘.
4. 내가 승인하기 전에는 아무것도 만들거나 올리지 마. 모르는 것은 물어봐.
```

### 요청문 2. 승인한 초안만 예약 올리기 (에이전트 · 예약)
- **언제 쓰나요:** 초안을 검수하고 승인한 뒤

```text
내가 승인한 초안은 [초안 파일 목록]이야. 이것만 예약으로 올려 줘.
1. 에고 라이트 브라우저로 [채널 관리 화면]을 열고, 로그인이 필요하면 나에게 넘겨 줘.
2. 각 영상의 제목·설명·예약 날짜를 [달력 파일]대로 넣되, 저장 직전에 목록을 보여 주고 내 확인을 받아.
3. 예약을 마치면 공개 상태가 '예약'인지 확인하고 결과를 표로 남겨 줘.
승인 안 한 파일은 올리지 마.
```

## 4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

- [ ] 주제 목록에서 내 채널과 안 맞는 주제를 뺐는가?
- [ ] 첫 초안을 직접 보고 고칠 점을 말했는가?
- [ ] 예약 직전 날짜·제목·공개 상태를 확인했는가?
- [ ] 승인하지 않은 콘텐츠가 올라가지 않았는가?
