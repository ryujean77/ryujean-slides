⑤ 나만의 규칙 파일 스타터 키트

쓰는 에이전트에 맞는 규칙 파일을 만들고, 정말 읽는지 확인하고, 거슬릴 때마다 한 줄씩 키웁니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 에이전트마다 먼저 읽는 파일이 있다: Antigravity는 GEMINI.md, Codex는 AGENTS.md, Claude Code는 CLAUDE.md를 실행하면 가장 먼저 읽습니다. 하나만 쓰면 그 파일에 규칙을 바로 씁니다.
  • 여러 개면 law.md 하나로 고삐를: 두세 에이전트를 섞어 쓰면 각 파일엔 “law.md를 먼저 읽어라”만 두고 규칙은 law.md에 모읍니다. 한 곳만 고쳐도 모두 같은 규칙을 따릅니다.
  • 외우지 말고 이해하고 지운다: 남의 기본 파일을 받으면 이름을 내 것으로 바꾸고, 쓰지 않는 파일을 가리키는 줄은 모두 지웁니다. 처음엔 몇 줄로 시작해 거슬릴 때마다 한 줄씩 더합니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_쓰는_에이전트.txt — 하나만 쓰는지, 여러 개를 섞어 쓰는지
  • 02_거슬렸던_것.md — 지금까지 에이전트가 해서 불편했던 행동 목록
  • 03_기본_규칙파일.md — (선택) 강사에게 받은 기본 파일

PROMPT 01 · 에이전트 · 만들기

첫 규칙 파일 만들기 요청문

작업 폴더에 규칙이 없을 때

이 작업 폴더의 맨 위에 [GEMINI.md / CLAUDE.md / AGENTS.md] 규칙 파일을 만들어 줘. 나는 [에이전트] 하나만 써.
규칙은 아래로 시작할게. 마크다운 번호 목록으로 써 줘.
1. 모든 답변은 한국어로 한다.
2. 결과물은 [폴더] 안에 [날짜 형식]_[영문 이름] 폴더를 만들어 저장한다.
3. 확인하지 않은 사실·자료·주소를 지어내지 않는다.
4. 문서 작성자는 [내 이름]으로 적는다.
5. 큰 작업을 끝내면 스스로 한 번 더 검수한다.
만든 뒤 전체 경로와 내용을 그대로 보여 줘.
PROMPT 02 · 에이전트 · 확인

규칙을 읽는지 확인하는 요청문

프로그램을 껐다 켜고 새 대화에서

이 작업 폴더에 [파일 이름] 설정 파일이 있어?
1. 있으면 전체 경로와 규칙 목록을 요약해 보여 줘.
2. 너는 새 대화를 시작할 때 이 파일을 가장 먼저 읽어 들여? 이번 대화에서도 읽었는지 알려 줘.
3. 규칙 가운데 이 폴더에 없는 파일(law.md 등)이나 폴더를 가리키는 줄이 있으면 찾아 줘.
4. 고칠 줄이 있으면 제안만 하고, 내가 "적용"이라고 할 때 고치고 고치기 전 파일은 백업해 줘.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 규칙 파일이 내 컴퓨터의 작업 폴더 맨 위에 있는가?
  • 작성자 이름이 내 이름으로 바뀌었는가?
  • 없는 파일을 가리키는 줄이 남아 있지 않은가?
  • 새 대화에서 에이전트가 이 파일을 먼저 읽는다고 확인했는가?
