# ⑥ 반복 작업을 스킬로 만드는 스타터 키트

> **분류:** KIT 06 · 스킬 · 반복 작업과 깃허브 스킬
> **목적:** 세 번 한 일을 스킬로 굳히고, 깃허브에서 남의 스킬을 골라 와 내 에이전트의 능력을 키웁니다.

---

## 1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

- **세 번 하면 스킬로:** 복습노트를 17일·19일·25일 세 번 만들자 에이전트가 먼저 스킬로 만들지 물었습니다. 샘플을 보고 두세 번 고쳐 확정하면, 다음부터는 빠르고 품질도 좋아집니다.
- **깃허브는 스킬 창고:** 영상 편집, 발표자료 디자인, 1인 회사 운영 같은 스킬이 깃허브에 공개돼 있습니다. 에이전트와 깃을 연결해 두면 필요한 스킬을 찾아 설치합니다.
- **남의 스킬은 설치 전에 읽는다:** 스킬은 내 PC에서 명령을 실행할 수 있습니다. 무엇을 하는지 요약을 먼저 받고, 출처가 분명한 것만 설치합니다. 마지막 결과는 늘 내가 검수합니다.

### 📁 작업 폴더(`workbox/`) 투입 원형 자료

- `01_반복한_결과물/` — 같은 일을 두세 번 한 결과 폴더들
- `02_마음에_든_기준.md` — 결과물에서 매번 지키고 싶은 기준

---

## 2. 반복 작업 스킬 설계서

### 1. 반복하는 일
- 가이드: 무엇을 몇 번 했나
- 작성(예시): 사업계획서 초안 / 3번

### 2. 결과물 위치
- 가이드: 비교할 재료
- 작성(예시): 결과물/계획서_1, _2, _3

### 3. 매번 같았던 순서
- 가이드: 에이전트가 뽑아 주면 확인
- 작성(예시): 자료 읽기 → 목차 → 근거 표 → 본문 → 검수

### 4. 완성 기준
- 가이드: 끝났다고 판단할 것
- 작성(예시): 10쪽, 근거 표 2개, 출처 주소 전부

---

## 남의 스킬 설치 전 점검

깃허브에서 고른 스킬을 설치하기 전에 확인합니다.

| 확인할 것 | 결과 |
| --- | --- |
| 누가 만들었고 언제 고쳤나 | 저장소 주소·업데이트 날짜 |
| 내 PC에서 무엇을 실행하나 | 에이전트 요약 |
| 내 일에 정말 필요한가 | 쓸 작업 한 줄 |

---

## 3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

### 요청문 1. 반복 작업을 스킬로 굳히는 요청문 (에이전트 · 스킬 만들기)
- **언제 쓰나요:** 같은 일을 두세 번 한 뒤

```text
나는 [반복하는 일]을 [횟수]번 했어. 결과물은 [폴더 경로들]에 있어.
1. 결과물을 비교해서 매번 같았던 순서와 기준을 뽑아 줘.
2. 그걸 스킬(SKILL.md)로 만들어 줘. 입력, 작업 순서, 완성 기준, 마지막 검수 항목을 넣어.
3. 그 스킬로 샘플을 하나 만들어 먼저 보여 줘. 내가 "확정"이라고 하기 전에는 고정하지 마.
4. 내가 고칠 점을 말하면 스킬에 반영하고 무엇을 바꿨는지 알려 줘.
```

### 요청문 2. 깃허브에서 스킬 골라 오기 (에이전트 · 스킬 찾기)
- **언제 쓰나요:** 결과물을 더 좋게 만들고 싶을 때

```text
나는 [하려는 일]을 더 잘하고 싶어. 깃허브에서 이 일에 쓰는 에이전트 스킬 중 많이 쓰이는 것 세 가지를 찾아 줘.
1. 각각 이름, 저장소 주소, 별 수, 마지막 업데이트, 하는 일 한 줄.
2. 설치하면 내 PC에서 무엇을 실행하는지 요약해 줘.
3. 내가 하나를 고르면 그때만 설치해 줘.
4. 설치 뒤 같은 일을 시켜 전과 무엇이 달라졌는지 비교해 줘.
확인 못 한 정보는 지어내지 마.
```

## 4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

- [ ] 스킬로 만든 샘플을 직접 보고 고칠 점을 말했는가?
- [ ] 남의 스킬이 무엇을 실행하는지 설치 전에 읽었는가?
- [ ] 설치 전후 결과를 비교했는가?
- [ ] 스킬로 만든 결과물도 마지막에 내가 검수했는가?
