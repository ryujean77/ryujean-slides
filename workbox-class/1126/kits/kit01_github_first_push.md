# ① 깃허브 첫 연결 스타터 키트

> **분류:** KIT 01 · 깃허브 · 첫 연결과 업로드
> **목적:** 에이전트가 설치와 업로드를 맡고, 나는 로그인과 승인만 하도록 처음 한 번을 끝까지 넘깁니다.

---

## 1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

- **처음 한 번은 에이전트가 하게 둔다:** 방법 A로 “네가 해 줘”라고 하면 깃과 깃허브 CLI 설치, 저장소 준비를 에이전트가 합니다. 앞으로도 계속 올릴 것이니 손으로 한 번 올리는 것보다 에이전트가 올릴 수 있게 연결하는 편이 낫습니다.
- **막히면 강사 말고 에이전트에게 묻는다:** 에이전트의 말을 못 알아들으면 그 문장을 드래그해 붙이고 더 쉽게 설명해 달라고 합니다. 두 번 세 번 묻더라도 스스로 답을 받아 내는 것이 이 산을 넘는 방법입니다.
- **올라갔다고 추정하지 말고 눈으로 본다:** 에이전트의 “완료했습니다”만 믿지 않고 깃허브 저장소 페이지를 새로고침해 파일을 직접 확인합니다. 판단은 내가 합니다.

### 📁 작업 폴더(`workbox/`) 투입 원형 자료

- `01_작업폴더_경로.txt` — 올릴 워크스페이스 폴더의 전체 경로
- `02_깃허브_계정.txt` — 깃허브 아이디, 가입한 방식(구글 계정 등). 비밀번호는 적지 않음
- `03_올리면_안되는_것.md` — 개인정보·비밀번호·대용량 영상처럼 올리지 않을 파일과 폴더

## 2. 깃허브 첫 연결 준비표

### 1. 올릴 폴더
- 가이드: 에이전트가 지금 열고 있는 폴더와 같은가
- 작성(예시): D:\workspace (탐색기 주소창에서 복사)

### 2. 깃허브 아이디
- 가이드: 아이디가 두 개라면 어느 쪽인가
- 작성(예시): my-github-id (구글 계정으로 가입)

### 3. 저장소 이름과 공개 여부
- 가이드: 처음엔 비공개가 안전
- 작성(예시): my-workspace / private

### 4. 올리지 않을 것
- 가이드: 개인정보·비밀번호·큰 파일
- 작성(예시): 고객명단.xlsx / .env / 원본영상 폴더

### 5. 확인 방법
- 가이드: 끝났다고 판단할 기준
- 작성(예시): 저장소 페이지에 파일 목록이 보이고 Private 표시

## 막힌 곳 → 다시 묻는 말 대조표

수업에서 실제로 멈춘 지점입니다.

| 막힌 곳 | 다시 묻는 말 |
| --- | --- |
| 저장소 URL을 알려 달라고 함 | URL을 어떻게 알 수 있어? 없으면 네가 새로 만들어 줘 |
| 터미널 창을 클릭하라고 함 | 터미널을 못 찾겠어. 다른 방법으로 로그인 창을 띄워 줘 |
| 저장소가 안 보임 | 지금 연결된 계정 아이디와 저장소 주소를 알려 줘 |

## 3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

### 요청문 1. 설치부터 업로드까지 맡기는 요청문 (에이전트 · 첫 업로드)
- **언제 쓰나요:** 처음 깃허브에 올릴 때

```text
내 워크스페이스 폴더 [폴더 경로]를 깃허브에 올리고 싶어. 깃허브 아이디는 [아이디]야.
1. 먼저 지금 상태(깃 설치, 저장소 연결)를 확인해 알려 줘.
2. 필요한 프로그램 설치와 저장소 준비는 네가 해 줘. 저장소 이름은 [이름], 비공개로.
3. [올리지 않을 파일 목록]은 올리지 않도록 제외해 줘.
4. 로그인·승인처럼 내가 해야 하는 일은 그때 멈추고 한 단계씩 알려 줘.
5. 끝나면 저장소 주소와 올라간 파일 수를 알려 줘. 모르는 것은 지어내지 말고 물어봐.
```

### 요청문 2. 브라우저 인증 뒤 이어 가는 요청문 (에이전트 · 인증 뒤)
- **언제 쓰나요:** 일회용 코드를 넣고 승인한 직후

```text
브라우저에서 깃허브 인증을 마쳤어. 일회용 코드를 넣고 승인까지 눌렀어.
1. 인증이 실제로 됐는지, 어느 계정으로 연결됐는지 확인해 줘.
2. 됐으면 커밋한 내용을 푸시하고, 저장소 주소를 알려 줘.
3. 저장소가 공개로 되어 있으면 비공개로 바꿀지 나에게 물어봐.
4. 앞으로 다시 올릴 때 내가 할 말을 한 줄로 알려 줘.
안 되면 오류 문장을 그대로 보여 주고, 내가 할 다음 한 단계만 알려 줘.
```

## 4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

- [ ] 인증 화면의 아이디가 에이전트에 연결할 아이디와 같은가?
- [ ] 저장소 페이지를 직접 열어 파일을 눈으로 확인했는가?
- [ ] 저장소가 비공개(Private)로 되어 있는가?
- [ ] 개인정보·비밀번호가 든 파일이 올라가지 않았는가?
