# ② 에이전트 전용 브라우저 스타터 키트

> **분류:** KIT 02 · 브라우저 · 에고 라이트·어사이드
> **목적:** AI가 쓰기 좋은 브라우저를 설치하고, 로그인은 내가 하고 나머지는 에이전트가 하는 손발을 만듭니다.

---

## 1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

- **브라우저는 에이전트의 손발:** 브라우저를 주면 에이전트가 사이트를 열고, 검색하고, 글을 쓰고, 예약을 겁니다. 크롬과 쓰는 법은 같지만 AI 자동화용이라 토큰이 적게 듭니다.
- **로그인과 결제는 사람이:** 에이전트는 로그인 페이지까지 열고 제어권을 넘깁니다. 아이디·비밀번호·인증 문자는 내가 넣고 Return to agent로 돌려줍니다. 결제와 게시처럼 되돌리기 어려운 일은 내가 승인합니다.
- **설치도 에이전트에게 묻는다:** “에고 라이트를 연결해서 쓰고 싶어, 설치해 줘”라고 하면 에이전트가 방법을 찾아 연결 부분은 하고, 앱 설치 순서를 안내합니다. 공식 사이트에서만 받습니다.

- `01_쓰는_에이전트.txt` — Antigravity·Claude Code·Codex 중 지금 쓰는 것
- `02_자주_가는_사이트.md` — 에이전트에게 맡기고 싶은 사이트와 할 일 목록

## 2. 전용 브라우저 설치 점검표

### 1. 고른 브라우저
- 가이드: 에고 라이트 또는 어사이드
- 작성(예시): 에고 라이트 (lite.ego.app)

### 2. 온보딩 선택
- 가이드: 크롬 데이터 가져오기, 탭 모양
- 작성(예시): 크롬 탭 가져오기 예, 세로 탭, 기본값으로 설정

### 3. 연결 테스트 결과
- 가이드: 에이전트가 확인했는가
- 작성(예시): 에고 브라우저 연결까지 모두 확인됨

### 4. 규칙에 넣을지
- 가이드: 브라우저 작업은 이걸 쓰라고 정할지
- 작성(예시): 예. 규칙 파일에 기본 브라우저로 한 줄 추가

---

## 브라우저 방식 비교

수업에서 정리한 네 가지 방식입니다.

| 방식 | 특징 |
| --- | --- |
| 앱 내장 브라우저 | 설치 없음. 일부 사이트가 막음 |
| 크롬 + 확장 | 평소 크롬 그대로. 보안 경고로 막히기도 함 |
| 화면 제어 | 정보량이 많아 토큰이 많이 듦 |
| 에고 라이트·어사이드 | AI 전용. 토큰이 적고 빠름 |

## 3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

### 요청문 1. 전용 브라우저 설치 요청문 (에이전트 · 설치)
- **언제 쓰나요:** 처음 설치할 때

```text
나는 [에고 라이트 / 어사이드] 브라우저를 연결해서 쓰고 싶어. 설치해 줘.
1. 공식 사이트와 설치 방법을 먼저 확인해서 알려 줘. 공식이 아닌 다운로드 주소는 쓰지 마.
2. 네가 설치할 수 있는 부분은 네가 하고, 내가 직접 설치할 앱은 순서대로 알려 줘.
3. 내가 "설치 완료했어"라고 하면 연결 테스트를 하고 결과를 알려 줘.
4. 앞으로 브라우저 작업에 이걸 쓰도록 규칙 파일에 추가할지 나에게 물어봐.
```

### 요청문 2. 로그인은 내가, 일은 에이전트가 (에이전트 · 로그인 넘기기)
- **언제 쓰나요:** 로그인이 필요한 사이트 작업

```text
에고 라이트 브라우저를 열어서 [사이트 이름]에 로그인할 거야.
1. 로그인 페이지까지만 열고 나에게 제어권을 넘겨 줘. 아이디·비밀번호·인증은 내가 직접 할게.
2. 내가 "됐어"라고 하면 로그인 상태를 확인해 줘.
3. 그다음 [할 일]을 해 줘.
4. 결제·주문·게시·삭제처럼 되돌리기 어려운 일은 하기 전에 나에게 물어봐.
결과는 작업 폴더에 [파일 이름.md]로 남겨 줘.
```

## 4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

- [ ] 공식 사이트에서 내려받았는가?
- [ ] 로그인 정보는 내가 브라우저에 직접 넣었는가?
- [ ] 결제·게시 같은 일은 내가 승인한 것만 실행됐는가?
- [ ] 에이전트의 연결 테스트 통과 답을 확인했는가?
