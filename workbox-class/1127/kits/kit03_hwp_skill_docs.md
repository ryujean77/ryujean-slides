# ③ 한글 문서 스킬 스타터 키트

> **분류:** KIT 03 · 문서 · 한글(HWP) 스킬
> **목적:** 한글 편집기가 없어도 에이전트가 HWPX 문서를 만들고 읽게 합니다. 설치부터 시험 문서, 열어 보기까지.

---

## 1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

- **새 주제는 새 대화창:** 메일 일과 한글 스킬 설치는 다른 주제입니다. 같은 폴더 안에서 New conversation in project로 새 창을 열고 시작합니다.
- **처음부터 한글로 만든다:** PDF를 한글로 바꾸면 그림이 빠지는 등 잘 안 됩니다. 스킬이 있으니 처음부터 한글 파일로 만들어 달라고 합니다.
- **만든 파일은 열어 봐야 안다:** 옛 한글 2018에서는 글자가 까맣게 보이기도 했습니다. 호프(HOP) 같은 뷰어로 열어 실제 모양을 확인하는 것까지가 일입니다.

### 📁 작업 폴더(`workbox/`) 투입 원형 자료

- `01_문서_원본.md` — 한글 문서로 만들 내용(마크다운 원본)
- `02_양식_예시.hwpx` — 맞춰야 할 기존 양식이 있으면 그 파일

## 2. 한글 문서 사양서

### 1. 문서 종류
- 가이드: 보고서·공문·계획서 중 무엇인가
- 작성(예시): 사업계획서 요약 3장

### 2. 원본 내용
- 가이드: 마크다운 원본이 있는가
- 작성(예시): 01_문서_원본.md

### 3. 양식
- 가이드: 맞출 서식이 있는가
- 작성(예시): 02_양식_예시.hwpx의 제목·표 모양

### 4. 가릴 정보
- 가이드: 개인정보 마스킹이 필요한가
- 작성(예시): 이름·연락처·주민번호

### 5. 확인 방법
- 가이드: 무엇으로 열어 볼까
- 작성(예시): 호프(HOP)로 열어 표와 글자색 확인

## 3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

### 요청문 1. 한글 스킬 찾아 설치하는 요청문 (에이전트 · 스킬 설치)
- **언제 쓰나요:** 새 대화창을 연 직후

```text
깃허브에서 HWP 한글 파일 스킬을 검색해서 설치해 줘.
1. 후보가 여러 개면 가장 널리 쓰이고 관리가 잘 되는 것 하나를 골라 이유를 알려 줘.
2. 설치한 뒤 실제로 동작하는지 검증해 줘.
3. 이 스킬로 할 수 있는 것(읽기·변환·만들기·편집)과 못 하는 것을 쉬운 말로 정리해 줘.
4. 원본을 직접 편집하려면 추가로 필요한 스킬이 있는지도 알려 줘.
설치 중에 내 허락이 필요하면 멈추고 물어봐. 토큰이 많이 드는 작업이면 미리 알려 줘.
```

### 요청문 2. 마크다운 원본으로 한글 문서 만드는 요청문 (에이전트 · HWPX 만들기)
- **언제 쓰나요:** 스킬 설치가 끝난 뒤

```text
설치한 한글 스킬로 [01_문서_원본.md]를 HWPX 문서로 만들어 줘.
1. PDF를 거치지 말고 처음부터 한글 파일로 만들어 줘.
2. [양식 파일]이 있으면 제목·번호·표 모양을 그대로 따라 줘.
3. 글자색은 검정, 음영은 없음으로 해서 옛 한글 버전에서도 보이게 해 줘.
4. 이름·연락처 같은 개인정보는 가려 줘.
5. 만든 뒤 내용을 다시 읽어 깨진 곳이 없는지 확인하고 파일 경로를 알려 줘.
```
