KIT 06 · 보고서 · 통화에서 기획서까지

⑥ 통화→보고서·기획서 스킬 스타터 키트

통화 녹음과 기존 양식 폴더를 함께 주면 보고서나 기획서 초안이 몇 분 만에 나옵니다. 자주 하면 스킬로 굳힙니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 기준 원본 하나를 정한다: 강사는 11월 25일 복습노트를 기준 원본(SSOT)으로 정한 뒤부터 늘 같은 품질로 만들어지게 했습니다. 내 보고서도 가장 잘된 한 편을 기준으로 삼습니다.
  • 폴더 두 개를 같이 준다: 통화 녹음 폴더와 기존 보고서·양식 폴더를 함께 주면, 에이전트가 형식과 말투를 따라 1~2분 만에 초안을 씁니다.
  • 초안은 나에게 먼저: 기획서는 상대에게 바로 보내지 않고 내 메일로 먼저 받습니다. 읽고 고친 뒤에 보냅니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_통화_녹음_폴더 — 인박스에서 이번 건에 해당하는 녹음과 텍스트
  • 02_양식_폴더 — 기존 보고서·기획서와 양식, 기준 원본 한 편
  • 03_조건.md — 타깃·예산·분량 같은 내가 정한 조건
STEP 02 · INTERACTIVE WORKSHEET

2. 통화→문서 작업 지시서

통화가 끝난 뒤 바로 채웁니다. (입력 내용은 현재 브라우저에 자동 저장됩니다.)

설계 항목 나의 프로젝트 내용 작성 (예시 수정 가능)
1. 문서 종류
보고서인가 기획서인가
2. 기준 원본
따라 할 가장 좋은 문서
3. 내가 정한 조건
녹음에 없는 내 생각
4. 뺄 내용
보고서에 넣지 않을 것
5. 받는 곳
초안을 어디로
💾 입력 시 브라우저에 자동 저장됩니다.
STEP 03 · COPY-PASTE PROMPTS FOR AGENT

3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

오른쪽 [요청문 원클릭 복사] 버튼을 누른 뒤 Antigravity(AGY)·Codex·Claude Code·타임리 에이전트에 붙여넣으세요. 대괄호 [...] 부분을 내 상황에 맞게 바꿔 쓰면 됩니다.

PROMPT 01 · 에이전트 · 보고서 초안

양식 폴더 + 녹음 폴더로 보고서 쓰는 요청문

통화가 끝난 직후

폴더 두 개를 줄게.
- 통화 녹음 폴더: [경로]
- 양식 폴더: [경로] (기존 보고서와 양식, 기준 원본은 [파일 이름])
1. 기준 원본의 형식과 말투를 그대로 따라서 오늘 통화 내용으로 [보고서 종류]를 써 줘.
2. 결재가 필요한 항목은 따로 표시해 줘.
3. 녹음에만 있는 개인적인 이야기는 빼.
4. 불확실한 부분은 [확인 필요]로 표시해.
다 쓰면 파일 경로를 알려 주고, 보내는 건 내가 확인한 뒤에만 해.
PROMPT 02 · 에이전트 · 스킬로 굳히기

자주 하는 문서 작업을 스킬로 만드는 요청문

같은 문서를 세 번 이상 만들었을 때

지금까지 통화 녹음으로 [문서 종류]를 만든 방식을 스킬로 만들어 줘.
1. 입력: 녹음 폴더와 양식 폴더 경로. 기준 원본은 [파일 이름]으로 고정해.
2. 순서: 녹음 읽기 → 합의·부탁·미정 정리 → 초안 작성 → 내 메일로 보내기.
3. 매번 지킬 규칙: 개인 이야기 제외, [확인 필요] 표시, 상대에게는 승인 뒤에만 발송.
4. 스킬 이름과 쓰는 법을 한 줄로 알려 줘.
스킬 파일을 만들기 전에 초안을 보여 주고 내 승인을 받아.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 기준 원본이 정말 가장 잘된 문서인가?
  • 녹음과 다른 내용이 지어내어 들어가지 않았는가?
  • 개인적인 대화와 연락처가 빠졌는가?
  • 상대에게 보내기 전에 내가 끝까지 읽었는가?
