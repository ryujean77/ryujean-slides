① 배운 것·활용 능력 보고서 스타터 키트

내 작업 폴더를 가진 에이전트에게 나를 인터뷰하게 해서, 지금 어디까지 왔는지 보고서 두 개로 받고 메일로 보냅니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 보고서는 내 폴더에서 시작한다: 프로젝트 밖 대화에서 시키면 에이전트가 내 작업을 못 찾습니다. 워크스페이스 폴더를 연 상태에서 시켜야 실제 파일 이름이 들어간 보고서가 나옵니다.
  • 요청문은 빠짐없이 넣는다: 수업에서 요청문 일부만 넣었더니 배운 것도 활용 능력도 빠진 보고서가 나왔습니다. 무엇을 알고 싶은지 두 가지를 모두 적어야 의도대로 나옵니다.
  • 보낸 뒤 보낸편지함이 증거다: 첨부 없이 도착한 메일이 여러 통 있었습니다. 보내고 끝이 아니라 보낸편지함에서 클립 표시와 파일 이름을 확인해야 끝입니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_워크스페이스_경로.txt — 그동안 실습한 작업 폴더의 전체 경로
  • 02_복습노트_목록.md — 들은 수업 날짜와 복습노트 주소
  • 03_받는사람.txt — 보고서를 받을 메일 주소와 보낼 계정(Gmail·네이버)

STEP 03 · COPY-PASTE PROMPTS FOR AGENT

PROMPT 01 · 에이전트 · 보고서 A

지금까지 배운 것 보고서 요청문

작업 폴더를 연 직후

나는 [과정 이름] 수업을 듣고 있어. 이 워크스페이스는 그동안 실습한 폴더야.
폴더 안의 파일과 복습노트를 읽고 "지금까지 배운 것과 내가 작업한 것" 보고서를 만들어 줘.
1. 날짜·주제별로 무엇을 배웠는지
2. 내가 실제로 만든 파일과 그 위치
3. 아직 끝내지 못한 것
4. 다음에 해 볼 것 세 가지
[MD와 HTML] 두 가지로 저장하고 경로를 알려 줘. 모르는 건 지어내지 말고 나에게 질문해. 다 만들면 내가 열어 보고 확인할 때까지 기다려.
PROMPT 02 · 에이전트 · 보고서 B

AI 에이전트 활용 능력 평가 요청문

보고서 A를 받은 뒤

방금 만든 보고서와 이 워크스페이스의 작업 기록을 바탕으로 나의 AI 에이전트 활용 능력 수준을 평가해 줘.
1. 평가 전에 나에게 질문을 다섯 개 이상 먼저 해 줘. 내가 답한 뒤에 평가해.
2. 실행·지시·검수·산출물 관리·위임·문제 해결 항목별로 지금 수준과 근거를 적어 줘.
3. 다음 단계로 가려면 무엇을 연습할지 세 가지.
결과는 [평가 보고서 이름]으로 따로 저장하고, 근거가 부족한 평가는 '근거 부족'이라고 표시해 줘.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 보고서에 적힌 파일 이름이 내 폴더에 실제로 있는가?
  • 평가 근거가 내 실제 작업과 맞는가?
  • 개인정보(연락처·계정)가 보고서에 들어가지 않았는가?
  • 보낸편지함에서 첨부 두 개를 확인했는가?
