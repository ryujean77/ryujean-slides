② 스킬로 만드는 쇼츠 기획·영상 제작 스타터 키트

스킬을 찾아 비교하고, 대본을 먼저 검수한 다음, 재생되는 영상 파일과 업로드까지 한 단계씩 확인합니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 스킬은 비교하고 설치: 추천 수만 보지 말고 최신성·만든 사람·요구 권한을 함께 봅니다.
  • 대본과 영상은 다른 파일: 대본이나 HTML 렌더러가 생겼다고 영상이 된 것이 아닙니다. 재생해야 완성입니다.
  • 내 기준 이상만 업로드: 목표 조회수와 원하는 반응을 정하고, 기준에 못 미치면 다시 만듭니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_영상_목표.md — 이 키트의 양식을 채운 기획 기준
  • 02_참고영상.txt — 참고할 영상 주소와 좋았던 이유
  • 03_내_소재/ — 직접 쓴 이야기와 사용 권한이 있는 사진·영상

PROMPT 01 · AGY · GitHub

숏폼 스킬 3종 비교·설치 요청문

영상 제작 능력이 없거나 부족할 때

YouTube 숏폼을 기획하고 실제 영상 파일로 만드는 데 좋은 스킬을 GitHub에서 찾아 줘.

사람들이 많이 추천한 세 개를 골라 역할, 별 수, 최근 갱신일, 만든 사람, 필요한 프로그램과 권한, 비용을 표로 비교해 줘.
내 컴퓨터에 이미 있는 환경도 확인하고 가장 단순한 조합 하나를 추천해.
내가 동의하면 설치와 시험 실행까지 하고, 설치된 것과 안 된 것을 구분해서 쉬운 말로 알려 줘.
PROMPT 02 · AGY · 조사와 대본

인기 영상 구조 조사·대본 선검수 요청문

주문서를 채운 뒤

아래 주문서로 쇼츠를 만들 거야.
[주문서 붙여넣기]

같은 시청자에게 반응이 큰 영상 5개를 조사해 제목, 첫 3초, 기승전결, 내레이션 분위기, 화면 구도를 비교해 줘. 확인한 주소를 함께 적어.
문장을 베끼지 말고 구조만 참고해서 내 주제의 대본을 구간(초)·화면·내레이션 표로 작성해.
대본을 나에게 먼저 검수받고, 승인 전에는 영상을 만들지 마.
PROMPT 03 · AGY · Codex

재생되는 파일까지 만들기 요청문

대본을 승인한 뒤 또는 영상이 안 보일 때

승인한 [대본 파일 경로]를 재생되는 영상 파일로 만들어 줘. 나는 대본이나 HTML이 아니라 영상이 필요해.

필요한 프로그램이 없으면 무엇이 왜 필요한지 말하고, 설치할 수 있는 것은 네가 해 줘.
내가 눌러야 할 일이 있으면 한 번에 한 단계씩, 화면의 어느 위치인지 알려 줘.
완료되면 저장 경로, 길이, 해상도와 재생 확인 방법을 알려 주고 업로드는 내 확인을 기다려.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 영상 파일을 처음부터 끝까지 소리를 켜고 재생했는가?
  • 타인의 영상·음원·이미지·문장을 그대로 쓰지 않았는가?
  • 실제처럼 보이는 AI 생성 장면이면 YouTube의 표시 항목을 선택했는가?
  • 내 채널과 공개 범위를 확인하고 최종 공개는 내가 했는가?
