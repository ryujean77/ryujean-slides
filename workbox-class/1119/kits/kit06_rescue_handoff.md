# ⑥ 막힘 해결·다른 에이전트로 이어가기 스타터 키트

> **분류:** KIT 06 · 문제 해결 · 재질문 · 에이전트 이어가기
> **목적:** 오류와 한도에 걸려도 목표를 놓치지 않도록, 상황을 설명하고 같은 폴더를 다른 에이전트에 넘깁니다.

---

## 1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

- **문제 해결이 먼저:** 환경을 완벽히 꾸미기보다 원래 만들려던 것을 끝내는 길을 찾습니다.
- **답을 읽고 다시 묻기:** AI가 이미 알려 준 단계를 놓쳤는지 보고, 모르는 부분만 다시 묻습니다.
- **도구에 종속되지 않기:** 폴더와 맥락을 주면 Antigravity에서 Codex·Claude Code로 이어집니다.

### 📁 작업 폴더(`workbox/`) 투입 원형 자료

- `01_현재_상황.md` — 목표, 한 일, 멈춘 곳
- `02_오류_캡처.png` — 비밀번호·개인정보를 가린 화면
- `03_작업_폴더/` — 지금까지 만든 파일이 든 같은 폴더

---

## 2. 막힘·인계 메모

### 1. 원래 목표
- 가이드: 고치려는 오류가 아닌 산출물
- 작성(예시): 90초 쇼츠 영상 파일 한 개

### 2. 여기까지 한 일
- 가이드: 도구와 만든 파일
- 작성(예시): Antigravity로 대본과 렌더러 HTML까지 만들었다. [경로]

### 3. 멈춘 지점
- 가이드: 본 메시지 그대로
- 작성(예시): 사용 한도가 끝났고 영상 파일은 찾지 못했다.

### 4. 시도한 질문
- 가이드: AI의 답도 요약
- 작성(예시): 영상 보는 법을 물었더니 렌더링이 필요하다고 했다.

### 5. 해결의 증거
- 가이드: 열고 재생해서 확인
- 작성(예시): 폴더의 영상 파일이 소리와 함께 끝까지 재생된다.

## 3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

### 요청문 1. 캡처 설명과 쉬운 재질문 요청문 (Gemini · ChatGPT · Claude)
- **언제 쓰나요:** 메시지나 다음 동작을 모르겠을 때

```text
첨부한 화면은 내가 [원래 목표]를 하다가 멈춘 상황이야.
나는 컴퓨터 용어가 낯설어.

이 메시지가 오류인지 단순 안내인지 먼저 한 문장으로 말해 줘.
그다음 내가 놓친 것과 해결 방법을 한 번에 한 동작씩, 화면의 위치와 성공했을 때 보일 모습까지 알려 줘.
모르는 단어는 쉬운 비유로 풀고, 내가 '못 알아듣겠어'라고 하면 같은 말을 반복하지 말고 더 쉽게 설명해.
```

### 요청문 2. 한도 소진 작업 이어받기 요청문 (Codex · Claude Code)
- **언제 쓰나요:** 같은 폴더를 다른 에이전트에서 연 직후

```text
[작업 폴더 경로]는 Antigravity에서 작업하다가 사용 한도가 끝난 폴더야.
원래 목표: [목표]
마지막으로 하던 일: [멈춘 지점]

파일을 먼저 읽고 완료된 것, 덜 된 것, 실제로 열어 확인되지 않은 것을 구분해 줘.
이미 된 것은 다시 만들지 말고 원본도 덮어쓰지 마.
남은 순서를 보여 준 뒤 내 동의를 받아 이어서 하고, 완료 증거로 파일 경로와 확인 방법을 남겨 줘.
```

### 요청문 3. 해결 과정 5줄 기록 요청문 (현재 에이전트 · 기록)
- **언제 쓰나요:** 문제가 실제로 해결된 직후

```text
방금 해결한 대화에서 다음에 다시 볼 중요한 것만 5줄로 정리해 [저장 경로]에 새 파일로 남겨 줘.
1. 원래 목표
2. 막힌 증상
3. 문제를 푼 핵심 질문
4. 실제 해결 동작
5. 다음에 먼저 확인할 것

시도했지만 실패한 것을 성공으로 쓰지 말고, 비밀번호와 개인정보는 빼.
내가 다른 사람에게 설명할 수 있게 쉬운 말로 써 줘.
```

- [ ] 완료됐다는 답이 아니라 실제 파일을 열어 확인했는가?
- [ ] 이어받으면서 이전 파일이 사라지거나 덮어써지지 않았는가?
