KIT 06 · 모델 고르기 · 이어 가기

⑥ 모델 고르기 + 한도 바닥 대비 스타터 키트

일에 맞는 모델을 아래에서부터 고르고, 사용량이 바닥나도 같은 폴더를 다른 에이전트에 지정해 끊김 없이 이어 갑니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 아래에서 시작해 올라간다: 낮은 모델이나 기본값으로 시작해 답이 마음에 들면 계속 쓰고, 아니면 상위 모델로 올라갑니다. 모델을 고르는 이유는 시간과 비용 대비 효율입니다.
  • 채팅이 아니라 에이전트로 옮긴다: 기록이 내 워크스페이스에 남아야 도구를 바꿔도 이어집니다. 한도가 바닥나면 다른 에이전트에 같은 폴더를 지정합니다.
  • 진행 메모를 남겨 둔다: 단계가 끝날 때마다 진행 상황을 폴더에 메모로 남기게 하면, 새 에이전트가 폴더만 읽고도 이어 갑니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_작업_폴더/ — 지금 하는 프로젝트 폴더 전체
  • 02_진행_메모.md — 어디까지 했는지, 남은 일, 결정한 것
  • 03_쓸_수_있는_도구.md — 결제했거나 무료로 쓸 수 있는 에이전트와 모델 목록
STEP 02 · INTERACTIVE WORKSHEET

2. 모델·도구 선택표

STEP 03 · COPY-PASTE PROMPTS FOR AGENT

3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

오른쪽 [요청문 원클릭 복사] 버튼을 누른 뒤 Antigravity(AGY)·Codex·Claude Code·타임리 에이전트에 붙여넣으세요. 대괄호 [...] 부분을 내 상황에 맞게 바꿔 쓰면 됩니다.

PROMPT 01 · 에이전트 · 모델 선택

이 일에 맞는 모델 고르기 요청문

새 일을 맡기기 전

이번에 맡길 일은 [작업 내용]이야.
지금 고를 수 있는 모델은 [화면에 보이는 모델 이름들]이야.
1. 이 일에 고급 추론이 얼마나 필요한지 상·중·하로 판단해 줘.
2. 가장 낮은 단계부터 시험할 모델 하나와, 결과가 마음에 안 들 때 올라갈 모델 하나를 골라 줘.
3. 마음에 안 든다를 판단할 기준 세 가지를 적어 줘.
모르는 모델이면 추측하지 말고 모른다고 말해 줘.
PROMPT 02 · 다른 에이전트 · 이어 가기

한도 바닥 뒤 이어 가기 요청문

사용량이 바닥나 다른 에이전트로 옮길 때

다른 에이전트에서 하던 작업을 여기서 이어서 하려고 해. 작업 폴더는 [폴더 경로]야.
1. 폴더 안의 파일과 기록(계획서, 진행 메모, .md 파일)을 읽고 어디까지 됐는지 세 줄로 정리해 줘.
2. 남은 일을 순서대로 적어 줘.
3. 내가 확인하면 남은 일의 첫 단계부터 이어서 해 줘.
4. 앞으로는 단계가 끝날 때마다 진행 메모를 이 폴더에 갱신해 줘.
앞에서 만든 파일은 덮어쓰지 말고, 고칠 때는 백업을 먼저 만들어.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 지금 쓰는 창이 채팅이 아니라 에이전트인가?
  • 새 에이전트의 요약이 실제 진행 상황과 맞는가?
  • 시작 모델의 결과를 판단 기준 세 가지로 평가했는가?
  • 진행 메모가 폴더에 갱신되고 있는가?
