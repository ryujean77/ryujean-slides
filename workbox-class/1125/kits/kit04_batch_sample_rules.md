# ④ 샘플 → 규칙 → 대량 제작 스타터 키트

> **분류:** KIT 04 · 대량 제작 · 샘플과 규칙
> **목적:** 52강처럼 많이 만들 일을 샘플 하나로 검수하고, 고친 기준을 규칙으로 쌓은 뒤 백그라운드로 돌리며 정기 점검을 겁니다.

---

## 1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

- **이름과 백업이 기억을 대신한다:** 2~3일 지나면 가물가물해지니 산출물 폴더는 날짜·시간·제목으로 짓고, 고칠 때마다 백업을 남깁니다.
- **샘플을 통과시킨 뒤 늘린다:** 많이 만들기 전에 하나를 먼저 만들어 검수합니다. 통과한 기준을 규칙으로 남기면 그다음부터 내 입맛대로 나옵니다.
- **오래 도는 일에는 점검을 건다:** 대화창을 닫아도 도는 제작이라면 주기적으로 점검하게 하고, 같은 오류가 반복되면 끝까지 가기 전에 멈추게 합니다.

### 📁 작업 폴더(`workbox/`) 투입 원형 자료

- `01_원자료/` — 조사 자료, 예전 강의 녹음, 캡처, 유튜브 주소
- `02_형식.md` — 한 편이 따라야 할 순서(예: 배울 것 셋 → 본문 → 역사 → 지금의 쓰임)
- `03_규칙.md` — 샘플 검수에서 나온 기준. 에이전트가 갱신

---

## 2. 대량 제작 규칙 설계서

### 1. 만들 것과 개수
- 가이드: 형식과 총량
- 작성(예시): 5분짜리 강의 영상 52편과 수업 원고

### 2. 한 편의 형식
- 가이드: 순서
- 작성(예시): 오늘 배울 것 세 가지 → 이야기 → 역사 → 지금의 쓰임 → 정리

### 3. 폴더·백업 규칙
- 가이드: 이름 짓기와 백업
- 작성(예시): 연월일_시분_제목, 고치기 전 원본 백업

### 4. 통과 기준
- 가이드: 검수할 때 볼 것
- 작성(예시): 글자 깨짐 0, 화면 떨림 0, 말끝 잘림 0

### 5. 점검 주기
- 가이드: 오래 도는 작업
- 작성(예시): 55분마다 점검, 같은 오류 2건이면 멈춤

## 3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

### 요청문 1. 샘플 하나 먼저 요청문 (에이전트 · 샘플)
- **언제 쓰나요:** 원자료와 형식을 모은 뒤

```text
[원자료 폴더 경로]의 자료로 [산출물]을 모두 [개수]개 만들 거야.
많이 만들기 전에 [첫 주제] 하나만 샘플로 만들어 줘.
형식은 [형식 파일 경로]를 따라 줘.
산출물 폴더는 연월일_시분_제목 규칙으로 만들고, 고칠 때마다 이전 판을 백업해 줘.
다 만들면 사용한 자료와 새로 만든 그림 수를 결과 보고로 적어 줘.
내가 통과라고 하기 전에는 나머지를 만들지 마.
```

### 요청문 2. 대량 제작과 정기 점검 요청문 (에이전트 · 대량·점검)
- **언제 쓰나요:** 샘플이 통과한 뒤

```text
샘플이 통과됐어. 지금까지 고친 기준을 [규칙 파일 경로]에 정리한 다음, 그 규칙대로 나머지 [개수]개를 만들어 줘.
1. 먼저 계획서(순서, 폴더 구조, 걸리는 시간)를 보여 줘.
2. 오래 걸리면 대화창을 닫아도 계속 돌게 만들고 그렇게 되는지 알려 줘.
3. [55분]마다 점검해 규칙에 어긋난 것을 보고해 줘. 같은 오류가 두 개 이상이면 멈추고 물어봐.
4. 판단이 어려운 선택은 권장안과 이유를 붙여 물어봐.
```

## 4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

- [ ] 샘플을 직접 열어 처음부터 끝까지 보고 통과시켰는가?
- [ ] 규칙 문서에 이번에 고친 기준이 모두 들어갔는가?
- [ ] 중간 결과 몇 개를 직접 열어 검수했는가?
- [ ] 멈춤 보고가 왔을 때 이유를 읽고 대응했는가?
