KIT 05 · 자료 학습 · 규칙 검증

⑤ 전략 문서 학습 + 모의 검증 스타터 키트

흩어진 글을 PDF로 모아 학습시키고, 단순한 규칙 두세 개를 과거 데이터로 모의 검증합니다. 실제 주문 연결은 하지 않습니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 프로그램보다 기준이 먼저: 내가 기준을 모르면 에이전트가 알아서 해 줄 수 없습니다. 내 기준이나 참고할 전략을 먼저 세웁니다.
  • 규칙은 두세 개로 단순하게: 지표가 많아지면 신호가 너무 다양해져 결정이 어렵습니다. 가장 간단한 규칙 두세 개로 시작합니다.
  • 검증과 모의가 먼저: 지난 몇 달의 데이터로 시뮬레이션하고, 한두 달 모의로 돌려 본 뒤에 판단합니다. 실제 주문 연결은 사람이 승인합니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_전략글_PDF/ — 카페·블로그 글을 인쇄 → PDF로 저장해 모은 것
  • 02_내_기준.md — 시간 단위, 대상, 지표, 시간대, 자금 규모
  • 03_과거_데이터.csv — 차트 프로그램에서 내보낸 과거 데이터(있으면)
STEP 02 · INTERACTIVE WORKSHEET

2. 내 기준 설계서

자료를 학습시키기 전에 채웁니다. (입력 내용은 현재 브라우저에 자동 저장됩니다.)

설계 항목 나의 프로젝트 내용 작성 (예시 수정 가능)
1. 시간 단위
일·주·월, 시간·분·초, 틱
2. 대상
무엇을 볼지
3. 지표
두세 개까지
4. 시간대
언제 하는지
5. 검증 기간과 판단 기준
얼마나 돌려 보고 무엇을 볼지
💾 입력 시 브라우저에 자동 저장됩니다.
STEP 03 · COPY-PASTE PROMPTS FOR AGENT

3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

오른쪽 [요청문 원클릭 복사] 버튼을 누른 뒤 Antigravity(AGY)·Codex·Claude Code·타임리 에이전트에 붙여넣으세요. 대괄호 [...] 부분을 내 상황에 맞게 바꿔 쓰면 됩니다.

PROMPT 01 · 에이전트 · 학습

PDF 학습과 규칙 정리 요청문

전략 글을 PDF로 모은 뒤

[PDF 폴더 경로]에 내가 공부한 전략 글을 PDF로 모아 뒀어. 모두 읽고 학습해 줘.
내 기준은 [내 기준 파일 경로]에 있어.
1. 글에서 나온 규칙 중 내 기준에 맞는 것을 두세 개로 줄여 '이럴 때 들어가고 이럴 때 나온다' 문장으로 정리해 줘.
2. 각 규칙이 어느 글의 어느 부분에서 나왔는지 출처를 붙여 줘.
3. 글끼리 서로 다른 말을 하면 표로 비교해 줘.
실제 주문이나 계좌 연결은 하지 마.
PROMPT 02 · 에이전트 · 모의 검증

과거 데이터 모의 검증 요청문

규칙 두세 개가 정해진 뒤

정리한 규칙 [규칙 번호]를 지난 [6개월/3개월/1개월] 데이터로 시뮬레이션해 줘.
데이터는 [데이터 파일 경로]를 쓰고, 없으면 구하는 방법을 먼저 알려 줘.
1. 결과는 수익·손실 비율, 거래 횟수, 가장 크게 잃은 구간을 표로 보여 줘.
2. 기간별로 결과가 얼마나 달라지는지 비교해 줘.
3. 규칙을 하나 줄이거나 바꾸면 어떻게 달라지는지도 한 가지만 보여 줘.
이것은 모의 검증이야. 실제 주문이나 계좌 연결, 인증 정보 입력은 하지 마.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 규칙이 두세 개로 단순한가?
  • 모의 결과에서 가장 크게 잃은 구간을 확인했는가?
  • 계좌 비밀번호나 인증 정보를 에이전트에게 주지 않았는가?
  • 실제 돈이 오가는 연결 전에 사람이 승인하는 단계를 두었는가?
