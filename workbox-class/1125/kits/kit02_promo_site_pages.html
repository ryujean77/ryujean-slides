KIT 02 · 홍보 사이트 · 깃허브 페이지

② 홍보 사이트 + 주소 공유 스타터 키트

껍데기 HTML에 기능을 하나씩 붙이고, 깃허브 페이지 주소로 휴대폰에서도 그림과 영상까지 보이게 합니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 영상이 아니라 사이트가 목표일 수 있다: 유튜브 영상을 만들고 싶은지, 영상이 잘 보이는 내 사이트를 만들고 싶은지 먼저 가립니다. 최종 산출물을 말해야 엉뚱한 것이 안 나옵니다.
  • 처음 나온 것은 껍데기: HTML은 모양만 있는 껍데기입니다. 문의를 어디로 받을지 같은 기능을 하나씩 붙이고 매번 눌러 봅니다.
  • 공유는 파일이 아니라 주소: index.html만 보내면 그림과 영상이 함께 가지 않습니다. 깃허브 페이지 주소를 만들어 그 주소를 보냅니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_사이트_목적.md — 누가 들어와 무엇을 하길 바라는지, 방문 목표
  • 02_소재/ — 홍보 영상, 사진, 소개 글, 유튜브 주소
  • 03_참고_사이트.md — 마음에 드는 사이트 주소와 좋은 점
STEP 02 · INTERACTIVE WORKSHEET

2. 홍보 사이트 설계서

에이전트에게 첫 요청을 하기 전에 채웁니다. (입력 내용은 현재 브라우저에 자동 저장됩니다.)

설계 항목 나의 프로젝트 내용 작성 (예시 수정 가능)
1. 최종 산출물
사이트 한 개인지 여러 쪽인지
2. 방문자가 할 행동
신청, 문의, 구독 등
3. 신청을 받을 곳
구글 드라이브 문서, 메일 등
4. 방문 목표
숫자로
5. 공개 범위
누구나 / 나만
💾 입력 시 브라우저에 자동 저장됩니다.

PROMPT 01 · 에이전트 · 만들기

껍데기부터 기능까지 요청문

설계서를 채운 뒤 첫 요청

이 작업의 최종 산출물은 [사이트 설명]이야. 목적은 방문자가 [행동]하게 하는 거야.
소재는 [소재 폴더 경로]에 있어.
1. 먼저 한 화면짜리 사이트 껍데기를 한국어로 만들어 줘.
2. 그다음 [기능, 예: 체험 신청을 받아 내 구글 드라이브 문서에 쌓기]를 붙여 줘. 쉬운 방법을 추천하고 내가 직접 해야 할 일(로그인, 권한 허용)을 따로 알려 줘.
3. 다 되면 내가 시험해 볼 순서를 알려 줘.
개인정보를 저장하는 부분은 진행 전에 나에게 확인받아.
PROMPT 02 · 에이전트 · 깃허브

깃허브 페이지 주소로 공유 요청문

사이트가 마음에 들게 완성된 뒤

이 사이트 폴더([폴더 경로])를 깃허브에 올리고 인터넷 주소로 공유하고 싶어.
1. 깃이 없으면 설치를 도와주고, 비밀번호나 큰 파일은 올리지 않게 .gitignore를 먼저 만들어 줘.
2. 저장소는 처음엔 비공개로 만들고, 깃허브 페이지로 보이게 하려면 공개가 필요한지 알려 줘. 공개로 바꾸기 전에 꼭 나에게 확인받아.
3. 다른 사람에게 보낼 페이지 주소를 알려 주고, 휴대폰 화면에서도 깨지지 않게 다듬어 줘.
깃허브 로그인은 내가 직접 할게.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 휴대폰에서 페이지 주소를 열었을 때 그림과 영상이 보이는가?
  • 공개 저장소에 비밀번호, 개인 연락처, 신청자 정보가 올라가지 않았는가?
  • 시험 신청을 보냈을 때 내가 정한 곳에 들어오는가?
  • 공유한 주소가 저장소 주소가 아니라 페이지 주소인가?
