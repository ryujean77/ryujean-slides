KIT 03 · 영상 편집 · 내 목소리

③ 무음 컷 편집 + 내 목소리 나레이션 스타터 키트

녹화 파일 경로만 주고 군말과 무음을 잘라 유튜브용으로 만들고, 내 목소리 모델로 짧은 나레이션을 붙입니다.

STEP 01 · CORE STRATEGY & RAW MATERIALS

1. 현장 합격/성공 공식 & 폴더에 넣을 원형 자료

  • 배운 도구는 자양분: 시댄스, 캔바, 다빈치 리졸브로 해 본 경험이 맡길 때의 기준이 됩니다. 이제는 파일 경로와 원하는 결과를 말하면 됩니다.
  • 빠름은 배속이 아니라 텀: 말 속도는 그대로 두고 말과 말 사이의 공백을 줄입니다. 보는 사람이 젊은 층인지 중장년인지에 따라 속도를 정합니다.
  • 모델은 특화되어 있다: 목소리 모델에게 엑셀을 시키면 못합니다. 목소리는 목소리 모델로, 오픈 모델을 로컬에서 돌리려면 그래픽카드가 필요합니다.
📁 내 작업 폴더(workbox/)에 먼저 넣어둘 원형 자료:
  • 01_원본_녹화.mp4 — 편집할 녹화 파일. 원본은 그대로 둡니다
  • 02_표지_제목/ — 캔바 등에서 만든 표지와 제목 그림
  • 03_내_목소리_샘플.wav — 내 목소리 모델을 만들 때 쓸 녹음(본인 목소리만)
STEP 02 · INTERACTIVE WORKSHEET

2. 영상 편집 기준 설계서

편집을 맡기기 전에 채웁니다. (입력 내용은 현재 브라우저에 자동 저장됩니다.)

설계 항목 나의 프로젝트 내용 작성 (예시 수정 가능)
1. 보는 사람
속도를 정하는 기준
2. 남길 공백
말 사이 몇 초
3. 자를 것
무음, 군말, 실수
4. 넣을 것
표지, 제목, 자막
5. 결과 파일
이름과 형식
💾 입력 시 브라우저에 자동 저장됩니다.
STEP 03 · COPY-PASTE PROMPTS FOR AGENT

3. 바로 복사해 쓰는 실전 요청문 (프롬프트)

오른쪽 [요청문 원클릭 복사] 버튼을 누른 뒤 Antigravity(AGY)·Codex·Claude Code·타임리 에이전트에 붙여넣으세요. 대괄호 [...] 부분을 내 상황에 맞게 바꿔 쓰면 됩니다.

PROMPT 01 · 에이전트 · 컷 편집

무음·군말 컷 편집 요청문

녹화 파일을 작업 폴더에 넣은 뒤

[녹화 파일 경로]를 유튜브용으로 편집해 줘. 보는 사람은 [대상]이야.
1. 말이 없는 구간과 아·음 같은 군말을 잘라 줘. 말 사이 공백은 [0.3초]만 남겨 줘.
2. 배속은 바꾸지 말고 목소리는 자연스럽게 유지해 줘.
3. [표지 그림 경로]를 첫 3초에 넣어 줘.
4. 원본은 건드리지 말고 [파일이름_편집본]으로 새로 만들고, 잘라 낸 구간 목록을 텍스트로 남겨 줘.
필요한 프로그램은 설치 전에 이름과 이유를 먼저 알려 줘.
PROMPT 02 · 에이전트 · 목소리

내 목소리 모델 가능성 점검 요청문

나레이션을 내 목소리로 만들고 싶을 때

내 목소리로 짧은 나레이션을 만들고 싶어. 내 목소리 녹음은 [녹음 파일 경로]에 있어.
1. 내 PC의 그래픽카드와 메모리로 목소리 오픈 모델을 로컬에서 돌릴 수 있는지 확인해 줘.
2. 로컬이 어렵다면 유료 서비스와 비교해 비용과 품질 차이를 알려 줘.
3. 가능하면 [원고 파일 경로]의 첫 문단만 시험으로 읽어 줘.
내 목소리 외에 다른 사람 목소리는 쓰지 마. 설치는 내가 진행하라고 할 때만 해.
STEP 04 · HUMAN-IN-THE-LOOP

4. 사람 승인(Human-in-the-Loop) 최종 검수 점검표

AI가 초안을 10배 빠르게 만들어 주더라도, 최종 책임과 결재 도장은 반드시 사람(디렉터)이 찍습니다.

  • 원본 녹화 파일이 그대로 남아 있는가?
  • 편집본을 끝까지 보았을 때 말끝이 잘린 곳이 없는가?
  • 목소리 모델에 쓴 녹음이 내 목소리뿐인가?
  • 보는 사람에게 맞는 속도인가(너무 급하지 않은가)?
