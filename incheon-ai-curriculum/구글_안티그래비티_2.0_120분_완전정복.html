🎯 [0교시] 오리엔테이션 — 왜 지금 안티그래비티인가 (0~10분 / 10분)

📘 [교재] 한 줄 정의

안티그래비티 2.0은 "대화하는 AI"가 아니라 "내 컴퓨터에서 실제로 일하는 AI 직원"입니다.

제미나이·챗GPT가 답변을 말해주는 도구였다면, 안티그래비티는 내 PC의 폴더를 열고, 파일을 읽고, 문서를 만들고, 브라우저를 켜서 공고문을 찾아오는 것까지 직접 수행합니다. 구글이 이것을 "에이전트 우선(Agent-First) 플랫폼"이라 부르는 이유입니다.

🗣️ 강사 멘트

"지금까지 여러분은 제미나이에게 '사업계획서 초안 좀 써줘'라고 물어보고, 나온 답을 복사해서 한글에 붙여넣으셨죠. 오늘 배울 안티그래비티는 그 복사·붙여넣기 단계 자체가 없습니다. 폴더를 통째로 맡기면, 그 안의 30개 파일을 스스로 읽고, 정리하고, 결과 문서를 그 폴더에 저장해 놓습니다. 일을 시키는 방식이 '질문'에서 '지시'로 바뀝니다."

📘 [교재] 세 가지 사고 전환

기존 AI 사용 방식 안티그래비티 방식
질문 → 답변 복사 → 내가 적용 지시 → 에이전트가 직접 수행 → 나는 검수
대화창 하나, 한 번에 하나씩 에이전트 여러 명 동시 투입 (병렬)
결과만 보임 (과정 불투명) Artifacts로 계획·과정·근거를 전부 공개

📘 [교재] 4단계. Artifacts — AI의 업무 일지

에이전트가 일하면서 만들어내는 모든 증빙 자료를 Artifacts라고 합니다. Artifacts 탭에서 확인할 수 있습니다.

Artifact 종류 내용
Task List 할 일 목록과 현재 진행 단계

💡 Artifacts는 AI가 한 일을 사람이 검수할 수 있게 만든 장치입니다. 자활센터 문서 작업에 AI를 쓸 때, "AI가 어떤 근거로 이 수치를 넣었는가"를 설명해야 하는 순간이 반드시 옵니다. 그때 Walkthrough를 그대로 보여주면 됩니다.

4. 결과를 표로 정리한 '문서정리_제안표.md'를 만든다.

[제약]
- 원본 파일은 절대 이동·삭제하지 않는다. 제안표만 만든다.
- 개인 식별 정보(주민번호, 연락처, 성명)가 포함된 파일은
  '⚠️민감' 표시만 하고 내용은 요약하지 않는다.

⚠️ 제약 조건을 반드시 붙이십시오. "원본은 건드리지 마라", "개인정보는 요약하지 마라" 같은 문장이 에이전트에게는 실제 안전장치로 작동합니다.

📘 [교재] 실전 시나리오 2. 브라우저 에이전트 — 공고문 수집

Chrome 확장을 설치하면 에이전트가 브라우저를 직접 조작합니다. 클릭·스크롤·다운로드까지 대신하고, 그 과정을 화면 녹화로 남깁니다.

실습 프롬프트

/browser

한국자활복지개발원과 인천광역자활센터 홈페이지의 공지사항을 열어서,
최근 2개월 내 올라온 '공모' 또는 '지원사업' 관련 공고를 찾아줘.

각 건마다 [제목 / 게시일 / 접수마감일 / 원문 링크]를 표로 정리하고
'공모현황_요약.md'로 저장해줘. 마감이 임박한 순으로 정렬해줘.

🗣️ 강사 멘트

"여기서 중요한 건, 에이전트가 찾아온 결과를 그대로 믿지 말라는 겁니다. Artifacts에 남은 브라우저 녹화를 재생해 보면 '아, 이 페이지에서 이걸 봤구나'가 보입니다. AI의 결과를 검증할 수 있는 근거가 함께 남는 것 — 이게 안티그래비티의 진짜 가치입니다."

📘 [교재] 실전 시나리오 3. 예약 실행 (/schedule)

/schedule

반복 업무를 에이전트에게 고정 배치하는 기능입니다. 월요일 아침 회의 전에 요약이 준비되어 있게 됩니다.

📘 [교재] 실전 시나리오 4. Rules & Workflows — 우리 센터 방식 학습시키기

에이전트가 매번 같은 지적을 받지 않도록, 행동 규칙을 저장할 수 있습니다.

기능 설명 적용 범위
Rules 에이전트가 항상 지켜야 할 작업 스타일·금지 사항 Global(전체) / Workspace(프로젝트별)
Workflows 반복되는 업무의 단계를 미리 정의해 둔 절차서 프로젝트별
Knowledge 센터 표준 서식·용어·과거 문서 등 지속 기억 계정/프로젝트

자활센터 표준 Rules 예시 (복사해서 등록)

# 문체 규칙
- 모든 산출 문서는 공문 어투(~함, ~임)를 사용한다.
- 숫자는 천 단위 쉼표를 넣고, 금액은 '원' 단위를 명시한다.

# 데이터 규칙
- 출처가 불명확한 통계·수치는 절대 임의로 생성하지 않는다.
  근거가 없으면 "[근거 확인 필요]"로 표시한다.
- 참여자 성명·주민번호·연락처는 어떤 산출물에도 기재하지 않는다.

# 작업 규칙
- 파일을 수정하기 전 반드시 원본 사본을 남긴다.
- 작업 완료 시 무엇을 왜 바꿨는지 Walkthrough로 요약한다.

📘 [교재] 실전 시나리오 5. 에이전트 병렬 운영

Agent Manager에서 New Agent를 여러 개 만들면 동시에 일을 시킬 수 있습니다. 각 에이전트를 New Worktree Mode로 띄우면 서로의 작업이 섞이지 않습니다.

에이전트 A : 사업계획서 초안 작성
에이전트 B : 작년 실적 데이터 표 정리
에이전트 C : 공모 공고 수집

→ Inbox에서 세 명의 결재 요청을 순서대로 처리

💡 하드웨어 현실: 에이전트 3개 이상 동시 운영은 RAM 16GB 이상에서 쾌적합니다. 8GB PC라면 1~2개까지만 돌리십시오.

✋ 실습 ③ (15분) — 조별 자유 과제

각자 자기 센터 실무 폴더(민감정보 제외 사본) 하나를 골라, 위 프롬프트 중 하나를 변형해 실행하고 Walkthrough를 발표합니다.

🔒 [4교시] 안전·권한·비용 관리 (105~120분 / 15분)

📘 [교재] 권한 체계 — 우선순위는 Deny > Ask > Allow

안티그래비티는 에이전트가 할 수 있는 일을 항목별로 통제합니다. 금지(Deny)가 항상 허용(Allow)을 이깁니다.

권한 항목 통제 대상
read_file(path) / write_file(path) 파일 읽기 / 쓰기 경로
read_url / execute_url 웹 열람 / 웹 실행
command(prefix) 실행 가능한 명령어
unsandboxed(prefix) 보호막 밖에서 실행되는 명령 (가장 위험)

📘 [교재] 자활센터 권장 안전 설정값

설정 권장값 이유
Strict Mode 켜기 샌드박싱 자동 활성화 + 네트워크 차단 + 검토 강제
Artifact Review Policy Request Review 결과물을 반드시 사람이 승인
Terminal Command Auto Execution 자동 실행 끄기 명령어 자동 수행 차단
Non-Workspace File Access 차단 지정 폴더 밖 파일 접근 금지
작업 모드 New Worktree Mode 원본 보존

🗣️ 강사 멘트

"딱 한 문장만 기억하십시오. '수급자 정보가 든 폴더는 절대 프로젝트로 등록하지 않는다.' 브라우저 에이전트는 별도 크롬 프로필을 쓰지만, 그 프로필에 로그인 정보가 영구 저장됩니다. 센터 행정망 계정이나 개인정보 포함 시스템에는 에이전트를 붙이지 마십시오."

📘 [교재] 자활센터 AI 도입 보안 체크리스트 7

□ 1. 공식 도메인(antigravity.google)에서만 설치했는가
□ 2. 설치 파일 디지털 서명(Google LLC)을 확인했는가
□ 3. 프로젝트 폴더를 업무 범위로 좁게 지정했는가
□ 4. 수급자·참여자 개인정보 폴더를 제외했는가
□ 5. Strict Mode / Request Review를 켰는가
□ 6. 브라우저 에이전트에 행정망 계정을 로그인하지 않았는가
□ 7. AI 산출물을 사람이 최종 검수한 기록(Walkthrough)을 남겼는가

📘 [교재] 요금제와 사용 한도

플랜 한도 갱신 사용 가능 모델
Standard (무료) 주 단위 갱신 Gemini 계열 기본 모델
Google AI Pro 5시간마다 갱신 (한도 상향) Gemini 계열
Google AI Ultra 5시간마다 갱신 (최고 한도) Gemini 계열 + Claude / GPT-OSS 등 외부 모델
  • 모든 플랜에서 Gemini 기본 모델과 탭 자동완성은 사용 가능합니다.
  • 한도 초과분은 크레딧으로 이어서 쓸 수 있으며, 설정에서 차단할 수 있습니다.
  • 현재 개인 API 키(BYOK) 연결은 지원되지 않습니다.

💡 센터 도입 권고: 실무자 체험은 무료 Standard로 충분합니다. 문서 작업이 일상화되면 센터장·기획 담당자 1~2명만 Google AI Pro로 올리는 것이 비용 대비 효율이 가장 좋습니다.
