4-1GAS(Google Apps Script) 기초 개념 및 에디터 진입

📘 [교재 내용: 개념 이해]

GAS(Google Apps Script)란 무엇인가? 구글 앱스 스크립트(GAS)는 구글 워크스페이스(Docs, Sheets, Calendar, Gmail 등)의 다양한 서비스들을 하나로 연결하고 자동화해주는 클라우드 기반 스크립팅 언어입니다.

  • 핵심 원리: 자바스크립트(JavaScript)를 기반으로 작동하지만, 우리는 코드를 직접 짤 필요가 없습니다. ChatGPT나 Gemini 같은 AI에게 '이러이러한 자동화 코드를 짜줘'라고 명령하고, 그 결과물을 GAS 에디터에 붙여넣기만 하면 됩니다.
  • 왜 중요한가? (인지 부하 최소화 관점): 인간의 뇌는 반복적이고 기계적인 작업에 에너지를 쏟을 때 쉽게 지치고 창의력을 잃습니다. GAS는 이러한 '단순 반복 작업'을 기계에 위임함으로써, 여러분이 자활 참여자를 상담하고 창의적인 자활 프로그램을 기획하는 '진짜 중요한 업무'에 집중할 수 있도록 돕습니다.
🗣️ [강사 멘트: 💻 시연]

"화면을 보실까요? 우리가 매일 쓰는 구글 스프레드시트입니다. 보통 메뉴바에는 '파일', '수정', '보기' 이런 것들이 있죠. 그런데 여기에 잘 알려지지 않은 메뉴가 하나 있습니다. [확장 프로그램] -> [Apps Script]를 클릭합니다. 새로운 창이 열렸죠? 바로 이곳이 우리가 AI가 짜준 코드를 붙여넣을 '자동화 공장'의 입구입니다. 아주 단순합니다. 이 하얀 도화지에 코드를 넣고 '실행' 버튼만 누르면, 스프레드시트와 구글 문서, 캘린더가 서로 대화를 나누며 알아서 일을 처리합니다."

4-2Google Docs 문서 자동 생성 봇

📘 [Visual Asset: 교육 시각화 자료]
📘 [교재 내용: 개념 이해]

이번 항목에서는 구글 스프레드시트에 입력된 데이터(예: 자활 참여자 상담 일지, 초기 면접지 등)를 바탕으로, 클릭 한 번에 잘 양식화된 Google Docs(구글 문서)가 자동 생성되는 봇을 만듭니다.

  • 작동 원리 (행동 공학적 접근): 미리 만들어둔 구글 문서 템플릿(예: {{이름}}, {{상담일자}} 등의 태그를 포함)과 구글 시트를 연동합니다. GAS 코드가 시트의 각 행을 읽어 템플릿의 태그를 실제 데이터로 치환(Replace)한 뒤, 새로운 문서 파일로 저장합니다.
  • 인지적 이점: 'Ctrl+C, Ctrl+V'를 수십 번 반복하며 느끼는 지루함과 오타 발생에 대한 불안감을 완벽히 제거합니다. 성취감 회로(도파민)를 자극하여 '클릭 한 번으로 100장의 문서가 생성되는 쾌감'을 경험하게 됩니다.
🗣️ [강사 멘트: 💻 시연]

"이 시트를 보세요. 10명의 자활 참여자 이름, 연락처, 상담 내용이 적혀 있습니다. 보통이라면 빈 한글 파일이나 워드 파일을 열고 10번을 복붙하셨겠죠? 그리고 꼭 한 두 명은 이름 수정하는 걸 깜빡해서 민망한 상황이 생깁니다. 하지만! 제가 시트 상단에 새로 만든 [자동화 메뉴] -> [상담일지 자동생성] 버튼을 눌러보겠습니다. 3초 후... 자, 제 구글 드라이브 폴더를 보세요. 10명의 이름이 적힌 상담일지 파일이 방금 만들어졌습니다! 열어볼까요? 내용이 정확히 들어가 있습니다. 여러분도 오늘 바로 만들어 보실 수 있습니다."

📘 [교재 내용: ✍️ 실습]
  • 목표: 스프레드시트 데이터로 구글 문서 수료증/상담일지 자동 생성기 만들기
  • 가상 샘플데이터 상황 설정:
  • 구글 드라이브에 '템플릿_상담일지' 구글 문서 생성 (문서 내에 <<참여자명>>, <<상담내용>> 텍스트 포함)
  • 템플릿 문서의 고유 ID (URL에서 /d/와 /edit 사이의 긴 문자열) 복사해두기
  • 실습용 스프레드시트 A열에 '참여자명', B열에 '상담내용' 작성
  • 실습 프롬프트 (AI에게 물어볼 때):

> "나는 자활센터 실무자야. 구글 스프레드시트의 A열(참여자명)과 B열(상담내용) 데이터를 읽어서, 내가 미리 만들어둔 구글 문서 템플릿(문서ID: [여기에 ID 입력])의 <<참여자명>>과 <<상담내용>>을 실제 데이터로 바꾸고, 새로운 문서로 복사해서 특정 폴더(폴더ID: [여기에 ID 입력])에 저장하는 GAS 코드를 작성해줘. 코드는 초보자도 이해할 수 있게 주석을 꼼꼼히 달아줘."

  • 실습 체크리스트 (Nudge 넛지 설계):
  • [ ] 구글 문서 템플릿을 생성하고 치환용 태그(예: <<이름>>)를 정확히 삽입했는가?
  • [ ] 템플릿 문서 ID와 저장할 폴더 ID를 정확히 추출하여 AI에게 프롬프트로 전달했는가?
  • [ ] AI가 짜준 코드를 GAS에 넣고 실행했을 때, 대상 폴더에 문서들이 정상적으로 생성되었는가?

4-3Google Calendar 연동 기한 알림 봇

📘 [Visual Asset: 교육 시각화 자료]
📘 [교재 내용: 개념 이해]

자활센터 실무자들의 뇌를 가장 피곤하게 만드는 것 중 하나가 바로 '기한 관리'입니다. 지원금 신청 마감일, 참여자 사후관리 도래일, 각종 보고서 제출일 등...

  • 작동 원리 (행동 공학적 접근): 스프레드시트에 기재된 '날짜' 데이터를 GAS가 매일 새벽에 스스로 읽어들입니다. 그리고 오늘이 마감일 3일 전이라면? 여러분의 구글 캘린더에 자동으로 일정을 등록하거나, 지정된 이메일로 알림을 보내줍니다.

      var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("메일발송명단");
      var startRow = 2; // 데이터 시작 행
      var numRows = sheet.getLastRow() - 1; // 처리할 데이터 개수

      if (numRows < 1) return; // 데이터가 없으면 종료

      var dataRange = sheet.getRange(startRow, 1, numRows, 3); // A, B, C열 가져오기
      var data = dataRange.getValues();

      for (var i = 0; i < data.length; i++) {
        var row = data[i];
        var name = row[0];        // A열: 이름
        var emailAddress = row[1]; // B열: 이메일
        var hours = row[2];        // C열: 이수시간

        if (!emailAddress) continue; // 이메일이 빈칸이면 건너뜀

        // 이메일 템플릿 설정
        var subject = "[자활센터] " + name + "님, 교육 이수 현황 안내";
        var message = name + "님, 안녕하세요.\n\n" +
                      "이번 달 선생님의 교육 이수 시간은 총 " + hours + "시간입니다.\n\n" +
                      "감사합니다.";

        // Gmail 임시보관함에 초안 생성 (바로 발송되지 않음!)
        GmailApp.createDraft(emailAddress, subject, message);
      }
      SpreadsheetApp.getUi().alert('임시보관함에 메일 초안이 생성되었습니다. Gmail을 확인해 보세요!');
    }

  • 존 스웰러(John Sweller)의 인지 부하 이론에 따르면, 인간의 작업 기억(Working Memory) 용량은 한계가 있습니다. 실무자가 참여자의 태도, 직무 능력, 대인 관계 등을 백지상태에서 주관적으로 서술하여 평가하려 하면 '외재적 인지 부하(Extraneous Cognitive Load)'가 극도로 상승하여 엄청난 피로감을 느낍니다.
  • 루브릭은 수행 목표에 도달했는지를 판단하기 위해 명확한 기준(Criteria)과 수준(Levels)을 제시하는 다차원적 평가 척도입니다.
  • AI(ChatGPT, Gemini)를 활용하면 상황과 직무(예: 바리스타, 청소, 자원순환, 세차 등)에 맞는 맞춤형 행동 지표 루브릭을 즉시 생성할 수 있습니다. 피평가자(참여자)는 모호한 지적이 아닌 '구체적 행동 지침'을 받게 되어 심리적 저항감이 낮아지고 성취 동기가 유발됩니다.

[💻 시연]

  1. 기존 방식의 한계 노출: 강사가 화면을 통해 빈 엑셀 시트를 엽니다. "자, 참여자 10명의 이번 달 근태와 직무 태도를 적어봅시다"라고 말하며, 커서만 깜빡이는 막막한 화면(높은 인지 부하 상태)을 보여줍니다.
  2. AI 프롬프트 매직 시연: ChatGPT 또는 Gemini를 열고 고도화된 프롬프트를 입력합니다.
  • 입력창 시연: "자활근로 바리스타 사업단 참여자를 위한 4단계 루브릭 표를 작성해줘. 평가 항목은 [위생 관리, 고객 응대, 레시피 숙지도, 팀워크]이며, 각 단계(우수/보통/미흡/개선필요)별 구체적인 행동 지표를 포함해줘."
  1. 결과물 리뷰 및 Nudge 적용: 도출된 결과물에서 부정적인 단어(예: '불성실함', '못함')를 AI에게 요청하여 긍정적이고 중립적인 행동 교정 언어(예: '위생 지침에 대한 추가 안내가 필요함')로 즉시 변환하는 과정을 시연합니다.

[개념 이해]

행동 유도(Nudge)와 뇌과학적 습관 형성의 법칙 (The Habit Loop)

  • 찰스 두히그(Charles Duhigg)와 제임스 클리어(James Clear)의 이론에 따르면, 모든 습관은 [신호(Cue) → 열망(Craving) → 반응(Response) → 보상(Reward)]의 루프를 거칩니다.
  • AI를 실무에 적용하는 것도 마찬가지입니다. "내일 당장 거대한 사업계획서를 AI로 써야지"라는 목표는 너무 큰 마찰력(Friction)을 발생시켜 뇌가 실행을 포기하게 만듭니다.
  • 대신 환경을 조작해야 합니다(신호 조작). 출근해서 크롬을 켜면 무조건 AI 화면이 뜨게 만들고, '매일 아침 이메일 요약을 AI에게 시켜보기'처럼 아주 사소한 행동(반응)으로 쪼갠 뒤, 5분 만에 끝난 업무로 커피 한 잔의 여유(보상)를 즐기는 사이클을 만들어야 합니다.

[💻 시연]

  1. 신호(Cue) 설계: 크롬 브라우저 설정(Settings) > 시작 그룹(On startup)에서 특정 페이지 열기로 chatgpt.com 또는 gemini.google.com을 고정하는 방법을 시연합니다. (마찰력 제로 만들기)
  2. 반응(Response) 설계: 자주 쓰는 '기본 뼈대 프롬프트'를 윈도우 스티커 메모(Sticky Notes)나 노션, 바탕화면 메모장에 템플릿화하여 복사-붙여넣기 1초 컷으로 만드는 과정을 시연합니다.
  3. 넛지(Nudge) 알림: 구글 캘린더를 열어 매주 금요일 오후 4시에 "이번 주 업무 중 AI로 10분 아낀 사례 1개 찾기"라는 반복 일정을 등록하고, 10분 전 스마트폰 푸시 알림이 오도록 세팅하는 넛지 기법을 보여줍니다.

[✍️ 실습]

상황 설정: 교육이 끝난 다음 날 아침, 여러분은 바쁜 센터로 출근했습니다. 정신없는 업무 속에서도 AI를 잊지 않고 활용하여 점진적으로 퇴근 시간을 앞당길 수 있는 자신만의 '4주 환경 설계 플랜'을 인공지능에게 직접 짜달라고 요청합니다.

실천 과제 및 프롬프트 (AI를 나의 개인 코치로 만들기):

역할: 세계 최고 수준의 행동경제학 기반 습관 형성 코치 및 업무 생산성 전문가
상황: 나는 방금 4주간의 '생성형 AI 자활 실무 활용' 교육을 수료한 사회복지사/직업상담사야.
목표: 교육 내용을 까먹지 않고 실무에 자연스럽게 녹여내기 위해, 매일 딱 '하루 3분~5분'만 투자하는 4주짜리 <AI 활용 마이크로 루틴 플랜>을 표로 짜줘.
조건:
1. 나의 의지력을 절대 믿지 마. 무조건 아주 쉽고, 사소하고, 실패할 수 없는 미션이어야 해. (예: 하루 1번 무조건 AI에게 날씨 묻기 등 워밍업 포함)
2. 매일 미션을 달성할 때마다 작은 성취감을 느낄 수 있도록 도파민을 뿜뿜하게 만드는 위트 있는 응원 멘트(한 줄)를 표의 우측 비고란에 포함해 줘.
3. 1~4주차까지 난이도가 아주 미세하게 계단식으로 올라가게 설계해 줘.
4. 월~금까지만 미션을 주고, 주말은 철저히 쉬게 해. 금요일 미션은 항상 '한 주간의 소소한 회고'로 고정해 줘.
출력 형식: 주차별, 요일별 미션과 응원 멘트가 담긴 깔끔한 마크다운 표
