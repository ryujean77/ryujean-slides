# 역할 분담 — 남미화 박사 / 오빠(프로젝트 총괄)

회의 내용을 기준으로, 누가 무엇을 이미 하고 있었고 앞으로 무엇을 맡아야 하는지를 정리한다.
(화자 추정 근거는 [회의록](01_회의록.md) 상단 참고. 실제 역할과 다르면 정정 요청 바람.)

---

## 남미화 박사 — 콘텐츠·이론 담당

대화에서 이미 확인된 강점: 사상체질×패션테라피의 인문학적 프레임, 문화비교 통찰, 카피라이팅 감각(연애심리·육아심리 훅 아이디어를 즉석에서 다수 제시).

| 구분 | 해야 할 일 |
|---|---|
| **이론/콘텐츠 원고** | 문항 텍스트, 유형별 설명 카피, 결과 화면 문구를 텍스트(원고)로 먼저 작성 — 총괄이 반복 요청한 "스크립트/텍스트부터 써 달라"는 요청의 핵심 |
| **유형 체계 확정** | 사상체질 4유형을 그대로 쓸지, 앱 전용 독자 유형을 만들지 결정하고 각 유형의 이름·설명·추천 스타일링 팁 확정 |
| **소재 우선순위 선택** | 제시된 후보(연애심리/육아심리/유년기심리) 중 1차 MVP로 밀 소재 1개 선택 — 전부 동시 진행 금지 |
| **책 연계 포인트 지정** | 어느 챕터/개념을 앱 결과 카피와 CTA에 인용할지 지정 |
| **톤앤매너 검수** | "이기적 패션" 등 강연·집필용 표현을 앱 사용자 카피로 옮길 때 평가적으로 읽히지 않는지 최종 검수 |

## 오빠(프로젝트 총괄) — 구조·개발·마케팅 담당

대화에서 이미 확인된 역할: 벤치마크 UX 구조 분석, "구조 vs 외형" 프레임 정립, 마케팅 퍼널·타겟 세그먼트 설계, 협업 커뮤니케이션 코칭.

| 구분 | 해야 할 일 |
|---|---|
| **UX/데이터 구조 설계** | 문항 수, 페이지당 배치, 응답 방식(예/아니오 등), 채점 로직 — 남박사의 원고가 나오는 대로 구조에 매핑 (이미 [개발지시서 v1](../20260821_2352_패션테라피_심리테스트앱_개발지시서/개발지시서.md)에서 1차 완료) |
| **원고 → 데이터 구조화** | 남박사의 텍스트 원고를 `questions.json`/`types.json` 형태로 구조화(직접 또는 ChatGPT/Claude 활용, 회의 중 본인이 제안한 방식) |
| **MVP 범위 확정 및 일정관리** | 여러 에디션 아이디어가 동시에 나온 상태이므로, 1개 에디션으로 스코프를 좁히고 일정 리드 |
| **마케팅 퍼널/채널 전략** | SNS 스니펫 콘텐츠 기획, 리드 수집 폼 연동, 공유 루프 설계 |
| **의사결정 정리 및 확인 요청** | 매 회의 후 미결 사항을 정리해 남박사에게 확인 요청(본 문서 시리즈가 그 역할을 대행) |

## 공동 결정 필요 (둘 다 참여)

- 서비스 목적: 라이트 마케팅용 vs 신뢰도 있는 진단 도구
- 1차 MVP 타겟 세그먼트 및 제목(가칭)
- 출시 후 확인할 핵심 지표(§2 린캔버스의 Key Metrics) 합의

## 진행 방식 제안 (대화 중 본인들이 언급한 방식 그대로 채택)

1. 남박사: 아이디어를 텍스트로 정리 → 이메일/공유폴더에 전달
2. 총괄: 해당 텍스트를 구조화(ChatGPT/Claude 활용) → 개발지시서 업데이트
3. 매 라운드마다 "미결 사항" 리스트를 줄여나가는 방식으로 반복 (현재 문서 세트가 1라운드)
