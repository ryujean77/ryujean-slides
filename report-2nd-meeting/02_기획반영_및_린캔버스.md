# 기획 반영 분류 & 린캔버스(Lean Canvas)

[회의록](01_회의록.md)의 논의 내용을 개발지시서 및 사업 기획에 반영하기 위해 분류하고,
개발지시서보다 상위 레벨(사업 모델) 문서로 스케일업한다.

---

## 1. 논의 내용 분류

### ① 즉시 적용할 것 (개발지시서에 바로 반영 — v1.1에 반영 완료, [개발지시서](../20260821_2352_패션테라피_심리테스트앱_개발지시서/개발지시서.md) 참고)
- 구조(뼈대)와 외형(스킨)을 분리해서 설계 원칙 문서화
- 설계 순서를 "유형체계(내용) 확정 → 문항 설계(형식)"로 명문화
- "이기적 패션 vs 배려 패션" 2분 축을 유형 진단 로직의 후보 축(§3.2 옵션 C)으로 추가

### ② 추가할 것 (기존 지시서에 없던 신규 아이디어)
- **멀티 버전 콘텐츠 전략**: 앱 하나에 문항을 몰아넣지 않고, 타겟별 "에디션"으로 분리
  - 연애심리 에디션(남성 타겟, "오늘 여친 패션으로 보는 심리")
  - 육아심리 에디션("아이 패션으로 보는 엄마의 심리")
  - 유년기 심리 에디션(전연령, 회고형)
- **SNS 스니펫 콘텐츠**: 앱 결과를 유튜브 쇼츠/인스타그램용 1문항짜리 초압축 버전으로 재가공해 유입 채널로 활용
- **책 연계 CTA**: 결과 화면 하단에 "더 알고 싶다면 [남박사 저서]를 읽어보세요" 형태의 소프트 세일즈 문구 슬롯
- **원형 콘텐츠(Content Master) 관리 방식**: 문항/유형 텍스트를 먼저 원고로 확정하고, 이를 여러 에디션에 재사용하는 콘텐츠 파이프라인

### ③ 부족한 부분 (미결/리스크 — 개발 착수 전 반드시 확정)
- 1차 목적이 "라이트 마케팅용"인지 "신뢰도 있는 진단 도구"인지 미정 → 문항 설계 공수가 5배 이상 차이 남
- 유형 체계(사상체질 4유형 기반 vs 독자 유형)가 아직 미확정 → 데이터 모델(§5) 자체가 확정 불가 상태
- 여러 에디션을 만들 경우 **개발 리소스/일정이 선형으로 늘어남** — 우선순위 없이 전부 진행 시 아무것도 완성 못 할 위험(대화 중 "너무 길다", "몇 페이지 정도 되네" 등 스코프 불안 신호 반복 확인됨)
- 콘텐츠 저작권/근거 문제: "책 3~4권 분량 안에서 데이터 경계를 정한다"는 언급은 있으나, 실제 인용/재구성 시 저작권·표절 리스크 검토 프로세스가 없음

### ④ Claude 추가 제안 분류

**(a) 톤앤매너 리스크**
- "이기적인 패션" 같은 개념은 자칫 사용자에게 평가/비난처럼 읽힐 수 있음(대화 속 표현 "이기적", "눈살이 찌푸려지는" 등은 강연·집필용 표현이지, 앱 UX 카피로 그대로 쓰면 사용자 이탈 유발 가능) → 앱 카피로 옮길 때 "관계지향형/자기표현형"처럼 중립적 리네이밍 필요

**(b) 데이터/측정 공백**
- 회의에서 "재미로 볼지 진단으로 볼지"를 사용자 반응으로 검증하자는 언급이 없음 → 출시 후 어떤 지표(완료율, 공유율, 리드 전환율)로 두 방향 중 무엇이 맞았는지 확인할지 정의 필요(§2 린캔버스 Key Metrics에 반영)

**(c) 의사결정 병목**
- 대화 내내 "결정을 못 내렸다"는 표현이 반복(문항 수, 제목, 타겟 등) → 의사결정자가 남박사 단독인지, 총괄과 공동인지 프로세스가 불명확. §3(역할분담)에서 결정권 구조를 명시적으로 분리함.

## 2. 린캔버스 (Lean Canvas) — 패션테라피 심리테스트 서비스

BMC(비즈니스모델캔버스) 대신 **린캔버스**를 선택한 이유: 본 프로젝트는 기존 강연/저서 사업에 신규 채널(웹앱)을 얹는 **검증 전 단계의 신규 서비스**이므로, "문제-솔루션 적합성"을 먼저 좁히는 린캔버스가 더 적합함. 사업이 검증된 이후(리드가 실제 강연/워크숍 매출로 전환되기 시작하면) 파트너십·비용구조가 복잡해지는 BMC로 확장 권장.

| 블록 | 내용 |
|---|---|
| **1. 문제 (Problem)** | ① 잠재 고객이 패션테라피/사상체질 개념을 진지하게 접할 진입장벽이 높음(강연·책은 고관여 채널) ② 재미있게 자기이해를 하고 싶은 니즈는 있으나 기존 컬러/MBTI류 테스트는 "옷/스타일"이라는 실행 가능한 축이 없음 ③ 패션테라피진흥원 입장에서는 저관여 잠재고객을 고관여(강연/워크숍/책구매)로 끌어올릴 중간 단계 채널이 없음 |
| **2. 고객군 (Customer Segments)** | 1순위 후보(택1 우선 출시, 회의 §3 미결): (a) 연애심리 궁금한 2030 남성 (b) 자녀 옷 문제로 고민하는 3040 엄마 (c) 자기이해에 관심 많은 2030 여성(범용) — *조기수용자(Early Adopter)*: 남박사 기존 독자/수강생, SNS 팔로워 |
| **3. 고유가치제안 (UVP)** | "당신의 옷장이 곧 당신의 마음이다 — 사상체질 기반 패션테라피가 알려주는 나(또는 상대방)의 진짜 심리" — 기존 컬러/성격 테스트와 달리 **인문학적 근거(사상체질+철학)** 와 **실행 가능한 스타일링 처방**을 함께 제공 |
| **4. 솔루션 (Solution)** | 모바일 웹 심리테스트(예/아니오 문항) + 유형별 결과 카드 + (선택)책/강연 CTA. MVP는 에디션 1개만 우선 출시 |
| **5. 채널 (Channels)** | 인스타그램/유튜브 쇼츠(스니펫 콘텐츠로 유입) → 웹앱(본 진단) → 결과 공유(바이럴 루프) → 이메일/카카오채널(리드) → 책 구매·강연 신청(전환) |
| **6. 수익원 (Revenue Streams)** | 앱 자체는 무료(리드 제너레이션 목적). 실제 매출은 ① 저서 판매 ② 강연/워크숍 신청 ③ (장기) 유료 심화 리포트/1:1 컨설팅 |
| **7. 비용구조 (Cost Structure)** | 콘텐츠 원고 집필(남박사 시간), 앱 개발/디자인(총괄+Claude 협업), 배포 인프라(GitHub Pages, 무료), SNS 콘텐츠 제작 |
| **8. 핵심지표 (Key Metrics)** | 테스트 완료율, 결과 공유율(바이럴계수), 리드 폼 전환율, 리드→강연신청 전환율, 에디션별 완료율 비교(어떤 타겟이 진짜 반응하는지 검증) |
| **9. 경쟁우위 (Unfair Advantage)** | 남박사의 저서·강연 실적 기반 **검증된 이론 체계(사상체질×패션테라피)** — 일반 재미용 테스트 제작사가 복제 불가능한 인문학적 깊이 |

### 린캔버스 관점에서 본 다음 액션
- **가장 먼저 검증할 가설**: "재미(라이트) 콘텐츠"와 "진단(딥) 콘텐츠" 중 무엇이 리드 전환율을 더 높이는지 — 리소스를 갈라 쓰기 전에 **1개 에디션 MVP로 먼저 실험** 권장
- MVP 후보 1순위 제안: 회의에서 가장 구체적 실행안까지 나온 **"연애심리(남자 편)"** — 다만 §3 역할분담에서 남박사·총괄 공동 확정 필요
