안티 슬롭(Anti-Slop) 7대 엄격 금지 규칙

AI가 쉽게 빠지는 흔한 저품질 디자인 패턴을 철저하게 방지합니다.

❌ 절대 금지 (AI Slop)
  • 보라/네온 그라데이션 남발 (`from-purple-500 to-indigo-600`)
  • 무의미한 3단 복제 카드 (아이콘 + 볼드 제목 + 2줄 설명)
  • 카드 속에 카드를 또 넣는 불필요한 테두리 중첩 (Padding Hell)
  • 흐리멍덩한 회색 텍스트 (`text-gray-400`)로 인한 가독성 저하
  • 모든 버튼이 똑같은 무개성 라운드 버튼 일색
  • "Lorem ipsum" 더미 텍스트 방치
  • 모바일에서 가로 스크롤이 터지는 무성의한 레이아웃
✅ 권장 적용 (High-Craft Standard)
  • 도메인 맞춤형 컬러 팔레트 (샌달우드 웜앰버, 세이지 그린 등)
  • 비대칭 벤토 그리드(Bento Grid) 및 기능별 차별화 레이아웃
  • 여백(Negative Space)과 마이크로 보더(1px border)의 정밀 조화
  • WCAG AAA 기준의 선명하고 또렷한 타이포그래피 대비
  • 브랜드 아이덴티티에 맞는 셰이프, 마이크로 섀도우, 호버 이펙트
  • 100% 실제 비즈니스 도메인 데이터와 스토리텔링 삽입
  • 모바일(390px) · 태블릿(768px) · 데스크톱(1440px) 3단 반응형 완비
