Dialogue 01 👤 질문: 구글 드라이브 써도 될까?
👤
사용자 실제 질문
"어제 agy, codex, claude cli를 설정했어. 폴더 지정해서 작업했는데, 이거를 구글 드라이브를 이용해서 데스크탑과 맥북에서 같이 사용해도 될까? law.md도 설정했거든."
🤖 AI 진단: 위험! (비추천)
일반 문서와 달리 AI CLI는 수초 내에 수십 개 파일을 빠르게 읽고 씁니다.
  • 파일 락(Lock) 충돌: AI가 파일 쓰는 순간 구글 드라이브가 동기화하느라 파일을 잠가 에러 발생
  • 사본 파일 생성: law (1).md 같은 충돌 사본이 생겨 규칙(SSOT)이 파괴됨
  • 의존성 재앙: node_modules (수만 개 파일) 동기화 시 과도한 CPU/네트워크 병목
💡 최적 해결책: Git + GitHub
동기화 시점을 사용자가 완전히 통제하는 명시적 스냅샷 방식이 필수입니다.
  • 작업 중: 내 로컬 디스크에서만 100% 빠르고 안전하게 작업
  • 작업 완료 후: 내가 원할 때만 깔끔하게 클라우드로 전송 (충돌 0%)

Dialogue 02 👤 질문: 외장 디스크에 들고 다니면?
👤
사용자 실제 질문
"음 그렇다면, 내가 외장 디스크에 이 작업 폴더를 아예 들고 다니면 어떨까?"
👍 외장 SSD의 장점
클라우드 동기화 프로그램의 백그라운드 개입이 없어 파일 락 문제는 해결됩니다.
  • 동기화 충돌 제로: 클라우드 데몬이 없으므로 파일 잠김 현상 없음
  • 단일 진실 공급원: 물리적으로 1개의 디스크만 존재하므로 최신 상태 유지
  • 오프라인 작업: 인터넷이 없어도 작업 가능
⚠️ 외장 SSD의 치명적 한계
Mac과 Windows를 오갈 때 포맷과 하드웨어 분실 리스크가 존재합니다.
  • exFAT 포맷 문제: 양쪽 OS를 쓰려면 exFAT이어야 하나, 심볼릭링크와 실행 권한 미지원으로 개발 환경 깨짐
  • 버전 롤백 불가: AI가 코드를 망가뜨리면 이전 상태로 되돌릴 수 없음
  • 분실/파손 위험: 디스크 분실 시 모든 산출물과 스킬 영구 유실

Dialogue 04 👤 질문: 유료인가? 내 HDD 파일은?
👤
사용자 실제 질문
"깃허브 비공개 저장소는 유료야? 깃으로 초기화 해도 내 HDD에는 남아 있는거지?"
🎉 100% 완전 무료!
개인 비공개(Private) 저장소는 개수 제한 없이 평생 무료입니다.
  • 비공개 저장소: 무제한 무료 생성 가능
  • 완벽한 보안: 나 외에는 아무도 볼 수 없음 (검색 노출 X)
  • 넉넉한 용량: 문서/스킬 관리는 평생 써도 남는 대용량 제공
💾 내 컴퓨터 파일 100% 유지!
파일이 어디로 이동하거나 사라지는 것이 전혀 아닙니다.
  • 기존 파일 그대로: Finder/탐색기에서 언제든 확인 가능
  • .git 폴더 생성: 단지 변경 이력을 기록하는 '장부'만 내 컴퓨터에 추가됨
  • 인터넷 끊겨도 동작: 로컬 디스크에서 모든 기능 작동
