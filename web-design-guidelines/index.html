접근성(A11y), 키보드 포커스 링, 폼 UX, GPU 가속 애니메이션, 고아 단어 없는 타이포그래피까지 — 프론트엔드 코드의 결함을 사전에 100% 잡아냅니다.

8대 프로덕션 인터페이스 표준

01

접근성 (A11y)

  • 아이콘 버튼 `aria-label` 필수
  • `
    ` 금지 (시맨틱 버튼 사용)
  • 장식 아이콘 `aria-hidden="true"`
  • `

    `~`

    ` 위계 준수
02

포커스 링 (Focus)

  • `outline-none` 단독 사용 엄격 금지
  • `:focus-visible` 우선 적용
  • 그룹 요소 `:focus-within`
  • `scroll-margin-top` 요소 가림 방지
03

폼 UX (Forms)

  • `autocomplete`, `inputmode` 최적화
  • 붙여넣기(`onPaste`) 차단 절대 금지
  • 체크박스/라벨 44px 터치 영역 확보
  • 인라인 에러 및 1번 필드 자동 포커스
04

애니메이션 (Motion)

  • `prefers-reduced-motion` 미디어쿼리
  • `transform`/`opacity` 위주 애니메이션
  • `transition: all` 금지 (속성 명시)
  • 인터럽트(중도 사용자 인터랙션) 지원
05

타이포그래피

  • 줄임표 `…`, 곡선 따옴표 `“”`
  • 제목 `text-wrap: balance` (고아 방지)
  • 숫자열 `tabular-nums` 정렬
  • 단위 줄바꿈 방지 `10 MB`
06

콘텐츠 넘침 방지

  • 긴 텍스트 `truncate`, `line-clamp`
  • Flex 자식 요소 `min-w-0` 필수
  • 데이터 부재 시 빈 상태(Empty) UI
  • 사용자 입력 최대/최소 길이 대응
07

이미지 & CLS

  • 명시적 `width`/`height` 지정 (CLS 방지)
  • 스크롤 하단 `loading="lazy"`
  • 히어로 LCP `fetchpriority="high"`
  • 반응형 `srcset` 및 WebP 포맷
08

반응형 & 성능

  • 모바일 390px 가로 스크롤 터짐 방지
  • 50개 이상 대량 리스트 가상화
  • Render 단계 레이아웃 재계산 금지
  • WCAG AAA급 고대비 컬러 스키마
